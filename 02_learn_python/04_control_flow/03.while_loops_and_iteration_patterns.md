## 📖 Concept Overview
A **`while` loop** repeatedly executes a block of code **as long as a specified condition remains `True`**.

```python
while condition:
    # Code block executed repeatedly
```

### 1. Essential Loop Anatomy
Every well-formed `while` loop requires:
1. **Initialization**: Setting an initial loop control variable before loop begins.
2. **Condition Check**: Testing the boolean condition before each iteration.
3. **Update / Increment**: Modifying the loop variable inside the body so the condition eventually becomes `False` (avoiding infinite loops).

```python
count = 1             # 1. Initialization
while count <= 5:     # 2. Condition Check
    print(count)
    count += 1        # 3. Update / Increment
```

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Exponential Backoff Network Reconnection Loop
Simulate an industrial network client retrying connection to an unstable server with exponential delays.

```python
import time
import random

def connect_with_exponential_backoff(max_attempts: int = 4):
    attempt = 1
    delay_sec = 0.1
    connected = False
    
    while attempt <= max_attempts and not connected:
        print(f"[ATTEMPT {attempt}/{max_attempts}] Contacting remote host...")
        
        # Simulate network success rate (succeeds on attempt 3)
        if attempt == 3:
            connected = True
            print("[CONNECTED] Handshake established successfully!")
        else:
            print(f"[FAILED] Connection timed out. Backing off for {delay_sec:.2f}s...")
            time.sleep(delay_sec)
            delay_sec *= 2  # Double delay
            attempt += 1
            
    if not connected:
        print("[FATAL] Unable to connect after maximum retries.")

connect_with_exponential_backoff()
```

#### Step-by-Step Explanation:
1. Uses dual loop conditions: `attempt <= max_attempts and not connected`.
2. Multiplies delay by 2 on each failure to prevent server request flooding.

#### Expected Output:
```text
[ATTEMPT 1/4] Contacting remote host...
[FAILED] Connection timed out. Backing off for 0.10s...
[ATTEMPT 2/4] Contacting remote host...
[FAILED] Connection timed out. Backing off for 0.20s...
[ATTEMPT 3/4] Contacting remote host...
[CONNECTED] Handshake established successfully!
```

### Example 2: Number Reversal & Palindrome Checker (Mathematical Digits)
Extract individual digits from an integer using `% 10` and `// 10` in a `while` loop.

```python
def reverse_integer(n: int) -> int:
    original = n
    reversed_num = 0
    
    while n > 0:
        remainder = n % 10          # Extract last digit
        reversed_num = (reversed_num * 10) + remainder  # Shift and append
        n = n // 10                 # Truncate last digit
        
    print(f"Original: {original} -> Reversed: {reversed_num} (Palindrome? {original == reversed_num})")
    return reversed_num

reverse_integer(12345)
reverse_integer(12321)
```

#### Step-by-Step Explanation:
1. Modulus `% 10` isolates the rightmost digit.
2. Floor division `// 10` discards the rightmost digit.
3. Loops until `n` reaches 0.

#### Expected Output:
```text
Original: 12345 -> Reversed: 54321 (Palindrome? False)
Original: 12321 -> Reversed: 12321 (Palindrome? True)
```

### Example 3: Simulated User Interactive CLI Menu
Implement an interactive command-line loop that processes user instructions until an exit command is received.

```python
def simulate_cli_session(commands: list[str]):
    session_active = True
    idx = 0
    
    print("=== Terminal Interactive Shell Started ===")
    while session_active and idx < len(commands):
        cmd = commands[idx].strip().lower()
        idx += 1
        print(f"\nUser Entered: '{cmd}'")
        
        if cmd == "status":
            print("System Status: All services operational.")
        elif cmd == "ping":
            print("PONG! Response time: 2ms")
        elif cmd == "exit" or cmd == "quit":
            print("Terminating session. Goodbye!")
            session_active = False
        else:
            print(f"Command '{cmd}' unrecognized. Type 'status', 'ping', or 'exit'.")

simulate_cli_session(["ping", "status", "unknown_cmd", "exit"])
```

#### Step-by-Step Explanation:
1. While condition `session_active` keeps the prompt open.
2. Receiving `'exit'` sets `session_active = False`, terminating gracefully.

#### Expected Output:
```text
=== Terminal Interactive Shell Started ===

User Entered: 'ping'
PONG! Response time: 2ms

User Entered: 'status'
System Status: All services operational.

User Entered: 'unknown_cmd'
Command 'unknown_cmd' unrecognized. Type 'status', 'ping', or 'exit'.

User Entered: 'exit'
Terminating session. Goodbye!
```
