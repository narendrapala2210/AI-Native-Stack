## 1. Conceptual Deep-Dive: First-Class Functions & Decorator Syntax

In Python, functions are **first-class citizens**: they can be passed as arguments, assigned to variables, returned from other functions, and stored in data structures.

A **decorator** is a callable that takes a function as input, extends or alters its behavior without modifying its source code, and returns a replacement callable:
1. **Syntactic Sugar (`@decorator`)**:
   ```python
   @my_decorator
   def my_func(): pass
   # Is exactly equivalent to:
   def my_func(): pass
   my_func = my_decorator(my_func)
   ```
2. **Metadata Erasure Problem**:
   - When returning an inner wrapper function, the original function's metadata (`__name__`, `__doc__`, `__annotations__`, `__module__`) is replaced by the wrapper's metadata.
   - This breaks introspection, debuggers, doc generators, and framework routing.
3. **`@functools.wraps`**:
   - A built-in decorator applied to the inner wrapper function.
   - Automatically copies `__name__`, `__doc__`, and attaches `__wrapped__` pointing to the original unwrapped callable.

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Execution Time Profiler with `@functools.wraps`
Measure runtime latency of functions while preserving docstrings and identity.

```python
import functools
import time

def timing_decorator(func):
    @functools.wraps(func)  # Preserves func.__name__ and func.__doc__
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        elapsed = (time.perf_counter() - start) * 1000
        print(f"[LATENCY] Function '{func.__name__}' executed in {elapsed:.2f}ms")
        return result
    return wrapper

@timing_decorator
def calculate_prime_sum(limit: int) -> int:
    # Computes sum of prime numbers up to limit.
    primes = []
    for num in range(2, limit):
        if all(num % i != 0 for i in range(2, int(num ** 0.5) + 1)):
            primes.append(num)
    return sum(primes)

def test_timing():
    print("Function Name :", calculate_prime_sum.__name__)
    print("Function Doc  :", calculate_prime_sum.__doc__.strip())
    
    total = calculate_prime_sum(10_000)
    print("Prime sum:", total)

test_timing()
```

#### Step-by-Step Explanation:
1. `@functools.wraps(func)` preserves `calculate_prime_sum.__name__` instead of renaming it to `wrapper`.
2. Measures microsecond execution time cleanly.

#### Expected Output:
```text
Function Name : calculate_prime_sum
Function Doc  : Computes sum of prime numbers up to limit.
[LATENCY] Function 'calculate_prime_sum' executed in ...ms
Prime sum: 5736396
```

### Example 2: Access Authorization Guard Decorator
Protect privileged administrative endpoints by verifying user role contexts.

```python
import functools

# Simulated global security context
CURRENT_USER_SESSION = {"user": "bob", "role": "ANALYST"}

class UnauthorizedError(PermissionError):
    pass

def require_role(required_role: str):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            user_role = CURRENT_USER_SESSION.get("role")
            if user_role != required_role:
                raise UnauthorizedError(
                    f"Access Denied: User '{CURRENT_USER_SESSION.get('user')}' with role "
                    f"'{user_role}' cannot execute '{func.__name__}' (Requires: '{required_role}')."
                )
            return func(*args, **kwargs)
        return wrapper
    return decorator

@require_role("ADMIN")
def purge_database_records():
    return "Database purge completed successfully."

def test_authorization():
    try:
        purge_database_records()
    except UnauthorizedError as e:
        print("Security Guard Blocked Call:")
        print(f"  {e}")

test_authorization()
```

#### Step-by-Step Explanation:
1. The outer `require_role` receives configuration arguments.
2. The wrapper inspects `CURRENT_USER_SESSION` prior to granting execution.

#### Expected Output:
```text
Security Guard Blocked Call:
  Access Denied: User 'bob' with role 'ANALYST' cannot execute 'purge_database_records' (Requires: 'ADMIN').
```

### Example 3: Unwrapping Decorated Callables via `__wrapped__`
Bypass decorators during unit tests to isolate the pure underlying function.

```python
import functools

def audit_logger(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print(f"[AUDIT LOG] Invoking {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@audit_logger
def add_numbers(a: int, b: int) -> int:
    return a + b

def test_unwrapping():
    # 1. Decorated invocation
    print("Normal Decorated Call:")
    res1 = add_numbers(10, 20)

    # 2. Bypassing decorator via __wrapped__
    print("\nBypassed Core Call (Direct Execution):")
    pure_func = add_numbers.__wrapped__
    res2 = pure_func(10, 20)
    print(f"Result without audit log: {res2}")

test_unwrapping()
```

#### Step-by-Step Explanation:
1. `@functools.wraps` assigns the original target function to the wrapper's `__wrapped__` attribute.
2. Unit tests can directly test `pure_func = func.__wrapped__` without executing side-effects.

#### Expected Output:
```text
Normal Decorated Call:
[AUDIT LOG] Invoking add_numbers

Bypassed Core Call (Direct Execution):
Result without audit log: 30
```
