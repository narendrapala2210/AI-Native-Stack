## 1. Conceptual Deep-Dive: 3-Tier Closures & Execution Stacks

### 1. Parameterized Decorators (Decorators Taking Arguments)
When a decorator takes arguments (e.g. `@retry(max_attempts=3, delay=1.0)`):
- It requires **three levels of nested functions**:
  1. **Factory Function**: Accepts configuration arguments (`max_attempts`, `delay`) and returns the actual decorator.
  2. **Decorator Function**: Accepts the target function (`func`) and returns the wrapper.
  3. **Wrapper Function**: Accepts runtime arguments (`*args`, `**kwargs`) and executes the wrapped logic.

### 2. Decorator Stacking Order (Bottom-Up Application, Top-Down Execution)
When multiple decorators are stacked:
```python
@decorator_one
@decorator_two
def target(): pass
```
- **Application Order (Bottom-Up)**:
  `target = decorator_one(decorator_two(target))`
- **Execution Order (Top-Down)**:
  1. `decorator_one`'s pre-execution logic runs first.
  2. `decorator_two`'s pre-execution logic runs second.
  3. Core `target()` executes.
  4. `decorator_two`'s post-execution logic runs third.
  5. `decorator_one`'s post-execution logic runs last.

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Exponential Backoff Network Retry Decorator
Build a parameterized decorator that retries flaky network requests with exponential backoff delay.

```python
import functools
import time

def retry_with_backoff(max_retries: int = 3, initial_delay: float = 0.05, backoff_factor: float = 2.0):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            delay = initial_delay
            for attempt in range(1, max_retries + 1):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    if attempt == max_retries:
                        print(f"[RETRY] Attempt #{attempt} failed. Exceeded maximum retries!")
                        raise
                    print(f"[RETRY] Attempt #{attempt} failed with {type(e).__name__}. Retrying in {delay*1000:.1f}ms...")
                    time.sleep(delay)
                    delay *= backoff_factor
        return wrapper
    return decorator

# Flaky function counter
SIMULATED_ATTEMPTS = 0

@retry_with_backoff(max_retries=3, initial_delay=0.01, backoff_factor=2.0)
def fetch_remote_payload():
    global SIMULATED_ATTEMPTS
    SIMULATED_ATTEMPTS += 1
    if SIMULATED_ATTEMPTS < 3:
        raise ConnectionResetError("Connection dropped by peer")
    return {"status": 200, "data": "PAYLOAD_OK"}

def test_retry():
    res = fetch_remote_payload()
    print("Final Output:", res)

test_retry()
```

#### Step-by-Step Explanation:
1. `retry_with_backoff` configures retry parameters.
2. Intercepts failures and pauses with exponential delay before attempting again.

#### Expected Output:
```text
[RETRY] Attempt #1 failed with ConnectionResetError. Retrying in 10.0ms...
[RETRY] Attempt #2 failed with ConnectionResetError. Retrying in 20.0ms...
Final Output: {'status': 200, 'data': 'PAYLOAD_OK'}
```

### Example 2: Decorator Stacking Execution Visualizer
Demonstrate and trace the exact execution flow of multiple stacked decorators.

```python
import functools

def tag_bold(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print("  -> Entering <b>")
        result = func(*args, **kwargs)
        print("  <- Exiting </b>")
        return f"<b>{result}</b>"
    return wrapper

def tag_italic(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print("  -> Entering <i>")
        result = func(*args, **kwargs)
        print("  <- Exiting </i>")
        return f"<i>{result}</i>"
    return wrapper

# Stacking order: bold wraps italic wraps format_text
@tag_bold
@tag_italic
def format_text(content: str) -> str:
    print(f"     [Executing core function with '{content}']")
    return content

def test_stacking():
    print("Calling stacked format_text('Hello World'):")
    final_html = format_text("Hello World")
    print("\nResulting HTML:", final_html)

test_stacking()
```

#### Step-by-Step Explanation:
1. Outer decorator (`tag_bold`) executes its prologue first.
2. Inner decorator (`tag_italic`) executes next, followed by core function.
3. Epilogues unwind in reverse order.

#### Expected Output:
```text
Calling stacked format_text('Hello World'):
  -> Entering <b>
  -> Entering <i>
     [Executing core function with 'Hello World']
  <- Exiting </i>
  <- Exiting </b>

Resulting HTML: <b><i>Hello World</i></b>
```

### Example 3: Result Caching with Time-To-Live (TTL) Expiration
Implement a custom TTL cache decorator with expiration eviction.

```python
import functools
import time

def ttl_cache(seconds: float):
    def decorator(func):
        cache = {}

        @functools.wraps(func)
        def wrapper(*args):
            now = time.time()
            if args in cache:
                val, timestamp = cache[args]
                if now - timestamp < seconds:
                    return val  # Cache hit within TTL
            
            # Compute fresh
            result = func(*args)
            cache[args] = (result, now)
            return result
        return wrapper
    return decorator

@ttl_cache(seconds=0.1)
def expensive_query(entity_id: int):
    print(f"  [DB CALL] Computing heavy calculation for #{entity_id}...")
    return f"ENTITY_DATA_{entity_id}"

def test_ttl():
    print("Call 1:", expensive_query(10))
    print("Call 2 (Immediate Cache Hit):", expensive_query(10))
    
    print("Sleeping 120ms to expire TTL...")
    time.sleep(0.12)
    
    print("Call 3 (After Expiration - Cache Miss):", expensive_query(10))

test_ttl()
```

#### Step-by-Step Explanation:
1. `ttl_cache(seconds=0.1)` encapsulates a persistent cache mapping with timestamps.
2. Cache hits return immediately; expired entries trigger re-computation.

#### Expected Output:
```text
  [DB CALL] Computing heavy calculation for #10...
Call 1: ENTITY_DATA_10
Call 2 (Immediate Cache Hit): ENTITY_DATA_10
Sleeping 120ms to expire TTL...
  [DB CALL] Computing heavy calculation for #10...
Call 3 (After Expiration - Cache Miss): ENTITY_DATA_10
```
