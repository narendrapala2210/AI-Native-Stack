## 1. Conceptual Deep-Dive: Classes in Decorator Architecture

There are two distinct ways classes interact with decorators:
1. **Class-Based Decorators (Callable Class wrapping a Function)**:
   - Instead of a nested wrapper function, define a class implementing `__init__(self, func)` and `__call__(self, *args, **kwargs)`.
   - Offers clean, object-oriented encapsulation of complex decorator state (e.g. counters, history, statistics).
2. **Decorating Entire Classes (`@decorator class MyClass:`)**:
   - A decorator that takes a class object as input and returns a modified class.
   - Used for registering classes into service registries, injecting mixin methods, or enforcing security policies across all class methods.

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: State-Tracking Execution Profiler via Class-Based Decorator
Track total call counts, total elapsed latency, and execution history inside a callable class.

```python
import functools
import time

class ExecutionProfiler:
    def __init__(self, func):
        self.func = func
        self.call_count = 0
        self.total_time_ms = 0.0
        functools.update_wrapper(self, func)

    def __call__(self, *args, **kwargs):
        start = time.perf_counter()
        self.call_count += 1
        try:
            return self.func(*args, **kwargs)
        finally:
            elapsed = (time.perf_counter() - start) * 1000
            self.total_time_ms += elapsed

    def report_stats(self):
        avg = self.total_time_ms / self.call_count if self.call_count else 0
        return f"Function '{self.__name__}': {self.call_count} calls | Total: {self.total_time_ms:.2f}ms | Avg: {avg:.2f}ms"

@ExecutionProfiler
def render_template(template_name: str):
    time.sleep(0.01)
    return f"<h1>{template_name}</h1>"

def test_class_decorator():
    render_template("home.html")
    render_template("about.html")
    render_template("contact.html")

    # Access custom state methods on the decorator instance!
    print(render_template.report_stats())

test_class_decorator()
```

#### Step-by-Step Explanation:
1. `ExecutionProfiler` encapsulates state across multiple function calls.
2. `render_template.report_stats()` provides direct inspection of accumulated metrics.

#### Expected Output:
```text
Function 'render_template': 3 calls | Total: ~30.00ms | Avg: ~10.00ms
```

### Example 2: Class Decorator for Automatic Method Logging
Decorate an entire class to automatically wrap every public method with execution logging.

```python
import functools
import types

def log_all_methods(cls):
    # Iterate through class dictionary
    for attr_name, attr_value in cls.__dict__.items():
        # Check if attribute is a regular function (method) and not private
        if isinstance(attr_value, types.FunctionType) and not attr_name.startswith("_"):
            def make_wrapper(fn):
                @functools.wraps(fn)
                def wrapped_method(self, *args, **kwargs):
                    print(f"[CLASS LOG] Invoking {cls.__name__}.{fn.__name__}() with args={args}")
                    return fn(self, *args, **kwargs)
                return wrapped_method

            setattr(cls, attr_name, make_wrapper(attr_value))
    return cls

@log_all_methods
class AccountService:
    def open_account(self, customer: str):
        return f"Account opened for {customer}"

    def close_account(self, account_id: int):
        return f"Account {account_id} closed"

def test_class_method_logging():
    service = AccountService()
    print(service.open_account("Alice Smith"))
    print(service.close_account(9941))

test_class_method_logging()
```

#### Step-by-Step Explanation:
1. `@log_all_methods` inspects `cls.__dict__` upon class definition.
2. Dynamically replaces every public method with a logged wrapper.

#### Expected Output:
```text
[CLASS LOG] Invoking AccountService.open_account() with args=('Alice Smith',)
Account opened for Alice Smith
[CLASS LOG] Invoking AccountService.close_account() with args=(9941,)
Account 9941 closed
```

### Example 3: Global Component Registry via Class Decorators
Automatically register plugins and microservices into a global dispatch registry.

```python
PLUGIN_REGISTRY = {}

def register_plugin(plugin_name: str):
    def decorator(cls):
        if plugin_name in PLUGIN_REGISTRY:
            raise ValueError(f"Plugin name collision: '{plugin_name}' already registered!")
        PLUGIN_REGISTRY[plugin_name] = cls
        cls.plugin_name = plugin_name
        return cls
    return decorator

@register_plugin("auth_oauth2")
class OAuth2Authenticator:
    def authenticate(self): return "OAuth2 Success"

@register_plugin("auth_jwt")
class JwtAuthenticator:
    def authenticate(self): return "JWT Success"

def test_registry():
    print("Registered Security Plugins in Engine:")
    for name, cls in PLUGIN_REGISTRY.items():
        instance = cls()
        print(f"  [{name}] -> {cls.__name__} (Status: {instance.authenticate()})")

test_registry()
```

#### Step-by-Step Explanation:
1. Decorating a class registers it into `PLUGIN_REGISTRY` at definition time without needing manual lists.

#### Expected Output:
```text
Registered Security Plugins in Engine:
  [auth_oauth2] -> OAuth2Authenticator (Status: OAuth2 Success)
  [auth_jwt] -> JwtAuthenticator (Status: JWT Success)
```
