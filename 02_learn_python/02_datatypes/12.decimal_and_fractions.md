## 1. Conceptual Deep-Dive: Exact Rational & Financial Arithmetic

Standard IEEE 754 floating-point numbers (`float`) cannot accurately represent many base-10 fractions (such as $0.1$ or $0.2$) because binary numbers cannot represent $1/10$ without an infinitely repeating binary expansion. This introduces rounding errors unacceptable in finance, currency conversions, and high-precision scientific calibrations.

Python provides two specialized built-in numeric modules in the standard library:
1. **`decimal.Decimal`**:
   - Represents numbers in exact base-10 decimal format with user-configurable precision.
   - Provides exact arithmetic for monetary and fiscal operations (e.g. `0.1 + 0.2 == 0.3`).
   - Supports explicit rounding modes: `ROUND_HALF_UP`, `ROUND_HALF_EVEN` (Bankers' Rounding), `ROUND_FLOOR`, `ROUND_CEILING`.
   - **Crucial Rule**: Always initialize `Decimal` with a **string literal** (e.g., `Decimal("0.1")`), NOT a float (`Decimal(0.1)`), to avoid inheriting the float's binary representation error!
2. **`fractions.Fraction`**:
   - Represents exact rational numbers as a numerator and denominator pair ($p/q$).
   - Automatically reduces fractions to lowest terms using GCD.
   - Preserves exact mathematical ratios without any truncation or floating-point drift.

```python
from decimal import Decimal, getcontext
from fractions import Fraction

# Decimal precision setting
getcontext().prec = 28
d = Decimal("10.50")

# Fraction construction
f = Fraction(3, 4)  # 3/4
```

## 2. Complete Methods Reference: `Decimal` & `Fraction`

### `Decimal` Key Methods & Operations
- `Decimal.quantize(exp, rounding=ROUND_HALF_EVEN)`: Quantizes decimal to target exponent and rounding mode.
- `Decimal.as_tuple()`: Returns `DecimalTuple(sign, digits, exponent)`.
- `Decimal.is_finite()`, `Decimal.is_nan()`, `Decimal.is_infinite()`: Boundary checks.
- `Decimal.to_integral_value(rounding=...)`: Rounds to integral value without changing exponent.

### `Fraction` Key Methods & Operations
- `Fraction.numerator`: Returns the numerator in lowest terms.
- `Fraction.denominator`: Returns the denominator in lowest terms.
- `Fraction.as_integer_ratio()`: Returns `(numerator, denominator)` tuple.
- `Fraction.limit_denominator(max_denominator=1000000)`: Finds closest rational approximation.

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: High-Precision Banking Ledger & Currency Quantization
Demonstrate calculating retail transactions, compounding tax, and applying `ROUND_HALF_UP` banking rules without floating-point drift.

```python
from decimal import Decimal, ROUND_HALF_UP, getcontext

def calculate_invoice_totals():
    # Set global arithmetic context to 28 decimal places
    getcontext().prec = 28
    
    line_items = [
        {"desc": "Cloud GPU Compute Unit", "unit_price": Decimal("149.99"), "qty": Decimal("3")},
        {"desc": "Cold Storage Vault (TB)", "unit_price": Decimal("18.45"),  "qty": Decimal("12")},
        {"desc": "Egress Bandwidth (TB)",    "unit_price": Decimal("89.125"), "qty": Decimal("2.5")}
    ]

    subtotal = Decimal("0.00")
    for item in line_items:
        line_total = item["unit_price"] * item["qty"]
        subtotal += line_total

    tax_rate = Decimal("0.0825")  # 8.25% Sales Tax
    raw_tax = subtotal * tax_rate
    
    # Financial standard: Quantize to 2 decimal places with ROUND_HALF_UP
    cents = Decimal("0.01")
    rounded_tax = raw_tax.quantize(cents, rounding=ROUND_HALF_UP)
    grand_total = (subtotal + rounded_tax).quantize(cents, rounding=ROUND_HALF_UP)

    print(f"Subtotal   : ${subtotal:,.2f}")
    print(f"Sales Tax  : ${rounded_tax:,.2f} (Calculated from: {raw_tax})")
    print(f"Grand Total: ${grand_total:,.2f}")

calculate_invoice_totals()
```

#### Step-by-Step Explanation:
1. `Decimal("149.99")` string constructors initialize numbers with exact precision.
2. `quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)` enforces conventional currency rounding where half-cent values round up, eliminating accounting reconciliation errors.

#### Expected Output:
```text
Subtotal   : ${subtotal:,.2f}
Sales Tax  : $55.63 (Calculated from: 55.62640625)
Grand Total: $729.85
```

### Example 2: Exact Rational Proportion Calculator with `fractions.Fraction`
Compute exact ingredient proportions and scale recipes without any rounding loss.

```python
from fractions import Fraction

def scale_chemical_solution():
    # Baseline batch ratios: 1/3 reagent A, 2/5 solvent B, remainder buffer C
    reagent_a = Fraction(1, 3)
    solvent_b = Fraction(2, 5)
    
    # Calculate remainder buffer C: 1 - (A + B)
    buffer_c = Fraction(1, 1) - (reagent_a + solvent_b)
    
    print(f"Reagent A : {reagent_a} ({reagent_a.numerator}/{reagent_a.denominator})")
    print(f"Solvent B : {solvent_b} ({solvent_b.numerator}/{solvent_b.denominator})")
    print(f"Buffer C  : {buffer_c} ({buffer_c.numerator}/{buffer_c.denominator})")
    print(f"Sum check : {reagent_a + solvent_b + buffer_c} (Exact 1.0)")

    # Scale for an industrial vat of 750 liters
    vat_liters = 750
    liters_c = buffer_c * vat_liters
    print(f"Buffer C Volume for {vat_liters}L Vat: {float(liters_c)} Liters ({liters_c})")

scale_chemical_solution()
```

#### Step-by-Step Explanation:
1. `Fraction(1, 3) + Fraction(2, 5)` finds the common denominator (15) and computes `11/15` automatically.
2. `buffer_c` resolves to exact `4/15` without repeating decimals (`0.266666...`).
3. Multiplying by 750 liters computes exact integers (`200.0 Liters`).

#### Expected Output:
```text
Reagent A : 1/3 (1/3)
Solvent B : 2/5 (2/5)
Buffer C  : 4/15 (4/15)
Sum check : 1 (Exact 1.0)
Buffer C Volume for 750L Vat: 200.0 Liters (200)
```

### Example 3: Rational Approximation of Irrational Calibration Constants
Use `Fraction.limit_denominator()` to find optimal mechanical gear ratios approximating $\pi$ or continuous physical constants.

```python
import math
from fractions import Fraction

def find_gear_ratios():
    target_ratio = math.pi  # 3.141592653589793...
    
    print("Finding optimal gear tooth ratios (Numerator / Denominator) to approximate Pi:")
    print(f"{'Max Teeth':<12} {'Ratio':<15} {'Value':<18} {'Error':<12}")
    print("-" * 57)

    for max_teeth in [10, 50, 100, 500, 1000]:
        # Approximate Pi with a fraction whose denominator <= max_teeth
        f = Fraction(target_ratio).limit_denominator(max_teeth)
        approx = float(f)
        err = abs(approx - target_ratio)
        print(f"{max_teeth:<12} {str(f):<15} {approx:<18.10f} {err:<12.2e}")

find_gear_ratios()
```

#### Step-by-Step Explanation:
1. `Fraction(math.pi)` begins with the full precision of float pi.
2. `limit_denominator(max_teeth)` uses continued fraction algorithms to find the mathematically closest ratio with teeth count at or below the limit (such as the famous `355/113`).

#### Expected Output:
```text

```
