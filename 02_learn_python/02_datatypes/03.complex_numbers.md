## 📖 Concept Overview
Python has native built-in support for **complex numbers (`complex`)**. A complex number consists of a **real part** and an **imaginary part**, represented mathematically as:
$$z = a + bj$$
where $a$ is the real component, $b$ is the imaginary component, and $j = \sqrt{-1}$ (Python uses engineering notation `j` instead of `i`).

---

### 1. Creating Complex Numbers
- **Literal Syntax**: `3 + 4j` or `2.5 - 1.2j`
- **Constructor Function**: `complex(real, imag=0.0)`
```python
z1 = 3 + 4j
z2 = complex(2, -5)
print(type(z1))  # <class 'complex'>
```

---

### 2. Accessing Attributes
A complex number object provides two read-only floating-point attributes:
- **`z.real`**: Returns the real component (`float`).
- **`z.imag`**: Returns the imaginary component (`float`).

```python
z = 3.5 + 7.2j
print("Real Part     :", z.real)  # 3.5
print("Imaginary Part:", z.imag)  # 7.2
```

---

## 🛠️ Complete Catalog of Built-in Complex Methods

| Method / Attribute | Syntax | Description & Example |
| :--- | :--- | :--- |
| **`real`** | `z.real` | Floating-point real component. |
| **`imag`** | `z.imag` | Floating-point imaginary component. |
| **`conjugate()`** | `z.conjugate()` | Returns complex conjugate $a - bj$.<br>`(3 + 4j).conjugate()` -> `(3 - 4j)`. |

For advanced polar coordinate transformations ($\text{magnitude } |z|$, $\text{phase angle } \theta$), Python provides the standard library **`cmath`** module (`cmath.polar()`, `cmath.rect()`, `cmath.phase()`).

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: AC Electrical Engineering Circuit Impedance
Compute total impedance, current, and phase angle in an alternating current (AC) circuit containing resistors ($R$), inductors ($X_L$), and capacitors ($X_C$).

```python
import cmath

def calculate_ac_circuit_impedance(resistance_ohms: float, inductive_reactance: float, capacitive_reactance: float):
    # Total Impedance Z = R + j(X_L - X_C)
    r = resistance_ohms
    x = inductive_reactance - capacitive_reactance
    z = complex(r, x)
    
    # Polar form: Magnitude |Z| and Phase angle theta
    magnitude, phase_rad = cmath.polar(z)
    phase_deg = phase_rad * (180 / cmath.pi)
    
    print("=== AC Circuit Impedance Analysis ===")
    print(f"Impedance (Rectangular Form): {z} ohms")
    print(f"Impedance Magnitude |Z|     : {magnitude:.2f} ohms")
    print(f"Phase Angle (Theta)         : {phase_deg:.2f}°")
    print(f"Complex Conjugate (Z*)      : {z.conjugate()}")

calculate_ac_circuit_impedance(resistance_ohms=50.0, inductive_reactance=80.0, capacitive_reactance=30.0)
```

#### Step-by-Step Explanation:
1. Uses `complex(r, x)` to model impedance in an electrical circuit.
2. `cmath.polar()` converts rectangular form to magnitude and phase angle.

#### Expected Output:
```text
=== AC Circuit Impedance Analysis ===
Impedance (Rectangular Form): (50+50j) ohms
Impedance Magnitude |Z|     : 70.71 ohms
Phase Angle (Theta)         : 45.00°
Complex Conjugate (Z*)      : (50-50j)
```

### Example 2: 2D Spatial Vector Rotation via Complex Multiplication
Rotate a 2D spatial coordinate vector around the origin by an angle $\theta$ using Euler's formula $e^{j\theta} = \cos\theta + j\sin\theta$.

```python
import cmath
import math

def rotate_2d_point(x: float, y: float, angle_degrees: float) -> tuple[float, float]:
    # Represent 2D point as complex number
    point = complex(x, y)
    
    # Rotation factor: e^(j * theta)
    theta_rad = math.radians(angle_degrees)
    rotation_operator = cmath.rect(1.0, theta_rad)
    
    # Complex multiplication executes 2D rotation matrix math automatically!
    rotated = point * rotation_operator
    return round(rotated.real, 2), round(rotated.imag, 2)

original_pt = (10.0, 0.0)
rotated_90  = rotate_2d_point(original_pt[0], original_pt[1], 90.0)
rotated_180 = rotate_2d_point(original_pt[0], original_pt[1], 180.0)

print(f"Original Point (10, 0) Rotated  90°: {rotated_90}")
print(f"Original Point (10, 0) Rotated 180°: {rotated_180}")
```

#### Step-by-Step Explanation:
1. Multiplying complex numbers combines magnitude scaling and angle addition.
2. Rotating `(10, 0)` by 90 degrees yields `(0, 10)`.

#### Expected Output:
```text
Original Point (10, 0) Rotated  90°: (0.0, 10.0)
Original Point (10, 0) Rotated 180°: (-10.0, 0.0)
```

### Example 3: Mandelbrot Fractal Escape-Time Iterator
Compute escape-time iterations for coordinates in the complex plane to determine membership in the Mandelbrot Set ($z_{n+1} = z_n^2 + c$).

```python
def compute_mandelbrot_escape(c: complex, max_iterations: int = 100) -> int:
    z = 0j
    for i in range(max_iterations):
        z = z ** 2 + c
        # If magnitude |z| > 2, point escapes to infinity
        if abs(z) > 2.0:
            return i
    return max_iterations  # Inside the Mandelbrot set!

c_inside  = complex(-0.5, 0.0)
c_edge    = complex(-0.75, 0.1)
c_outside = complex(1.0, 1.0)

print(f"Point {c_inside}  Iterations: {compute_mandelbrot_escape(c_inside)} (Inside Set)")
print(f"Point {c_edge}    Iterations: {compute_mandelbrot_escape(c_edge)} (Edge Boundary)")
print(f"Point {c_outside} Iterations: {compute_mandelbrot_escape(c_outside)} (Escaped immediately)")
```

#### Step-by-Step Explanation:
1. Native complex arithmetic (`z = z ** 2 + c`) computes complex polynomials directly.
2. `abs(z)` computes complex absolute magnitude $\sqrt{z_{real}^2 + z_{imag}^2}$.

#### Expected Output:
```text
Point (-0.5+0j)  Iterations: 100 (Inside Set)
Point (-0.75+0.1j)    Iterations: 100 (Edge Boundary)
Point (1+1j) Iterations: 1 (Escaped immediately)
```
