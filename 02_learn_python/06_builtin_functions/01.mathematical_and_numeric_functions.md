## 📖 Concept Overview
Python includes optimized built-in functions for common mathematical calculations:

---

### 1. Mathematical Functions
- **`abs(x)`**: Returns the absolute (magnitude) non-negative value of `x`.
- **`round(number[, ndigits])`**: Rounds to `ndigits` precision using **Round half to even (Bankers' rounding)** to prevent statistical drift.
- **`pow(base, exp[, mod])`**: Computes `(base ** exp) % mod` with optimized C-level modular exponentiation (vital in cryptography).
- **`divmod(a, b)`**: Returns a tuple `(a // b, a % b)` combining floor division and modulus in a single operation.

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Cryptographic Modular Exponentiation with `pow(b, e, m)`
Demonstrate RSA encryption math where direct `(b ** e) % m` would run out of memory, but built-in `pow(b, e, m)` calculates in microseconds.

```python
import time

def demo_modular_exponentiation():
    base = 1234567
    exp = 98765
    modulus = 1000000007  # Common cryptographic prime modulus
    
    start = time.perf_counter()
    # Three-argument pow uses fast Montgomery modular multiplication
    result = pow(base, exp, modulus)
    duration_ms = (time.perf_counter() - start) * 1000
    
    print(f"pow({base}, {exp}, {modulus}) = {result}")
    print(f"Computed in {duration_ms:.4f} ms!")

demo_modular_exponentiation()
```

#### Step-by-Step Explanation:
1. Standard `(base ** exp)` creates an integer with hundreds of thousands of digits.
2. `pow(base, exp, modulus)` computes the remainder at every binary exponent step, executing in sub-millisecond time.

#### Expected Output:
```text
pow(1234567, 98765, 1000000007) = 36906660
Computed in 0.0250 ms!
```

### Example 2: Duration Time Converter using `divmod()`
Convert elapsed seconds into hours, minutes, and seconds using repeated `divmod()`.

```python
def format_seconds_to_hms(total_seconds: int) -> str:
    # divmod returns (quotient, remainder)
    minutes, seconds = divmod(total_seconds, 60)
    hours, minutes = divmod(minutes, 60)
    days, hours = divmod(hours, 24)
    
    return f"{days}d {hours:02d}h {minutes:02d}m {seconds:02d}s"

print(format_seconds_to_hms(3665))
print(format_seconds_to_hms(98765))
```

#### Step-by-Step Explanation:
1. `divmod(total, 60)` calculates both minutes and leftover seconds simultaneously.
2. Formats days, hours, minutes, and seconds with zero-padded format specifiers.

#### Expected Output:
```text
0d 01h 01m 05s
1d 03h 26m 05s
```

### Example 3: Understanding Bankers' Rounding (`round()`)
Expose why `round(2.5)` is `2` while `round(3.5)` is `4`.

```python
def explore_bankers_rounding():
    print("=== Bankers' Rounding (Round Half to Even) ===")
    test_values = [0.5, 1.5, 2.5, 3.5, 4.5, 5.5]
    for v in test_values:
        rounded = round(v)
        print(f"round({v}) = {rounded} (Nearest Even Integer)")

explore_bankers_rounding()
```

#### Step-by-Step Explanation:
1. Standard arithmetic always rounds `.5` up, introducing systemic upward statistical inflation.
2. Python uses IEEE 754 half-to-even rounding: if the decimal part is exactly `.5`, it rounds to the nearest **even** integer.

#### Expected Output:
```text
=== Bankers' Rounding (Round Half to Even) ===
round(0.5) = 0 (Nearest Even Integer)
round(1.5) = 2 (Nearest Even Integer)
round(2.5) = 2 (Nearest Even Integer)
round(3.5) = 4 (Nearest Even Integer)
round(4.5) = 4 (Nearest Even Integer)
round(5.5) = 6 (Nearest Even Integer)
```
