## 1. Conceptual Deep-Dive: Bitwise Operations & Assignment Expressions

### 1. Low-Level Bitwise Operators
Bitwise operators operate directly on the binary representations (bits) of integers using two's complement arithmetic:

| Operator | Name | Description | Example (Binary) |
| :--- | :--- | :--- | :--- |
| `&` | **Bitwise AND** | Bit is 1 if both operands have 1. | `0b1100 & 0b1010` -> `0b1000` (8) |
| `\|` | **Bitwise OR** | Bit is 1 if either operand has 1. | `0b1100 \| 0b1010` -> `0b1110` (14) |
| `^` | **Bitwise XOR** | Bit is 1 if operands have differing bits. | `0b1100 ^ 0b1010` -> `0b0110` (6) |
| `~` | **Bitwise NOT** | Inverts all bits (yields `-(x + 1)` in two's complement). | `~0b1010` -> `-11` |
| `<<` | **Left Shift** | Shifts bits left by $n$ places (multiplies by $2^n$). | `0b0011 << 2` -> `0b1100` (12) |
| `>>` | **Right Shift** | Shifts bits right by $n$ places (integer division by $2^n$). | `0b1100 >> 2` -> `0b0011` (3) |

### 2. The Walrus Operator (`:=`) — PEP 572
Introduced in Python 3.8, the **assignment expression operator** (`:=`), nicknamed the *Walrus Operator*, allows you to **assign values to variables inside an expression**:
- Traditional assignment (`x = 5`) is a *statement* and cannot produce a value inside an `if` condition or `while` loop.
- Assignment expression (`(x := 5)`) assigns the value to `x` and *simultaneously returns that value* for immediate evaluation.
- Prevents repetitive computations, enables clean stream reading loops, and eliminates duplicate lookups in comprehensions.

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Stream Processing with the Walrus Operator (`:=`)
Read and process simulated streaming sensor data batches without repeated function calls.

```python
def simulated_data_source():
    # Simulates streaming sensor records yielding None when complete
    stream = ["TEMP:24.5C", "HUMID:62%", "PRESS:1013hPa", "TEMP:25.1C", "END", "TEMP:26.0C"]
    for item in stream:
        yield item

def process_sensor_stream():
    source = simulated_data_source()
    readings = []

    # Walrus operator assigns next item to 'data' and checks condition in one step
    while (data := next(source, None)) and data != "END":
        print(f"Processing sensor packet: {data}")
        readings.append(data)

    print(f"Stream finished. Total valid packets ingested: {len(readings)}")

process_sensor_stream()
```

#### Step-by-Step Explanation:
1. `(data := next(source, None))` assigns the next yielded value to `data` and immediately evaluates its truthiness and boundary check `data != "END"`.
2. Eliminates boilerplate `while True:` loops containing manual `if not data: break`.

#### Expected Output:
```text
Processing sensor packet: TEMP:24.5C
Processing sensor packet: HUMID:62%
Processing sensor packet: PRESS:1013hPa
Processing sensor packet: TEMP:25.1C
Stream finished. Total valid packets ingested: 4
```

### Example 2: Bitmask Feature Flag Configuration Engine
Manage 8 distinct feature flags in a single compact byte using bitwise `&`, `|`, and `^`.

```python
# Bit flag positions (Powers of 2)
FLAG_BETA_UI      = 1 << 0  # 0001 (1)
FLAG_DARK_MODE    = 1 << 1  # 0010 (2)
FLAG_DEBUG_LOGS   = 1 << 2  # 0100 (4)
FLAG_ADMIN_ACCESS = 1 << 3  # 1000 (8)

def manage_feature_flags():
    # Start with empty profile
    user_flags = 0
    
    # 1. Enable BETA_UI and DARK_MODE using bitwise OR (|)
    user_flags |= FLAG_BETA_UI | FLAG_DARK_MODE
    print(f"Flags after enable: {bin(user_flags)} (Int: {user_flags})")
    
    # 2. Check if DARK_MODE is active using bitwise AND (&)
    is_dark = bool(user_flags & FLAG_DARK_MODE)
    is_admin = bool(user_flags & FLAG_ADMIN_ACCESS)
    print(f"Dark Mode Active? {is_dark}")
    print(f"Admin Access Active? {is_admin}")
    
    # 3. Toggle DEBUG_LOGS using bitwise XOR (^)
    user_flags ^= FLAG_DEBUG_LOGS
    print(f"After toggling DEBUG_LOGS: {bin(user_flags)}")
    
    # 4. Disable DARK_MODE using bitwise AND with NOT (~FLAG)
    user_flags &= ~FLAG_DARK_MODE
    print(f"After disabling DARK_MODE: {bin(user_flags)}")

manage_feature_flags()
```

#### Step-by-Step Explanation:
1. `1 << n` creates distinct single-bit masks efficiently.
2. Bitwise OR `|=` sets bits without disturbing others.
3. Bitwise AND `&` isolates target bit flags.
4. Bitwise AND with NOT `&= ~FLAG` cleanly unsets specific flags.

#### Expected Output:
```text
Flags after enable: 0b11 (Int: 3)
Dark Mode Active? True
Admin Access Active? False
After toggling DEBUG_LOGS: 0b111
After disabling DARK_MODE: 0b101
```

### Example 3: Regex Group Extraction and Filtering with Walrus
Extract structured values from log lines and filter them simultaneously within a list comprehension.

```python
import re

def parse_access_logs():
    raw_logs = [
        '192.168.1.1 - - [POST /api/v1/auth 401]',
        'INVALID LOG LINE CORRUPTED',
        '10.0.0.5 - - [GET /index.html 200]',
        '172.16.0.4 - - [GET /api/v1/metrics 200]',
        'NO_HTTP_DATA'
    ]

    log_pattern = re.compile(r'\[(?P<method>GET|POST)\s+(?P<path>\S+)\s+(?P<status>\d{3})\]')

    # Use walrus operator to match, assign, and extract in a single line comprehension!
    successful_apis = [
        {"method": match.group("method"), "path": match.group("path"), "status": int(match.group("status"))}
        for line in raw_logs
        if (match := log_pattern.search(line)) and match.group("status") == "200"
    ]

    print("Parsed Successful API Endpoints:")
    for entry in successful_apis:
        print(f"  {entry['method']:<5} {entry['path']:<20} (Status: {entry['status']})")

parse_access_logs()
```

#### Step-by-Step Explanation:
1. `(match := log_pattern.search(line))` executes the regex search and assigns the match object to `match`.
2. If matched and `status == "200"`, the comprehension uses the already-bound `match` variable to extract groups without executing the regex a second time.

#### Expected Output:
```text
Parsed Successful API Endpoints:
  GET   /index.html          (Status: 200)
  GET   /api/v1/metrics      (Status: 200)
```
