## 1. Conceptual Deep-Dive: Resource Management & The `with` Statement

The `with` statement guarantees deterministic resource acquisition and cleanup (e.g. closing files, releasing locks, terminating database transactions), regardless of whether code exits normally or via unhandled exceptions.

### 1. The Context Manager Protocol
Any Python class implementing two dunder methods satisfies the **Context Manager Protocol**:
1. `__enter__(self)`:
   - Executed before entering the `with` block.
   - Return value is bound to the target in `with Context() as target:`.
2. `__exit__(self, exc_type, exc_val, exc_tb)`:
   - Executed upon exiting the `with` block.
   - Receives exception details if an error occurred inside the block (or `None, None, None` if execution completed cleanly).
   - **Exception Suppression**: If `__exit__` returns `True`, Python **suppresses the exception**, preventing it from bubbling up! If it returns `False` (or `None`), the exception propagates normally.

### 2. High-Level Utilities in `contextlib`
- `@contextlib.contextmanager`: Turn generator functions with `yield` into context managers without writing a class.
- `contextlib.suppress(*exceptions)`: Clean syntax for ignoring expected errors (`with suppress(FileNotFoundError): ...`).
- `contextlib.ExitStack`: Dynamically manage an arbitrary number of context managers programmatically.

```python
import contextlib

@contextlib.contextmanager
def managed_resource():
    # Setup
    yield "RESOURCE"
    # Teardown
```

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Transactional Atomic File Writer Context Manager
Ensure output files are written to a temporary swapfile first, replacing the destination file atomically only on success.

```python
import os

class AtomicFileWriter:
    def __init__(self, target_filepath: str):
        self.target_filepath = target_filepath
        self.temp_filepath = target_filepath + ".tmp"
        self.file_handle = None

    def __enter__(self):
        # Open the temporary file for writing
        self.file_handle = open(self.temp_filepath, "w", encoding="utf-8")
        return self.file_handle

    def __exit__(self, exc_type, exc_val, exc_tb):
        # Close file handle first
        self.file_handle.close()

        if exc_type is not None:
            # An error occurred inside the 'with' block: Discard temporary file!
            if os.path.exists(self.temp_filepath):
                os.remove(self.temp_filepath)
            print(f"Transaction Aborted: Cleaned up temporary file due to {exc_type.__name__}")
            # Return False to let exception propagate
            return False

        # Success: Replace destination file atomically
        os.replace(self.temp_filepath, self.target_filepath)
        print(f"Transaction Committed: Atomically updated '{self.target_filepath}'")
        return True

def test_atomic_writer():
    dest = "atomic_config.json"
    
    # 1. Successful atomic transaction
    with AtomicFileWriter(dest) as f:
        f.write('{"status": "OK", "version": 1}')

    # 2. Failed atomic transaction (simulating crash mid-write)
    try:
        with AtomicFileWriter(dest) as f:
            f.write('{"status": "CORRUPTED"')
            raise ValueError("Disk write interruption simulated!")
    except ValueError:
        pass

    # Destination file still retains valid original state!
    with open(dest, "r") as f:
        print(f"Active file contents on disk: {f.read()}")

    # Cleanup test artifact
    if os.path.exists(dest): os.remove(dest)

test_atomic_writer()
```

#### Step-by-Step Explanation:
1. `__enter__` creates the staging swapfile.
2. If an exception is raised, `__exit__` catches it, deletes the corrupt staging file, and keeps the original destination intact.
3. On success, `os.replace` executes an atomic OS-level rename.

#### Expected Output:
```text
Transaction Committed: Atomically updated 'atomic_config.json'
Transaction Aborted: Cleaned up temporary file due to ValueError
Active file contents on disk: {"status": "OK", "version": 1}
```

### Example 2: Execution Time Benchmark Context Manager with `@contextmanager`
Build an execution profiling context manager with the `contextlib` decorator.

```python
import time
from contextlib import contextmanager

@contextmanager
def benchmark_timer(label: str):
    start_time = time.perf_counter()
    metrics = {"elapsed_ms": 0.0}
    try:
        # Code inside 'with' block executes while yielded
        yield metrics
    finally:
        # Guarantees timer stops even if an exception is thrown
        elapsed = (time.perf_counter() - start_time) * 1000
        metrics["elapsed_ms"] = elapsed
        print(f"[{label}] Finished in {elapsed:.2f}ms")

def test_benchmark():
    # Measure list comprehension execution speed
    with benchmark_timer("Vector Multiplication") as bench:
        result = [x * 2 for x in range(1_000_000)]
    
    print(f"Benchmark metric recorded: {bench['elapsed_ms']:.2f}ms")

test_benchmark()
```

#### Step-by-Step Explanation:
1. `@contextmanager` converts a generator function into a context manager.
2. The code before `yield` represents `__enter__`; the code in `finally` represents `__exit__`.

#### Expected Output:
```text
[Vector Multiplication] Finished in ~25.00ms
Benchmark metric recorded: ~25.00ms
```

### Example 3: Dynamic Multi-Resource Coordination with `contextlib.ExitStack`
Open and process an unknown, dynamic list of files simultaneously without manual nested `with` blocks.

```python
from contextlib import ExitStack
import os

def merge_multiple_logs(file_paths: list[str], output_path: str):
    with ExitStack() as stack:
        # Dynamically register an arbitrary number of file context managers
        input_files = [stack.enter_context(open(fp, "r", encoding="utf-8")) for fp in file_paths]
        out_file = stack.enter_context(open(output_path, "w", encoding="utf-8"))

        # Merge lines
        for f in input_files:
            out_file.write(f.read() + "\n")

    print(f"Successfully merged {len(file_paths)} streams into '{output_path}'")

def test_exit_stack():
    # Setup test files
    files = ["log1.txt", "log2.txt", "log3.txt"]
    for i, fname in enumerate(files, 1):
        with open(fname, "w") as f: f.write(f"Log Stream {i}")

    merged = "merged_log.txt"
    merge_multiple_logs(files, merged)

    with open(merged) as f:
        print(f"Merged output:\n{f.read().strip()}")

    # Cleanup
    for f in files + [merged]:
        if os.path.exists(f): os.remove(f)

test_exit_stack()
```

#### Step-by-Step Explanation:
1. Standard `with open(f1), open(f2):` requires knowing file count at compile time.
2. `ExitStack.enter_context` dynamically manages any number of resources and guarantees LIFO teardown.

#### Expected Output:
```text
Successfully merged 3 streams into 'merged_log.txt'
Merged output:
Log Stream 1
Log Stream 2
Log Stream 3
```
