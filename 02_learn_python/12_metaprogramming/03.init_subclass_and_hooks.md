## 1. Conceptual Deep-Dive: Modern Class Customization

### 1. `__init_subclass__` (PEP 487)
Before Python 3.6, customizing subclass creation required writing complex custom metaclasses. Python 3.6 introduced `__init_subclass__`:
- A simple classmethod hook on base classes that executes whenever a subclass is derived.
- Solves 90% of metaclass use cases without metaclass syntax or metaclass conflict errors.
- Can receive arbitrary keyword arguments from the subclass definition (`class Derived(Base, keyword=val):`).

### 2. Dynamic Attribute Interception Hooks
Python provides low-level hooks for intercepting attribute lookups:
- `__getattr__(self, name)`: Called ONLY when `name` is **not found** in normal attribute lookup (fallback handler).
- `__getattribute__(self, name)`: Called **unconditionally** on EVERY attribute access. Requires caution to avoid infinite recursion (call `super().__getattribute__(name)`).
- `__setattr__(self, name, value)`: Called unconditionally on every attribute assignment.

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Auto-Registering Plugin Architecture with `__init_subclass__`
Automatically catalog subclasses into a plugin engine without decorators or metaclasses.

```python
class DataExporterPlugin:
    # Central registry for all subclasses
    REGISTRY = {}

    def __init_subclass__(cls, format_type: str, **kwargs):
        super().__init_subclass__(**kwargs)
        if format_type in cls.REGISTRY:
            raise ValueError(f"Format collision: '{format_type}' already registered!")
        cls.REGISTRY[format_type] = cls
        cls.format_type = format_type
        print(f"[REGISTRY] Auto-registered exporter plugin: '{format_type}' -> {cls.__name__}")

    def export(self, data: list) -> str:
        raise NotImplementedError

# Subclasses register automatically at definition time!
class CsvExporter(DataExporterPlugin, format_type="csv"):
    def export(self, data: list) -> str: return "CSV_EXPORTED_DATA"

class JsonExporter(DataExporterPlugin, format_type="json"):
    def export(self, data: list) -> str: return "JSON_EXPORTED_DATA"

def test_init_subclass():
    print("\nActive Exporter Registry:")
    for fmt, cls in DataExporterPlugin.REGISTRY.items():
        print(f"  Format '{fmt}': Handled by {cls.__name__}")

test_init_subclass()
```

#### Step-by-Step Explanation:
1. When `CsvExporter` inherits `DataExporterPlugin`, `__init_subclass__` runs immediately.
2. Subclasses pass configuration arguments (`format_type="csv"`) cleanly in their class header.

#### Expected Output:
```text
[REGISTRY] Auto-registered exporter plugin: 'csv' -> CsvExporter
[REGISTRY] Auto-registered exporter plugin: 'json' -> JsonExporter

Active Exporter Registry:
  Format 'csv': Handled by CsvExporter
  Format 'json': Handled by JsonExporter
```

### Example 2: Dynamic Fallback Access with `__getattr__`
Build a dynamic JSON wrapper allowing dot-notation access to nested dictionary keys.

```python
class DynamicJsonWrapper:
    def __init__(self, data: dict):
        self._data = data

    def __getattr__(self, name: str):
        # Called ONLY if name is not found on self
        if name in self._data:
            val = self._data[name]
            if isinstance(val, dict):
                return DynamicJsonWrapper(val)  # Recursive wrapping
            return val
        raise AttributeError(f"JSON payload has no attribute '{name}'")

def test_dynamic_getattr():
    payload = {
        "status": 200,
        "user": {
            "name": "Sarah",
            "preferences": {
                "theme": "dark_mode"
            }
        }
    }

    obj = DynamicJsonWrapper(payload)
    print("Status   :", obj.status)
    print("User Name:", obj.user.name)
    print("Theme    :", obj.user.preferences.theme)

test_dynamic_getattr()
```

#### Step-by-Step Explanation:
1. `obj.user.preferences.theme` triggers `__getattr__` at each step, accessing dictionary keys as natural dot-notation attributes.

#### Expected Output:
```text
Status   : 200
User Name: Sarah
Theme    : dark_mode
```

### Example 3: Auditing Attribute Access with `__getattribute__` and `__setattr__`
Audit every read and write to sensitive model attributes while avoiding infinite recursion.

```python
class AuditedEntity:
    def __init__(self, entity_id: str, balance: float):
        # Use object.__setattr__ during init or standard assignment
        super().__setattr__("entity_id", entity_id)
        super().__setattr__("balance", balance)

    def __getattribute__(self, name: str):
        # Must delegate to super() to avoid infinite loop!
        value = super().__getattribute__(name)
        if not name.startswith("_"):
            print(f"[AUDIT READ] Read attribute '{name}' => {value}")
        return value

    def __setattr__(self, name: str, value):
        print(f"[AUDIT WRITE] Setting '{name}' to {value}")
        super().__setattr__(name, value)

def test_attribute_audit():
    acc = AuditedEntity("ACC-1002", 5000.0)
    bal = acc.balance
    acc.balance = 7500.0

test_attribute_audit()
```

#### Step-by-Step Explanation:
1. `__getattribute__` intercepts all attribute reads unconditionally.
2. Invoking `super().__getattribute__(name)` retrieves the actual value without triggering recursion.

#### Expected Output:
```text
[AUDIT READ] Read attribute 'balance' => 5000.0
[AUDIT WRITE] Setting 'balance' to 7500.0
```
