## 1. Conceptual Deep-Dive: Python's Data Model & Dunder Methods

Special methods in Python begin and end with double underscores (`__method__`), commonly known as **dunder methods**. They form the core of the **Python Data Model** (the object model that powers operator overloading, container emulation, and lifecycle hooks).

Rather than calling these methods directly (e.g. `obj.__len__()`), the Python interpreter automatically invokes them when corresponding syntax is used (e.g. `len(obj)`).

### Complete Dunder Methods Categorization

| Category | Dunder Method | Triggering Syntax / Python Built-in |
| :--- | :--- | :--- |
| **Object Lifecycle** | `__new__(cls, ...)` | Allocates memory for a new instance (called before `__init__`). |
| | `__init__(self, ...)` | Initializes attributes of the allocated instance. |
| | `__del__(self)` | Destructor invoked when `ob_refcnt` reaches zero. |
| **String Representation** | `__repr__(self)` | Unambiguous official representation for debugging (`repr(obj)` or interactive shell). |
| | `__str__(self)` | Human-friendly readable representation (`print(obj)` or `str(obj)`). |
| | `__format__(self, spec)` | Custom string format specification (`f"{obj:spec}"` or `format()`). |
| | `__bytes__(self)` | Binary byte serialization (`bytes(obj)`). |
| **Comparison & Hashing** | `__eq__(self, other)` | Equality comparison (`self == other`). |
| | `__lt__`, `__le__` | Less-than, less-or-equal (`<`, `<=`). |
| | `__gt__`, `__ge__` | Greater-than, greater-or-equal (`>`, `>=`). |
| | `__hash__(self)` | Hash computation for set membership and dictionary keys (`hash(obj)`). |
| **Arithmetic Operators** | `__add__`, `__sub__` | Binary addition and subtraction (`+`, `-`). |
| | `__mul__`, `__truediv__` | Binary multiplication and float division (`*`, `/`). |
| | `__floordiv__`, `__mod__` | Integer division and modulo (`//`, `%`). |
| | `__pow__(self, other)` | Exponentiation (`**`). |
| | `__matmul__(self, other)` | Matrix multiplication (`@`). |
| | `__iadd__`, `__imul__` | In-place augmented assignments (`+=`, `*=`). |
| **Container Protocol** | `__len__(self)` | Collection size (`len(obj)`). |
| | `__getitem__(self, key)` | Element access or slicing (`obj[key]`). |
| | `__setitem__(self, key, v)` | Element assignment (`obj[key] = v`). |
| | `__delitem__(self, key)` | Element deletion (`del obj[key]`). |
| | `__contains__(self, item)` | Membership check (`item in obj`). |
| | `__iter__(self)` | Iterator retrieval (`iter(obj)` or `for x in obj:`). |

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: High-Performance 2D Vector with Full Operator Overloading
Implement arithmetic operators (`+`, `-`, `*`), magnitude comparisons (`<`, `==`), and clean representations.

```python
import math

class Vector2D:
    def __init__(self, x: float, y: float):
        self.x = float(x)
        self.y = float(y)

    # 1. Unambiguous developer representation
    def __repr__(self) -> str:
        return f"Vector2D(x={self.x}, y={self.y})"

    # 2. Pretty end-user string
    def __str__(self) -> str:
        return f"<{self.x}, {self.y}>"

    # 3. Binary addition: v1 + v2
    def __add__(self, other: "Vector2D") -> "Vector2D":
        if not isinstance(other, Vector2D):
            return NotImplemented
        return Vector2D(self.x + other.x, self.y + other.y)

    # 4. Scalar multiplication: v * scalar
    def __mul__(self, scalar: float) -> "Vector2D":
        if not isinstance(scalar, (int, float)):
            return NotImplemented
        return Vector2D(self.x * scalar, self.y * scalar)

    # 5. Right-hand scalar multiplication: scalar * v
    def __rmul__(self, scalar: float) -> "Vector2D":
        return self.__mul__(scalar)

    # 6. Magnitude calculation via abs(v)
    def __abs__(self) -> float:
        return math.hypot(self.x, self.y)

    # 7. Equality check: v1 == v2
    def __eq__(self, other) -> bool:
        if not isinstance(other, Vector2D):
            return False
        return math.isclose(self.x, other.x) and math.isclose(self.y, other.y)

    # 8. Comparison by magnitude: v1 < v2
    def __lt__(self, other: "Vector2D") -> bool:
        return abs(self) < abs(other)

def test_vector():
    v1 = Vector2D(3, 4)
    v2 = Vector2D(1, 2)

    print(f"Vector 1 : {v1!r}")
    print(f"Vector 2 : {v2}")
    print(f"v1 + v2  : {v1 + v2}")
    print(f"v1 * 3   : {v1 * 3}")
    print(f"Magnitude: abs(v1) = {abs(v1)}")
    print(f"Is v2 < v1? {v2 < v1}")

test_vector()
```

#### Step-by-Step Explanation:
1. `__repr__` returns an executable representation `Vector2D(x=3.0, y=4.0)`.
2. `__add__` and `__mul__` intercept the `+` and `*` operators. If an unsupported type is provided, returning `NotImplemented` allows Python to check for reverse operations (`__radd__`, `__rmul__`).
3. `__abs__` binds straight to `abs(v1)`.

#### Expected Output:
```text
Vector 1 : Vector2D(x=3.0, y=4.0)
Vector 2 : <1.0, 2.0>
v1 + v2  : <4.0, 6.0>
v1 * 3   : <9.0, 12.0>
Magnitude: abs(v1) = 5.0
Is v2 < v1? True
```

### Example 2: Custom In-Memory Ring Buffer Emulating Containers
Build a custom circular queue implementing `__len__`, `__getitem__`, `__setitem__`, and `__contains__`.

```python
class RingBuffer:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.buffer = [None] * capacity
        self.size = 0
        self.head = 0

    def append(self, value):
        self.buffer[self.head] = value
        self.head = (self.head + 1) % self.capacity
        if self.size < self.capacity:
            self.size += 1

    def __len__(self) -> int:
        return self.size

    def __getitem__(self, index: int):
        if index < 0 or index >= self.size:
            raise IndexError("RingBuffer index out of bounds!")
        # Map logical index to physical circular array offset
        start = (self.head - self.size) % self.capacity
        return self.buffer[(start + index) % self.capacity]

    def __contains__(self, item) -> bool:
        for i in range(self.size):
            if self[i] == item:
                return True
        return False

def test_ring_buffer():
    rb = RingBuffer(capacity=3)
    rb.append("A")
    rb.append("B")
    rb.append("C")
    print(f"Buffer size: {len(rb)} | Items: {[rb[i] for i in range(len(rb))]}")

    # Adding 4th item overwrites 'A'
    rb.append("D")
    print(f"After append 'D': Items: {[rb[i] for i in range(len(rb))]}")
    print(f"Is 'A' in buffer? {'A' in rb}")
    print(f"Is 'D' in buffer? {'D' in rb}")

test_ring_buffer()
```

#### Step-by-Step Explanation:
1. `__len__` enables Python's native `len(rb)` function.
2. `__getitem__` allows standard subscript notation `rb[i]`.
3. `__contains__` allows `item in rb` syntax.

#### Expected Output:
```text
Buffer size: 3 | Items: ['A', 'B', 'C']
After append 'D': Items: ['B', 'C', 'D']
Is 'A' in buffer? False
Is 'D' in buffer? True
```

### Example 3: Callable Class (Function Object) via `__call__`
Implement a configurable memoized polynomial evaluation object using `__call__`.

```python
class Polynomial:
    def __init__(self, *coefficients):
        # Coefficients from highest degree to constant: a*x^2 + b*x + c
        self.coefficients = coefficients

    def __call__(self, x: float) -> float:
        # Evaluates polynomial at x using Horner's Method: O(n)
        result = 0.0
        for coeff in self.coefficients:
            result = result * x + coeff
        return result

    def __repr__(self):
        terms = [f"{c}*x^{len(self.coefficients)-1-i}" for i, c in enumerate(self.coefficients)]
        return " + ".join(terms)

def test_callable():
    # 2*x^2 + 3*x + 5
    poly = Polynomial(2, 3, 5)
    print(f"Polynomial Function: f(x) = {poly!r}")

    # Invoke directly like a function using __call__
    print(f"f(0) = {poly(0)}")
    print(f"f(2) = {poly(2)}")
    print(f"f(5) = {poly(5)}")

test_callable()
```

#### Step-by-Step Explanation:
1. Defining `__call__` turns instances of `Polynomial` into callables (`poly(2)`).
2. Allows objects to maintain internal state across invocations while mimicking functions.

#### Expected Output:
```text
Polynomial Function: f(x) = 2*x^2 + 3*x^1 + 5*x^0
f(0) = 5.0
f(2) = 19.0
f(5) = 70.0
```
