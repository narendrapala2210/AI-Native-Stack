## 1. Conceptual Deep-Dive: Bidirectional Coroutines

In Python, generators can both produce data (`yield`) and **consume data**:
1. **The `yield` Expression**:
   - Inside a coroutine, `received = yield output` both sends `output` to caller and pauses waiting to receive input.
2. **Coroutine Methods**:
   - `gen.send(value)`: Resumes generator, passing `value` into the `yield` expression.
   - `gen.throw(type, val, tb)`: Raises an exception inside the generator at the paused `yield` point.
   - `gen.close()`: Raises `GeneratorExit` inside the generator to trigger cleanup blocks.
3. **Coroutine Priming**:
   - A newly instantiated generator must be **primed** by calling `next(gen)` or `gen.send(None)` to advance execution to the first `yield` before sending active data.

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Running Moving Average Consumer Coroutine
Compute streaming rolling averages by pushing real-time metrics into a generator coroutine with `send()`.

```python
def moving_average_coroutine():
    total = 0.0
    count = 0
    average = 0.0

    while True:
        # Pauses and receives input from caller
        term = yield average
        total += term
        count += 1
        average = total / count

def test_moving_average():
    # 1. Instantiate and prime
    avg_gen = moving_average_coroutine()
    next(avg_gen)  # Priming

    # 2. Send streaming values
    print("Average after 10:", avg_gen.send(10))
    print("Average after 20:", avg_gen.send(20))
    print("Average after 30:", avg_gen.send(30))
    print("Average after 40:", avg_gen.send(40))

    avg_gen.close()

test_moving_average()
```

#### Step-by-Step Explanation:
1. `term = yield average` yields current average and halts until caller invokes `avg_gen.send(val)`.
2. Encapsulates state (`total`, `count`) without a custom class.

#### Expected Output:
```text
Average after 10: 10.0
Average after 20: 15.0
Average after 30: 20.0
Average after 40: 25.0
```

### Example 2: Coroutine Exception Injection with `throw()`
Simulate an external hardware fault injected into an active receiver using `gen.throw()`.

```python
class HardwareFault(Exception):
    pass

def sensor_receiver():
    try:
        while True:
            packet = yield
            print(f"Telemetry packet received: {packet}")
    except HardwareFault:
        print("ALERT: Hardware fault caught inside coroutine! Switching to fallback backup.")
    finally:
        print("Cleanup: Sensor channel closed.")

def test_coroutine_throw():
    coro = sensor_receiver()
    next(coro)  # Prime

    coro.send("PKT_001")
    coro.send("PKT_002")

    # Inject exception
    coro.throw(HardwareFault("Bus Voltage Spike!"))

test_coroutine_throw()
```

#### Step-by-Step Explanation:
1. `coro.throw(...)` raises an exception inside the generator at the exact line of the paused `yield`.
2. Allows error recovery and cleanup handling within generator execution frames.

#### Expected Output:
```text
Telemetry packet received: PKT_001
Telemetry packet received: PKT_002
ALERT: Hardware fault caught inside coroutine! Switching to fallback backup.
Cleanup: Sensor channel closed.
```

### Example 3: Pipeline Processing Chain (Producer -> Filter -> Consumer)
Build a modular stream-processing pipeline using interconnected coroutines.

```python
def pipeline_printer():
    # Consumer sink
    try:
        while True:
            item = yield
            print(f"SINK [Alert Processor]: {item}")
    except GeneratorExit:
        print("SINK: Closed.")

def threshold_filter(threshold: float, target_coroutine):
    # Filter stage
    try:
        while True:
            val = yield
            if val > threshold:
                target_coroutine.send(f"WARNING: High value {val} exceeds threshold {threshold}!")
    except GeneratorExit:
        target_coroutine.close()

def test_pipeline():
    sink = pipeline_printer()
    next(sink)

    filter_stage = threshold_filter(50.0, sink)
    next(filter_stage)

    # Stream values into the head of the pipeline
    test_values = [12.0, 55.4, 23.1, 98.2, 45.0]
    print("Feeding data to pipeline:")
    for v in test_values:
        filter_stage.send(v)

    filter_stage.close()

test_pipeline()
```

#### Step-by-Step Explanation:
1. `filter_stage` intercepts incoming metrics, applies threshold evaluation, and forwards alerts to `sink`.
2. Closing the head of the pipeline triggers cascade closures down the entire chain.

#### Expected Output:
```text
Feeding data to pipeline:
SINK [Alert Processor]: WARNING: High value 55.4 exceeds threshold 50.0!
SINK [Alert Processor]: WARNING: High value 98.2 exceeds threshold 50.0!
SINK: Closed.
```
