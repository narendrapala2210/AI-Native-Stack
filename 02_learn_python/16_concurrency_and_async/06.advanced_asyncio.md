## 1. Conceptual Deep-Dive: Advanced Asynchronous Constructs

Beyond basic `async`/`await` functions, modern async Python provides:
1. **Asynchronous Iterators (`async for`)**:
   - Objects implementing `__aiter__()` and `__anext__()`.
   - Used for streaming real-time websocket packets or database cursors.
2. **Asynchronous Context Managers (`async with`)**:
   - Objects implementing `__aenter__()` and `__aexit__()`.
   - Essential for non-blocking HTTP connection pools and async database transactions.
3. **`asyncio.Queue`**:
   - Non-blocking FIFO queue for coordinating producer and consumer coroutines within the event loop.

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Asynchronous Streaming Iterator with `async for`
Stream real-time financial ticker metrics asynchronously using an async generator.

```python
import asyncio

async def stock_ticker_stream(symbol: str, count: int):
    price = 150.0
    for i in range(count):
        await asyncio.sleep(0.01)  # Non-blocking network tick
        price += (i - 1) * 0.5
        yield f"{symbol}: ${price:.2f}"

async def consume_ticks():
    print("Subscribing to live ticker stream:")
    # async for consumes async generators smoothly
    async for tick in stock_ticker_stream("AAPL", 4):
        print(" ", tick)

asyncio.run(consume_ticks())
```

#### Step-by-Step Explanation:
1. An `async def` function containing `yield` produces an asynchronous generator.
2. `async for` awaits each yielded item without blocking.

#### Expected Output:
```text
Subscribing to live ticker stream:
  AAPL: $149.50
  AAPL: $149.50
  AAPL: $150.00
  AAPL: $151.00
```

### Example 2: Asynchronous Context Manager with `__aenter__` and `__aexit__`
Manage network socket lifecycle asynchronously.

```python
import asyncio

class AsyncConnectionPool:
    def __init__(self, host: str):
        self.host = host
        self.is_connected = False

    async def __aenter__(self):
        print(f"[AENTER] Establishing async connection to {self.host}...")
        await asyncio.sleep(0.02)  # Non-blocking handshake
        self.is_connected = True
        return self

    async def __aexit__(self, exc_type, exc_val, exc_tb):
        print(f"[AEXIT] Terminating async connection to {self.host}...")
        await asyncio.sleep(0.01)
        self.is_connected = False

async def test_async_cm():
    async with AsyncConnectionPool("redis.internal.net") as pool:
        print(f"Connected? {pool.is_connected}")

asyncio.run(test_async_cm())
```

#### Step-by-Step Explanation:
1. `__aenter__` and `__aexit__` are coroutines, allowing non-blocking setup and teardown.

#### Expected Output:
```text
[AENTER] Establishing async connection to redis.internal.net...
Connected? True
[AEXIT] Terminating async connection to redis.internal.net...
```

### Example 3: Producer-Consumer Coordination with `asyncio.Queue`
Build a high-throughput async processing pipeline.

```python
import asyncio

async def producer(queue: asyncio.Queue):
    for item in [1, 2, 3]:
        await asyncio.sleep(0.01)
        await queue.put(item)
    await queue.put(None)  # Sentinel

async def consumer(queue: asyncio.Queue):
    while True:
        item = await queue.get()
        if item is None:
            queue.task_done()
            break
        print(f"Consumer processed item: {item * 10}")
        queue.task_done()

async def run_queue_pipeline():
    q = asyncio.Queue()
    await asyncio.gather(producer(q), consumer(q))

asyncio.run(run_queue_pipeline())
```

#### Step-by-Step Explanation:
1. `asyncio.Queue.put()` and `.get()` are coroutines that pause gracefully when queue is full or empty.

#### Expected Output:
```text
Consumer processed item: 10
Consumer processed item: 20
Consumer processed item: 30
```
