## 1. Conceptual Deep-Dive: Structural Design Patterns

Structural patterns ease design by identifying a simple way to realize relationships among entities:
1. **Adapter Pattern**:
   - Converts the interface of an incompatible class into another interface that clients expect.
2. **Facade Pattern**:
   - Provides a simplified, high-level interface to a complex subsystem of classes.
3. **Proxy Pattern**:
   - Provides a surrogate or placeholder for another object to control access, log operations, or perform lazy loading.

### Example 1: Legacy API Adapter
Adapt a legacy third-party XML weather service to a modern JSON-compatible interface.

```python
class LegacyXmlWeatherService:
    def get_weather_xml(self, city: str) -> str:
        # Legacy interface returns XML string
        return f"<weather><city>{city}</city><temp>72F</temp></weather>"

class ModernWeatherClient:
    def fetch_temperature_celsius(self, city: str) -> float:
        raise NotImplementedError

class WeatherServiceAdapter(ModernWeatherClient):
    def __init__(self, legacy_service: LegacyXmlWeatherService):
        self.legacy_service = legacy_service

    def fetch_temperature_celsius(self, city: str) -> float:
        xml_data = self.legacy_service.get_weather_xml(city)
        # Parse XML (simulated extraction of 72F)
        temp_f = 72.0
        temp_c = (temp_f - 32) * 5 / 9
        return round(temp_c, 1)

def test_adapter():
    legacy = LegacyXmlWeatherService()
    adapter = WeatherServiceAdapter(legacy)

    celsius = adapter.fetch_temperature_celsius("San Francisco")
    print(f"Adapted Weather Reading: {celsius}C")

test_adapter()
```

#### Step-by-Step Explanation:
1. `WeatherServiceAdapter` wraps the legacy service, transforming interfaces without modifying original source code.

#### Expected Output:
```text
Adapted Weather Reading: 22.2C
```

### Example 2: E-Commerce Microservice Facade
Expose a single clean `checkout()` facade method hiding inventory, payment, and logistics subsystems.

```python
class InventorySystem:
    def reserve_stock(self, item_id: str): print(f"  [Inventory] Reserved stock for '{item_id}'")

class PaymentEngine:
    def process_charge(self, amount: float): print(f"  [Payment] Charged ${amount:,.2f}")

class ShippingNotifier:
    def dispatch_courier(self, address: str): print(f"  [Shipping] Dispatched order to '{address}'")

class CheckoutFacade:
    def __init__(self):
        self.inventory = InventorySystem()
        self.payment = PaymentEngine()
        self.shipping = ShippingNotifier()

    def checkout(self, item_id: str, price: float, shipping_address: str):
        print(f"Executing Checkout Facade for {item_id}:")
        self.inventory.reserve_stock(item_id)
        self.payment.process_charge(price)
        self.shipping.dispatch_courier(shipping_address)
        return "Order Placed Successfully"

def test_facade():
    facade = CheckoutFacade()
    status = facade.checkout("PROD-881", 149.99, "100 Market St, SF")
    print("Status:", status)

test_facade()
```

#### Step-by-Step Explanation:
1. `CheckoutFacade` shields client code from coordinating multiple interdependent services.

#### Expected Output:
```text
Executing Checkout Facade for PROD-881:
  [Inventory] Reserved stock for 'PROD-881'
  [Payment] Charged $149.99
  [Shipping] Dispatched order to '100 Market St, SF'
Status: Order Placed Successfully
```

### Example 3: Access-Control Security Proxy
Control access to sensitive internal database records using a proxy wrapper.

```python
class RealDatabaseWriter:
    def write_record(self, data: str):
        print(f"  [DATABASE WRITE] Record committed to disk: '{data}'")

class SecurityDatabaseProxy:
    def __init__(self, real_writer: RealDatabaseWriter, user_role: str):
        self._real_writer = real_writer
        self.user_role = user_role

    def write_record(self, data: str):
        if self.user_role != "ADMIN":
            raise PermissionError(f"Security Proxy: Role '{self.user_role}' denied write permission!")
        print("[Security Proxy] Authorization verified. Forwarding call...")
        self._real_writer.write_record(data)

def test_proxy():
    writer = RealDatabaseWriter()
    admin_proxy = SecurityDatabaseProxy(writer, "ADMIN")
    guest_proxy = SecurityDatabaseProxy(writer, "GUEST")

    admin_proxy.write_record("SYSTEM_CONFIG_UPDATED")

    try:
        guest_proxy.write_record("ATTEMPTED_OVERWRITE")
    except PermissionError as e:
        print("Proxy Blocked:", e)

test_proxy()
```

#### Step-by-Step Explanation:
1. The proxy intercepts calls, performs authorization checks, and delegates to the real object.

#### Expected Output:
```text
[Security Proxy] Authorization verified. Forwarding call...
  [DATABASE WRITE] Record committed to disk: 'SYSTEM_CONFIG_UPDATED'
Proxy Blocked: Security Proxy: Role 'GUEST' denied write permission!
```
