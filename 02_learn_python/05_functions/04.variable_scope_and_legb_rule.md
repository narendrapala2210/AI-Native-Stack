## 📖 Concept Overview
A **Namespace** in Python is a mapping from variable names (identifiers) to objects in memory. The **Scope** of a name defines the region of a program where that name is directly accessible.

---

### 1. The LEGB Scope Resolution Rule
When a variable name is referenced in Python, the interpreter searches for the identifier across four nested scope layers in a strict sequence:
1. **L - Local Scope**: Names assigned within the currently executing function body.
2. **E - Enclosing Scope**: Names defined in outer (enclosing) functions (relevant in closures and nested functions).
3. **G - Global Scope**: Names assigned at the top-level of a module file or declared with `global`.
4. **B - Built-in Scope**: Names pre-defined in Python (`print`, `len`, `int`, `range`, `ValueError`).

```text
    ┌─────────────────────────────────────────┐
    │ Built-in (print, len, id, int, etc.)    │
    │   ┌─────────────────────────────────────┤
    │   │ Global (Module top-level names)     │
    │   │   ┌─────────────────────────────────┤
    │   │   │ Enclosing (Outer function body) │
    │   │   │   ┌─────────────────────────────┤
    │   │   │   │ Local (Inner function body) │
    └─◀─┴─◀─┴─◀─┴─◀─┴─────────────────────────┘
        Search proceeds from innermost (Local) outwards!
```
If an identifier is not found after searching all 4 scope layers, Python raises `NameError: name 'x' is not defined`.

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Demonstrating the Complete LEGB Hierarchy in Action
Trace variable resolution through all four nested levels in a single execution flow.

```python
# 1. Global Scope (G)
x = "GLOBAL_X"

def outer_function():
    # 2. Enclosing Scope (E)
    e = "ENCLOSING_E"
    
    def inner_function():
        # 3. Local Scope (L)
        l = "LOCAL_L"
        
        # Accessing all levels:
        print("Inner Function Scope Inspection:")
        print(f"  Local     : {l}")
        print(f"  Enclosing : {e}")
        print(f"  Global    : {x}")
        # 4. Built-in Scope (B): len() and print() are loaded from built-ins!
        print(f"  Built-in  : len() exists in built-ins -> len(x) = {len(x)}")
        
    inner_function()

outer_function()
```

#### Step-by-Step Explanation:
1. `l` is resolved immediately in the Local scope.
2. `e` is not in Local, so Python searches and finds it in Enclosing.
3. `x` is not in Local or Enclosing, so Python resolves it in Global.
4. `len` is resolved in Built-ins.

#### Expected Output:
```text
Inner Function Scope Inspection:
  Local     : LOCAL_L
  Enclosing : ENCLOSING_E
  Global    : GLOBAL_X
  Built-in  : len() exists in built-ins -> len(x) = 8
```

### Example 2: Variable Shadowing & The UnboundLocalError Trap
Demonstrate how assigning to a variable inside a function shadows any global variable with the same name, and explain the classic `UnboundLocalError`.

```python
score = 100

def try_increment_score():
    # Attempting to read 'score' before assigning in local scope
    try:
        # In Python, if a variable is assigned anywhere inside a function body,
        # Python marks it as LOCAL for the entire function!
        # Thus, reading it before assignment raises UnboundLocalError!
        score = score + 10
    except UnboundLocalError as err:
        print(f"[TRAPPED ERROR] {err}")

print(f"Global Score Before: {score}")
try_increment_score()
print(f"Global Score After : {score}")
```

#### Step-by-Step Explanation:
1. Because `score = ...` appears in the function body, Python classifies `score` as a local variable.
2. Attempting to evaluate `score + 10` before `score` is initialized locally triggers `UnboundLocalError`.
3. Demonstrates why modifying global variables requires the explicit `global` keyword.

#### Expected Output:
```text
Global Score Before: 100
[TRAPPED ERROR] cannot access local variable 'score' where it is not associated with a value
Global Score After : 100
```

### Example 3: Inspecting Namespaces Programmatically (`locals()` and `globals()`)
Inspect the active symbol tables at runtime using Python's built-in namespace inspection functions.

```python
GLOBAL_APP_NAME = "MetricsEngine"

def inspect_runtime_namespaces(param_a: int, param_b: str):
    local_calc = param_a * 2
    
    # locals() returns dictionary of current local namespace
    current_locals = locals()
    print("=== Current Local Namespace Dictionary ===")
    for k, v in current_locals.items():
        print(f"  Local Identifier: {k:<12} -> Value: {v}")
        
    print(f"\nIs 'GLOBAL_APP_NAME' in globals()? {'GLOBAL_APP_NAME' in globals()}")

inspect_runtime_namespaces(42, "Telemetry")
```

#### Step-by-Step Explanation:
1. `locals()` returns a dictionary representation of current local scope bindings.
2. `globals()` returns the module-level namespace dictionary.

#### Expected Output:
```text
=== Current Local Namespace Dictionary ===
  Local Identifier: param_a      -> Value: 42
  Local Identifier: param_b      -> Value: Telemetry
  Local Identifier: local_calc   -> Value: 84

Is 'GLOBAL_APP_NAME' in globals()? True
```
