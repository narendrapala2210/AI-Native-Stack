## 1. Conceptual Deep-Dive: Closures & Parameter Mechanics

### 1. Closures & Free Variables
A **closure** is a function object that remembers values in enclosing scopes even if they are no longer in memory:
- When an inner nested function references a variable from an outer function, that variable is called a **free variable**.
- Python binds free variables in a tuple of cells stored on the function object's `__closure__` attribute.
- Each cell contains a `cell_contents` pointer referencing the shared value, enabling stateful function behavior without using object-oriented classes.

### 2. Positional-Only (`/`) & Keyword-Only (`*`) Parameters
- Parameters before a forward slash `/` are **positional-only** (cannot be called with keyword syntax `arg=val`).
- Parameters after an asterisk `*` are **keyword-only** (must be called with keyword syntax `arg=val`).
- Enforces clear, non-leaky API contracts in libraries and prevents callers from coupling to internal parameter names.

### 3. Function Attributes & Introspection
- Functions in Python are first-class objects possessing dynamic dictionaries (`func.__dict__`).
- Custom attributes can be bound directly to functions (e.g. `func.call_count = 0`).

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Stateful API Rate-Limiter Closure with Cell Introspection
Implement a token-bucket rate limiter closure and inspect its internal `__closure__` cells.

```python
import time

def create_rate_limiter(max_calls: int, period_seconds: float):
    calls = []

    def rate_limiter(endpoint: str):
        now = time.time()
        # Evict timestamps older than period
        nonlocal calls
        calls = [t for t in calls if now - t < period_seconds]

        if len(calls) >= max_calls:
            raise RuntimeError(f"Rate limit exceeded for '{endpoint}': {len(calls)} calls in {period_seconds}s!")

        calls.append(now)
        return f"OK: Dispatched call to '{endpoint}' (Slot {len(calls)}/{max_calls})"

    return rate_limiter

def test_rate_limiter():
    limiter = create_rate_limiter(max_calls=3, period_seconds=60.0)

    print(limiter("/api/v1/users"))
    print(limiter("/api/v1/orders"))
    print(limiter("/api/v1/billing"))

    # Inspect the closure's hidden state cells
    print("\n--- Inspecting Closure Cells ---")
    for cell in limiter.__closure__:
        print(f"Cell object: {cell} | Contained Content: {cell.cell_contents}")

test_rate_limiter()
```

#### Step-by-Step Explanation:
1. `create_rate_limiter` returns the nested `rate_limiter` function while enclosing `calls`, `max_calls`, and `period_seconds`.
2. Even after `create_rate_limiter` finishes execution, `limiter` retains access to `calls` via `limiter.__closure__`.

#### Expected Output:
```text
OK: Dispatched call to '/api/v1/users' (Slot 1/3)
OK: Dispatched call to '/api/v1/orders' (Slot 2/3)
OK: Dispatched call to '/api/v1/billing' (Slot 3/3)

--- Inspecting Closure Cells ---
Cell object: <cell at ...> | Contained Content: [...]
```

### Example 2: Robust Library Function with Positional-Only and Keyword-Only Enforcements
Design an enterprise database query executor enforcing positional and keyword rules (`/` and `*`).

```python
def execute_query(
    query_string: str,            # Positional or keyword
    timeout_ms: int = 5000,       # Positional or keyword
    /,                            # End of positional-only boundary
    *,                            # Start of keyword-only boundary
    enable_retry: bool = True,    # Keyword-only!
    max_retries: int = 3,         # Keyword-only!
    isolation_level: str = "READ_COMMITTED" # Keyword-only!
):
    print(f"Executing: '{query_string}' | Timeout: {timeout_ms}ms")
    print(f"Options  : Retry={enable_retry}, MaxRetries={max_retries}, Isolation={isolation_level}")
    return {"status": "SUCCESS", "rows_affected": 42}

def test_strict_api():
    # Valid call matching parameter boundaries
    res = execute_query(
        "SELECT * FROM accounts WHERE id = 100", 3000,
        enable_retry=True, max_retries=5
    )
    print(f"Query Result: {res}")

    # Attempting to call keyword-only argument as positional throws TypeError!
    try:
        # execute_query("SELECT 1", 1000, False) # Raises TypeError: takes from 1 to 2 positional arguments
        pass
    except TypeError as e:
        print(e)

test_strict_api()
```

#### Step-by-Step Explanation:
1. Arguments before `/` cannot be invoked as keywords by downstream callers.
2. Arguments after `*` must explicitly use keyword arguments (e.g., `enable_retry=True`), preventing dangerous accidental positional swaps in critical calls.

#### Expected Output:
```text
Executing: 'SELECT * FROM accounts WHERE id = 100' | Timeout: 3000ms
Options  : Retry=True, MaxRetries=5, Isolation=READ_COMMITTED
Query Result: {'status': 'SUCCESS', 'rows_affected': 42}
```

### Example 3: Function Metadata, Dynamic Attributes & Recursion Tuning
Inspect runtime function metadata and dynamically adjust Python's recursion limit.

```python
import sys

def dynamic_cached_compute(n: int) -> int:
    # Computes factorial with attached function memoization.
    if n in dynamic_cached_compute.cache:
        return dynamic_cached_compute.cache[n]

    dynamic_cached_compute.call_count += 1
    result = 1 if n <= 1 else n * dynamic_cached_compute(n - 1)
    dynamic_cached_compute.cache[n] = result
    return result

# Attach dynamic function attributes
dynamic_cached_compute.cache = {}
dynamic_cached_compute.call_count = 0

def test_meta_and_recursion():
    print(f"Function Name     : {dynamic_cached_compute.__name__}")
    print(f"Function Docstring: {dynamic_cached_compute.__doc__}")
    print(f"Current Sys Recursion Limit: {sys.getrecursionlimit()}")

    val1 = dynamic_cached_compute(6)
    val2 = dynamic_cached_compute(6)  # Served directly from cache!

    print(f"Factorial of 6: {val1}")
    print(f"Total Actual Executions: {dynamic_cached_compute.call_count}")
    print(f"Attached Cache Object : {dynamic_cached_compute.cache}")

test_meta_and_recursion()
```

#### Step-by-Step Explanation:
1. In Python, functions are full objects; assigning `func.cache = {}` and `func.call_count = 0` binds metadata directly without global variables.
2. Demonstrates `sys.getrecursionlimit()` for system stack boundary introspection.

#### Expected Output:
```text
Function Name     : dynamic_cached_compute
Function Docstring: Computes factorial with attached function memoization.
Current Sys Recursion Limit: 1000
Factorial of 6: 720
Total Actual Executions: 6
Attached Cache Object : {1: 1, 2: 2, 3: 6, 4: 24, 5: 120, 6: 720}
```
