## 1. Conceptual Deep-Dive: Cryptography & Integrity Verification

Python provides robust security and data integrity primitives in the standard library:
1. **`hashlib` Module (Cryptographic Hashing)**:
   - Provides one-way cryptographic hash functions: SHA-256 (`hashlib.sha256()`), SHA-512, SHA-3, BLAKE2.
   - Computes deterministic, fixed-length digests from arbitrary binary byte inputs.
   - **Salted Hashes**: Adding random data (salts) prior to hashing prevents precomputed rainbow table attacks.
   - **Key Derivation (`hashlib.pbkdf2_hmac`)**: Slow, iterative hashing designed for secure password storage.
2. **`secrets` Module (Cryptographically Secure Random Numbers)**:
   - Backed by the operating system's CSPRNG (`/dev/urandom` or Windows CryptGenRandom).
   - Generates unpredictable tokens, salts, and password resets (`secrets.token_hex()`, `secrets.token_urlsafe()`).
   - Constant-time string comparison (`secrets.compare_digest()`) prevents **timing side-channel attacks**.
3. **`base64` Module**:
   - Encodes binary byte buffers into ASCII characters (`base64.b64encode`, `base64.urlsafe_b64encode`) for safe transmission across text-based protocols.
4. **`warnings` Module**:
   - Emits non-terminating deprecation and security notices (`warnings.warn()`).

### Example 1: SHA-256 File Integrity Checksum Generator
Stream and compute cryptographic SHA-256 checksums for large files in chunked buffers.

```python
import hashlib
import os

def compute_file_sha256(filepath: str, chunk_size: int = 65536) -> str:
    hasher = hashlib.sha256()
    
    with open(filepath, "rb") as f:
        # Stream file in 64KB blocks to prevent exhausting RAM on multi-gigabyte files
        while chunk := f.read(chunk_size):
            hasher.update(chunk)
            
    return hasher.hexdigest()

def test_file_integrity():
    test_file = "payload_artifact.bin"
    with open(test_file, "wb") as f:
        f.write(b"CRITICAL_SYSTEM_BINARY_DATA_BLOCK" * 1000)

    digest = compute_file_sha256(test_file)
    print(f"File: {test_file}")
    print(f"SHA-256 Digest: {digest}")

    # Cleanup
    if os.path.exists(test_file): os.remove(test_file)

test_file_integrity()
```

#### Step-by-Step Explanation:
1. `hasher.update(chunk)` incrementally digests binary streams without loading the entire file into memory.
2. `hasher.hexdigest()` returns the hex-encoded 64-character SHA-256 checksum.

#### Expected Output:
```text
File: payload_artifact.bin
SHA-256 Digest: 56934c...
```

### Example 2: Secure Password Hashing with Salt & PBKDF2
Hash user passwords using industrial PBKDF2 HMAC-SHA256 with 100,000 iterations and salt.

```python
import hashlib
import secrets

def hash_user_password(password: str) -> tuple[bytes, bytes]:
    # 1. Generate cryptographically secure 16-byte random salt
    salt = secrets.token_bytes(16)
    
    # 2. Derive key using 100,000 iterations of SHA-256
    key = hashlib.pbkdf2_hmac(
        hash_name="sha256",
        password=password.encode("utf-8"),
        salt=salt,
        iterations=100_000
    )
    return salt, key

def verify_user_password(password: str, salt: bytes, stored_key: bytes) -> bool:
    new_key = hashlib.pbkdf2_hmac(
        hash_name="sha256",
        password=password.encode("utf-8"),
        salt=salt,
        iterations=100_000
    )
    # Constant-time comparison prevents timing attacks!
    return secrets.compare_digest(new_key, stored_key)

def test_password_auth():
    raw_pass = "SuperSecretP@ssword2026"
    salt, key = hash_user_password(raw_pass)

    print(f"Salt (Hex) : {salt.hex()}")
    print(f"Derived Key: {key.hex()[:32]}...")

    # Verification checks
    is_valid = verify_user_password("SuperSecretP@ssword2026", salt, key)
    is_wrong = verify_user_password("WrongPasswordAttempt", salt, key)

    print(f"Correct Password Verification: {is_valid}")
    print(f"Wrong Password Verification  : {is_wrong}")

test_password_auth()
```

#### Step-by-Step Explanation:
1. `secrets.token_bytes(16)` ensures salts cannot be predicted.
2. `hashlib.pbkdf2_hmac` imposes intentional CPU friction, making brute-force cracking mathematically infeasible.
3. `secrets.compare_digest` guards against timing side-channel attacks.

#### Expected Output:
```text
Salt (Hex) : ...
Derived Key: ...
Correct Password Verification: True
Wrong Password Verification  : False
```

### Example 3: URL-Safe Authentication Token Generation with `secrets` and `base64`
Generate URL-safe bearer tokens and serialize structured credentials in Base64.

```python
import secrets
import base64
import json

def generate_session_token() -> str:
    # 32 cryptographically secure random bytes encoded into URL-safe base64 string
    return secrets.token_urlsafe(32)

def encode_auth_header(username: str, role: str) -> str:
    payload = json.dumps({"user": username, "role": role})
    encoded_bytes = base64.b64encode(payload.encode("utf-8"))
    return encoded_bytes.decode("ascii")

def decode_auth_header(token: str) -> dict:
    decoded_bytes = base64.b64decode(token.encode("ascii"))
    return json.loads(decoded_bytes.decode("utf-8"))

def test_token_auth():
    token = generate_session_token()
    print(f"Generated Session Bearer Token: {token} (Length: {len(token)})")

    # Base64 header encode & decode
    header_token = encode_auth_header("alice_admin", "SECURITY_ADMIN")
    print(f"Base64 Auth Token             : {header_token}")
    
    restored = decode_auth_header(header_token)
    print(f"Restored Payload              : {restored}")

test_token_auth()
```

#### Step-by-Step Explanation:
1. `secrets.token_urlsafe` outputs strings safe for direct inclusion in HTTP headers and URLs.
2. `base64.b64encode` and `b64decode` handle binary-to-text serializations.

#### Expected Output:
```text
Generated Session Bearer Token: ... (Length: 43)
Base64 Auth Token             : eyJ1c2VyIjogImFsaWNlX2FkbWluIiwgInJvbGUiOiAiU0VDVVJJVFlfQURNSU4ifQ==
Restored Payload              : {'user': 'alice_admin', 'role': 'SECURITY_ADMIN'}
```
