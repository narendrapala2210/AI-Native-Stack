## 1. Conceptual Deep-Dive: Pattern Matching Engine

Python's built-in `re` module provides a high-performance C-based regular expression engine:
1. **Pre-Compilation (`re.compile`)**:
   - Compiling a regex pattern string into a `Pattern` object parses and caches the deterministic finite automaton (DFA) state machine.
   - Saves CPU overhead when reusing patterns in loops.
2. **Primary Search Functions**:
   - `re.search(pattern, string)`: Scans throughout string looking for the first location producing a match.
   - `re.match(pattern, string)`: Matches only at the absolute beginning of the string.
   - `re.fullmatch(pattern, string)`: Matches only if the entire string matches the pattern.
   - `re.findall(pattern, string)`: Returns all non-overlapping matches as a list of strings or tuples.
   - `re.finditer(pattern, string)`: Returns an iterator yielding `Match` objects (memory-efficient for large text).
   - `re.sub(pattern, repl, string)`: Replaces occurrences with string or dynamic callable replacement.
3. **Named Capture Groups**: `(?P<name>...)` allows extracting fields by semantic name rather than fragile numeric indices.
4. **Regex Compilation Flags**:
   - `re.IGNORECASE` (`re.I`): Case-insensitive matching.
   - `re.MULTILINE` (`re.M`): `^` and `$` match start/end of each line.
   - `re.DOTALL` (`re.S`): Dot `.` matches any character including newline `\n`.
   - `re.VERBOSE` (`re.X`): Allows formatted multi-line regexes with whitespace and comments.

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Robust Email & URL Extraction with Named Groups
Extract structured components from unformatted text using named regex capture groups.

```python
import re

def parse_contact_entities(raw_text: str):
    email_pattern = re.compile(
        r'(?P<username>[a-zA-Z0-9_.+-]+)@(?P<domain>[a-zA-Z0-9-]+\.[a-zA-Z0-9-.]+)'
    )

    print("Extracted Email Contacts:")
    for match in email_pattern.finditer(raw_text):
        print(f"  Full Email: {match.group(0)}")
        print(f"    -> User:   {match.group('username')}")
        print(f"    -> Domain: {match.group('domain')}")
        print(f"    -> Offset: {match.span()}")

def test_extraction():
    text = "Please reach out to support@acme-corp.com or admin.alex@cloud-systems.org for escalations."
    parse_contact_entities(text)

test_extraction()
```

#### Step-by-Step Explanation:
1. `(?P<username>...)` and `(?P<domain>...)` define named groups.
2. `match.group('username')` retrieves components directly by key.
3. `match.span()` provides exact start and end character offsets.

#### Expected Output:
```text
Extracted Email Contacts:
  Full Email: support@acme-corp.com
    -> User:   support
    -> Domain: acme-corp.com
    -> Offset: (20, 41)
  Full Email: admin.alex@cloud-systems.org
    -> User:   admin.alex
    -> Domain: cloud-systems.org
    -> Offset: (45, 73)
```

### Example 2: Dynamic Text Sanitization with Callable `re.sub` Replacement
Mask sensitive personally identifiable information (PII) using a dynamic transformation function.

```python
import re

def mask_sensitive_data(text: str) -> str:
    # Pattern matching 16-digit credit cards with optional hyphens
    card_pattern = re.compile(r'\b(?P<prefix>\d{4})[- ]?\d{4}[- ]?\d{4}[- ]?(?P<suffix>\d{4})\b')

    def masking_replacer(match: re.Match) -> str:
        # Keep first 4 and last 4 digits, mask middle 8 digits
        prefix = match.group("prefix")
        suffix = match.group("suffix")
        return f"{prefix}-****-****-{suffix}"

    return card_pattern.sub(masking_replacer, text)

def test_masking():
    log_entry = "Payment charged to card 4111-2222-3333-4444 and fallback 5500 0000 1111 9898."
    sanitized = mask_sensitive_data(log_entry)
    print("Original Log :", log_entry)
    print("Sanitized Log:", sanitized)

test_masking()
```

#### Step-by-Step Explanation:
1. Passing a callable function to `re.sub()` evaluates the function for each regex match.
2. Formats a sanitized token with masked asterisks while retaining valid card routing prefixes.

#### Expected Output:
```text
Original Log : Payment charged to card 4111-2222-3333-4444 and fallback 5500 0000 1111 9898.
Sanitized Log: Payment charged to card 4111-****-****-4444 and fallback 5500-****-****-9898.
```

### Example 3: Self-Documenting Multi-Line Regex with `re.VERBOSE`
Parse complex ISO 8601 timestamps using verbose formatting and embedded comments.

```python
import re

def parse_iso_timestamp(timestamp_str: str):
    iso_pattern = re.compile(r'''
        ^
        (?P<year>\d{4})        # 4 digit year
        -
        (?P<month>\d{2})       # 2 digit month (01-12)
        -
        (?P<day>\d{2})         # 2 digit day (01-31)
        [T\s]                  # Date-time separator (T or space)
        (?P<hour>\d{2})        # 2 digit hour (00-23)
        :
        (?P<minute>\d{2})      # 2 digit minute
        :
        (?P<second>\d{2})      # 2 digit second
        (?:\.(?P<ms>\d+))?     # Optional fractional milliseconds
        (?P<tz>Z|[+-]\d{2}:\d{2}) # Timezone offset
        $
    ''', re.VERBOSE)

    match = iso_pattern.match(timestamp_str)
    if match:
        return match.groupdict()
    return None

def test_verbose_regex():
    sample = "2026-09-14T14:30:00.520Z"
    parsed = parse_iso_timestamp(sample)
    print(f"Timestamp: {sample}")
    print("Parsed Dictionary:")
    for k, v in parsed.items():
        print(f"  {k:<8} => {v}")

test_verbose_regex()
```

#### Step-by-Step Explanation:
1. `re.VERBOSE` ignores non-escaped whitespace and enables inline `#` comments.
2. Converts complex patterns into maintainable, self-documenting code.

#### Expected Output:
```text
Timestamp: 2026-09-14T14:30:00.520Z
Parsed Dictionary:
  year     => 2026
  month    => 09
  day      => 14
  hour     => 14
  minute   => 30
  second   => 00
  ms       => 520
  tz       => Z
```
