## 📖 Concept Overview
Type conversion is the process of converting an object from one data type to another. Python provides two distinct mechanisms for type conversion:
1. **Implicit Type Conversion (Automatic Coercion)**
2. **Explicit Type Conversion (Type Casting)**

---

### 1. Implicit Type Conversion
When performing operations between mixed numeric types (e.g., adding an integer and a float), Python automatically converts the narrower type to the wider type to prevent data loss:
```python
num_int = 12
num_float = 1.5

result = num_int + num_float
print(result)        # 13.5
print(type(result))  # <class 'float'>
```
Here, Python automatically converts `num_int` to a float (`12.0`) before performing the addition.

---

### 2. Explicit Type Conversion (Type Casting)
Developers use built-in constructor functions to manually convert an object:
- **`int(x)`**: Converts `x` to an integer. Truncates decimal components towards zero (does not round).
- **`float(x)`**: Converts `x` to a floating-point number.
- **`str(x)`**: Converts any Python object into its string representation.
- **`bool(x)`**: Evaluates truthiness and converts `x` into `True` or `False`.

```python
# Float to integer (truncates)
pi = 3.999
print(int(pi))      # 3

# String to float
price = float("19.95")
print(price * 2)    # 39.9
```

### Type Conversion Errors & Caveats
1. **Invalid Literals for `int()`**:
   Passing a string containing non-numeric characters or decimals to `int()` raises `ValueError`:
   ```python
   int("Five")   # ValueError: invalid literal for int() with base 10: 'Five'
   int("5.0")    # ValueError: invalid literal for int() with base 10: '5.0'
   ```
   > [!TIP]
   > To convert a string containing a float into an integer, parse it as float first:
   > `int(float("5.0"))` -> `5`

2. **Truthiness & `bool()` Casting**:
   In Python, empty collections (`""`, `[]`, `{}`, `set()`), numeric zeroes (`0`, `0.0`), and `None` evaluate to `False`. All other values evaluate to `True`.

---

## 📋 Summary & Conversion Reference Table

| Target Type | Constructor | Valid Inputs | Common Error Trap |
| :--- | :--- | :--- | :--- |
| **`int`** | `int(val)` | Integer literals, floats (truncated), string integers (`"42"`) | `"42.5"` raises `ValueError` (must use `int(float("42.5"))`). |
| **`float`** | `float(val)` | Numeric values, numeric string representations (`"3.14"`, `"1e-3"`) | `"NaN"` and `"inf"` are valid floats, but `"abc"` raises `ValueError`. |
| **`str`** | `str(val)` | **Any** Python object (invokes object's `__str__()` method) | Never raises an error for standard built-ins. |
| **`bool`** | `bool(val)` | Any object; converts via truthiness evaluation | Non-empty strings like `"False"` evaluate to `True`! |

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Robust Multi-Type Sensor Telemetry Ingestion
Parse incoming raw text data packets containing heterogeneous datatypes, casting each to its appropriate Python type.

```python
def ingest_telemetry_packet(packet_data: dict[str, str]) -> dict:
    cleaned = {}
    
    # 1. Device ID (String)
    cleaned["device_id"] = str(packet_data.get("device_id", "UNKNOWN")).strip()
    
    # 2. Reading Count (Integer)
    try:
        cleaned["reading_count"] = int(packet_data["reading_count"])
    except (ValueError, KeyError):
        cleaned["reading_count"] = 0
        
    # 3. Ambient Temperature (Float)
    try:
        cleaned["temperature_c"] = float(packet_data["temperature"])
    except (ValueError, KeyError):
        cleaned["temperature_c"] = 0.0
        
    # 4. Sensor Online Status (Boolean)
    # Caution: bool("False") is True! Check explicitly against string tokens:
    raw_status = str(packet_data.get("is_online", "")).strip().lower()
    cleaned["is_online"] = raw_status in ("true", "1", "yes", "on")
    
    return cleaned

raw_packet = {
    "device_id": "  IOT-STATION-DELTA-9  ",
    "reading_count": "1540",
    "temperature": "24.85",
    "is_online": "True"
}

parsed = ingest_telemetry_packet(raw_packet)
print("Parsed Telemetry Record:")
for k, v in parsed.items():
    print(f"  {k:<16}: {v!r:<12} (Type: {type(v).__name__})")
```

#### Step-by-Step Explanation:
1. Demonstrates the critical trap where `bool("False")` yields `True` because any non-empty string is truthy.
2. Uses explicit membership testing (`raw_status in ("true", "1", "yes")`) to safely cast boolean strings.
3. Wraps `int()` and `float()` parsing in `try...except` to assign safe default fallbacks.

#### Expected Output:
```text
Parsed Telemetry Record:
  device_id       : 'IOT-STATION-DELTA-9' (Type: str)
  reading_count   : 1540         (Type: int)
  temperature_c   : 24.85        (Type: float)
  is_online       : True         (Type: bool)
```

### Example 2: Financial Currency Ledger with Accurate Casting
Demonstrate the precision danger of direct floating point casting in finance and how to properly format and cast currency values.

```python
def calculate_exchange(amount_str: str, exchange_rate: float) -> dict:
    # 1. Cast string to float
    clean_amount_str = amount_str.replace("$", "").replace(",", "").strip()
    source_amount = float(clean_amount_str)
    
    # 2. Compute converted value
    converted_raw = source_amount * exchange_rate
    
    # 3. Round to 2 decimal places and cast back to formatted currency string
    converted_rounded = round(converted_raw, 2)
    formatted_str = f"€{converted_rounded:,.2f}"
    
    return {
        "original_input": amount_str,
        "source_usd": source_amount,
        "exchange_rate": exchange_rate,
        "target_eur": converted_rounded,
        "display_output": formatted_str
    }

transaction = calculate_exchange("$ 1,450.75", 0.92)
print("Currency Conversion Summary:")
for key, val in transaction.items():
    print(f"  {key:<16}: {val}")
```

#### Step-by-Step Explanation:
1. Real-world user input often contains currency symbols (`$`) and thousand separators (`,`).
2. Cleans the string using `replace()` before casting to `float` to avoid `ValueError`.
3. Performs numeric math, rounds, and formats the output into a standardized currency string.

#### Expected Output:
```text
Currency Conversion Summary:
  original_input  : $ 1,450.75
  source_usd      : 1450.75
  exchange_rate   : 0.92
  target_eur      : 1334.69
  display_output  : €1,334.69
```

### Example 3: Truth Value Testing (Truthiness) Matrix in Dynamic Filtering
Use `bool()` casting to demonstrate Python's truthiness rules and build a dynamic query parameter cleaner for web APIs.

```python
def clean_api_query_parameters(query_params: dict) -> dict:
    print("=== Filtering Empty / Falsy Query Parameters ===")
    
    # Python considers 0, 0.0, "", [], {}, None, and False as falsy.
    # In API query filtering, we want to drop empty strings or None, but keep active False or numeric 0!
    cleaned = {}
    for key, val in query_params.items():
        # Let's inspect boolean casting
        is_truthy = bool(val)
        print(f"Key: '{key:<10}', Value: {val!r:<15}, bool(val): {is_truthy}")
        
        # Keep if value is not None and not an empty string
        if val is not None and val != "":
            cleaned[key] = val
            
    return cleaned

raw_params = {
    "search": "python tutorials",
    "page": 1,
    "filter_active": False,  # Note: bool(False) is False, but it's a valid filter!
    "category": "",          # Empty string is falsy -> should be omitted
    "min_price": 0,          # Note: bool(0) is False, but 0 is a valid price!
    "tag": None              # None is falsy -> should be omitted
}

result = clean_api_query_parameters(raw_params)
print(f"
Final Active Query Parameters: {result}")
```

#### Step-by-Step Explanation:
1. Demonstrates `bool(val)` on multiple Python primitives.
2. Explains the subtle architectural difference between "falsiness" and "intentional falsy values" (like `0` or `False`).
3. Retains valid zeroes and boolean flags while discarding nulls and empty strings.

#### Expected Output:
```text
=== Filtering Empty / Falsy Query Parameters ===
Key: 'search    ', Value: 'python tutorials', bool(val): True
Key: 'page      ', Value: 1              , bool(val): True
Key: 'filter_active', Value: False          , bool(val): False
Key: 'category  ', Value: ''             , bool(val): False
Key: 'min_price ', Value: 0              , bool(val): False
Key: 'tag       ', Value: None           , bool(val): False

Final Active Query Parameters: {'search': 'python tutorials', 'page': 1, 'filter_active': False, 'min_price': 0}
```
