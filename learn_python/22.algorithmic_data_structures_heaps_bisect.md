# 22. Algorithmic Data Structures: Heaps, Bisect & Performance Extractors

### 22.1 Priority Queues & Heaps with `heapq`

`heapq` provides an implementation of the Min-Heap algorithm on top of regular Python lists with $O(\log n)$ push and pop.

```python
import heapq

# 1. Heap operations
tasks = []
# heapq stores tuples sorted by the first element (priority)
heapq.heappush(tasks, (3, "Low priority cleanup"))
heapq.heappush(tasks, (1, "CRITICAL: Database failover"))
heapq.heappush(tasks, (2, "Medium priority email batch"))

print("Root of heap (highest priority):", tasks[0])

# Pop items in priority order
while tasks:
    priority, task_name = heapq.heappop(tasks)
    print(f"Processing (Level {priority}): {task_name}")

# 2. Finding top N elements efficiently without full O(n log n) sorting
scores = [45, 99, 23, 87, 56, 91, 78, 100, 62]
top_3 = heapq.nlargest(3, scores)
bottom_2 = heapq.nsmallest(2, scores)
print("Top 3 scores:", top_3)
print("Bottom 2 scores:", bottom_2)
```

### 22.2 Binary Search & Sorted Insertion with `bisect`

The `bisect` module implements binary search algorithms over sorted lists in $O(\log n)$ time.

```python
import bisect

sorted_ids = [10, 20, 30, 40, 50, 60, 70]

# Finding insertion index to maintain sort order
idx = bisect.bisect_left(sorted_ids, 35)
print(f"35 should be inserted at index: {idx}")

# Inserting directly in sorted position: insort
bisect.insort(sorted_ids, 35)
print("Updated sorted list:", sorted_ids)

# Practical application: Grade lookup table using bisect
def calculate_letter_grade(score: int) -> str:
    breakpoints = [60, 70, 80, 90]
    grades = ["F", "D", "C", "B", "A"]
    index = bisect.bisect_right(breakpoints, score)
    return grades[index]

print("Score 85 Grade:", calculate_letter_grade(85))  # B
print("Score 92 Grade:", calculate_letter_grade(92))  # A
print("Score 55 Grade:", calculate_letter_grade(55))  # F
```

### 22.3 C-Speed Extraction with the `operator` Module (`itemgetter`, `attrgetter`)

Instead of writing slow lambda functions (`lambda x: x['age']`), the `operator` module provides built-in C-level extractors.

```python
from operator import itemgetter, attrgetter, methodcaller

users = [
    {"username": "charlie", "score": 85, "age": 30},
    {"username": "alice", "score": 98, "age": 25},
    {"username": "bob", "score": 98, "age": 22}
]

# itemgetter: Sort by score DESCENDING, then age ASCENDING
# itemgetter runs significantly faster in C than pure Python lambdas
sorted_users = sorted(users, key=itemgetter("score", "age"))
print("Sorted by score then age:", [(u["username"], u["score"], u["age"]) for u in sorted_users])

# attrgetter & methodcaller
words = ["python", "machine", "learning"]
uppercased = list(map(methodcaller("upper"), words))
print("Uppercased via methodcaller:", uppercased)
```

### Example 1: Priority Job Scheduler with Task Preemption via `heapq`
Schedule background jobs where higher priority jobs are always processed ahead of lower priority jobs.

```python
import heapq
import time

class PriorityScheduler:
    def __init__(self):
        self._queue = []
        self._index = 0

    def add_job(self, name: str, priority: int):
        # Priority: lower integer = higher priority
        # index avoids comparison collision on duplicate priorities
        heapq.heappush(self._queue, (priority, self._index, name))
        self._index += 1

    def pop_next_job(self) -> str | None:
        if not self._queue:
            return None
        priority, _, name = heapq.heappop(self._queue)
        return f"Job: {name} (Priority {priority})"

scheduler = PriorityScheduler()
scheduler.add_job("Batch log upload", priority=3)
scheduler.add_job("Emergency failover", priority=1)
scheduler.add_job("Send marketing emails", priority=2)

while job := scheduler.pop_next_job():
    print("Executing:", job)
```

### Example 2: Dynamic Leaderboard with Fast Insertion via `bisect`
Maintain a live sorted score leaderboard with $O(\log n)$ insertion instead of expensive $O(n \log n)$ re-sorting.

```python
import bisect

class SortedLeaderboard:
    def __init__(self):
        self.scores = []  # Kept sorted ascending

    def add_score(self, score: int):
        bisect.insort(self.scores, score)

    def get_rank(self, score: int) -> int:
        # How many players scored strictly lower?
        lower_count = bisect.bisect_left(self.scores, score)
        return len(self.scores) - lower_count  # 1-based rank

board = SortedLeaderboard()
for s in [100, 250, 400, 150, 300]:
    board.add_score(s)

print("Current sorted scores:", board.scores)
print("Rank of 250:", board.get_rank(250))
print("Rank of 500 (New high score!):", board.get_rank(500))
```

### Example 3: High-Performance Multi-Field Record Sorter with `operator.itemgetter`
Benchmark and demonstrate multi-key sorting using C-optimized `operator.itemgetter`.

```python
from operator import itemgetter

records = [
    {"dept": "Engineering", "level": 3, "name": "Charlie"},
    {"dept": "Sales", "level": 2, "name": "Alice"},
    {"dept": "Engineering", "level": 5, "name": "Bob"},
    {"dept": "Sales", "level": 4, "name": "Diana"}
]

# Sort by department ASCENDING, then level DESCENDING
# To invert numeric sorts, sort in passes:
records.sort(key=itemgetter("level"), reverse=True)
records.sort(key=itemgetter("dept"))

print("Sorted Records:")
for r in records:
    print(f"  {r['dept']:<12} Level {r['level']} - {r['name']}")
```
