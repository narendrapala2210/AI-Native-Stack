## 1. Conceptual Deep-Dive: The Asynchronous Web Contract

While WSGI handles synchronous HTTP request/response cycles effectively, it cannot natively support WebSockets, Server-Sent Events (SSE), or long-lived streaming connections.

**ASGI (Asynchronous Server Gateway Interface)** extends WSGI to modern asynchronous architectures:
- An ASGI 3 application is an async callable: `async def app(scope, receive, send)`.
- **`scope`**: A dictionary containing connection metadata (protocol type: `'http'`, `'websocket'`, or `'lifespan'`).
- **`receive`**: An async callable yielding incoming event dictionaries (e.g. `{'type': 'http.request', 'body': b'...'}`).
- **`send`**: An async callable dispatching outgoing event dictionaries (e.g. `{'type': 'http.response.start'}`, `{'type': 'http.response.body'}`).

```
+-----------------------------------------------------------+
|               ASGI Architecture Data Flow                 |
|                                                           |
| ASGI Server (Uvicorn / Hypercorn)                         |
|       |                                                   |
|       V  async def app(scope, receive, send)              |
| ASGI Application (FastAPI / Starlette / Quart)            |
|       |                                                   |
|       +---> event = await receive()  (Read request chunks)|
|       +---> await send({'type': 'http.response.start'})   |
|       +---> await send({'type': 'http.response.body'})    |
+-----------------------------------------------------------+
```

## 2. WSGI vs. ASGI Comparison Matrix

| Feature | WSGI | ASGI |
|---|---|---|
| Invocation Paradigm | Synchronous callable `(environ, start_response)` | Asynchronous coroutine `(scope, receive, send)` |
| Execution Model | One thread / process per request | Async event loop (thousands of concurrent coroutines) |
| Protocol Support | HTTP/1.1 request-response only | HTTP/1.1, HTTP/2, WebSockets, Lifespan |
| Standard Servers | Gunicorn, uWSGI, mod_wsgi | Uvicorn, Hypercorn, Granian |
| Modern Frameworks | Django (classic), Flask | FastAPI, Starlette, Quart, Django Channels |

## 3. Practical Code Examples with Step-by-Step Explanations

### Example 1: Minimal ASGI HTTP Application
Build a compliant ASGI application from scratch using `asyncio`.

```python
import asyncio
import json

async def minimal_asgi_app(scope, receive, send):
    # Ensure scope is HTTP
    if scope["type"] != "http":
        return

    # Wait for incoming request body
    request_event = await receive()
    body_data = request_event.get("body", b"")

    # Construct JSON response
    response_payload = {
        "protocol": "ASGI 3.0",
        "path": scope["path"],
        "method": scope["method"],
        "body_received_len": len(body_data)
    }
    encoded_body = json.dumps(response_payload).encode("utf-8")

    # Step 1: Send response start headers
    await send({
        "type": "http.response.start",
        "status": 200,
        "headers": [
            (b"content-type", b"application/json"),
            (b"content-length", str(len(encoded_body)).encode("ascii")),
        ],
    })

    # Step 2: Send response body
    await send({
        "type": "http.response.body",
        "body": encoded_body,
        "more_body": False,
    })

# Simulated execution harness
async def test_asgi():
    sent_events = []
    async def mock_receive():
        return {"type": "http.request", "body": b'{"ping": "pong"}'}
    async def mock_send(event):
        sent_events.append(event)

    test_scope = {"type": "http", "method": "POST", "path": "/v1/async-ping"}
    await minimal_asgi_app(test_scope, mock_receive, mock_send)
    
    print(f"Sent {len(sent_events)} ASGI events:")
    for ev in sent_events:
        print(f"  Event Type: {ev['type']}")

asyncio.run(test_asgi())
```

#### Step-by-Step Explanation:
1. `scope["type"]` indicates whether the connection is `'http'` or `'websocket'`.
2. `await receive()` asynchronously yields chunks of the incoming request body without blocking the server event loop.
3. `await send(...)` dispatches event dictionaries for response status headers followed by body payloads.

#### Expected Output:
```text
Sent 2 ASGI events:
  Event Type: http.response.start
  Event Type: http.response.body
```

### Example 2: Streaming Long-Lived Responses
Stream large data chunks to the client over an open connection.

```python
import asyncio

async def streaming_asgi_app(scope, receive, send):
    if scope["type"] != "http":
        return

    # Start response with chunked encoding
    await send({
        "type": "http.response.start",
        "status": 200,
        "headers": [(b"content-type", b"text/plain")],
    })

    # Stream 3 chunks sequentially
    for i in range(1, 4):
        chunk_data = f"Chunk {i}\n".encode("utf-8")
        is_last = (i == 3)
        await send({
            "type": "http.response.body",
            "body": chunk_data,
            "more_body": not is_last,
        })
        await asyncio.sleep(0.01)

async def test_streaming():
    received_chunks = []
    async def mock_send(event):
        if event["type"] == "http.response.body":
            received_chunks.append(event["body"].decode("utf-8").strip())

    await streaming_asgi_app({"type": "http"}, lambda: None, mock_send)
    print("Received streaming response chunks:")
    for c in received_chunks:
        print(f"  -> {c}")

asyncio.run(test_streaming())
```

#### Step-by-Step Explanation:
1. Setting `more_body=True` keeps the response stream open for subsequent chunks.
2. Setting `more_body=False` on the final chunk signals the server adapter to complete the HTTP response.
3. This powers Server-Sent Events (SSE) and AI LLM streaming token outputs.

#### Expected Output:
```text
Received streaming response chunks:
  -> Chunk 1
  -> Chunk 2
  -> Chunk 3
```

### Example 3: Lifespan Protocol for Application Startup and Shutdown
Manage database connection pools and background tasks during application startup and teardown.

```python
import asyncio

async def lifespan_aware_app(scope, receive, send):
    if scope["type"] == "lifespan":
        while True:
            message = await receive()
            if message["type"] == "lifespan.startup":
                # Initialize resources (e.g. DB connection pool, cache clients)
                print("[App Lifecycle] Starting background connection pools...")
                await send({"type": "lifespan.startup.complete"})
            elif message["type"] == "lifespan.shutdown":
                # Cleanup resources
                print("[App Lifecycle] Closing connection pools...")
                await send({"type": "lifespan.shutdown.complete"})
                return

async def test_lifespan():
    # Simulate Uvicorn lifespan handling
    events_in = asyncio.Queue()
    await events_in.put({"type": "lifespan.startup"})
    await events_in.put({"type": "lifespan.shutdown"})

    async def mock_receive():
        return await events_in.get()

    async def mock_send(event):
        print(f"[Server Lifespan ACK] Received: {event['type']}")

    await lifespan_aware_app({"type": "lifespan"}, mock_receive, mock_send)

asyncio.run(test_lifespan())
```

#### Step-by-Step Explanation:
1. ASGI defines a `'lifespan'` scope type handled before and after request serving begins.
2. Applications perform startup initialization and respond with `lifespan.startup.complete`.
3. During graceful shutdown, applications release database connections and respond with `lifespan.shutdown.complete`.

#### Expected Output:
```text
[App Lifecycle] Starting background connection pools...
[Server Lifespan ACK] Received: lifespan.startup.complete
[App Lifecycle] Closing connection pools...
[Server Lifespan ACK] Received: lifespan.shutdown.complete
```

## 4. Key Takeaways & Best Practices

1. ASGI applications must never execute blocking synchronous I/O directly in coroutines; offload blocking work with `asyncio.to_thread`.
2. Use the ASGI Lifespan protocol to manage resource startup and teardown instead of doing work at module import time.
3. Always pair ASGI applications with production-grade servers like Uvicorn or Hypercorn.
