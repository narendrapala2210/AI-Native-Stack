## 1. Project Overview & Architectural Design

Large-scale data engineering and AI agent pipelines rely on high-throughput asynchronous network fetching and data transformation. Building a robust data scraping pipeline requires:
1. **Producer-Consumer Work Queues**: Decoupling URL discovery from page fetching and parsing.
2. **Concurrency Control & Throttling**: Using `asyncio.Semaphore` to avoid overwhelming target endpoints.
3. **Resilience & Exponential Backoff**: Retrying failed requests gracefully when encountering timeouts or rate limits.
4. **Structured Storage**: Streaming extracted JSON records directly to disk without memory accumulation.

```
URL Seed List
      |
      V
[ asyncio.Queue (Pending Tasks) ]
      |
      +=============================+
      |                             |
[ Worker Coroutine 1 ]    [ Worker Coroutine 2 ] ... (Up to Concurrency Limit)
      |                             |
      +---> Fetches URL with Retry  +
      +---> Extracts Data           +
      |                             |
      +=============================+
                    |
                    V
        [ Result Consumer Queue ]
                    |
                    V
     [ Persistent JSONL Disk Stream ]
```

## 2. Core Architectural Components

| Component | Class / Construct | Responsibility |
|---|---|---|
| Work Queue | `asyncio.Queue` | Coordinates URL dispatch between discovery producers and fetch workers |
| Concurrency Gate | `asyncio.Semaphore(N)` | Restricts maximum concurrent outbound HTTP connections |
| Worker Routine | `worker(queue, semaphore)` | Consumes URLs, executes backoff retries, extracts fields |
| Data Sink | Stream Writer | Writes cleaned structured JSON records directly to disk |

### Example 1: Async Worker Pool with `asyncio.Queue` & `Semaphore`
Build an asynchronous worker pool with bounded concurrency.

```python
import asyncio
import random

async def simulate_fetch(url: str) -> dict:
    """Simulates an asynchronous HTTP GET request."""
    latency = random.uniform(0.05, 0.15)
    await asyncio.sleep(latency)
    return {
        "url": url,
        "status": 200,
        "title": f"Page Title for {url}",
        "word_count": random.randint(100, 1500)
    }

async def crawler_worker(worker_id: int, queue: asyncio.Queue, results: list, sem: asyncio.Semaphore):
    while True:
        url = await queue.get()
        try:
            # Concurrency throttle
            async with sem:
                print(f"[Worker {worker_id}] Fetching: {url}")
                page_data = await simulate_fetch(url)
                results.append(page_data)
        finally:
            queue.task_done()

async def run_crawler_pipeline():
    queue = asyncio.Queue()
    results = []
    concurrency_limit = asyncio.Semaphore(2)  # Max 2 concurrent HTTP requests

    urls = [f"https://example.com/article/{i}" for i in range(1, 6)]
    for u in urls:
        queue.put_nowait(u)

    # Spawn 3 worker coroutines
    workers = [
        asyncio.create_task(crawler_worker(i, queue, results, concurrency_limit))
        for i in range(1, 4)
    ]

    # Wait until queue is completely processed
    await queue.join()

    # Cancel idle background workers
    for w in workers:
        w.cancel()

    print(f"\nPipeline finished. Collected {len(results)} pages:")
    for res in results[:2]:
        print(f"  Result: {res['url']} -> {res['title']}")

asyncio.run(run_crawler_pipeline())
```

#### Step-by-Step Explanation:
1. `asyncio.Queue` coordinates work items across multiple worker coroutines.
2. `async with sem:` enforces that no more than 2 network requests execute simultaneously across all workers.
3. `await queue.join()` pauses the orchestrator until every item has been marked completed via `queue.task_done()`.

#### Expected Output:
```text
[Worker 1] Fetching: https://example.com/article/1
[Worker 2] Fetching: https://example.com/article/2
...
Pipeline finished. Collected 5 pages:
  Result: https://example.com/article/... -> Page Title for ...
```

### Example 2: Exponential Backoff & Retry Logic
Handle transient HTTP timeouts and 503 errors gracefully.

```python
import asyncio

async def resilient_request(url: str, max_retries: int = 3) -> dict:
    attempt = 0
    base_delay = 0.1

    while attempt < max_retries:
        attempt += 1
        try:
            # Simulate transient failure on first 2 attempts
            if attempt < 3:
                raise TimeoutError("Connection reset by peer (simulated)")

            print(f"[Fetch OK] Successfully loaded {url} on attempt {attempt}")
            return {"url": url, "status": 200, "attempts": attempt}

        except (TimeoutError, ConnectionError) as exc:
            if attempt == max_retries:
                print(f"[Fetch FAILED] {url} exceeded {max_retries} attempts.")
                raise exc

            # Exponential backoff formula: delay * 2^(attempt - 1)
            backoff = base_delay * (2 ** (attempt - 1))
            print(f"[Retry Warning] Attempt {attempt} failed: {exc}. Retrying in {backoff:.2f}s...")
            await asyncio.sleep(backoff)

async def test_retry():
    data = await resilient_request("https://api.example.com/stream")
    print(f"Final resolved payload: {data}")

asyncio.run(test_retry())
```

#### Step-by-Step Explanation:
1. Catches transient network errors (`TimeoutError`, `ConnectionError`) without crashing the pipeline.
2. Doubles the backoff sleep duration with each failed attempt, allowing upstream servers time to recover.
3. Successfully returns the payload once the connection stabilizes.

#### Expected Output:
```text
[Retry Warning] Attempt 1 failed: Connection reset by peer (simulated). Retrying in 0.10s...
[Retry Warning] Attempt 2 failed: Connection reset by peer (simulated). Retrying in 0.20s...
[Fetch OK] Successfully loaded https://api.example.com/stream on attempt 3
Final resolved payload: {'url': 'https://api.example.com/stream', 'status': 200, 'attempts': 3}
```

### Example 3: Streaming JSON Lines (JSONL) Data Persistence
Stream processed records to disk one line at a time to prevent high memory consumption.

```python
import json
import tempfile
import os

def stream_records_to_jsonl(records: list[dict], output_filepath: str):
    with open(output_filepath, "w", encoding="utf-8") as f:
        for record in records:
            # Write each JSON record on its own line
            line = json.dumps(record, ensure_ascii=False)
            f.write(line + "\n")

# Verify line-by-line reading
def verify_jsonl(filepath: str):
    loaded = []
    with open(filepath, "r", encoding="utf-8") as f:
        for line in f:
            if line.strip():
                loaded.append(json.loads(line))
    return loaded

test_records = [
    {"doc_id": 101, "url": "https://example.com/1", "tags": ["python", "async"]},
    {"doc_id": 102, "url": "https://example.com/2", "tags": ["database", "sql"]},
]

temp_path = os.path.join(tempfile.gettempdir(), "test_crawler_sink.jsonl")
stream_records_to_jsonl(test_records, temp_path)
read_back = verify_jsonl(temp_path)

print(f"Successfully streamed and verified {len(read_back)} JSONL records from {temp_path}")
print(f"Sample Record: {read_back[0]}")
os.remove(temp_path)
```

#### Step-by-Step Explanation:
1. Standard JSON lists (`[ {...}, {...} ]`) require loading the entire file into memory to parse.
2. JSON Lines (`.jsonl`) writes one independent JSON record per newline, permitting streaming reads across multi-gigabyte datasets.
3. This is the industry standard format for LLM training sets, log archives, and BigQuery imports.

#### Expected Output:
```text
Successfully streamed and verified 2 JSONL records from ...
Sample Record: {'doc_id': 101, 'url': 'https://example.com/1', 'tags': ['python', 'async']}
```

## 4. Key Takeaways & Enterprise Best Practices

1. Always use `asyncio.Semaphore` to cap concurrent outbound connections when writing crawlers or API clients.
2. Implement exponential backoff with jitter to prevent retrying clients from hammering struggling services (the "thundering herd" problem).
3. Use JSON Lines (`.jsonl`) for pipeline outputs so downstream consumers can process records in constant $O(1)$ memory streams.
