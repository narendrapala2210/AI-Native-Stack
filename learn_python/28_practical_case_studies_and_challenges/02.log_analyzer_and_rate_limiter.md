## 1. Project Overview & Production Context

In high-scale web infrastructure, two critical operational tasks occur continuously:
1. **Log Analysis & Telemetry**: Parsing gigabytes of structured and semi-structured HTTP access logs (Nginx, Envoy, Apache) to compute error rates, traffic spikes, and identify anomalous IPs.
2. **Rate Limiting & Traffic Shaping**: Preventing Denial of Service (DoS) and API abuse by enforcing request quotas across client IP addresses using algorithms like the **Token Bucket** or **Sliding Window Counter**.

```
Inbound HTTP Traffic
        |
        V
[ Token Bucket Rate Limiter ]
   |                    |
(Allowed)            (Exceeded Quota)
   |                    |
   V                    V
[ Route Handler ]   [ 429 Too Many Requests ]
   |
   V (Generates Access Log Entry)
"192.168.1.10 - - [14/Sep/2026:12:00:01] 'GET /api/v1/users HTTP/1.1' 200 450"
   |
   V
[ Log Analyzer & Metrics Aggregator ]
   |
   +---> Top IP Request Counts
   +---> 4xx / 5xx Error Anomalies
   +---> Response Latency Percentiles
```

## 2. Core Architecture & Components

| Component | Responsibility |
|---|---|
| `LogRecord` | Dataclass representing a parsed access log entry (IP, timestamp, verb, path, status, bytes) |
| `LogParser` | Regex-powered stream processor that validates and extracts structured entries from raw log lines |
| `MetricsAggregator` | Summarizes top IP request counts, error percentages, and total bandwidth using `collections.Counter` |
| `TokenBucketLimiter` | Implements an in-memory token bucket rate limiter with configurable capacity and refill rate |

### Example 1: High-Performance Access Log Parser with Regex
Parse standard Common Log Format (CLF) text entries into structured dataclass objects.

```python
import re
from dataclasses import dataclass
from typing import Optional

# Standard Nginx access log format pattern:
# IP - - [timestamp] "VERB PATH HTTP/1.1" STATUS BYTES
LOG_REGEX = re.compile(
    r'^(?P<ip>[\d\.]+)\s+-\s+-\s+\[(?P<timestamp>[^\]]+)\]\s+"(?P<verb>[A-Z]+)\s+(?P<path>\S+)\s+[^"]+"\s+(?P<status>\d{3})\s+(?P<bytes>\d+)$'
)

@dataclass
class LogRecord:
    ip: str
    timestamp: str
    verb: str
    path: str
    status: int
    bytes_sent: int

def parse_log_line(line: str) -> Optional[LogRecord]:
    match = LOG_REGEX.match(line.strip())
    if not match:
        return None
    data = match.groupdict()
    return LogRecord(
        ip=data["ip"],
        timestamp=data["timestamp"],
        verb=data["verb"],
        path=data["path"],
        status=int(data["status"]),
        bytes_sent=int(data["bytes"])
    )

sample_logs = [
    '192.168.1.10 - - [14/Sep/2026:12:00:01 +0000] "GET /api/v1/health HTTP/1.1" 200 120',
    '10.0.0.5 - - [14/Sep/2026:12:00:02 +0000] "POST /api/v1/checkout HTTP/1.1" 500 45',
    '192.168.1.10 - - [14/Sep/2026:12:00:03 +0000] "GET /api/v1/users HTTP/1.1" 200 4096',
    'CORRUPT_MALFORMED_LINE_SKIP_ME',
]

parsed_records = [rec for line in sample_logs if (rec := parse_log_line(line)) is not None]
print(f"Successfully parsed {len(parsed_records)} of {len(sample_logs)} lines:")
for r in parsed_records:
    print(f"  [{r.status}] {r.ip} -> {r.verb} {r.path} ({r.bytes_sent} bytes)")
```

#### Step-by-Step Explanation:
1. `LOG_REGEX` uses named capture groups (`(?P<name>...)`) to map log fields into dictionary keys cleanly.
2. Malformed lines are filtered out using Python's walrus operator (`if (rec := parse_log_line(line)) is not None`).
3. Extracted fields are typed into a `LogRecord` dataclass for downstream aggregation.

#### Expected Output:
```text
Successfully parsed 3 of 4 lines:
  [200] 192.168.1.10 -> GET /api/v1/health (120 bytes)
  [500] 10.0.0.5 -> POST /api/v1/checkout (45 bytes)
  [200] 192.168.1.10 -> GET /api/v1/users (4096 bytes)
```

### Example 2: Metric Aggregation Engine with `collections`
Compute top traffic sources, 5xx server error counts, and bandwidth metrics.

```python
from collections import Counter, defaultdict

class MetricsAggregator:
    def __init__(self):
        self.ip_counter = Counter()
        self.status_counter = Counter()
        self.endpoint_counter = Counter()
        self.total_bandwidth = 0

    def ingest(self, record: LogRecord):
        self.ip_counter[record.ip] += 1
        self.status_counter[record.status] += 1
        self.endpoint_counter[record.path] += 1
        self.total_bandwidth += record.bytes_sent

    def generate_report(self) -> dict:
        total_requests = sum(self.ip_counter.values())
        error_requests = sum(count for status, count in self.status_counter.items() if status >= 500)
        error_rate_pct = (error_requests / total_requests * 100) if total_requests else 0.0

        return {
            "total_requests": total_requests,
            "error_rate_pct": round(error_rate_pct, 2),
            "total_bandwidth_kb": round(self.total_bandwidth / 1024, 2),
            "top_ips": self.ip_counter.most_common(2),
            "top_endpoints": self.endpoint_counter.most_common(2),
        }

aggregator = MetricsAggregator()
for rec in parsed_records:
    aggregator.ingest(rec)

report = aggregator.generate_report()
print("Log Analytics Health Report:")
for k, v in report.items():
    print(f"  {k}: {v}")
```

#### Step-by-Step Explanation:
1. `Counter` provides fast $O(1)$ tallying and `.most_common(N)` extraction for top-N ranking.
2. Identifies server errors ($\text{status} \ge 500$) and computes error rates for automated alert triggers.
3. Aggregates data transfer volume across the entire stream.

#### Expected Output:
```text
Log Analytics Health Report:
  total_requests: 3
  error_rate_pct: 33.33
  total_bandwidth_kb: 4.16
  top_ips: [('192.168.1.10', 2), ('10.0.0.5', 1)]
  top_endpoints: [('/api/v1/health', 1), ('/api/v1/checkout', 1)]
```

### Example 3: In-Memory Token Bucket Rate Limiter
Enforce request rate quotas to throttle abusive clients before processing expensive requests.

```python
import time

class TokenBucketLimiter:
    def __init__(self, capacity: int, refill_rate: float):
        """
        :param capacity: Maximum burst token capacity.
        :param refill_rate: Tokens added per second.
        """
        self.capacity = capacity
        self.refill_rate = refill_rate
        # Per-client state: {client_id: (current_tokens, last_refill_timestamp)}
        self._buckets: dict[str, tuple[float, float]] = {}

    def is_allowed(self, client_id: str, cost: int = 1) -> bool:
        now = time.perf_counter()

        if client_id not in self._buckets:
            tokens = float(self.capacity)
            last_check = now
        else:
            tokens, last_check = self._buckets[client_id]
            # Refill tokens based on elapsed time
            elapsed = now - last_check
            tokens = min(float(self.capacity), tokens + elapsed * self.refill_rate)

        # Check if client has sufficient tokens
        if tokens >= cost:
            tokens -= cost
            self._buckets[client_id] = (tokens, now)
            return True
        else:
            self._buckets[client_id] = (tokens, now)
            return False

# Configure limiter: Bucket capacity of 3 requests, refills 1 token per second
limiter = TokenBucketLimiter(capacity=3, refill_rate=1.0)
client_ip = "192.168.1.100"

print(f"Burst Request 1: Allowed = {limiter.is_allowed(client_ip)}")
print(f"Burst Request 2: Allowed = {limiter.is_allowed(client_ip)}")
print(f"Burst Request 3: Allowed = {limiter.is_allowed(client_ip)}")
print(f"Burst Request 4 (Exceeds capacity): Allowed = {limiter.is_allowed(client_ip)}")

# Wait for token refill
print("Waiting 1.1 seconds for bucket to refill 1 token...")
time.sleep(1.1)
print(f"Request 5 (After refill): Allowed = {limiter.is_allowed(client_ip)}")
```

#### Step-by-Step Explanation:
1. The token bucket algorithm allows bursts up to `capacity` while enforcing a sustainable long-term rate (`refill_rate`).
2. Elapsed time (`now - last_check`) calculates fractional token refills dynamically without background worker threads.
3. Exceeding available tokens rejects the request immediately, returning `False` (mapped to HTTP 429).

#### Expected Output:
```text
Burst Request 1: Allowed = True
Burst Request 2: Allowed = True
Burst Request 3: Allowed = True
Burst Request 4 (Exceeds capacity): Allowed = False
Waiting 1.1 seconds for bucket to refill 1 token...
Request 5 (After refill): Allowed = True
```

## 4. Key Takeaways & Production Best Practices

1. Use compiled regular expressions (`re.compile`) when parsing log streams to avoid recompilation overhead across millions of lines.
2. In distributed multi-server architectures, use Redis-backed token buckets (via Redis Lua scripts) instead of in-memory dictionaries so rate limits apply cluster-wide.
3. Pair log metrics aggregation with alerting thresholds (e.g. error rate $\ge 1\%$) to detect service degradations in real time.
