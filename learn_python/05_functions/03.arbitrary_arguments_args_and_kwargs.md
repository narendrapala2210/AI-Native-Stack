# 03. Arbitrary Arguments: `*args` and `**kwargs`

## 📖 Concept Overview
When defining functions where the exact number of input arguments cannot be known in advance, Python provides **arbitrary argument packing**:
1. **`*args` (Arbitrary Positional Arguments)**
2. **`**kwargs` (Arbitrary Keyword Arguments)**

---

### 1. Arbitrary Positional Arguments: `*args`
A parameter preceded by a single asterisk `*` gathers any number of extra positional arguments into an **immutable tuple**:
```python
def calculate_sum(*args):
    print("Type of args:", type(args))  # <class 'tuple'>
    return sum(args)

print(calculate_sum(10, 20, 30))       # 60
print(calculate_sum(1, 2, 3, 4, 5, 6)) # 21
```

---

### 2. Arbitrary Keyword Arguments: `**kwargs`
A parameter preceded by two asterisks `**` gathers any number of extra keyword arguments into a **standard dictionary**:
```python
def print_user_profile(**kwargs):
    print("Type of kwargs:", type(kwargs))  # <class 'dict'>
    for key, value in kwargs.items():
        print(f"  {key}: {value}")

print_user_profile(name="Sarah", role="Engineer", location="Berlin")
```

---

### 3. Combining All Parameter Types
When combining parameter types in a single function definition, they must follow this strict ordering:
```python
def function(positional, *args, default_param="xyz", **kwargs):
    pass
```

---

### 4. Argument Unpacking (`*` and `**`) in Function Calls
In reverse, you can use `*` and `**` during a function **call** to unpack sequences and dictionaries into distinct parameters:
```python
coords = [10, 20, 30]
# Unpacks list elements into 3 separate arguments:
print(*coords)  # 10 20 30

config = {"host": "localhost", "port": 8080}
# Unpacks dict items into keyword arguments:
connect(**config)
```

---

## 📋 Summary & Parameter Ordering Reference

```text
    def func(standard_arg, *args, keyword_only_arg, **kwargs):
             │              │       │                 │
             │              │       │                 └─ Packed dictionary of extra kwargs
             │              │       └─────────────────── Must be passed as key=val
             │              └─────────────────────────── Packed tuple of extra positional args
             └────────────────────────────────────────── Standard positional parameter
```

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Flexible Mathematical Aggregator & Statistical Pipeline
Accept arbitrary numeric streams, optional filter exclusions, and dynamic formatting flags.

```python
def compute_metrics(*values: float, scale_factor: float = 1.0, **metadata) -> dict:
    if not values:
        return {"count": 0, "total": 0.0}
        
    scaled_values = [v * scale_factor for v in values]
    result = {
        "count": len(scaled_values),
        "min": min(scaled_values),
        "max": max(scaled_values),
        "average": round(sum(scaled_values) / len(scaled_values), 2),
        "metadata": metadata
    }
    return result

# Pass any quantity of positional values, plus arbitrary keyword metadata:
report = compute_metrics(
    12.5, 45.0, 33.2, 88.9, 10.0,
    scale_factor=1.1,
    sensor_id="IOT-99",
    location="Warehouse B",
    operator="Alice"
)

print("Metrics Report:")
for k, v in report.items():
    print(f"  {k:<10}: {v}")
```

**Step-by-Step Explanation**:
1. `*values` gathers five numeric arguments into a tuple.
2. `scale_factor` is passed as a keyword parameter.
3. `**metadata` captures `sensor_id`, `location`, and `operator` into a dictionary.

**Expected Console Output**:
```text
Metrics Report:
  count     : 5
  min       : 11.0
  max       : 97.79000000000002
  average   : 41.71
  metadata  : {'sensor_id': 'IOT-99', 'location': 'Warehouse B', 'operator': 'Alice'}
```

### Example 2: Universal Logging Decorator / Proxy Wrapper
Build a logging decorator that intercepts and transparently forwards arbitrary arguments to any underlying function.

```python
import time

def audit_log(func):
    def wrapper(*args, **kwargs):
        print(f"\n[AUDIT] Invoking function '{func.__name__}'...")
        print(f"  Positional Args Received: {args}")
        print(f"  Keyword Args Received   : {kwargs}")
        
        start_time = time.perf_counter()
        # Transparently forward all packed arguments
        result = func(*args, **kwargs)
        duration_ms = (time.perf_counter() - start_time) * 1000
        
        print(f"[AUDIT] '{func.__name__}' finished in {duration_ms:.4f} ms -> Result: {result}")
        return result
    return wrapper

@audit_log
def transfer_funds(source_acc: str, target_acc: str, amount: float, currency: str = "USD") -> str:
    return f"Transferred {amount:.2f} {currency} from {source_acc} to {target_acc}"

transfer_funds("ACC-101", "ACC-202", 500.0, currency="EUR")
```

**Step-by-Step Explanation**:
1. `def wrapper(*args, **kwargs)` accepts any signature whatever.
2. `func(*args, **kwargs)` unpacks them dynamically to the wrapped target function.
3. This is the foundational pattern behind all Python decorators and middleware.

**Expected Console Output**:
```text
[AUDIT] Invoking function 'transfer_funds'...
  Positional Args Received: ('ACC-101', 'ACC-202', 500.0)
  Keyword Args Received   : {'currency': 'EUR'}
[AUDIT] 'transfer_funds' finished in 0.0450 ms -> Result: Transferred 500.00 EUR from ACC-101 to ACC-202
```

### Example 3: Dictionary & List Unpacking for Dynamic Database Insertions
Simulate an ORM database query builder where table rows are dynamically constructed via sequence and dictionary unpacking.

```python
def mock_db_insert(table_name: str, **column_values):
    columns = list(column_values.keys())
    values = list(column_values.values())
    
    col_str = ", ".join(columns)
    placeholders = ", ".join(["%s"] * len(values))
    
    sql = f"INSERT INTO {table_name} ({col_str}) VALUES ({placeholders});"
    print("Generated SQL Query:")
    print(f"  {sql}")
    print(f"  Binding Parameters: {values}")

user_payload = {
    "username": "alex_dev",
    "email": "alex@cloud.io",
    "role": "Software Engineer",
    "active": True
}

# Unpack dictionary keys and values directly into mock_db_insert kwargs!
mock_db_insert("users", **user_payload)
```

**Step-by-Step Explanation**:
1. `**user_payload` unpacks dictionary keys and values into keyword arguments.
2. Demonstrates database layer abstraction common in frameworks like Django and SQLAlchemy.

**Expected Console Output**:
```text
Generated SQL Query:
  INSERT INTO users (username, email, role, active) VALUES (%s, %s, %s, %s);
  Binding Parameters: ['alex_dev', 'alex@cloud.io', 'Software Engineer', True]
```
