## 📖 Concept Overview
Python supports functional programming paradigms: treating functions as **first-class citizens** that can be passed as arguments, returned from other functions, and defined anonymously.

---

### 1. Anonymous Functions (`lambda`)
A **`lambda`** function is a small, inline anonymous function restricted to a **single expression**:
```python
lambda arguments: expression
```
```python
# Traditional
def square(x):
    return x ** 2

# Equivalent Lambda
square_lambda = lambda x: x ** 2
print(square_lambda(5))  # 25
```

---

### 2. The `map()` Function
Applies a transformation function to all items in an iterable:
```python
map(function, iterable)
```
```python
nums = [1, 2, 3, 4]
doubled = list(map(lambda x: x * 2, nums))  # [2, 4, 6, 8]
```

---

### 3. The `filter()` Function
Constructs an iterator from elements of an iterable for which a predicate function returns `True`:
```python
filter(function, iterable)
```
```python
nums = [1, 2, 3, 4, 5, 6]
evens = list(filter(lambda x: x % 2 == 0, nums))  # [2, 4, 6]
```

---

### 4. The `functools.reduce()` Function
Successively applies a binary function to elements, reducing the entire sequence to a **single cumulative scalar value**:
```python
from functools import reduce
nums = [1, 2, 3, 4]
product = reduce(lambda acc, x: acc * x, nums)  # 1 * 2 * 3 * 4 = 24
```

---

## 📋 Summary & Functional Operations Reference

| Tool | Purpose | Sample Usage | Output |
| :--- | :--- | :--- | :--- |
| `lambda x, y: ...` | Single-line anonymous function | `(lambda x: x + 1)(10)` | `11` |
| `map(f, iter)` | Transforms every element | `list(map(str, [1, 2]))` | `['1', '2']` |
| `filter(f, iter)` | Selects matching elements | `list(filter(lambda x: x > 0, [-1, 2]))` | `[2]` |
| `reduce(f, iter)` | Aggregates to single value | `reduce(lambda a, b: a + b, [1, 2, 3])` | `6` |

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Custom In-Line Sorting with Lambda Keys
Sort complex dictionary records by multiple custom criteria (e.g., sort by department ascending, then salary descending).

```python
employees = [
    {"name": "Alice",   "dept": "Engineering", "salary": 95000},
    {"name": "Bob",     "dept": "Sales",       "salary": 65000},
    {"name": "Charlie", "dept": "Engineering", "salary": 115000},
    {"name": "Diana",   "dept": "Sales",       "salary": 80000},
    {"name": "Evan",    "dept": "HR",          "salary": 60000},
]

# Sort by department, then by negative salary (-x['salary']) for descending order!
sorted_staff = sorted(employees, key=lambda x: (x["dept"], -x["salary"]))

print(f"{'Name':<10} {'Department':<14} {'Salary':>8}")
print("-" * 35)
for emp in sorted_staff:
    print(f"{emp['name']:<10} {emp['dept']:<14} ${emp['salary']:>7,}")
```

#### Step-by-Step Explanation:
1. `key=lambda x: (x["dept"], -x["salary"])` creates a composite sorting tuple.
2. In-line lambda avoids creating a named helper function.

#### Expected Output:
```text
Name       Department       Salary
-----------------------------------
Charlie    Engineering   $115,000
Alice      Engineering   $ 95,000
Evan       HR            $ 60,000
Diana      Sales         $ 80,000
Bob        Sales         $ 65,000
```

### Example 2: ETL Pipeline using `map()`, `filter()` and `reduce()`
Process raw telemetry data: filter out invalid sensors, map temperature from Celsius to Fahrenheit, and compute cumulative energy consumption.

```python
from functools import reduce

def process_telemetry_pipeline(sensor_records: list[dict]):
    # 1. Filter: Keep only verified active sensors with non-negative readings
    valid_sensors = filter(lambda s: s["is_active"] and s["temp_c"] >= 0.0, sensor_records)
    
    # 2. Map: Transform records adding temperature in Fahrenheit: (C * 9/5) + 32
    transformed = list(map(
        lambda s: {
            "id": s["id"],
            "temp_f": round((s["temp_c"] * 9/5) + 32, 1),
            "kwh": s["kwh"]
        },
        valid_sensors
    ))
    
    # 3. Reduce: Sum total electricity consumption across all filtered nodes
    total_power = reduce(lambda acc, item: acc + item["kwh"], transformed, 0.0)
    
    print(f"Total Valid Nodes Processed: {len(transformed)}")
    for node in transformed:
        print(f"  Node {node['id']}: {node['temp_f']}°F ({node['kwh']} kWh)")
    print(f"Total Cumulative Grid Draw : {total_power:.2f} kWh")

raw_nodes = [
    {"id": "S1", "is_active": True,  "temp_c": 20.0, "kwh": 4.5},
    {"id": "S2", "is_active": False, "temp_c": 22.0, "kwh": 8.0},  # Inactive
    {"id": "S3", "is_active": True,  "temp_c": -99.0, "kwh": 0.0}, # Corrupt
    {"id": "S4", "is_active": True,  "temp_c": 25.0, "kwh": 6.2},
]

process_telemetry_pipeline(raw_nodes)
```

#### Step-by-Step Explanation:
1. `filter()` drops inactive and corrupt nodes.
2. `map()` standardizes units to Fahrenheit.
3. `reduce()` computes cumulative power consumption.

#### Expected Output:
```text
Total Valid Nodes Processed: 2
  Node S1: 68.0°F (4.5 kWh)
  Node S4: 77.0°F (6.2 kWh)
Total Cumulative Grid Draw : 10.70 kWh
```

### Example 3: Higher-Order Function Combinator (Function Factory)
Create a function multiplier generator using higher-order functions and lambdas.

```python
def make_multiplier(factor: float):
    # Returns a lambda function parameterized by factor!
    return lambda x: x * factor

double = make_multiplier(2)
triple = make_multiplier(3)
ten_x  = make_multiplier(10)

val = 15
print(f"Original: {val}")
print(f"Double  : {double(val)}")
print(f"Triple  : {triple(val)}")
print(f"Ten-Fold: {ten_x(val)}")
```

#### Step-by-Step Explanation:
1. `make_multiplier` returns an anonymous lambda closing over `factor`.
2. Demonstrates generator factories for flexible functional programming.

#### Expected Output:
```text
Original: 15
Double  : 30
Triple  : 45
Ten-Fold: 150
```
