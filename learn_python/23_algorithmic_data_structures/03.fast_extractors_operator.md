## 1. Conceptual Deep-Dive: C-Speed Functional Primitives

When sorting, grouping, or mapping large collections, developers commonly write anonymous lambda functions:
```python
sorted(records, key=lambda r: r.price)
```
Every invocation of `lambda r: r.price` requires allocating a Python function call frame and running bytecode dispatch.

The `operator` module provides native C-level function equivalents for all Python operators and attribute/item lookups:
- **`itemgetter(k)`**: Resolves `obj[k]`.
- **`attrgetter(attr)`**: Resolves `obj.attr` (supports dotted paths like `attrgetter("profile.email")`).
- **`methodcaller(name, *args)`**: Calls `obj.name(*args)`.
- **Mathematical / Logical operators**: `add`, `mul`, `xor`, `contains`, etc.

```
lambda r: r.price:
Python Bytecode -> LOAD_FAST -> LOAD_ATTR -> RETURN_VALUE (Python Frame Overhead)

operator.attrgetter("price"):
Direct C PyObject_GetAttr (Zero Python Frame Overhead)
```

---

## 2. Speed & Feature Comparison

| Function | Equivalent Lambda | Key Feature |
|---|---|---|
| `operator.itemgetter(1)` | `lambda x: x[1]` | Fast dictionary/tuple element extraction |
| `operator.itemgetter("a", "b")` | `lambda x: (x["a"], x["b"])` | Multi-key extraction in a single call |
| `operator.attrgetter("name")` | `lambda x: x.name` | Direct attribute access in C |
| `operator.attrgetter("a.b.c")` | `lambda x: x.a.b.c` | Deep dotted path navigation |
| `operator.methodcaller("strip")` | `lambda x: x.strip()` | Invokes method across an iterable of items |

## 3. Practical Code Examples with Step-by-Step Explanations

### Example 1: Multi-Key Sorting with `itemgetter`
Sort a collection of dictionary records by department, then descending salary.

```python
from operator import itemgetter

employees = [
    {"name": "Alice", "dept": "Engineering", "salary": 120_000},
    {"name": "Bob", "dept": "HR", "salary": 85_000},
    {"name": "Charlie", "dept": "Engineering", "salary": 140_000},
    {"name": "Diana", "dept": "Marketing", "salary": 95_000},
    {"name": "Eve", "dept": "Engineering", "salary": 110_000},
]

# Sort by department alphabetically, then by salary ascending
employees_sorted = sorted(employees, key=itemgetter("dept", "salary"))

print("Employees sorted by dept, then salary:")
for emp in employees_sorted:
    print(f"  {emp['dept']:12} | ${emp['salary']:7,d} | {emp['name']}")
```

#### Step-by-Step Explanation:
1. `itemgetter("dept", "salary")` extracts a two-element tuple `(emp["dept"], emp["salary"])`.
2. Python orders tuples element by element.
3. The extraction runs at compiled C speed, outperforming comparable lambda functions over large datasets.

#### Expected Output:
```text
Employees sorted by dept, then salary:
  Engineering  | $110,000 | Eve
  Engineering  | $120,000 | Alice
  Engineering  | $140,000 | Charlie
  HR           | $ 85,000 | Bob
  Marketing    | $ 95,000 | Diana
```

### Example 2: Deep Dotted Attribute Access with `attrgetter`
Access nested attributes through object hierarchies in a single operation.

```python
from operator import attrgetter

class Address:
    def __init__(self, city: str):
        self.city = city

class Company:
    def __init__(self, address: Address):
        self.address = address

class Employee:
    def __init__(self, name: str, company: Company):
        self.name = name
        self.company = company

staff = [
    Employee("Liam", Company(Address("Tokyo"))),
    Employee("Emma", Company(Address("London"))),
    Employee("Noah", Company(Address("Berlin"))),
]

# Deep dotted path navigation: employee.company.address.city
get_city = attrgetter("company.address.city")
staff_sorted = sorted(staff, key=get_city)

print("Staff sorted by nested company city:")
for s in staff_sorted:
    print(f"  {s.name:5} -> {get_city(s)}")
```

#### Step-by-Step Explanation:
1. `attrgetter("company.address.city")` traverses the object hierarchy using dots.
2. It eliminates verbose nested lambda chains (`lambda e: e.company.address.city`).

#### Expected Output:
```text
Staff sorted by nested company city:
  Noah  -> Berlin
  Emma  -> London
  Liam  -> Tokyo
```

### Example 3: Batch Method Invocation with `methodcaller`
Invoke methods across collections of objects cleanly.

```python
from operator import methodcaller

raw_strings = ["  alpha \n", "\tbeta ", "  gamma\r\n", "DELTA  "]

# Clean all whitespace using methodcaller
cleaner = methodcaller("strip")
cleaned = list(map(cleaner, raw_strings))
print(f"Cleaned strings: {cleaned}")

# methodcaller with arguments
replacer = methodcaller("replace", " ", "_")
slugs = list(map(replacer, ["hello world", "foo bar baz"]))
print(f"Slugified:       {slugs}")
```

#### Step-by-Step Explanation:
1. `methodcaller("strip")` generates a reusable callable that invokes `.strip()` on any passed object.
2. Extra arguments (`methodcaller("replace", " ", "_")`) are forwarded to each method invocation.

#### Expected Output:
```text
Cleaned strings: ['alpha', 'beta', 'gamma', 'DELTA']
Slugified:       ['hello_world', 'foo_bar_baz']
```

---

## 4. Key Takeaways & Best Practices

1. Replace `key=lambda x: x.attr` with `key=operator.attrgetter("attr")` in performance-sensitive code.
2. Use `itemgetter` with multiple keys to create compound sorting tuples concisely.
3. Combine `operator.methodcaller` with `map()` for clean functional pipelines.
