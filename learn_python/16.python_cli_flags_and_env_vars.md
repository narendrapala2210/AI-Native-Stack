# 16. Python CLI Flags, Runtime Options & Environment Variables

### 16.1 Essential Python Command-Line Flags (-m, -c, -O, -X dev, -u)

Understanding Python CLI options allows fine-tuning runtime performance, debugging, and container behavior:

| Flag | Purpose | Example |
| :--- | :--- | :--- |
| `-m <mod>` | Runs a library module as a script (sets up `sys.path` correctly). | `python -m venv .venv`, `python -m http.server 8000` |
| `-c <cmd>` | Executes a Python command string directly from the terminal. | `python -c "import sys; print(sys.version)"` |
| `-O` | **Optimization**: Strips `assert` statements and ignores `if __debug__:` blocks. | `python -O production_service.py` |
| `-i` | **Inspect**: Runs the script and then drops into the interactive REPL with script variables loaded. | `python -i train_model.py` |
| `-u` | **Unbuffered**: Forces `stdout` and `stderr` to be unbuffered (prevents logs being delayed in Docker/Kubernetes). | `python -u worker.py` |
| `-W <action>` | Sets warning filter (`ignore`, `always`, `error`, `default`). | `python -W error script.py` |
| `-X dev` | **Python Development Mode**: Enables extra runtime checks, validates encoding, tracks memory allocators. | `python -X dev test_suite.py` |

### 16.2 Critical Python Environment Variables (PYTHONPATH, PYTHONUNBUFFERED)

Environment variables configure CPython's startup behavior without modifying source code:

- `PYTHONPATH`: Colon-separated (or semicolon on Windows) directories prepended to `sys.path` for module search.
- `PYTHONUNBUFFERED=1`: Equivalent to passing `-u`. **Essential best practice for all Docker containers**.
- `PYTHONDONTWRITEBYTECODE=1`: Prevents Python from writing `.pyc` files or `__pycache__` directories to disk.
- `PYTHONDEVMODE=1`: Equivalent to `-X dev`.
- `PYTHONIOENCODING=utf-8`: Forces standard I/O encoding to UTF-8 regardless of OS defaults.

```powershell
# PowerShell examples
$env:PYTHONPATH = "src;libs"
$env:PYTHONUNBUFFERED = "1"
python main.py
```

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Multi-Environment App Configuration Loader (Dev/Staging/Prod)
Configure runtime behavior dynamically based on system environment variables.

```python
import os

class EnvironmentConfig:
    def __init__(self):
        self.env = os.getenv("APP_ENV", "development").lower()
        self.debug = os.getenv("DEBUG", "true").lower() in ("1", "true", "yes")
        self.port = int(os.getenv("PORT", "8000"))

    def print_config(self):
        print(f"Loaded Environment: {self.env.upper()}")
        print(f"Debug Mode:        {self.debug}")
        print(f"Listening Port:    {self.port}")

# Test with temporary env var override
os.environ["APP_ENV"] = "production"
os.environ["DEBUG"] = "false"
os.environ["PORT"] = "443"

config = EnvironmentConfig()
config.print_config()
```

### Example 2: Runtime Optimization & Assertions Checker (`-O` Flag)
Demonstrate how assertions and `__debug__` blocks are stripped when running with `-O`.

```python
# Run this script with:
#   python script.py       -> Debug mode active, assertions enforced
#   python -O script.py    -> Optimized mode, assertions stripped!

def process_secure_transaction(amount: float):
    # This assert is completely stripped out when -O is passed!
    assert amount > 0, "Amount must be strictly positive!"
    return f"Processed: ${amount:.2f}"

print("Is Python running in debug mode?", __debug__)
try:
    print(process_secure_transaction(50.0))
except AssertionError as ae:
    print("[ASSERTION FAILED]", ae)
```

### Example 3: Unbuffered Output Demonstration (Simulating `-u` Flag)
Demonstrate line flushing behavior for container logging systems.

```python
import sys
import time

def stream_logs(unbuffered: bool = False):
    print(f"Streaming logs (Unbuffered={unbuffered}):")
    for i in range(3):
        # With flush=True or -u flag, output appears immediately in Docker / Kubernetes logs
        print(f"Heartbeat #{i}", end=" ", flush=unbuffered)
        time.sleep(0.02)
    print("\nDone.")

stream_logs(unbuffered=True)
```
