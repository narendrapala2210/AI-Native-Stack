## 📖 Concept Overview
Effective input/output (I/O) communication is the backbone of user interaction. Python provides built-in mechanisms for printing formatted data to standard output (`stdout`) and receiving strings from standard input (`stdin`).

### The `print()` Function Internals
The `print()` function accepts variable arguments and customizable keyword options:
```python
print(*objects, sep=' ', end='\n', file=None, flush=False)
```
- **`*objects`**: Zero or more expressions to print, separated by commas.
- **`sep`**: Delimiter string placed between objects (defaults to a single space `' '`).
- **`end`**: Suffix string appended after the final object (defaults to a newline `'\n'`).
- **`file`**: Target output stream (defaults to `sys.stdout`).
- **`flush`**: Boolean forcing immediate flush of the output buffer without waiting for newline.

```python
# Custom separator and end character
print("2026", "09", "14", sep="-")           # 2026-09-14
print("Loading", end="...")
print("Done!")                               # Loading...Done!
```

### The `input()` Function
The `input()` function pauses program execution and waits for user input from the console:
```python
user_name = input("Enter your name: ")
print("Hello,", user_name)
```
> [!IMPORTANT]
> **`input()` ALWAYS returns a string (`str`)**, even if the user enters digits! To treat input as an integer or float, you must explicitly type-cast it:
> ```python
> age = int(input("Enter age: "))
> ```

### Comments in Python
Comments document code rationale and are ignored by the Python interpreter:
1. **Single-Line Comments**: Begin with a hash `#`.
   ```python
   # Calculate gross revenue with 18% GST
   gross = net * 1.18
   ```
2. **Inline Comments**: Placed on the same line after executable code.
   ```python
   total_score += bonus  # Add seasonal performance bonus
   ```
3. **Multi-line Docstrings**: Triple-quoted strings (`"""..."""`) attached to modules, classes, and functions to document API contracts.

### Common Syntax & Name Errors
- **`SyntaxError`**: Occurs when code violates Python grammar rules (e.g., mismatched quotes, unclosed parentheses).
- **`NameError`**: Occurs when referencing a variable name that has not yet been defined or assigned.

## 📋 Summary & Reference

| Parameter / Feature | Syntax | Behavior / Purpose |
| :--- | :--- | :--- |
| **Separator (`sep`)** | `print(a, b, sep="|")` | Replaces default space delimiter between items with custom string. |
| **Terminator (`end`)** | `print(a, end="")` | Suppresses newline; subsequent prints continue on the same console line. |
| **Buffer Flush (`flush`)** | `print(..., flush=True)` | Forces console buffer to write immediately to screen (essential for progress bars). |
| **Standard Input** | `data = input(prompt)` | Displays prompt, halts execution until Enter is pressed, returns text as `str`. |
| **Single-line Comment** | `# Text` | Human-readable note; completely ignored by the bytecode compiler. |

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Real-Time Terminal Progress Bar with `flush=True`
Build an interactive console progress indicator that updates in-place on a single line without emitting newlines.

```python
import time
import sys

def simulate_file_upload(total_chunks: int = 10):
    print("Initiating secure upload to cloud repository...")
    for chunk in range(1, total_chunks + 1):
        percent = (chunk / total_chunks) * 100
        bar = "█" * chunk + "-" * (total_chunks - chunk)
        # Use 
 (carriage return) to reset cursor to line start, and flush buffer
        print(f"
Upload Progress: |{bar}| {percent:5.1f}% Complete", end="", flush=True)
        time.sleep(0.08)  # Simulate network latency
    print("
[SUCCESS] File upload finalized and integrity checksum verified!")

simulate_file_upload()
```

#### Step-by-Step Explanation:
1. `
` (carriage return) repositions the console cursor back to the start of the current line.
2. `end=""` suppresses the default newline, preventing each progress update from filling the terminal window.
3. `flush=True` forces the C-level I/O buffer to flush immediately so the user sees smooth animation.

#### Expected Output:
```text
Initiating secure upload to cloud repository...
Upload Progress: |██████████| 100.0% Complete
[SUCCESS] File upload finalized and integrity checksum verified!
```

### Example 2: Formatted Invoice Summary Generator
Demonstrate custom separators, aligned fields, and structured reporting using `print()` parameters.

```python
def print_invoice(customer_name: str, items: list[tuple[str, int, float]]):
    divider = "=" * 45
    print(divider)
    print(f"TAX INVOICE - CUSTOMER: {customer_name.upper()}")
    print(divider)
    # Header
    print(f"{'Item Description':<20} {'Qty':>5} {'Unit ($)':>8} {'Total ($)':>8}")
    print("-" * 45)
    
    grand_total = 0.0
    for name, qty, price in items:
        line_total = qty * price
        grand_total += line_total
        print(f"{name:<20} {qty:>5} {price:>8.2f} {line_total:>8.2f}")
        
    print("-" * 45)
    print(f"{'GRAND TOTAL:':<35} ${grand_total:>7.2f}")
    print(divider)

sample_items = [
    ("Wireless Mouse", 2, 24.99),
    ("Mechanical Keyboard", 1, 89.50),
    ("USB-C Cable (2m)", 3, 9.99)
]

print_invoice("TechCorp Ltd", sample_items)
```

#### Step-by-Step Explanation:
1. Formats text with alignment specifiers: `<20` (left-aligned 20 chars), `>5` (right-aligned 5 chars), `>8.2f` (right-aligned float with 2 decimal places).
2. Calculates cumulative line totals and outputs a structured financial receipt.

#### Expected Output:
```text
=============================================
TAX INVOICE - CUSTOMER: TECHCORP LTD
=============================================
Item Description       Qty Unit ($) Total ($)
---------------------------------------------
Wireless Mouse           2    24.99    49.98
Mechanical Keyboard      1    89.50    89.50
USB-C Cable (2m)         3     9.99    29.97
---------------------------------------------
GRAND TOTAL:                        $ 169.45
=============================================
```

### Example 3: Defensive Console User Input Parser with Error Traps
Create a user prompt that safely reads and validates numeric user input, catching potential input errors gracefully.

```python
def mock_user_input_flow(simulated_inputs: list[str]):
    print("=== Registration Portal Validation Simulation ===")
    
    for raw_input in simulated_inputs:
        print(f"
Simulated User Entered: '{raw_input}'")
        try:
            # Attempt to convert raw string input to integer
            age = int(raw_input)
            
            if age < 0 or age > 120:
                print("[VALIDATION FAILED] Age must be between 0 and 120.")
            else:
                print(f"[VALIDATION SUCCESS] User age recorded as {age} years.")
                
        except ValueError:
            print(f"[CRITICAL ERROR] Cannot cast '{raw_input}' to an integer! Please input numbers only.")

mock_user_input_flow(["28", "abc", "-5", "42.5", "105"])
```

#### Step-by-Step Explanation:
1. When receiving console inputs, invalid strings like `"abc"` or floating literals `"42.5"` raise `ValueError` when passed directly to `int()`.
2. The `try...except ValueError` construct shields the application from crashing and returns informative guidance to the user.

#### Expected Output:
```text
=== Registration Portal Validation Simulation ===

Simulated User Entered: '28'
[VALIDATION SUCCESS] User age recorded as 28 years.

Simulated User Entered: 'abc'
[CRITICAL ERROR] Cannot cast 'abc' to an integer! Please input numbers only.

Simulated User Entered: '-5'
[VALIDATION FAILED] Age must be between 0 and 120.

Simulated User Entered: '42.5'
[CRITICAL ERROR] Cannot cast '42.5' to an integer! Please input numbers only.

Simulated User Entered: '105'
[VALIDATION SUCCESS] User age recorded as 105 years.
```
