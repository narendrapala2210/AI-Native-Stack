# 04. Static Methods & Utility Helpers (`@staticmethod`)

## 📖 Concept Overview
A **Static Method (`@staticmethod`)** is a function bound to a class that **does not receive an implicit first argument**—neither `self` nor `cls`.

### 1. When to Use Static Methods
Use static methods for **pure utility or helper functions** that have logical belonging within a class namespace, but do not read or modify instance state (`self`) or class state (`cls`).

```python
class MathUtils:
    @staticmethod
    def is_even(number):
        return number % 2 == 0

# Called on the class without instantiation:
print(MathUtils.is_even(42))  # True
```

---

## 📋 Comprehensive Methods Comparison Table

| Method Type | Decorator | First Parameter | Access To | Can Be Called By |
| :--- | :--- | :--- | :--- | :--- |
| **Instance Method** | None | `self` | Instance attributes & class attributes | Instance (`obj.method()`) |
| **Class Method** | `@classmethod` | `cls` | Class attributes only | Class (`Cls.method()`) or Instance |
| **Static Method** | `@staticmethod` | None | Self-contained parameters only | Class (`Cls.method()`) or Instance |

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Security Token & Password Sanitizer Utility
Group encryption and password strength evaluation utilities under an `AuthenticationManager` class using `@staticmethod`.

```python
import re

class AuthenticationManager:
    @staticmethod
    def validate_password_strength(password: str) -> tuple[bool, str]:
        if len(password) < 8:
            return False, "Password must be at least 8 characters long."
        if not re.search(r"[A-Z]", password):
            return False, "Password must contain at least one uppercase letter."
        if not re.search(r"[0-9]", password):
            return False, "Password must contain at least one digit."
        return True, "Strong password."

    @staticmethod
    def sanitize_username(raw_username: str) -> str:
        # Strip whitespace, lowercase, allow alphanumeric and underscore only
        clean = raw_username.strip().lower()
        return "".join(ch for ch in clean if ch.isalnum() or ch == "_")

# Direct invocation without needing to instantiate AuthenticationManager:
valid, msg = AuthenticationManager.validate_password_strength("Secret123")
print("Password check:", valid, f"({msg})")

clean_name = AuthenticationManager.sanitize_username("  Developer_99!@#  ")
print("Sanitized Username:", clean_name)
```

**Step-by-Step Explanation**:
1. Static methods do not require instantiating `AuthenticationManager()`.
2. Packages utility logic in a logical domain class namespace.

**Expected Console Output**:
```text
Password check: True (Strong password.)
Sanitized Username: developer_99
```

### Example 2: Financial Currency Formatter & Tax Calculators
Group tax calculation formulas under a financial accounting class.

```python
class TaxAccounting:
    @staticmethod
    def compute_sales_tax(subtotal: float, tax_rate_pct: float) -> float:
        return round(subtotal * (tax_rate_pct / 100.0), 2)

    @staticmethod
    def format_currency_usd(amount: float) -> str:
        return f"${amount:,.2f}"

subtotal = 1250.00
tax = TaxAccounting.compute_sales_tax(subtotal, 8.25)
total = subtotal + tax

print(f"Subtotal: {TaxAccounting.format_currency_usd(subtotal)}")
print(f"Tax     : {TaxAccounting.format_currency_usd(tax)}")
print(f"Total   : {TaxAccounting.format_currency_usd(total)}")
```

**Step-by-Step Explanation**:
1. Mathematical calculations take inputs and return outputs with zero side effects.
2. Eliminates unneeded object instantiation overhead.

**Expected Console Output**:
```text
Subtotal: $1,250.00
Tax     : $103.13
Total   : $1,353.13
```

### Example 3: Coordinate Conversion & Distance Utility
Convert geographic coordinates between degrees, minutes, seconds (DMS) and decimal degrees.

```python
class GeoMath:
    @staticmethod
    def dms_to_decimal(degrees: int, minutes: int, seconds: float) -> float:
        return round(degrees + (minutes / 60.0) + (seconds / 3600.0), 6)

    @staticmethod
    def decimal_to_dms(decimal: float) -> tuple[int, int, float]:
        deg = int(decimal)
        min_float = (decimal - deg) * 60
        minutes = int(min_float)
        sec = (min_float - minutes) * 60
        return deg, minutes, round(sec, 2)

dec_lat = GeoMath.dms_to_decimal(37, 46, 29.7)
print(f"DMS 37° 46' 29.7\" -> Decimal: {dec_lat}")

d, m, s = GeoMath.decimal_to_dms(dec_lat)
print(f"Decimal {dec_lat} -> DMS: {d}° {m}' {s}\"")
```

**Step-by-Step Explanation**:
1. Pure calculation utilities grouped logically inside `GeoMath`.
2. Neither `self` nor `cls` is needed.

**Expected Console Output**:
```text
DMS 37° 46' 29.7" -> Decimal: 37.774917
Decimal 37.774917 -> DMS: 37° 46' 29.7"
```
