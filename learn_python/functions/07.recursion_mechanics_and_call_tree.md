# 07. Recursion Mechanics & Call Trees

## 📖 Concept Overview
**Recursion** is a programming technique where a function solves a problem by calling itself with a smaller sub-problem.

### 1. The Two Fundamental Rules of Recursion
Every recursive function must define:
1. **The Base Case**: A terminating condition that returns a direct result without making further recursive calls.
2. **The Recursive Step (Reduction)**: A call to itself with arguments that strictly progress towards the base case.

> [!WARNING]
> If a recursive function lacks a base case or fails to reduce inputs toward it, it results in infinite recursion, triggering:
> `RecursionError: maximum recursion depth exceeded`

---

### 2. The Recursion Call Tree (Factorial Example)
Calculating $4! = 4 \times 3 \times 2 \times 1$:
```text
  factorial(4)
    ├── 4 * factorial(3)
    │         ├── 3 * factorial(2)
    │         │         ├── 2 * factorial(1)
    │         │         │         └── Base Case: returns 1
    │         │         └── returns 2 * 1 = 2
    │         └── returns 3 * 2 = 6
    └── returns 4 * 6 = 24
```

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Recursive Factorial and Fibonacci with Call Tracing
Implement classic factorial and Fibonacci algorithms with visual call stack indentations.

```python
def trace_factorial(n: int, depth: int = 0) -> int:
    indent = "  " * depth
    print(f"{indent}--> factorial({n}) called")
    
    # 1. Base Case
    if n <= 1:
        print(f"{indent}<-- Base Case reached! Returning 1")
        return 1
        
    # 2. Recursive Step
    result = n * trace_factorial(n - 1, depth + 1)
    print(f"{indent}<-- factorial({n}) returning {result}")
    return result

print("=== Computing 4! Recursively ===")
ans = trace_factorial(4)
print(f"Final Result: 4! = {ans}")
```

**Step-by-Step Explanation**:
1. Base case `n <= 1` stops further recursion.
2. Indentation visually illustrates frame allocation and stack unwinding.

**Expected Console Output**:
```text
=== Computing 4! Recursively ===
--> factorial(4) called
  --> factorial(3) called
    --> factorial(2) called
      --> factorial(1) called
      <-- Base Case reached! Returning 1
    <-- factorial(2) returning 2
  <-- factorial(3) returning 6
<-- factorial(4) returning 24
Final Result: 4! = 24
```

### Example 2: Recursive File System Directory Tree Walker
Traverse a nested folder hierarchy containing subdirectories and calculate total aggregate disk size.

```python
def calculate_tree_size(node: dict, indent_level: int = 0) -> int:
    name = node["name"]
    is_dir = node.get("is_dir", False)
    indent = "  " * indent_level
    
    # Base Case: Leaf file node
    if not is_dir:
        size = node.get("size_kb", 0)
        print(f"{indent}📄 {name} ({size} KB)")
        return size
        
    # Recursive Case: Directory containing children
    print(f"{indent}📁 {name}/")
    total_dir_size = 0
    for child in node.get("children", []):
        total_dir_size += calculate_tree_size(child, indent_level + 1)
        
    print(f"{indent}==> Total {name}/ size: {total_dir_size} KB")
    return total_dir_size

file_system = {
    "name": "root",
    "is_dir": True,
    "children": [
        {"name": "index.html", "is_dir": False, "size_kb": 12},
        {
            "name": "assets",
            "is_dir": True,
            "children": [
                {"name": "style.css", "is_dir": False, "size_kb": 25},
                {"name": "logo.png", "is_dir": False, "size_kb": 120}
            ]
        }
    ]
}

total_kb = calculate_tree_size(file_system)
print(f"\nFinal Aggregate Tree Size: {total_kb} KB")
```

**Step-by-Step Explanation**:
1. Files act as the base case returning direct sizes.
2. Directories loop over child elements, recursively calling `calculate_tree_size`.

**Expected Console Output**:
```text
📁 root/
  📄 index.html (12 KB)
  📁 assets/
    📄 style.css (25 KB)
    📄 logo.png (120 KB)
  ==> Total assets/ size: 145 KB
==> Total root/ size: 157 KB

Final Aggregate Tree Size: 157 KB
```

### Example 3: Tail Recursion & Recursion Limits Defense
Demonstrate catching `RecursionError` and restructuring runaway algorithms.

```python
import sys

def recursive_countdown(n: int):
    # Missing base case will crash!
    # Guarded countdown:
    if n <= 0:
        print("Liftoff! 🚀")
        return
    if n % 100 == 0:
        print(f"T-minus {n}...")
    recursive_countdown(n - 1)

try:
    recursive_countdown(300)
except RecursionError as err:
    print(f"Recursion Aborted: {err}")
```

**Step-by-Step Explanation**:
1. Countdown demonstrates clean base case termination at `n <= 0`.
2. Explains the risk of hitting `sys.getrecursionlimit()` if inputs exceed 1,000 steps.

**Expected Console Output**:
```text
T-minus 300...
T-minus 200...
T-minus 100...
Liftoff! 🚀
```
