## 1. Conceptual Deep-Dive: File System Orchestration

Python provides a powerful trio of modules for operating on files and archives:
1. **`shutil` Module (High-Level File Operations)**:
   - Copying files and metadata (`shutil.copy2()`).
   - Recursive directory copying (`shutil.copytree()`) and deletion (`shutil.rmtree()`).
   - Creating compressed archives (`shutil.make_archive()`).
   - Disk space querying (`shutil.disk_usage()`).
2. **`tempfile` Module (Secure Ephemeral Files)**:
   - `tempfile.NamedTemporaryFile()`: Creates temporary files with unique names that delete automatically upon closing.
   - `tempfile.TemporaryDirectory()`: Creates temporary isolated directory sandboxes.
   - Prevents race conditions and symlink security vulnerabilities.
3. **`zipfile` Module (ZIP Archive Compression)**:
   - Reads and writes ZIP files (`zipfile.ZipFile`).
   - Supports compression algorithms (`zipfile.ZIP_DEFLATED`).
   - Extracts archive contents securely (`zipfile.extractall()`).

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Ephemeral File Sandbox with `tempfile.TemporaryDirectory`
Run an isolated testing routine inside an automatically deleted temporary directory.

```python
import tempfile
from pathlib import Path

def run_isolated_build():
    # TemporaryDirectory creates an isolated sandbox and cleans it up on exit!
    with tempfile.TemporaryDirectory() as temp_dir:
        sandbox_path = Path(temp_dir)
        print(f"Isolated Sandbox Created at: {sandbox_path}")

        # Create intermediate files
        src = sandbox_path / "build_manifest.json"
        src.write_text('{"build_id": "v2.4.1", "status": "COMPILED"}')

        print(f"Files inside sandbox: {[p.name for p in sandbox_path.iterdir()]}")

    # Outside the 'with' block, the directory has been completely deleted from disk!
    print(f"Does sandbox still exist? {sandbox_path.exists()}")

run_isolated_build()
```

#### Step-by-Step Explanation:
1. `tempfile.TemporaryDirectory` guarantees deletion even if exceptions occur inside the block.
2. Prevents leftover temporary build artifacts from cluttering the host system.

#### Expected Output:
```text
Isolated Sandbox Created at: ...
Files inside sandbox: ['build_manifest.json']
Does sandbox still exist? False
```

### Example 2: Compressing Directory Trees into ZIP Archives with `zipfile`
Compress a collection of files into a `.zip` file and inspect archive metadata.

```python
import zipfile
from pathlib import Path

def create_backup_zip():
    zip_filename = "project_backup.zip"
    
    # 1. Create sample files
    f1 = Path("doc1.txt")
    f2 = Path("doc2.txt")
    f1.write_text("Hello from Document 1")
    f2.write_text("Hello from Document 2")

    # 2. Compress into ZIP archive
    with zipfile.ZipFile(zip_filename, "w", compression=zipfile.ZIP_DEFLATED) as zf:
        zf.write(f1)
        zf.write(f2)

    # 3. Inspect archive contents
    with zipfile.ZipFile(zip_filename, "r") as zf:
        print(f"Archive '{zip_filename}' Contents:")
        for info in zf.infolist():
            print(f"  File: {info.filename:<15} | Size: {info.file_size} bytes | Compressed: {info.compress_size} bytes")

    # Cleanup
    f1.unlink()
    f2.unlink()
    Path(zip_filename).unlink()

create_backup_zip()
```

#### Step-by-Step Explanation:
1. `zipfile.ZipFile("...", "w", compression=zipfile.ZIP_DEFLATED)` writes compressed archives.
2. `zf.infolist()` inspects file names and compression ratios.

#### Expected Output:
```text
Archive 'project_backup.zip' Contents:
  File: doc1.txt        | Size: 21 bytes | Compressed: ... bytes
  File: doc2.txt        | Size: 21 bytes | Compressed: ... bytes
```

### Example 3: Disk Space Capacity Query with `shutil.disk_usage`
Query available hard drive storage capacity across partitions.

```python
import shutil

def audit_disk_storage(path: str = "."):
    total, used, free = shutil.disk_usage(path)

    gb = 1024 ** 3
    print("Storage Capacity Metrics:")
    print(f"  Total Space: {total / gb:8.2f} GB")
    print(f"  Used Space : {used / gb:8.2f} GB ({used/total*100:5.1f}%)")
    print(f"  Free Space : {free / gb:8.2f} GB ({free/total*100:5.1f}%)")

audit_disk_storage()
```

#### Step-by-Step Explanation:
1. `shutil.disk_usage()` returns a named tuple containing total, used, and free byte capacities across any mounted drive.

#### Expected Output:
```text
Storage Capacity Metrics:
  Total Space: ... GB
  Used Space : ... GB (...)
  Free Space : ... GB (...)
```
