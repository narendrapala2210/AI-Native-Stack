## 1. Conceptual Deep-Dive: Tabular & Hierarchical Formats

Python's standard library provides dedicated modules for structured data:
1. **The `csv` Module**:
   - `csv.reader` / `csv.writer`: Reads and writes lists of row values.
   - `csv.DictReader` / `csv.DictWriter`: Maps lines to dictionaries keyed by header column names.
   - Handles quoting, delimiters, and dialect configurations.
2. **The `json` Module**:
   - `json.dumps()`: Serializes Python object hierarchy into a JSON string.
   - `json.loads()`: Deserializes a JSON string into Python dictionaries, lists, and primitives.
   - `json.dump()` and `json.load()`: Streams directly to/from open file handles.
   - `cls=CustomJSONEncoder`: Custom serializer for unsupported types (e.g. `datetime`, `UUID`, `Decimal`).

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Stream Processing CSV Records with `csv.DictReader`
Read and compute payroll aggregates from formatted tabular records.

```python
import csv
from pathlib import Path

def process_payroll_csv(csv_path: Path):
    with open(csv_path, "r", newline="", encoding="utf-8") as f:
        reader = csv.DictReader(f)
        total_payroll = 0.0
        departments = set()

        print(f"{'EMP ID':<8} {'NAME':<15} {'DEPT':<12} {'SALARY':<10}")
        print("-" * 48)

        for row in reader:
            salary = float(row["salary"])
            total_payroll += salary
            departments.add(row["department"])
            print(f"{row['emp_id']:<8} {row['name']:<15} {row['department']:<12} ${salary:,.2f}")

        print("-" * 48)
        print(f"Total Payroll : ${total_payroll:,.2f}")
        print(f"Departments   : {', '.join(sorted(departments))}")

def test_csv():
    csv_file = Path("payroll.csv")
    csv_file.write_text(
        "emp_id,name,department,salary\n"
        "101,Alice Smith,Engineering,135000\n"
        "102,Bob Jones,Marketing,95000\n"
        "103,Charlie Davis,Engineering,142000\n",
        encoding="utf-8"
    )

    process_payroll_csv(csv_file)
    csv_file.unlink()

test_csv()
```

#### Step-by-Step Explanation:
1. `csv.DictReader` parses header rows automatically, binding each subsequent line to a dictionary.
2. `newline=""` prevents blank line insertion on Windows operating systems.

#### Expected Output:
```text
EMP ID   NAME            DEPT         SALARY    
------------------------------------------------
101      Alice Smith     Engineering  $135,000.00
102      Bob Jones       Marketing    $95,000.00
103      Charlie Davis   Engineering  $142,000.00
------------------------------------------------
Total Payroll : $372,000.00
Departments   : Engineering, Marketing
```

### Example 2: Custom JSON Encoder for Complex Objects (Datetime, Sets, Decimal)
Extend `json.JSONEncoder` to serialize Python data types unsupported by standard JSON.

```python
import json
from datetime import datetime
from decimal import Decimal

class EnterpriseJSONEncoder(json.JSONEncoder):
    def default(self, obj):
        if isinstance(obj, datetime):
            return obj.isoformat()
        if isinstance(obj, Decimal):
            return float(obj)
        if isinstance(obj, set):
            return list(obj)
        return super().default(obj)

def test_custom_json():
    payload = {
        "transaction_id": 99201,
        "amount": Decimal("499.95"),
        "timestamp": datetime(2026, 9, 14, 15, 30, 0),
        "tags": {"ecommerce", "priority", "verified"}
    }

    # Serialize using our custom encoder class
    serialized = json.dumps(payload, cls=EnterpriseJSONEncoder, indent=2)
    print("Serialized JSON Output:")
    print(serialized)

test_custom_json()
```

#### Step-by-Step Explanation:
1. Standard `json.dumps()` raises `TypeError: Object of type Decimal is not JSON serializable`.
2. Overriding `default()` intercepts non-standard objects and transforms them into standard primitives.

#### Expected Output:
```text
Serialized JSON Output:
{
  "transaction_id": 99201,
  "amount": 499.95,
  "timestamp": "2026-09-14T15:30:00",
  "tags": [
    "...",
    "..."
  ]
}
```

### Example 3: Atomic Streaming JSON File Writing with Validation
Safely dump configuration state directly to disk files using `json.dump()`.

```python
import json
from pathlib import Path

def save_and_load_config(config_path: Path, config_data: dict):
    # Stream dump directly to file handle
    with open(config_path, "w", encoding="utf-8") as f:
        json.dump(config_data, f, indent=4)

    # Stream load from file handle
    with open(config_path, "r", encoding="utf-8") as f:
        loaded = json.load(f)

    print(f"Loaded config matches source? {loaded == config_data}")
    print("Environment Setting:", loaded["environment"])

def test_json_file():
    cfg_file = Path("app_settings.json")
    data = {"environment": "PRODUCTION", "workers": 8, "timeout": 30}

    save_and_load_config(cfg_file, data)
    cfg_file.unlink()

test_json_file()
```

#### Step-by-Step Explanation:
1. `json.dump(data, f)` formats and writes JSON directly to the stream without creating an intermediate monolithic string in memory.

#### Expected Output:
```text
Loaded config matches source? True
Environment Setting: PRODUCTION
```
