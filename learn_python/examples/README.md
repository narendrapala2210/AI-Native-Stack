# 🐍 Python Practical Examples Catalog

This directory contains standalone, runnable Python scripts corresponding to each chapter of the Python curriculum.

## 🚀 How to Run

Each script includes an interactive entry point (`if __name__ == '__main__':`) that runs all three practical examples sequentially.

To run any script from the project root:
```powershell
python learn_python/examples/04_control_flow_and_pattern_matching.py
```

Or from inside the `learn_python/examples/` folder:
```powershell
python 04_control_flow_and_pattern_matching.py
```
