## 1. Conceptual Deep-Dive: Fast, Memory-Efficient C Iterators

Python's built-in `itertools` module provides building blocks for creating fast, memory-efficient iterators implemented in C:
1. **Infinite Iterators**:
   - `itertools.count(start, step)`: Endless numeric stream ($0, 1, 2, \dots$).
   - `itertools.cycle(iterable)`: Cycles through an iterable indefinitely.
   - `itertools.repeat(elem[, n])`: Repeats an element endlessly or $n$ times.
2. **Terminating Iterators**:
   - `itertools.accumulate(iterable[, func])`: Running running totals or reductions.
   - `itertools.chain(*iterables)`: Chains multiple iterables into a single sequence.
   - `itertools.compress(data, selectors)`: Filters elements using boolean selectors.
   - `itertools.dropwhile(predicate, seq)`: Discards elements while predicate is true, then yields all rest.
   - `itertools.takewhile(predicate, seq)`: Yields elements while predicate is true, then halts immediately.
   - `itertools.groupby(iterable[, key])`: Groups consecutive matching elements.
   - `itertools.islice(iterable, start, stop[, step])`: Slices iterables lazily.
   - `itertools.pairwise(iterable)`: (Python 3.10+) Yields overlapping consecutive pairs `(s0, s1), (s1, s2)`.
3. **Combinatoric Generators**:
   - `itertools.product(*iterables, repeat=1)`: Cartesian product (nested for-loops).
   - `itertools.permutations(iterable, r)`: Order-dependent permutations.
   - `itertools.combinations(iterable, r)`: Order-independent combinations without replacement.
   - `itertools.combinations_with_replacement(iterable, r)`: Combinations allowing duplicate choices.

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Sliding Window Differencing with `itertools.pairwise`
Calculate rate-of-change deltas between consecutive metric timestamps.

```python
import itertools

def analyze_traffic_spikes():
    # Network packets per minute
    readings = [120, 135, 140, 290, 310, 150]

    print("Sliding Window Pairwise Deltas:")
    # pairwise yields: (120, 135), (135, 140), (140, 290), ...
    for prev, curr in itertools.pairwise(readings):
        delta = curr - prev
        pct = (delta / prev) * 100
        alert = " [SPIKE!]" if delta > 100 else ""
        print(f"  {prev} -> {curr} | Delta: {delta:+4d} ({pct:+5.1f}%){alert}")

analyze_traffic_spikes()
```

#### Step-by-Step Explanation:
1. `itertools.pairwise()` generates overlapping 2-tuples in linear time without manual indexing.
2. Identifies sharp traffic changes instantly.

#### Expected Output:
```text
Sliding Window Pairwise Deltas:
  120 -> 135 | Delta:  +15 ( +12.5%)
  135 -> 140 | Delta:   +5 (  +3.7%)
  140 -> 290 | Delta: +150 (+107.1%) [SPIKE!]
  290 -> 310 | Delta:  +20 (  +6.9%)
  310 -> 150 | Delta: -160 ( -51.6%)
```

### Example 2: Grouping Consecutive Ordered Records with `itertools.groupby`
Group server access logs by status code category.

```python
import itertools

def group_server_transactions():
    transactions = [
        {"tx_id": 101, "status": "SUCCESS"},
        {"tx_id": 102, "status": "SUCCESS"},
        {"tx_id": 103, "status": "FAILED"},
        {"tx_id": 104, "status": "SUCCESS"},
        {"tx_id": 105, "status": "SUCCESS"},
    ]

    # Note: groupby groups CONSECUTIVE items. To group globally, sort first!
    transactions.sort(key=lambda t: t["status"])

    print("Grouped Transactions by Status:")
    for status, group in itertools.groupby(transactions, key=lambda t: t["status"]):
        ids = [t["tx_id"] for t in group]
        print(f"  Status [{status:<7}] Count: {len(ids)} | IDs: {ids}")

group_server_transactions()
```

#### Step-by-Step Explanation:
1. `transactions.sort()` groups identical statuses adjacently.
2. `itertools.groupby()` extracts keys and sub-iterators efficiently.

#### Expected Output:
```text
Grouped Transactions by Status:
  Status [FAILED ] Count: 1 | IDs: [103]
  Status [SUCCESS] Count: 4 | IDs: [101, 102, 104, 105]
```

### Example 3: Combinatorial Team Generator with `itertools.combinations`
Generate all valid non-redundant team combinations from an employee roster.

```python
import itertools

def generate_audit_committees():
    candidates = ["Alice", "Bob", "Charlie", "Diana"]
    committee_size = 2

    # Combinations: Order does not matter ('Alice, Bob' == 'Bob, Alice')
    teams = list(itertools.combinations(candidates, committee_size))

    print(f"Total 2-person Committees from {len(candidates)} candidates: {len(teams)}")
    for i, (m1, m2) in enumerate(teams, 1):
        print(f"  Committee #{i}: {m1} & {m2}")

generate_audit_committees()
```

#### Step-by-Step Explanation:
1. `itertools.combinations()` mathematically computes $C(n, r)$ without duplicate sets.

#### Expected Output:
```text
Total 2-person Committees from 4 candidates: 6
  Committee #1: Alice & Bob
  Committee #2: Alice & Charlie
  Committee #3: Alice & Diana
  Committee #4: Bob & Charlie
  Committee #5: Bob & Diana
  Committee #6: Charlie & Diana
```
