# 01. Conditional Statements: if, elif, else

## 📖 Concept Overview
In Python, programs execute sequentially line-by-line by default. **Conditional statements** allow branching execution paths based on truth conditions.

### 1. Python Indentation & Code Blocks
Unlike languages that use curly braces `{}` to denote code blocks, Python uses **strict indentation** (4 spaces per level as per PEP 8). All statements with the same indentation level belong to the same block.

---

### 2. The `if` Statement
Executes a block of code only if its test expression evaluates to `True`:
```python
temperature = 35
if temperature > 30:
    print("Warning: High temperature detected!")
```

---

### 3. The `if-else` Statement
Provides an alternative execution path when the condition evaluates to `False`:
```python
age = 16
if age >= 18:
    print("Eligible to vote.")
else:
    print("Not eligible to vote.")
```

---

### 4. The `if-elif-else` Ladder
Evaluates multiple mutually exclusive conditions in sequential order. The first condition that evaluates to `True` runs its block, and all subsequent `elif`/`else` blocks are skipped:
```python
score = 85
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "F"
```

---

## 📋 Summary & Syntax Reference

```text
    if condition_1:
        # Executes if condition_1 is True
    elif condition_2:
        # Executes if condition_1 is False AND condition_2 is True
    else:
        # Executes if ALL preceding conditions are False
```

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: HTTP API Response Status Handler
Route and handle incoming REST API HTTP response codes using an `if-elif-else` branching tree.

```python
def handle_http_status_code(status_code: int) -> str:
    if 200 <= status_code < 300:
        if status_code == 200:
            return "SUCCESS (200): Request completed and payload returned."
        elif status_code == 201:
            return "CREATED (201): Resource created successfully."
        else:
            return f"SUCCESS ({status_code}): Accepted."
    elif 400 <= status_code < 500:
        if status_code == 401:
            return "UNAUTHORIZED (401): Missing or expired authentication token."
        elif status_code == 404:
            return "NOT FOUND (404): The requested URL does not exist."
        else:
            return f"CLIENT ERROR ({status_code}): Bad request parameters."
    elif 500 <= status_code < 600:
        return f"SERVER ERROR ({status_code}): Internal gateway failure."
    else:
        return f"UNKNOWN STATUS ({status_code}): Unhandled protocol code."

print(handle_http_status_code(200))
print(handle_http_status_code(404))
print(handle_http_status_code(502))
```

**Step-by-Step Explanation**:
1. Checks category status boundaries (`200 <= status_code < 300`).
2. Evaluates specific known error codes for actionable diagnostics.

**Expected Console Output**:
```text
SUCCESS (200): Request completed and payload returned.
NOT FOUND (404): The requested URL does not exist.
SERVER ERROR (502): Internal gateway failure.
```

### Example 2: E-Commerce Tiered Discount Calculator
Calculate progressive customer discounts based on cart volume and loyalty tiers.

```python
def calculate_order_discount(order_amount: float, loyalty_tier: str) -> float:
    discount_pct = 0.0
    tier = loyalty_tier.upper()
    
    if tier == "PLATINUM":
        discount_pct = 0.20  # 20% flat
    elif tier == "GOLD":
        if order_amount >= 500:
            discount_pct = 0.15
        else:
            discount_pct = 0.10
    elif tier == "SILVER":
        if order_amount >= 250:
            discount_pct = 0.08
        else:
            discount_pct = 0.05
    else:
        # Standard guest
        if order_amount >= 1000:
            discount_pct = 0.05
            
    discount_savings = order_amount * discount_pct
    return round(discount_savings, 2)

print("Platinum Customer ($400 order) Savings: $", calculate_order_discount(400, "Platinum"))
print("Gold Customer ($600 order) Savings    : $", calculate_order_discount(600, "Gold"))
print("Standard Guest ($1500 order) Savings  : $", calculate_order_discount(1500, "Standard"))
```

**Step-by-Step Explanation**:
1. Outer `if-elif-else` branches on user membership tier.
2. Inner conditions check volume spending thresholds.

**Expected Console Output**:
```text
Platinum Customer ($400 order) Savings: $ 80.0
Gold Customer ($600 order) Savings    : $ 90.0
Standard Guest ($1500 order) Savings  : $ 75.0
```

### Example 3: Ternary Conditional Operator (Inline `if-else`)
Use Python's inline conditional expression (`x if condition else y`) to simplify variable assignments.

```python
def format_user_greeting(is_authenticated: bool, username: str | None) -> str:
    # Syntax: value_if_true if condition else value_if_false
    display_user = username if (is_authenticated and username) else "Guest Visitor"
    status_badge = "Active Member" if is_authenticated else "Unregistered"
    
    return f"Welcome, {display_user}! Status: [{status_badge}]"

print(format_user_greeting(True, "Suresh"))
print(format_user_greeting(False, None))
```

**Step-by-Step Explanation**:
1. `val_true if cond else val_false` provides concise, readable single-line branching.
2. Avoids 4-line `if/else` blocks when simply assigning a computed variable.

**Expected Console Output**:
```text
Welcome, Suresh! Status: [Active Member]
Welcome, Guest Visitor! Status: [Unregistered]
```
