# 10. Sets: Uniqueness, Mathematical Operations & Methods

## 📖 Concept Overview
In Python, a **Set (`set`)** is an unordered collection of **unique, immutable (hashable)** items. Sets are implemented internally as hash tables, granting $O(1)$ average time complexity for membership testing, additions, and deletions.

### 1. Set Uniqueness & Hashability Rule
1. **Duplicates are Automatically Eliminated**:
   ```python
   num_set = {1, 2, 2, 3, 3, 3}
   print(num_set)  # {1, 2, 3}
   ```
2. **Items Must Be Immutable (Hashable)**:
   Set elements cannot be mutable types like lists or dictionaries.
   ```python
   valid_set = {"a", (1, 2)}  # Valid (tuples are hashable)
   # Attempting to add a list raises TypeError:
   invalid_set = {"a", [1, 2]} # TypeError: unhashable type: 'list'
   ```
3. **Empty Set Syntax**:
   `{}` creates an empty **dictionary**, NOT an empty set! To create an empty set, use **`set()`**.

---

### 2. Mathematical Set Operations
Python sets natively support classic Venn-diagram mathematical set algebra:

| Operation | Operator | Method | Description |
| :--- | :---: | :--- | :--- |
| **Union** | `A \| B` | `A.union(B)` | All elements in A, B, or both. |
| **Intersection** | `A & B` | `A.intersection(B)`| Elements present in **both** A and B. |
| **Difference** | `A - B` | `A.difference(B)` | Elements in A that are **not** in B. |
| **Symmetric Diff** | `A ^ B` | `A.symmetric_difference(B)` | Elements in either A or B, but **not both**. |

---

### 3. Set Relation Methods
- **`A.issubset(B)`**: Returns `True` if all elements of A are in B (`A <= B`).
- **`A.issuperset(B)`**: Returns `True` if all elements of B are in A (`A >= B`).
- **`A.isdisjoint(B)`**: Returns `True` if A and B have **no elements in common** (`A & B == empty`).

---

### 4. Modifying Sets
- **`s.add(item)`**: Adds a single item.
- **`s.update(iterable)`**: Adds multiple items from iterable.
- **`s.remove(item)`**: Removes item. Raises `KeyError` if item is absent.
- **`s.discard(item)`**: Removes item **safely** without raising an error if absent.
- **`s.pop()`**: Removes and returns an arbitrary element.

---

## 📋 Summary & Set Operations Reference

```text
    Set A: {1, 2, 3}       Set B: {2, 3, 4}
    
    Union (A | B)        : {1, 2, 3, 4}
    Intersection (A & B) : {2, 3}
    Difference (A - B)   : {1}
    Symmetric Diff (A ^ B): {1, 4}
```

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Real-Time Stream Deduplication & High-Speed Membership Testing
Demonstrate $O(1)$ constant-time set lookups compared to $O(n)$ linear-time list searches when filtering 100,000 user IDs.

```python
import time

def benchmark_membership_lookup():
    count = 50_000
    id_list = list(range(count))
    id_set = set(range(count))
    
    target = 49_999  # Worst-case search at very end
    
    # 1. Benchmark List lookup
    start = time.perf_counter()
    found_in_list = target in id_list
    list_time = (time.perf_counter() - start) * 1000
    
    # 2. Benchmark Set lookup
    start = time.perf_counter()
    found_in_set = target in id_set
    set_time = (time.perf_counter() - start) * 1000
    
    print("=== Membership Benchmark (50,000 Elements) ===")
    print(f"List Lookup Duration: {list_time:.4f} ms (Linear scan O(n))")
    print(f"Set Lookup Duration : {set_time:.4f} ms (Hash table O(1))")
    speedup = list_time / set_time if set_time > 0 else 1.0
    print(f"Set Speedup Factor  : {speedup:,.1f}x faster!")

benchmark_membership_lookup()
```

**Step-by-Step Explanation**:
1. Lists must scan element-by-element from index 0 until finding a match ($O(n)$).
2. Sets compute the hash of the target to jump directly to the memory bucket in $O(1)$ time.

**Expected Console Output**:
```text
=== Membership Benchmark (50,000 Elements) ===
List Lookup Duration: 0.8500 ms (Linear scan O(n))
Set Lookup Duration : 0.0008 ms (Hash table O(1))
Set Speedup Factor  : 1,062.5x faster!
```

### Example 2: Social Media Friend Suggestions & Mutual Connections (Venn Algebra)
Use set intersections, differences, and unions to calculate mutual friends, friend recommendations, and exclusive network contacts.

```python
def analyze_social_graph():
    user_a_friends = {"Alice", "Bob", "Charlie", "David", "Emma"}
    user_b_friends = {"Charlie", "David", "Frank", "Grace", "Heidi"}
    
    # 1. Mutual Friends (Intersection: A & B)
    mutual = user_a_friends & user_b_friends
    
    # 2. People user A knows that B does not (Difference: A - B)
    exclusive_to_a = user_a_friends - user_b_friends
    
    # 3. People user B knows that A does not (Friend Recommendations for A: B - A)
    recommended_for_a = user_b_friends - user_a_friends
    
    # 4. Total unique network reach (Union: A | B)
    combined_network = user_a_friends | user_b_friends
    
    print("=== Social Network Graph Analysis ===")
    print(f"User A Friends Count: {len(user_a_friends)}")
    print(f"User B Friends Count: {len(user_b_friends)}")
    print(f"Mutual Friends      : {sorted(mutual)}")
    print(f"Exclusive to User A : {sorted(exclusive_to_a)}")
    print(f"Recommended for A   : {sorted(recommended_for_a)}")
    print(f"Total Unique Reach  : {len(combined_network)} users")

analyze_social_graph()
```

**Step-by-Step Explanation**:
1. Uses `&` for mutual friend matching.
2. Uses `-` to compute candidate recommendations.
3. Uses `|` to determine total deduplicated network reach.

**Expected Console Output**:
```text
=== Social Network Graph Analysis ===
User A Friends Count: 5
User B Friends Count: 5
Mutual Friends      : ['Charlie', 'David']
Exclusive to User A : ['Alice', 'Bob', 'Emma']
Recommended for A   : ['Frank', 'Grace', 'Heidi']
Total Unique Reach  : 8 users
```

### Example 3: Role Permission Matrix Validation using `issubset()`
Verify whether an incoming user request contains all mandatory cryptographic and administrative permissions before granting API access.

```python
def verify_api_endpoint_authorization(user_granted_permissions: set[str], endpoint_required_permissions: set[str]) -> bool:
    # Check if endpoint requirements are a subset of user permissions
    is_authorized = endpoint_required_permissions.issubset(user_granted_permissions)
    
    missing_permissions = endpoint_required_permissions - user_granted_permissions
    
    print("=== Access Authorization Inspection ===")
    print(f"User Permissions    : {user_granted_permissions}")
    print(f"Required by Endpoint: {endpoint_required_permissions}")
    
    if is_authorized:
        print("[STATUS: GRANTED] Request Authorized successfully.")
        return True
    else:
        print(f"[STATUS: DENIED] Insufficient privileges. Missing: {missing_permissions}")
        return False

user_perms = {"read:reports", "write:reports", "export:csv"}
admin_endpoint = {"read:reports", "write:reports", "delete:database"}

verify_api_endpoint_authorization(user_perms, admin_endpoint)
```

**Step-by-Step Explanation**:
1. `endpoint.issubset(user_perms)` ensures every single required permission is granted.
2. The difference operator (`-`) pinpoints the exact missing privileges to emit actionable error diagnostics.

**Expected Console Output**:
```text
=== Access Authorization Inspection ===
User Permissions    : {'export:csv', 'write:reports', 'read:reports'}
Required by Endpoint: {'delete:database', 'write:reports', 'read:reports'}
[STATUS: DENIED] Insufficient privileges. Missing: {'delete:database'}
```
