# 08. List Methods & Nested Lists

## 📖 Concept Overview
Python lists provide built-in methods for appending, inserting, extending, removing, sorting, and querying items.

---

### 1. Adding Elements
- **`lst.append(item)`**: Appends `item` to the end of the list ($O(1)$ amortized).
- **`lst.insert(index, item)`**: Inserts `item` at `index`, shifting subsequent elements ($O(n)$).
- **`lst.extend(iterable)`**: Appends all elements from `iterable` to the list ($O(k)$).
  > Note: `lst.append([1, 2])` nests the list as a single child element. `lst.extend([1, 2])` unpacks both elements into the parent list!

---

### 2. Removing Elements
- **`lst.pop([index])`**: Removes and returns item at `index` (defaults to last element, $O(1)$).
- **`lst.remove(value)`**: Removes the **first** occurrence of `value` ($O(n)$). Raises `ValueError` if not found.
- **`lst.clear()`**: Removes all elements, leaving the list empty.
- **`del lst[index]`**: Deletes item at index or slice.

---

### 3. Searching, Counting & Ordering
- **`lst.index(value)`**: Returns index of first occurrence of `value`. Raises `ValueError` if absent.
- **`lst.count(value)`**: Returns number of occurrences of `value`.
- **`lst.sort(key=None, reverse=False)`**: In-place sorting using Python's **Timsort** algorithm ($O(n \log n)$).
- **`lst.reverse()`**: In-place reversal ($O(n)$).

---

### 4. Nested Lists (2D Arrays / Matrices)
A list containing other lists as elements represents a 2D matrix or grid:
```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
print(matrix[0][1])  # Row 0, Column 1 -> 2
```

---

## 📋 Summary & Method Reference

| Method | Syntax | Effect | Return Value |
| :--- | :--- | :--- | :--- |
| `append()` | `lst.append(x)` | Adds `x` to end of list. | `None` |
| `extend()` | `lst.extend(iterable)` | Unpacks elements of iterable into list. | `None` |
| `insert()` | `lst.insert(i, x)` | Inserts `x` at index `i`. | `None` |
| `pop()` | `val = lst.pop()` | Removes and returns last element. | Removed item |
| `remove()` | `lst.remove(x)` | Deletes first match of `x`. | `None` |
| `sort()` | `lst.sort()` | Sorts items in-place. | `None` |
| `copy()` | `new_lst = lst.copy()` | Creates a shallow copy. | New list object |

### Example 1: E-Commerce Shopping Cart Management
Simulate adding, modifying, and calculating shopping cart items with discounts and coupon validation.

```python
class ShoppingCartManager:
    def __init__(self):
        self.cart: list[dict] = []

    def add_product(self, product_id: str, name: str, unit_price: float, qty: int = 1):
        # Check if product already in cart
        for item in self.cart:
            if item["id"] == product_id:
                item["qty"] += qty
                print(f"Updated quantity for '{name}' to {item['qty']}.")
                return
        self.cart.append({"id": product_id, "name": name, "price": unit_price, "qty": qty})
        print(f"Added '{name}' (${unit_price:.2f}) x {qty} to cart.")

    def remove_product(self, product_id: str):
        for idx, item in enumerate(self.cart):
            if item["id"] == product_id:
                popped = self.cart.pop(idx)
                print(f"Removed '{popped['name']}' from cart.")
                return
        print(f"[WARN] Product ID '{product_id}' not found in cart.")

    def calculate_totals(self, tax_rate: float = 0.08) -> dict:
        subtotal = sum(item["price"] * item["qty"] for item in self.cart)
        tax = subtotal * tax_rate
        total = subtotal + tax
        return {"subtotal": round(subtotal, 2), "tax": round(tax, 2), "total": round(total, 2)}

cart_mgr = ShoppingCartManager()
cart_mgr.add_product("P100", "Mechanical Keyboard", 89.99, qty=1)
cart_mgr.add_product("P101", "Gaming Mouse", 45.00, qty=1)
cart_mgr.add_product("P100", "Mechanical Keyboard", 89.99, qty=1)  # Increments qty
cart_mgr.remove_product("P101")

totals = cart_mgr.calculate_totals()
print(f"Cart Final Totals: {totals}")
```

**Step-by-Step Explanation**:
1. Uses `self.cart.append()` to add structured dictionary items.
2. Uses `self.cart.pop(idx)` to remove items cleanly at a discovered index.
3. Aggregates financial totals with concise generator expressions.

**Expected Console Output**:
```text
Added 'Mechanical Keyboard' ($89.99) x 1 to cart.
Added 'Gaming Mouse' ($45.00) x 1 to cart.
Updated quantity for 'Mechanical Keyboard' to 2.
Removed 'Gaming Mouse' from cart.
Cart Final Totals: {'subtotal': 179.98, 'tax': 14.4, 'total': 194.38}
```

### Example 2: Matrix Transposition and Row-Column Arithmetic
Perform matrix transposition (swapping rows and columns) and compute row/column sums on a 2D nested list.

```python
def analyze_matrix(matrix: list[list[int]]):
    rows = len(matrix)
    cols = len(matrix[0]) if rows > 0 else 0
    
    print("=== Original Matrix ===")
    for row in matrix:
        print(" ", row)
        
    # Row sums
    row_sums = [sum(r) for r in matrix]
    
    # Transposition: convert rows into columns
    # Transposed[c][r] = matrix[r][c]
    transposed = [[matrix[r][c] for r in range(rows)] for c in range(cols)]
    
    col_sums = [sum(col) for col in transposed]
    
    print("
=== Transposed Matrix ===")
    for row in transposed:
        print(" ", row)
        
    print(f"
Row Totals   : {row_sums}")
    print(f"Column Totals: {col_sums}")

grid = [
    [10, 20, 30],
    [40, 50, 60],
    [70, 80, 90]
]

analyze_matrix(grid)
```

**Step-by-Step Explanation**:
1. Nested lists are accessed via `matrix[row][col]`.
2. Transposition swaps coordinates `[r][c]` to `[c][r]`.
3. Demonstrates mathematical grid processing for scientific computing and graphics.

**Expected Console Output**:
```text
=== Original Matrix ===
  [10, 20, 30]
  [40, 50, 60]
  [70, 80, 90]

=== Transposed Matrix ===
  [10, 40, 70]
  [20, 50, 80]
  [30, 60, 90]

Row Totals   : [60, 150, 240]
Column Totals: [120, 150, 180]
```

### Example 3: Shallow Copy Trap vs Deep Copy in Nested Collections
Expose the common production bug where modifying a nested list inside a copied list mutates the original parent collection, and solve it with `copy.deepcopy()`.

```python
import copy

def demonstrate_copy_semantics():
    original_team = [
        "Engineering",
        ["Alice (Lead)", "Bob (Backend)"]
    ]
    
    # 1. Shallow copy
    shallow_team = list(original_team)
    
    # 2. Deep copy
    deep_team = copy.deepcopy(original_team)
    
    # Mutate the nested list of members
    shallow_team[1].append("Charlie (Contractor)")
    
    print("=== Post Mutation of Shallow Copy ===")
    print("Original Team Members:", original_team[1])  # Mutated!
    print("Shallow Team Members :", shallow_team[1])   # Mutated!
    print("Deep Team Members    :", deep_team[1])      # Untouched & Safe!

demonstrate_copy_semantics()
```

**Step-by-Step Explanation**:
1. A shallow copy copies only top-level references. The inner list memory address is shared between `original_team` and `shallow_team`.
2. Appending to `shallow_team[1]` silently mutates `original_team[1]`.
3. `copy.deepcopy()` recursively copies all nested objects, ensuring complete isolation.

**Expected Console Output**:
```text
=== Post Mutation of Shallow Copy ===
Original Team Members: ['Alice (Lead)', 'Bob (Backend)', 'Charlie (Contractor)']
Shallow Team Members : ['Alice (Lead)', 'Bob (Backend)', 'Charlie (Contractor)']
Deep Team Members    : ['Alice (Lead)', 'Bob (Backend)']
```
