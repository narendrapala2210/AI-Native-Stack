# 06. String Formatting & Unicode

## 📖 Concept Overview
String formatting allows dynamic injection and alignment of variables within text templates. Python has evolved through three formatting systems, culminating in modern **f-strings (Formatted String Literals)**.

---

### 1. The Three Eras of Python String Formatting
1. **Old Style (`%` Operator)**:
   ```python
   name = "Ravi"
   age = 25
   print("Hello %s, you are %d years old." % (name, age))
   ```
2. **`str.format()` Method (Python 2.6+)**:
   ```python
   print("Hello {}, you are {} years old.".format(name, age))
   print("Hello {0}, {1} is your age.".format(name, age))
   print("Hello {n}, age: {a}.".format(n=name, a=age))
   ```
3. **F-Strings (Python 3.6+ / PEP 498 & PEP 701)**:
   Prefix string with `f` or `F`. Expressions inside curly braces `{}` are evaluated at runtime with C speed:
   ```python
   print(f"Hello {name}, you are {age} years old. In 5 years: {age + 5}.")
   ```

---

### 2. Advanced F-String Format Specifiers
Use `{value:specifier}` syntax:
- **Floating Point Precision**: `{pi:.2f}` -> `3.14`
- **Thousand Separator**: `{1000000:,}` -> `1,000,000`
- **Padding & Alignment**:
  - Left align: `{name:<15}`
  - Right align: `{score:>10}`
  - Center align: `{title:^20}`
  - Zero pad numbers: `{num:04d}` -> `0042`
- **Percentage Formatting**: `{0.856:.1%}` -> `85.6%`
- **Self-Documenting Debugging (Python 3.8+)**: `{x=}` prints `x=42`.

---

### 3. Unicode and Characters: `ord()` and `chr()`
Every character in computer memory maps to a numerical Unicode code point:
- **`ord(char)`**: Returns the integer Unicode code point for a character.
  ```python
  ord('A')  # 65
  ord('a')  # 97
  ```
- **`chr(code)`**: Returns the string character for an integer Unicode code point.
  ```python
  chr(65)   # 'A'
  chr(97)   # 'a'
  ```
Because `'a'` (97) > `'A'` (65), lowercase letters are lexicographically greater than uppercase letters in Python comparisons!

---

## 📋 Summary & Format Specifiers Reference

| Specifier | Syntax | Result for Value | Description |
| :--- | :--- | :--- | :--- |
| `:.2f` | `f"{3.14159:.2f}"` | `'3.14'` | Fixed-point 2 decimal places. |
| `:,` | `f"{1250000:,}"` | `'1,250,000'` | Comma thousands separator. |
| `:05d` | `f"{7:05d}"` | `'00007'` | Pad integer with leading zeroes to 5 digits. |
| `:<10` | `f"{'test':<10}"` | `'test      '` | Left-align within 10 spaces. |
| `:>10` | `f"{'test':>10}"` | `'      test'` | Right-align within 10 spaces. |
| `:^10` | `f"{'test':^10}"` | `'   test   '` | Center-align within 10 spaces. |
| `:.1%` | `f"{0.758:.1%}"` | `'75.8%'` | Convert fraction to percentage. |

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Terminal Dashboard with Clean Alignments
Generate an executive sales report using comprehensive f-string alignment and numerical format specifiers.

```python
def render_sales_dashboard(data: list[dict]):
    border = "=" * 55
    print(border)
    print(f"{'EXECUTIVE REGIONAL PERFORMANCE REPORT':^55}")
    print(border)
    print(f"{'Region':<12} {'Units':>8} {'Revenue ($)':>16} {'Target Met':>14}")
    print("-" * 55)
    
    total_units = 0
    total_rev = 0.0
    
    for row in data:
        region = row["region"]
        units = row["units"]
        rev = row["revenue"]
        achieved = row["target_achieved"]
        
        total_units += units
        total_rev += rev
        
        # Format currency with commas and 2 decimals, percentage with 1 decimal
        print(f"{region:<12} {units:>8,d} {rev:>16,.2f} {achieved:>13.1%}")
        
    print("-" * 55)
    print(f"{'TOTALS':<12} {total_units:>8,d} {total_rev:>16,.2f}")
    print(border)

dataset = [
    {"region": "North America", "units": 14200, "revenue": 1450200.50, "target_achieved": 1.125},
    {"region": "Europe West",   "units": 8900,  "revenue": 920400.00,  "target_achieved": 0.942},
    {"region": "Asia Pacific",  "units": 23500, "revenue": 2100800.75, "target_achieved": 1.340},
]

render_sales_dashboard(dataset)
```

**Step-by-Step Explanation**:
1. Uses `^55` to center the title across a 55-character terminal layout.
2. Uses `:>8,d` to format unit integers with comma separators.
3. Uses `:>16,.2f` for currency and `:>13.1%` to format decimals into percentages.

**Expected Console Output**:
```text

=======================================================
```

### Example 2: Self-Documenting Debugging with F-Strings (`{var=}`)
Use Python 3.8+ f-string debug syntax to monitor state variables and intermediate calculations during matrix multiplication.

```python
def debug_matrix_cell_multiplication():
    row_vector = [2, 4, 6]
    col_vector = [1, 3, 5]
    
    print("=== Debugging Dot Product Step-by-Step ===")
    dot_product = 0
    for idx, (a, b) in enumerate(zip(row_vector, col_vector)):
        product = a * b
        dot_product += product
        # Self-documenting f-string debug print
        print(f"Step {idx}: {a=}, {b=}, {product=}, {dot_product=}")
        
    print(f"
Final Result: {dot_product=}")

debug_matrix_cell_multiplication()
```

**Step-by-Step Explanation**:
1. `{a=}` automatically prints the identifier name along with its runtime evaluated value (`a=2`).
2. Eliminates repetitive debugging code like `print("a:", a, "b:", b)`.

**Expected Console Output**:
```text
=== Debugging Dot Product Step-by-Step ===
Step 0: a=2, b=1, product=2, dot_product=2
Step 1: a=4, b=3, product=12, dot_product=14
Step 2: a=6, b=5, product=30, dot_product=44

Final Result: dot_product=44
```

### Example 3: Caesar Cipher Encryption & Decryption via `ord()` & `chr()`
Implement a classic Caesar cipher cryptosystem shifting Unicode alphabet code points.

```python
def encrypt_caesar(plaintext: str, shift: int = 3) -> str:
    encrypted_chars = []
    for ch in plaintext:
        if ch.isupper():
            # Shift within 'A' (65) to 'Z' (90)
            shifted = chr((ord(ch) - ord('A') + shift) % 26 + ord('A'))
            encrypted_chars.append(shifted)
        elif ch.islower():
            # Shift within 'a' (97) to 'z' (122)
            shifted = chr((ord(ch) - ord('a') + shift) % 26 + ord('a'))
            encrypted_chars.append(shifted)
        else:
            # Non-alphabetic characters remain unchanged
            encrypted_chars.append(ch)
    return "".join(encrypted_chars)

def decrypt_caesar(ciphertext: str, shift: int = 3) -> str:
    return encrypt_caesar(ciphertext, shift=-shift)

secret_msg = "Python 3.12: Security First!"
cipher = encrypt_caesar(secret_msg, shift=5)
recovered = decrypt_caesar(cipher, shift=5)

print(f"Original Text : {secret_msg}")
print(f"Encrypted Text: {cipher}")
print(f"Decrypted Text: {recovered}")
```

**Step-by-Step Explanation**:
1. `ord(ch) - ord('A')` maps uppercase letters to indices $0-25$.
2. Adds the shift key and uses `% 26` to wrap around at the boundary.
3. `chr(...)` converts the numeric index back into an encrypted character.

**Expected Console Output**:
```text
Original Text : Python 3.12: Security First!
Encrypted Text: Udymts 3.12: Xjhzwnyd Knwxy!
Decrypted Text: Python 3.12: Security First!
```
