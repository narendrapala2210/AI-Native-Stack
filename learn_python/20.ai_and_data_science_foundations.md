### 20.1 Vectorization vs Python Loops (NumPy Contiguity & SIMD)

Python lists are arrays of **pointers** to distinct heap objects. NumPy arrays are **contiguous blocks of raw C data** in memory.

```
Python List:  [ ptr ] ───> [ PyObject: int 10 ]
              [ ptr ] ───> [ PyObject: int 20 ]   (Fragmented, dynamic type checks)

NumPy Array:  [ 10 | 20 | 30 | 40 ]                (Contiguous memory, SIMD CPU vectorization)
```

```python
import time

# Pure Python loop (Slow - checks type and unpacks PyObject on every iteration)
size = 1_000_000
list_a = list(range(size))
list_b = list(range(size))

start = time.perf_counter()
result_list = [x + y for x, y in zip(list_a, list_b)]
python_duration = time.perf_counter() - start
print(f"Pure Python loop addition: {python_duration:.4f} seconds")

# In NumPy (SIMD accelerated C vector loop):
# np_a + np_b runs 50x-100x faster by processing 4-8 elements per single CPU cycle!
```

### 20.2 Tabular Data & DataFrames vs Nested Dicts

```python
# Nested dictionary representation (Row-oriented: high memory overhead per record)
row_oriented = [
    {"user_id": 101, "name": "Alice", "score": 92.5},
    {"user_id": 102, "name": "Bob", "score": 88.0}
]

# Columnar representation (DataFrame-oriented: contiguous arrays per column)
column_oriented = {
    "user_id": [101, 102],
    "name": ["Alice", "Bob"],
    "score": [92.5, 88.0]
}

print("Average score calculated column-wise:", sum(column_oriented["score"]) / len(column_oriented["score"]))
```

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: SIMD Vectorization vs Python Loop Benchmark
Demonstrate why low-level memory contiguity and vectorized operations outperform pure Python loops for numerical AI datasets.

```python
import time

def benchmark_loops():
    size = 500_000
    a = list(range(size))
    b = list(range(size))

    start = time.perf_counter()
    # Pure Python loop: pointer chasing on each iteration
    result = [x * 2 + y for x, y in zip(a, b)]
    duration = time.perf_counter() - start

    print(f"Python list comprehension ({size:,} items): {duration:.4f} seconds")
    print(f"First 3 elements: {result[:3]}")

benchmark_loops()
```

### Example 2: Columnar Data Processing and Filtering Engine
Simulate the memory and indexing performance of columnar data layouts (similar to Pandas/Arrow) versus row-oriented dicts.

```python
class ColumnarTable:
    def __init__(self, columns: dict[str, list]):
        self.columns = columns
        self.row_count = len(next(iter(columns.values())))

    def filter_gt(self, column: str, threshold: float) -> dict[str, list]:
        indices = [i for i, val in enumerate(self.columns[column]) if val > threshold]
        return {col: [self.columns[col][i] for i in indices] for col in self.columns}

data = ColumnarTable({
    "id": [1, 2, 3, 4, 5],
    "model_score": [0.85, 0.94, 0.72, 0.99, 0.65],
    "is_active": [True, True, False, True, False]
})

high_scoring = data.filter_gt("model_score", 0.90)
print("High scoring predictions (Vectorized filter):", high_scoring)
```

### Example 3: Secure Environment Secret Masker & Validator
Safely retrieve API credentials with format validation, masking sensitive characters in logs.

```python
import os

def get_masked_secret(env_var_name: str, min_length: int = 10) -> str:
    val = os.getenv(env_var_name, "sk-mock-demo-key-123456789")
    if len(val) < min_length:
        raise ValueError(f"Environment variable '{env_var_name}' appears malformed or too short.")
    # Mask middle characters
    masked = f"{val[:3]}...{val[-4:]}"
    return masked

print("Masked Secret for Logging:", get_masked_secret("OPENAI_API_KEY"))
```
