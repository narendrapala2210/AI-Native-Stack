# 14. Concurrency: Threading, Multiprocessing & AsyncIO

### 14.1 Concurrency vs Parallelism & The Global Interpreter Lock (GIL)

- **Concurrency**: Dealing with lots of things at once (task switching / cooperative multi-tasking). Best for **I/O-bound** operations (network requests, database calls, file reading).
- **Parallelism**: Doing lots of things at once simultaneously on multiple CPU cores. Best for **CPU-bound** operations (machine learning, heavy mathematical computations, image transformation).
- **CPython GIL**: A mutex that prevents multiple native OS threads from executing Python bytecodes simultaneously in one process.
  - *Threads*: Good for I/O; locked by GIL for CPU.
  - *Processes*: Bypasses the GIL entirely by spawning distinct OS processes with separate memory spaces.
  - *Python 3.13 note*: Experimental free-threaded (no-GIL) build introduced (PEP 703).

### 14.2 Multithreading: Threads, Synchronization (`Lock`, `Semaphore`), Queues

```python
import threading
import time
from queue import Queue

# Shared state protected by a Lock
shared_counter = 0
counter_lock = threading.Lock()

def safe_increment(n: int):
    global shared_counter
    for _ in range(n):
        with counter_lock:  # Acquires and automatically releases lock
            shared_counter += 1

threads = [threading.Thread(target=safe_increment, args=(10_000,)) for _ in range(5)]
for t in threads:
    t.start()
for t in threads:
    t.join()  # Wait for thread to terminate

print("Synchronized counter result:", shared_counter)  # Exactly 50,000

# Producer-Consumer Pattern with Thread-Safe Queue
work_queue = Queue()

def worker():
    while True:
        task = work_queue.get()
        if task is None:  # Sentinel to shut down
            break
        print(f"Thread {threading.current_thread().name} processed: {task}")
        work_queue.task_done()

worker_thread = threading.Thread(target=worker, name="Worker-1")
worker_thread.start()

for i in range(3):
    work_queue.put(f"Job #{i}")

work_queue.join()
work_queue.put(None)  # Stop worker
worker_thread.join()
```

### 14.3 Multiprocessing: Process Pools & Shared Memory

Bypasses the GIL by spawning independent OS processes.

```python
import multiprocessing

def compute_square(number: int) -> int:
    return number * number

if __name__ == "__main__":
    numbers = [10_000 + i for i in range(8)]
    
    # Process Pool: distributes work across all available CPU cores
    with multiprocessing.Pool() as pool:
        results = pool.map(compute_square, numbers)
    
    print("Multiprocessing results computed in parallel:", results[:4], "...")
```

### 14.4 `concurrent.futures`: ThreadPoolExecutor & ProcessPoolExecutor

`concurrent.futures` provides a clean, unified high-level abstraction over threads and processes.

```python
from concurrent.futures import ThreadPoolExecutor, as_completed
import time

def simulate_network_fetch(endpoint: str) -> dict:
    time.sleep(0.05)  # Simulate network latency
    return {"endpoint": endpoint, "status": 200}

endpoints = [f"/api/v1/resource/{i}" for i in range(5)]

# ThreadPoolExecutor for I/O bound requests
with ThreadPoolExecutor(max_workers=3) as executor:
    # Submit tasks and collect Future objects
    future_to_url = {executor.submit(simulate_network_fetch, ep): ep for ep in endpoints}
    
    for future in as_completed(future_to_url):
        data = future.result()
        print(f"Fetched {data['endpoint']} -> {data['status']}")
```

### 14.5 Asynchronous Programming with `asyncio` (`async`/`await`, `TaskGroup`)

AsyncIO executes cooperative multitasking inside a single thread via an **Event Loop**.

```python
import asyncio
import time

async def fetch_remote_data(service_name: str, delay: float) -> str:
    print(f"[{service_name}] Request dispatched...")
    await asyncio.sleep(delay)  # Non-blocking pause
    print(f"[{service_name}] Data received!")
    return f"{service_name}: payload_ok"

async def main():
    start_time = time.perf_counter()

    # Modern Python 3.11+ TaskGroup (structured concurrency)
    async with asyncio.TaskGroup() as tg:
        task1 = tg.create_task(fetch_remote_data("AuthService", 0.1))
        task2 = tg.create_task(fetch_remote_data("DatabaseCluster", 0.15))
        task3 = tg.create_task(fetch_remote_data("PaymentGateway", 0.08))

    # All tasks are completed when exiting the TaskGroup block
    print("Results:", [task1.result(), task2.result(), task3.result()])
    elapsed = time.perf_counter() - start_time
    print(f"Total concurrent time: {elapsed:.3f}s (Runs concurrently!)")

# Entry point for asyncio
if __name__ == "__main__":
    asyncio.run(main())
```

### 14.6 Advanced AsyncIO: Async Iterators, Async Context Managers, Queues & to_thread

```python
import asyncio
import time

# 1. Async Context Manager (__aenter__, __aexit__)
class AsyncDatabaseSession:
    async def __aenter__(self):
        print("[ASYNC DB] Connection pool opened.")
        await asyncio.sleep(0.02)
        return self

    async def __aexit__(self, exc_type, exc_val, exc_tb):
        print("[ASYNC DB] Connection pool closed safely.")
        await asyncio.sleep(0.01)

    async def query(self, sql: str):
        await asyncio.sleep(0.03)
        return [{"id": 1, "record": "data"}]

# 2. Async Generator & Async Iterator (__aiter__, __anext__)
async def real_time_event_stream(limit: int = 3):
    for i in range(1, limit + 1):
        await asyncio.sleep(0.05)
        yield f"Event #{i}"

# 3. Offloading CPU-bound or blocking I/O calls: asyncio.to_thread() (Python 3.9+)
def heavy_cpu_blocking_work(n: int) -> int:
    time.sleep(0.1)  # Simulating synchronous blocking library (e.g., standard requests)
    return sum(i * i for i in range(n))

async def async_demonstration():
    # Using async context manager
    async with AsyncDatabaseSession() as session:
        results = await session.query("SELECT * FROM users")
        print("Query output:", results)

    # Consuming async generator with 'async for'
    async for event in real_time_event_stream():
        print("Stream received:", event)

    # Running blocking call in a separate thread pool without blocking event loop
    computed = await asyncio.to_thread(heavy_cpu_blocking_work, 100_000)
    print("Offloaded blocking task result:", computed)

    # Modern timeout enforcement with asyncio.timeout (Python 3.11+)
    try:
        async with asyncio.timeout(0.5):
            await asyncio.sleep(0.02)
            print("Task completed well before timeout.")
    except TimeoutError:
        print("Operation timed out!")

if __name__ == "__main__":
    asyncio.run(async_demonstration())
```

### Example 1: Concurrent Web Scraper / API Poller with `asyncio.TaskGroup`
Fetch data from multiple simulated endpoints concurrently with structured concurrency (auto-cancellation on error).

```python
import asyncio
import time

async def fetch_endpoint(url: str, delay: float) -> dict:
    await asyncio.sleep(delay)
    return {"url": url, "status": 200, "bytes": 1024}

async def scrape_all():
    urls = [
        ("https://api.one/metrics", 0.05),
        ("https://api.two/users", 0.08),
        ("https://api.three/logs", 0.03)
    ]
    results = []
    async with asyncio.TaskGroup() as tg:
        tasks = [tg.create_task(fetch_endpoint(url, d)) for url, d in urls]

    for t in tasks:
        results.append(t.result())
    return results

start = time.perf_counter()
data = asyncio.run(scrape_all())
elapsed = time.perf_counter() - start
print(f"Fetched {len(data)} endpoints concurrently in {elapsed:.3f}s:")
for item in data:
    print(f"  {item['url']} -> {item['status']}")
```

### Example 2: Parallel Batch Matrix Compute Engine with `multiprocessing.Pool`
Distribute CPU-intensive calculations across all available physical CPU cores simultaneously.

```python
import multiprocessing
import math

def compute_heavy_factorials(number: int) -> int:
    return sum(math.factorial(i % 20) for i in range(number))

if __name__ == "__main__":
    workloads = [200_000, 200_000, 200_000, 200_000]
    
    # Run across pool of workers
    with multiprocessing.Pool() as pool:
        outputs = pool.map(compute_heavy_factorials, workloads)
    print("Multi-core parallel computation results:", [o % 1000 for o in outputs])
```

### Example 3: Multi-Threaded Producer-Consumer Pipeline with `queue.Queue`
Build a thread-safe task processing pipeline with graceful worker shutdown.

```python
import threading
import time
from queue import Queue

task_queue = Queue()
results = []

def worker_consumer():
    while True:
        task = task_queue.get()
        if task is None:  # Shutdown sentinel
            task_queue.task_done()
            break
        # Process task
        time.sleep(0.01)
        results.append(f"Processed: {task}")
        task_queue.task_done()

# Start 2 worker threads
threads = [threading.Thread(target=worker_consumer) for _ in range(2)]
for t in threads:
    t.start()

# Produce 5 jobs
for i in range(5):
    task_queue.put(f"Invoice-Job-{i+1}")

# Wait for completion
task_queue.join()

# Stop workers
for _ in threads:
    task_queue.put(None)
for t in threads:
    t.join()

print(f"Pipeline finished! Completed {len(results)} jobs.")
```
