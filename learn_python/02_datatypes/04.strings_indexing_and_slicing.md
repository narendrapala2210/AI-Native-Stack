# 04. Strings: Indexing, Immutability & Slicing

## 📖 Concept Overview
In Python, a **String (`str`)** is an immutable sequence of Unicode characters.

### 1. Immutability
Strings in Python cannot be mutated in place. Once a string object is created in memory, its characters cannot be modified, replaced, or deleted:
```python
message = "sea you soon"
# Attempting in-place item assignment raises TypeError:
message[2] = "e"  # TypeError: 'str' object does not support item assignment
```
To "modify" a string, you create a new string object via slicing and concatenation:
```python
message = message[:2] + "e" + message[3:]  # "see you soon"
```

---

### 2. String Indexing (Positive and Negative)
Every character in a string occupies an index position:
- **Positive Indexing (Left-to-Right)**: Starts at `0` for the first character, up to `len(s) - 1`.
- **Negative Indexing (Right-to-Left)**: Starts at `-1` for the last character, `-2` for the second to last.

```text
 String:   P   y   t   h   o   n
 Index:    0   1   2   3   4   5
Neg Idx:  -6  -5  -4  -3  -2  -1
```

```python
lang = "Python"
print(lang[0])   # 'P'
print(lang[-1])  # 'n'
```
Accessing an index beyond the valid range raises `IndexError: string index out of range`.

---

### 3. String Slicing: `[start:stop:step]`
Slicing extracts a substring using the syntax:
```python
sub = string[start:stop:step]
```
- **`start`**: Index where slice begins (inclusive, defaults to `0` or end if step < 0).
- **`stop`**: Index where slice ends (**exclusive**, up to but not including `stop`).
- **`step`**: Stride / increment (defaults to `1`).

#### Slicing Rules & Shortcuts:
- Slicing **never raises `IndexError`** if indices exceed string boundaries; Python automatically clamps indices.
- **`s[::-1]`**: Reverses the string completely.
- **`s[::2]`**: Selects alternate characters.

---

## 📋 Summary & Slicing Reference

| Syntax | Description | Example on `"DEVELOPER"` | Result |
| :--- | :--- | :--- | :--- |
| `s[0]` | First character | `"DEVELOPER"[0]` | `'D'` |
| `s[-1]` | Last character | `"DEVELOPER"[-1]` | `'R'` |
| `s[2:6]` | Slices index 2 to 5 | `"DEVELOPER"[2:6]` | `'VELO'` |
| `s[:4]` | Prefix (start to 3) | `"DEVELOPER"[:4]` | `'DEVE'` |
| `s[5:]` | Suffix (index 5 to end) | `"DEVELOPER"[5:]` | `'OPER'` |
| `s[::-1]` | Reverse sequence | `"DEVELOPER"[::-1]` | `'REPOLEVED'` |
| `s[::2]` | Alternate characters | `"DEVELOPER"[::2]` | `'DVLP'` |

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Sensitive Data Masker (Credit Cards & Emails)
Use slicing and string length to dynamically mask sensitive identification numbers and emails for regulatory compliance (PCI-DSS).

```python
def mask_credit_card(card_number: str) -> str:
    # Strip spaces and dashes
    clean_card = card_number.replace(" ", "").replace("-", "")
    if len(clean_card) < 12:
        return "INVALID_CARD"
    # Keep last 4 digits visible, mask preceding with '*'
    last_four = clean_card[-4:]
    masked_prefix = "*" * (len(clean_card) - 4)
    # Group in blocks of 4 for presentation
    full_masked = masked_prefix + last_four
    return " ".join([full_masked[i:i+4] for i in range(0, len(full_masked), 4)])

def mask_email(email: str) -> str:
    if "@" not in email:
        return email
    user, domain = email.split("@", 1)
    if len(user) <= 2:
        masked_user = user[0] + "*"
    else:
        masked_user = user[0] + "*" * (len(user) - 2) + user[-1]
    return f"{masked_user}@{domain}"

print("Masked Card :", mask_credit_card("4532-7590-1234-8892"))
print("Masked Email:", mask_email("alexander.graham@telecom.org"))
```

**Step-by-Step Explanation**:
1. `clean_card[-4:]` extracts the last 4 digits via negative slicing.
2. `masked_prefix = "*" * (len(...) - 4)` dynamically calculates the masking length.
3. Slicing with step in list comprehension blocks digits into groups of 4.

**Expected Console Output**:
```text
Masked Card : **** **** **** 8892
Masked Email: a**************m@telecom.org
```

### Example 2: Palindrome Detection and DNA Sequence Inversion
Verify palindromic words and generate reverse-complementary genetic DNA sequences using slicing.

```python
def is_palindrome(text: str) -> bool:
    # Clean text: keep alphanumeric and lowercase
    cleaned = "".join(ch.lower() for ch in text if ch.isalnum())
    # Compare forward string with sliced reverse [::-1]
    return cleaned == cleaned[::-1]

def reverse_dna_strand(dna_strand: str) -> str:
    # Reverse string with step -1
    return dna_strand.upper()[::-1]

phrase_1 = "A man, a plan, a canal: Panama"
phrase_2 = "Artificial Intelligence"

print(f"Is '{phrase_1}' a palindrome? {is_palindrome(phrase_1)}")
print(f"Is '{phrase_2}' a palindrome? {is_palindrome(phrase_2)}")

dna = "ATGCGATCGG"
print(f"Original DNA: {dna} -> Reversed DNA: {reverse_dna_strand(dna)}")
```

**Step-by-Step Explanation**:
1. `cleaned[::-1]` creates a reversed copy of the string in $O(n)$ time.
2. Compares standard and reversed strings directly for palindrome validation.

**Expected Console Output**:
```text
Is 'A man, a plan, a canal: Panama' a palindrome? True
Is 'Artificial Intelligence' a palindrome? False
Original DNA: ATGCGATCGG -> Reversed DNA: GGCTAGCGTA
```

### Example 3: Binary Packet Header Field Extractor
Parse a fixed-width mainframe telecommunications packet string using multi-segment slice extraction.

```python
def parse_fixed_width_packet(packet_record: str) -> dict:
    # Packet Specification:
    # Bytes 00-03: Packet ID (4 chars)
    # Bytes 04-11: Timestamp YYYYMMDD (8 chars)
    # Bytes 12-14: Currency ISO Code (3 chars)
    # Bytes 15-24: Amount in Cents (10 chars, right-aligned)
    # Bytes 25-26: Status Code (2 chars)
    
    packet_id = packet_record[0:4]
    raw_date  = packet_record[4:12]
    currency  = packet_record[12:15]
    raw_cents = packet_record[15:25]
    status    = packet_record[25:27]
    
    formatted_date = f"{raw_date[:4]}-{raw_date[4:6]}-{raw_date[6:8]}"
    amount_dollars = int(raw_cents) / 100.0
    
    return {
        "packet_id": packet_id,
        "date": formatted_date,
        "currency": currency,
        "amount": f"${amount_dollars:,.2f}",
        "status": status
    }

raw_data = "PK0120260914USD0000145950OK"
parsed = parse_fixed_width_packet(raw_data)

print("Parsed Fixed-Width Header:")
for key, value in parsed.items():
    print(f"  {key:<12}: {value}")
```

**Step-by-Step Explanation**:
1. Fixed-width protocols rely on rigid positional slicing.
2. Extracts contiguous character slices without regex overhead, achieving microsecond parse times.

**Expected Console Output**:
```text
Parsed Fixed-Width Header:
  packet_id   : PK01
  date        : 2026-09-14
  currency    : USD
  amount      : $1,459.50
  status      : OK
```
