# 04. The Boolean (`bool`) Data Type

## 📖 Concept Overview
In Python, **booleans (`bool`)** represent truth values: **`True`** or **`False`**.

---

### 1. Booleans as Subclasses of Integers
In Python, `bool` is explicitly a subclass of `int`:
```python
print(issubclass(bool, int))  # True
print(int(True))               # 1
print(int(False))              # 0
print(True + True + False)     # 2
```
Because `True == 1` and `False == 0`, booleans inherit all integer methods, though they should primarily be used for logical branching.

---

### 2. Comprehensive Truthiness / Falsiness Matrix
Any Python object can be tested for truth value (using `bool(x)` or inside an `if`/`while` condition).

#### Falsy Values (Evaluate to `False`):
- Constants: `None` and `False`.
- Zero of any numeric type: `0`, `0.0`, `0j`, `Decimal(0)`.
- Empty sequences and collections: `""` (empty string), `()` (empty tuple), `[]` (empty list), `{}` (empty dict), `set()` (empty set), `range(0)`.
- Custom objects defining `__bool__()` or `__len__()` that return `False` or `0`.

#### Truthy Values (Evaluate to `True`):
- **Every other object in Python is truthy!**
- Non-empty strings (including `"False"` and `"0"`!).
- Non-zero numbers (`-1`, `3.14`).
- Non-empty collections (`[0]`, `(False,)`).

---

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Streamlined Pythonic Truthiness Evaluation
Eliminate redundant comparison checks (`len(x) > 0` or `x == True`) by evaluating collections and booleans directly.

```python
def process_work_queue(queue: list[str], is_maintenance_window: bool):
    # Non-Pythonic: if len(queue) > 0 and is_maintenance_window == True:
    # Pythonic Truthiness:
    if queue and not is_maintenance_window:
        print(f"Processing {len(queue)} pending item(s)...")
        while queue:
            task = queue.pop(0)
            print(f"  -> Finished: {task}")
    else:
        print("Queue is empty or system is in maintenance mode. Standing by.")

process_work_queue(["Backup DB", "Sync Users"], is_maintenance_window=False)
process_work_queue([], is_maintenance_window=False)
```

**Step-by-Step Explanation**:
1. `if queue:` implicitly evaluates `bool(queue)`, returning `False` when the list is empty.
2. `while queue:` runs until all items are popped, terminating cleanly when empty.

**Expected Console Output**:
```text
Processing 2 pending item(s)...
  -> Finished: Backup DB
  -> Finished: Sync Users
Queue is empty or system is in maintenance mode. Standing by.
```

### Example 2: Short-Circuit Chaining Fallback Value Resolver
Use `and` and `or` boolean short-circuit evaluation to establish safe defaults.

```python
def resolve_display_settings(user_theme: str | None, system_theme: str, default: str = "light") -> str:
    # Short-circuits to the first non-empty / truthy string!
    active_theme = (user_theme and user_theme.strip()) or system_theme or default
    return active_theme

print("Test 1 (User Theme Set)   :", resolve_display_settings("dark", "system-dark"))
print("Test 2 (User Theme Empty) :", resolve_display_settings("", "system-contrast"))
print("Test 3 (All Fallbacks)    :", resolve_display_settings(None, ""))
```

**Step-by-Step Explanation**:
1. If `user_theme` is truthy and non-empty, evaluation returns it immediately.
2. If falsy, it proceeds to evaluate `system_theme`, then `default`.

**Expected Console Output**:
```text
Test 1 (User Theme Set)   : dark
Test 2 (User Theme Empty) : system-contrast
Test 3 (All Fallbacks)    : light
```

### Example 3: Custom Domain Truthiness Implementation (`__bool__`)
Define a shopping cart that evaluates to `True` only if it contains items and meets a minimum checkout spending threshold.

```python
class CheckoutCart:
    def __init__(self, min_order_val: float = 25.0):
        self.min_order = min_order_val
        self.items: dict[str, float] = {}

    def add_item(self, item: str, price: float):
        self.items[item] = price

    def __bool__(self) -> bool:
        # Cart is truthy only if it contains items AND total meets minimum order
        return len(self.items) > 0 and sum(self.items.values()) >= self.min_order

cart = CheckoutCart(min_order_val=25.0)
print(f"Empty Cart Truthiness : {bool(cart)}")

cart.add_item("USB Hub", 15.0)
print(f"Cart with $15.00 Total: {bool(cart)} (Under $25 minimum)")

cart.add_item("Mousepad", 12.0)
print(f"Cart with $27.00 Total: {bool(cart)} (Meets criteria!)")

if cart:
    print("-> Checkout Permitted: Ready to charge customer.")
```

**Step-by-Step Explanation**:
1. Custom classes can define `__bool__()` to implement domain-specific business validation rules.
2. In an `if cart:` branch, Python invokes `cart.__bool__()` automatically.

**Expected Console Output**:
```text
Empty Cart Truthiness : False
Cart with $15.00 Total: False (Under $25 minimum)
Cart with $27.00 Total: True (Meets criteria!)
-> Checkout Permitted: Ready to charge customer.
```
