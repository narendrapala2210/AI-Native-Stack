# 12. Dictionary Methods & Nested Dictionaries

## 📖 Concept Overview
Python dictionaries provide built-in methods for managing key lifecycles, merging datasets, and safely populating defaults. Furthermore, dictionaries can be nested within one another to model complex hierarchical data (e.g. JSON payloads).

---

### 1. Essential Dictionary Methods
- **`d.update(iterable)`**: Inserts or overwrites items from another dictionary or iterable of key-value pairs.
- **`d.pop(key[, default])`**: Removes `key` and returns its value. If absent, returns `default` or raises `KeyError`.
- **`d.popitem()`**: Removes and returns the last inserted `(key, value)` pair in LIFO order ($O(1)$).
- **`d.setdefault(key, default)`**: If `key` exists, returns its value. If not, sets `d[key] = default` and returns `default`.
- **`d.clear()`**: Removes all elements from the dictionary.
- **`d.copy()`**: Returns a shallow copy.

---

### 2. Nested Dictionaries (JSON-Style Hierarchies)
A nested dictionary has another dictionary as its value. This represents parent-child relationships common in REST APIs, configuration files, and NoSQL databases:
```python
company = {
    "org_name": "CloudScale",
    "departments": {
        "engineering": {
            "head": "Sarah",
            "headcount": 42
        },
        "sales": {
            "head": "Mark",
            "headcount": 18
        }
    }
}

# Deep access
print(company["departments"]["engineering"]["head"])  # Sarah
```

---

## 📋 Summary & Methods Reference

| Method | Syntax | Description |
| :--- | :--- | :--- |
| `update()` | `d.update({"k2": v2})` | Merges keys in-place; overwrites duplicates. |
| `setdefault()` | `d.setdefault(k, [])` | Inserts key with default only if key is not yet present. |
| `pop()` | `val = d.pop(k, None)` | Removes key and returns value safely. |
| `popitem()` | `k, v = d.popitem()` | Removes and returns last inserted key-value pair. |
| **Dictionary Merge (`\|`)**| `merged = d1 \| d2` | Python 3.9+ dictionary union operator. |

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Grouping Data Efficiently with `setdefault()`
Group employees into departments from a raw tabular list without checking whether department keys already exist.

```python
def group_employees_by_department(records: list[tuple[str, str]]):
    department_roster: dict[str, list[str]] = {}
    
    for dept, employee in records:
        # setdefault initializes an empty list if dept is not present,
        # then returns the list reference to which we immediately append!
        department_roster.setdefault(dept, []).append(employee)
        
    return department_roster

data_feed = [
    ("Engineering", "Alice"),
    ("Marketing", "Bob"),
    ("Engineering", "Charlie"),
    ("HR", "Diana"),
    ("Engineering", "Evan"),
    ("Marketing", "Fiona")
]

roster = group_employees_by_department(data_feed)
print("Department Roster Groupings:")
for dept, staff in roster.items():
    print(f"  {dept:<14} ({len(staff)} staff): {', '.join(staff)}")
```

**Step-by-Step Explanation**:
1. Without `setdefault()`, one must check `if dept not in roster: roster[dept] = []`.
2. `setdefault(dept, []).append(employee)` handles existence checking and initialization atomically in a single line.

**Expected Console Output**:
```text
Department Roster Groupings:
  Engineering    (3 staff): Alice, Charlie, Evan
  Marketing      (2 staff): Bob, Fiona
  HR             (1 staff): Diana
```

### Example 2: Deep Nested Dictionary Query & Safe Path Resolver
Implement a safe path resolver function (similar to `lodash.get`) to traverse deep nested JSON objects without raising `KeyError` or `TypeError`.

```python
def safe_nested_get(data: dict, path: str, default: any = None) -> any:
    # Path format: 'user.profile.address.city'
    keys = path.split(".")
    current = data
    
    for key in keys:
        if isinstance(current, dict) and key in current:
            current = current[key]
        else:
            return default
            
    return current

api_payload = {
    "user": {
        "id": 8842,
        "profile": {
            "name": "David",
            "contact": {
                "email": "david@cloud.org",
                "phone": "+1-555-0199"
            }
        }
    }
}

# 1. Existing deep path
email = safe_nested_get(api_payload, "user.profile.contact.email")
print(f"Found Email: {email}")

# 2. Non-existent deep path
city = safe_nested_get(api_payload, "user.profile.address.city", default="Unknown City")
print(f"Found City : {city}")
```

**Step-by-Step Explanation**:
1. Traditional deep indexing `api_payload["user"]["profile"]["address"]["city"]` crashes with `KeyError: 'address'`.
2. The traversal verifies `isinstance(current, dict) and key in current` at every level, returning the specified default if broken.

**Expected Console Output**:
```text
Found Email: david@cloud.org
Found City : Unknown City
```

### Example 3: Python 3.9+ Dictionary Merge and Deep Configuration Override
Combine default application settings with user-specified runtime overrides using the modern dictionary merge operator (`|` and `|=`).

```python
def build_runtime_environment(base_defaults: dict, user_overrides: dict) -> dict:
    print("=== Configuration Merge Simulation (PEP 584) ===")
    
    # Using Python 3.9+ merge operator (|)
    # Right-hand side values overwrite left-hand side values on key collision
    merged_config = base_defaults | user_overrides
    
    return merged_config

default_settings = {
    "theme": "dark",
    "font_size": 14,
    "autosave_interval_sec": 300,
    "enable_telemetry": True,
    "cache_dir": "/tmp/cache"
}

user_preferences = {
    "font_size": 16,             # Overwrite default 14
    "enable_telemetry": False,    # Overwrite default True
    "custom_plugin": "vim-mode"   # New key added
}

final_env = build_runtime_environment(default_settings, user_preferences)

print("Resolved Runtime Settings:")
for k, v in final_env.items():
    print(f"  {k:<24}: {v}")
```

**Step-by-Step Explanation**:
1. PEP 584 introduced `|` (merge) and `|=` (update) for dictionaries in Python 3.9.
2. If keys collide, values from the right operand (`user_preferences`) overwrite values from the left (`default_settings`).

**Expected Console Output**:
```text
=== Configuration Merge Simulation (PEP 584) ===
Resolved Runtime Settings:
  theme                   : dark
  font_size               : 16
  autosave_interval_sec   : 300
  enable_telemetry        : False
  cache_dir               : /tmp/cache
  custom_plugin           : vim-mode
```
