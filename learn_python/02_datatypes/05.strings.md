# 05. The String (`str`) Data Type

## 📖 Concept Overview
In Python, a **String (`str`)** is an immutable sequence of Unicode characters.

---

### 1. Immutability & Memory Model
Strings in Python are strictly **immutable**. Once created in memory, characters cannot be modified, replaced, or deleted in-place:
```python
s = "sea you soon"
# Attempting in-place mutation raises TypeError:
s[2] = "e"  # TypeError: 'str' object does not support item assignment
```
To "modify" a string, a new string object must be constructed via slicing and concatenation.

---

### 2. Indexing & Slicing: `[start:stop:step]`
- **Positive Indexing**: `0` to `len(s) - 1` (left-to-right).
- **Negative Indexing**: `-1` to `-len(s)` (right-to-left).
- **Slicing**: `s[start:stop:step]` extracts substrings up to but not including `stop`.
- **Reverse Slicing**: `s[::-1]` creates a reversed copy.

---

### 3. String Formatting Systems
1. **Old Style (`%`)**: `"Name: %s, Age: %d" % ("Alex", 25)`
2. **`str.format()`**: `"Hello {}, you have {} messages".format(user, count)`
3. **F-Strings (PEP 498 & PEP 701)**: `f"Result: {val:.2f}, Aligned: {name:<10}"`

## 🛠️ Complete Catalog of ALL Built-in String Methods

Python strings provide **47 built-in methods**. Every method returns a new string, boolean, list, or integer without modifying the original object:

### 1. Case Conversion Methods
| Method | Syntax | Description & Example |
| :--- | :--- | :--- |
| **`capitalize()`** | `s.capitalize()` | Capitalizes the first character and lowercases the rest.<br>`'python'.capitalize()` -> `'Python'`. |
| **`casefold()`** | `s.casefold()` | Aggressive lowercase conversion for caseless matching (handles German 'ß' -> 'ss').<br>`'MASSE'.casefold()` -> `'masse'`. |
| **`lower()`** | `s.lower()` | Converts all characters to lowercase.<br>`'HELLO'.lower()` -> `'hello'`. |
| **`upper()`** | `s.upper()` | Converts all characters to uppercase.<br>`'hello'.upper()` -> `'HELLO'`. |
| **`title()`** | `s.title()` | Capitalizes the first letter of every word.<br>`'hello world'.title()` -> `'Hello World'`. |
| **`swapcase()`** | `s.swapcase()` | Inverts uppercase characters to lowercase and vice versa.<br>`'PyThOn'.swapcase()` -> `'pYtHoN'`. |

### 2. Searching & Finding Methods
| Method | Syntax | Description & Example |
| :--- | :--- | :--- |
| **`find()`** | `s.find(sub[, start[, end]])` | Returns lowest index of `sub`, or **`-1`** if not found.<br>`'hello'.find('l')` -> `2`. |
| **`rfind()`** | `s.rfind(sub[, start[, end]])` | Returns highest index of `sub`, or **`-1`** if not found.<br>`'hello'.rfind('l')` -> `3`. |
| **`index()`** | `s.index(sub[, start[, end]])` | Like `find()`, but raises **`ValueError`** if `sub` is absent. |
| **`rindex()`** | `s.rindex(sub[, start[, end]])` | Like `rfind()`, but raises **`ValueError`** if `sub` is absent. |
| **`count()`** | `s.count(sub[, start[, end]])` | Counts non-overlapping occurrences of `sub`.<br>`'banana'.count('an')` -> `2`. |

### 3. Verification & Character Testing Methods (Return `bool`)
| Method | Syntax | Returns `True` If: |
| :--- | :--- | :--- |
| **`isalnum()`** | `s.isalnum()` | All characters are alphanumeric (`a-z`, `A-Z`, `0-9`) and string is non-empty. |
| **`isalpha()`** | `s.isalpha()` | All characters are alphabetic letters (`a-z`, `A-Z`). |
| **`isascii()`** | `s.isascii()` | All characters are ASCII characters ($0-127$). |
| **`isdecimal()`** | `s.isdecimal()` | All characters are decimal characters ($0-9$). |
| **`isdigit()`** | `s.isdigit()` | All characters are digits (includes superscripts like ²). |
| **`isnumeric()`** | `s.isnumeric()` | All characters are numeric (includes fractions like ½). |
| **`isidentifier()`** | `s.isidentifier()` | String is a valid Python variable/identifier name. |
| **`islower()`** | `s.islower()` | All cased characters are lowercase. |
| **`isupper()`** | `s.isupper()` | All cased characters are uppercase. |
| **`isspace()`** | `s.isspace()` | All characters are whitespace (`' '`, `'\t'`, `'\n'`). |
| **`istitle()`** | `s.istitle()` | String is titlecased. |
| **`isprintable()`** | `s.isprintable()` | All characters are printable (not control characters). |
| **`startswith()`** | `s.startswith(prefix)` | String starts with `prefix` (can be a tuple of prefixes). |
| **`endswith()`** | `s.endswith(suffix)` | String ends with `suffix` (can be a tuple of suffixes). |

### 4. Stripping & Trimming Methods
| Method | Syntax | Description & Example |
| :--- | :--- | :--- |
| **`strip()`** | `s.strip([chars])` | Strips leading and trailing characters (defaults to whitespace). |
| **`lstrip()`** | `s.lstrip([chars])` | Strips leading characters from the left. |
| **`rstrip()`** | `s.rstrip([chars])` | Strips trailing characters from the right. |
| **`removeprefix()`** | `s.removeprefix(p)` | Python 3.9+ removes prefix `p` if present.<br>`'test.py'.removeprefix('test.')` -> `'py'`. |
| **`removesuffix()`** | `s.removesuffix(s)` | Python 3.9+ removes suffix `s` if present.<br>`'script.py'.removesuffix('.py')` -> `'script'`. |

### 5. Alignment & Padding Methods
| Method | Syntax | Description & Example |
| :--- | :--- | :--- |
| **`center()`** | `s.center(width[, fill])` | Centers string within `width`, padded by `fill`.<br>`'hi'.center(6, '-')` -> `'--hi--'`. |
| **`ljust()`** | `s.ljust(width[, fill])` | Left-justifies string within `width`.<br>`'hi'.ljust(5, '.')` -> `'hi...'`. |
| **`rjust()`** | `s.rjust(width[, fill])` | Right-justifies string within `width`.<br>`'hi'.rjust(5, '.')` -> `'...hi'`. |
| **`zfill()`** | `s.zfill(width)` | Pads string on left with ASCII zeros `'0'`.<br>`'42'.zfill(5)` -> `'00042'`. |

### 6. Splitting & Joining Methods
| Method | Syntax | Description & Example |
| :--- | :--- | :--- |
| **`split()`** | `s.split(sep=None, maxsplit=-1)` | Splits string into list of strings by delimiter. |
| **`rsplit()`** | `s.rsplit(sep=None, maxsplit=-1)` | Splits from right side up to `maxsplit` times. |
| **`splitlines()`** | `s.splitlines([keepends])` | Splits string at line boundaries (`\n`, `\r\n`). |
| **`join()`** | `sep.join(iterable)` | Joins iterable of strings using `sep` as delimiter. |
| **`partition()`** | `s.partition(sep)` | Splits at first occurrence into 3-tuple `(before, sep, after)`. |
| **`rpartition()`** | `s.rpartition(sep)` | Splits at last occurrence into 3-tuple `(before, sep, after)`. |

### 7. Translation & Replacement Methods
| Method | Syntax | Description & Example |
| :--- | :--- | :--- |
| **`replace()`** | `s.replace(old, new[, count])` | Replaces occurrences of `old` with `new`. |
| **`maketrans()`** | `str.maketrans(x[, y[, z]])` | Static method creating a mapping translation table. |
| **`translate()`** | `s.translate(table)` | Translates characters using mapping table from `maketrans()`. |
| **`encode()`** | `s.encode(encoding='utf-8')` | Encodes string into `bytes` object. |
| **`expandtabs()`** | `s.expandtabs(tabsize=8)` | Replaces tab characters with spaces. |
| **`format()`** | `s.format(*args, **kwargs)` | Formats string using positional and named placeholders. |
| **`format_map()`** | `s.format_map(mapping)` | Formats string directly from mapping dictionary. |

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Web URL Query String Parser & Component Extractor
Parse complex URL strings using `partition()`, `removeprefix()`, and `split()` to extract domain, route path, and query parameters.

```python
def parse_url_components(url: str) -> dict:
    # 1. Strip protocol
    clean_url = url
    for proto in ("https://", "http://"):
        clean_url = clean_url.removeprefix(proto)
        
    # 2. Partition host from path
    host, slash, rest = clean_url.partition("/")
    path, question, query_string = rest.partition("?")
    
    # 3. Parse query parameters
    params = {}
    if query_string:
        for pair in query_string.split("&"):
            k, eq, v = pair.partition("=")
            params[k] = v
            
    return {
        "host": host,
        "path": "/" + path,
        "params": params
    }

raw_url = "https://api.cloudmetrics.io/v2/telemetry/query?sensor_id=884&region=us-east&active=true"
parsed = parse_url_components(raw_url)

print("Parsed URL Components:")
print(f"  Host   : {parsed['host']}")
print(f"  Path   : {parsed['path']}")
print(f"  Params : {parsed['params']}")
```

**Step-by-Step Explanation**:
1. `removeprefix("https://")` removes leading protocol cleanly.
2. `partition("/")` guarantees a 3-tuple split even if `/` is missing.
3. Chained parsing separates parameters into a structured dictionary.

**Expected Console Output**:
```text
Parsed URL Components:
  Host   : api.cloudmetrics.io
  Path   : /v2/telemetry/query
  Params : {'sensor_id': '884', 'region': 'us-east', 'active': 'true'}
```

### Example 2: Fast Text Sanitizer using `maketrans()` & `translate()`
Scrub punctuation and mask numeric digits from sensitive text at compiled C speed.

```python
import string

def create_high_speed_scrubber():
    # Map all punctuation to spaces, and digits to '#'
    punct = string.punctuation
    digits = string.digits
    
    trans_table = str.maketrans(
        punct + digits,
        " " * len(punct) + "#" * len(digits)
    )
    
    def sanitize(text: str) -> str:
        scrubbed = text.translate(trans_table)
        # Collapse multi-space runs
        return " ".join(scrubbed.split())
        
    return sanitize

scrubber = create_high_speed_scrubber()
dirty_input = "Alert! Client ID: [ACC-9842] submitted credit card 4532-1209 at 12:45 PM."
sanitized = scrubber.sanitize(dirty_input)

print(f"Original Input : {dirty_input}")
print(f"Sanitized Text : {sanitized}")
```

**Step-by-Step Explanation**:
1. `str.maketrans()` builds an optimized 256-entry character mapping table in C.
2. `text.translate()` executes character replacements in a single compiled pass.

**Expected Console Output**:
```text
Original Input : Alert! Client ID: [ACC-9842] submitted credit card 4532-1209 at 12:45 PM.
Sanitized Text : Alert Client ID ACC #### submitted credit card #### #### at ## ## PM
```

### Example 3: Text Aligner & Pretty Console Table Generator
Format tabular text using `ljust()`, `rjust()`, `center()`, and `zfill()` methods.

```python
def render_inventory_table(products: list[tuple[int, str, float, int]]):
    divider = "+" + "-" * 8 + "+" + "-" * 22 + "+" + "-" * 12 + "+" + "-" * 8 + "+"
    print(divider)
    print(f"|{'SKU':^8}|{'Product Description':^22}|{'Unit Price':^12}|{'Qty':^8}|")
    print(divider)
    
    for sku, desc, price, qty in products:
        sku_str = str(sku).zfill(6).center(8)
        desc_str = (" " + desc).ljust(22)
        price_str = f"${price:,.2f}".rjust(10) + " "
        qty_str = str(qty).rjust(6) + " "
        print(f"|{sku_str}|{desc_str}|{price_str}|{qty_str}|")
        
    print(divider)

sample_data = [
    (14, "Wireless Mouse", 29.99, 45),
    (102, "4K Monitor 27in", 349.50, 8),
    (9, "USB-C Fast Cable", 12.00, 150)
]

render_inventory_table(sample_data)
```

**Step-by-Step Explanation**:
1. `zfill(6)` pads numeric SKU IDs with leading zeroes (`000014`).
2. `ljust()`, `rjust()`, and `center()` produce pixel-perfect console alignments.

**Expected Console Output**:
```text
+--------+----------------------+------------+--------+
|  SKU   | Product Description  | Unit Price |  Qty   |
+--------+----------------------+------------+--------+
| 000014 | Wireless Mouse       |     $29.99 |     45 |
| 000102 | 4K Monitor 27in      |    $349.50 |      8 |
| 000009 | USB-C Fast Cable     |     $12.00 |    150 |
+--------+----------------------+------------+--------+
```
