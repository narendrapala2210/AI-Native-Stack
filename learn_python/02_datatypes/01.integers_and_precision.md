# 01. Integers & Arbitrary Precision Arithmetic

## 📖 Concept Overview
In Python, integers (`int`) represent whole numbers—positive, negative, or zero—without fractional components.

### 1. Arbitrary Precision (Unlimited Magnitude)
Unlike languages such as C, C++, or Java where integers are constrained to fixed memory sizes (e.g. 32-bit: $-2^{31}$ to $2^{31}-1$, 64-bit: $-2^{63}$ to $2^{63}-1$), **Python 3 integers have arbitrary precision**.
Python automatically allocates as many bytes of memory as necessary to represent any integer value, limited solely by host machine RAM. There is zero risk of integer overflow:
```python
# 100 factorial is computed effortlessly without overflow
import math
print(math.factorial(100))
```

### 2. Number Bases: Binary, Octal, Hexadecimal
Python supports alternate number representations using distinct prefixes:
- **Binary (base 2)**: Prefix `0b` or `0B` (e.g., `0b1010` -> `10`)
- **Octal (base 8)**: Prefix `0o` or `0O` (e.g., `0o12` -> `10`)
- **Hexadecimal (base 16)**: Prefix `0x` or `0X` (e.g., `0x1F` -> `31`)

### 3. Small Integer Caching (Interning)
CPython optimizes memory allocation by pre-allocating an array of integer objects in the range **`-5` to `256`** at startup. Whenever an integer in this range is assigned, Python returns a reference to the existing singleton object:
```python
x = 250
y = 250
print(x is y)  # True (same memory identity)

a = 1000
b = 1000
print(a is b)  # False (distinct objects in separate memory addresses)
```

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Arbitrary Precision Astronomical Scale Calculations
Calculate astronomical distances and particle counts where standard 64-bit integer variables in other languages would catastrophically overflow.

```python
import sys

def compute_astronomical_metrics():
    # Number of atoms in observable universe (~ 10^80)
    atoms_in_universe = 10 ** 80
    
    # Square of atoms (10^160)
    super_large_number = atoms_in_universe ** 2
    
    print("=== Arbitrary Precision Integer Metric ===")
    print(f"Number of digits: {len(str(super_large_number))}")
    print(f"Memory allocated by Python: {sys.getsizeof(super_large_number)} bytes")
    print(f"First 20 digits: {str(super_large_number)[:20]}...")
    print(f"Last 10 digits: ...{str(super_large_number)[-10:]}")

compute_astronomical_metrics()
```

**Step-by-Step Explanation**:
1. `10 ** 80` produces an 81-digit number far exceeding standard 64-bit integer limits ($~1.84 \times 10^{19}$).
2. Squaring it produces a 161-digit number.
3. `sys.getsizeof()` verifies Python dynamically scales the underlying C array of digits.

**Expected Console Output**:
```text
=== Arbitrary Precision Integer Metric ===
Number of digits: 161
Memory allocated by Python: 100 bytes
First 20 digits: 10000000000000000000...
Last 10 digits: ...0000000000
```

### Example 2: Bitmask Role-Based Access Control (RBAC) System
Use integer bitwise flags to store and verify multiple user permission states in a single compact integer.

```python
class Permissions:
    READ    = 0b0001  # 1
    WRITE   = 0b0010  # 2
    EXECUTE = 0b0100  # 4
    ADMIN   = 0b1000  # 8

def check_permission(user_mask: int, required_perm: int) -> bool:
    # Bitwise AND checks if the permission bit is set
    return (user_mask & required_perm) == required_perm

def grant_permission(user_mask: int, new_perm: int) -> int:
    # Bitwise OR sets the permission bit
    return user_mask | new_perm

def revoke_permission(user_mask: int, remove_perm: int) -> int:
    # Bitwise AND with NOT clears the bit
    return user_mask & ~remove_perm

# Create a user with READ and WRITE permissions
user_roles = Permissions.READ | Permissions.WRITE
print(f"Initial Permission Mask: {bin(user_roles)} (Decimal: {user_roles})")

print("Has READ access?   :", check_permission(user_roles, Permissions.READ))
print("Has EXECUTE access?:", check_permission(user_roles, Permissions.EXECUTE))

# Grant EXECUTE access
user_roles = grant_permission(user_roles, Permissions.EXECUTE)
print(f"After Granting EXECUTE: {bin(user_roles)}")
print("Has EXECUTE access now?:", check_permission(user_roles, Permissions.EXECUTE))
```

**Step-by-Step Explanation**:
1. Uses binary integer literals (`0b0001`, `0b0010`, etc.) to define bit flags.
2. Combines flags with bitwise OR (`|`).
3. Validates permissions with bitwise AND (`&`) and clears permissions with bitwise NOT (`~`).

**Expected Console Output**:
```text
Initial Permission Mask: 0b11 (Decimal: 3)
Has READ access?   : True
Has EXECUTE access?: False
After Granting EXECUTE: 0b111
Has EXECUTE access now?: True
```

### Example 3: Radix Base Parsing and Hex Color Converter
Convert hexadecimal web color codes into integer RGB components, and format integer color channels back to CSS hex strings.

```python
def hex_to_rgb(hex_code: str) -> tuple[int, int, int]:
    # Strip leading '#'
    hex_clean = hex_code.lstrip("#")
    
    # Parse two characters at a time with base 16
    r = int(hex_clean[0:2], 16)
    g = int(hex_clean[2:4], 16)
    b = int(hex_clean[4:6], 16)
    return (r, g, b)

def rgb_to_hex(r: int, g: int, b: int) -> str:
    # Format integers as 2-digit uppercase hexadecimal strings
    return f"#{r:02X}{g:02X}{b:02X}"

sample_color = "#3498DB"
rgb = hex_to_rgb(sample_color)
print(f"Hex '{sample_color}' -> RGB Tuple: {rgb}")

reconstructed_hex = rgb_to_hex(*rgb)
print(f"RGB {rgb} -> Reconstructed Hex: '{reconstructed_hex}'")
```

**Step-by-Step Explanation**:
1. `int(string, 16)` converts hexadecimal byte strings into decimal integers ($0-255$).
2. Slices two hex digits representing Red, Green, and Blue channels.
3. `rgb_to_hex` uses formatting specifier `:02X` to zero-pad hex strings to 2 uppercase digits.

**Expected Console Output**:
```text
Hex '#3498DB' -> RGB Tuple: (52, 152, 219)
RGB (52, 152, 219) -> Reconstructed Hex: '#3498DB'
```
