# 01. The Integer (`int`) Data Type

## 📖 Concept Overview
In Python, **integers (`int`)** represent whole numbers—positive, negative, or zero—without fractional components.

---

### 1. Arbitrary Precision (Unlimited Magnitude)
Unlike low-level languages (such as C or Java) where integers are constrained to 32-bit ($-2^{31}$ to $2^{31}-1$) or 64-bit ($-2^{63}$ to $2^{63}-1$) boundaries, **Python 3 integers have arbitrary precision**.
Python dynamically allocates memory to represent numbers of any size, limited only by available system RAM:
```python
import math
# Computes 100! effortlessly without integer overflow:
huge_val = math.factorial(100)
print(f"100! has {len(str(huge_val))} digits.")
```

---

### 2. Number Bases: Binary, Octal & Hexadecimal
Python supports integer literals in multiple numerical bases using specific prefixes:
- **Binary (base 2)**: Prefix `0b` or `0B` (e.g. `0b1010` -> `10`)
- **Octal (base 8)**: Prefix `0o` or `0O` (e.g. `0o12` -> `10`)
- **Hexadecimal (base 16)**: Prefix `0x` or `0X` (e.g. `0x1F` -> `31`)

To convert an integer into its string base representation:
- `bin(x)` -> `'0b...'`
- `oct(x)` -> `'0o...'`
- `hex(x)` -> `'0x...'`

---

### 3. Small Integer Interning Cache
CPython pre-allocates and caches integer objects in the range **`-5` to `256`** during interpreter startup. Whenever an integer in this range is used, Python reuses the existing singleton object from memory:
```python
a = 250
b = 250
print(a is b)  # True (same memory identity)

x = 1000
y = 1000
print(x is y)  # False (distinct objects in separate memory blocks)
```

## 🛠️ Complete Catalog of Built-in Integer Methods

| Method | Syntax | Description & Example |
| :--- | :--- | :--- |
| **`bit_length()`** | `n.bit_length()` | Returns number of bits necessary to represent `n` in binary.<br>`(16).bit_length()` -> `5` (`0b10000`). |
| **`bit_count()`** | `n.bit_count()` | Returns the number of ones (popcount) in binary representation of $\|n\|$.<br>`(19).bit_count()` -> `3` (`0b10011`). |
| **`to_bytes()`** | `n.to_bytes(length, byteorder, *, signed=False)` | Converts integer to an array of bytes.<br>`(1024).to_bytes(2, byteorder='big')` -> `b'\x04\x00'`. |
| **`from_bytes()`** | `int.from_bytes(bytes, byteorder, *, signed=False)` | Classmethod parsing byte array back into integer.<br>`int.from_bytes(b'\x04\x00', 'big')` -> `1024`. |
| **`as_integer_ratio()`** | `n.as_integer_ratio()` | Returns tuple `(n, 1)` representing the exact rational ratio.<br>`(42).as_integer_ratio()` -> `(42, 1)`. |

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Arbitrary Precision Astronomical Scale Calculations
Calculate astronomical numbers where 64-bit integer variables in other languages would overflow.

```python
import sys

def compute_astronomical_metrics():
    # Estimated atoms in observable universe (~ 10^80)
    atoms_in_universe = 10 ** 80
    super_large_number = atoms_in_universe ** 2
    
    print("=== Arbitrary Precision Integer Metric ===")
    print(f"Number of digits: {len(str(super_large_number))}")
    print(f"Memory allocated by Python: {sys.getsizeof(super_large_number)} bytes")
    print(f"Bit length required: {super_large_number.bit_length()} bits")
    print(f"First 20 digits: {str(super_large_number)[:20]}...")

compute_astronomical_metrics()
```

**Step-by-Step Explanation**:
1. `10 ** 80` produces an 81-digit number exceeding standard $2^{64}-1$ limits.
2. `super_large_number.bit_length()` computes exact binary width required ($532$ bits).
3. `sys.getsizeof()` verifies Python dynamically scales internal memory buffers.

**Expected Console Output**:
```text
=== Arbitrary Precision Integer Metric ===
Number of digits: 161
Memory allocated by Python: 100 bytes
Bit length required: 532 bits
First 20 digits: 10000000000000000000...
```

### Example 2: Binary Serialization with `to_bytes()` and `from_bytes()`
Serialize integer numbers into compact network byte streams (big-endian and little-endian) and reconstruct them.

```python
def serialize_network_packet_id(packet_id: int):
    # Pack integer into 4 bytes (32-bit unsigned), Big-Endian network order
    network_bytes = packet_id.to_bytes(4, byteorder="big", signed=False)
    
    # Also generate Little-Endian (x86 CPU native)
    cpu_bytes = packet_id.to_bytes(4, byteorder="little", signed=False)
    
    print(f"Original ID : {packet_id}")
    print(f"Big-Endian  : {network_bytes} (Hex: {network_bytes.hex()})")
    print(f"Little-Endian: {cpu_bytes} (Hex: {cpu_bytes.hex()})")
    
    # Reconstruct from bytes
    restored_id = int.from_bytes(network_bytes, byteorder="big", signed=False)
    print(f"Restored ID : {restored_id} (Matches? {restored_id == packet_id})")

serialize_network_packet_id(45290)
```

**Step-by-Step Explanation**:
1. `packet_id.to_bytes(4, 'big')` writes most significant byte first.
2. `int.from_bytes()` parses the raw byte buffer back into a standard integer.

**Expected Console Output**:
```text
Original ID : 45290
Big-Endian  : b'\x00\x00\xb0\xea' (Hex: 0000b0ea)
Little-Endian: b'\xea\xb0\x00\x00' (Hex: eab00000)
Restored ID : 45290 (Matches? True)
```

### Example 3: Population Count Optimization with `bit_count()`
Use `bit_count()` to compute Hamming distances between bitmasks in sub-nanosecond speed.

```python
def compute_hamming_distance(mask_a: int, mask_b: int) -> int:
    # XOR yields 1 in positions where bits differ
    diff_mask = mask_a ^ mask_b
    # bit_count() counts the number of set bits (population count)
    return diff_mask.bit_count()

# Feature flag profiles (32-bit integer flags)
profile_user_1 = 0b10110010
profile_user_2 = 0b10100011

distance = compute_hamming_distance(profile_user_1, profile_user_2)
print(f"Profile 1 Bits: {bin(profile_user_1)}")
print(f"Profile 2 Bits: {bin(profile_user_2)}")
print(f"Hamming Distance (Discrepant Bits): {distance}")
```

**Step-by-Step Explanation**:
1. `mask_a ^ mask_b` sets bits to `1` only where the two profiles diverge.
2. `bit_count()` invokes CPU-level `POPCNT` instruction for immediate bit tallying.

**Expected Console Output**:
```text
Profile 1 Bits: 0b10110010
Profile 2 Bits: 0b10100011
Hamming Distance (Discrepant Bits): 3
```
