# 07. Lists: Creation, Indexing & Mutability

## 📖 Concept Overview
In Python, a **List (`list`)** is an ordered, mutable sequence of objects. Lists are one of the most versatile data structures in Python and can store heterogeneous elements (integers, strings, floats, even other lists or functions).

### 1. List Creation
Lists are defined using square brackets `[]` or the `list()` constructor:
```python
numbers = [10, 20, 30, 40]
mixed = [1, "Python", 3.14, True, [100, 200]]
empty_list = []
from_iterable = list("hello")  # ['h', 'e', 'l', 'l', 'o']
```

---

### 2. Mutability (In-Place Modifications)
Unlike strings and tuples, lists are **mutable**. You can add, replace, and delete elements in-place without creating a new list object in memory:
```python
fruits = ["apple", "banana", "cherry"]
print("Original ID:", id(fruits))

# Modify element at index 1
fruits[1] = "blueberry"
print("Mutated:", fruits)
print("Same ID?   :", id(fruits))  # True! Same object in memory
```

---

### 3. List Indexing & Slicing
Lists support zero-based positive indexing (`0` to `n-1`) and negative indexing (`-1` to `-n`).
```python
data = [10, 20, 30, 40, 50]
print(data[0])     # 10
print(data[-1])    # 50
print(data[1:4])   # [20, 30, 40]
print(data[::-1])  # [50, 40, 30, 20, 10]
```

### Slice Assignment
Because lists are mutable, you can assign an iterable to a slice to replace, insert, or delete multiple items at once:
```python
nums = [1, 2, 3, 4, 5]
nums[1:3] = [20, 30, 40]  # Replaces 2, 3 with 20, 30, 40
print(nums)  # [1, 20, 30, 40, 4, 5]

# Delete a slice
nums[1:4] = []
print(nums)  # [1, 4, 5]
```

---

## 📋 Summary & Mutability Reference

| Action | Syntax | In-Place Mutation? | Time Complexity |
| :--- | :--- | :--- | :--- |
| **Access Index** | `item = lst[i]` | No | $O(1)$ |
| **Update Index** | `lst[i] = val` | **Yes** | $O(1)$ |
| **Slice Read** | `sub = lst[a:b]` | No (creates copy) | $O(k)$ where $k=b-a$ |
| **Slice Replace** | `lst[a:b] = [x, y]` | **Yes** | $O(n + k)$ |
| **Delete Slice** | `del lst[a:b]` | **Yes** | $O(n)$ |

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: In-Place Circular Shift / Buffer Rotation
Demonstrate list mutability and slice reassignment by implementing an in-place circular rotation for task scheduling.

```python
def rotate_task_queue(tasks: list[str], shift_positions: int):
    print(f"Original Queue: {tasks} (ID: {id(tasks)})")
    n = len(tasks)
    if n == 0:
        return
    k = shift_positions % n
    
    # In-place slice reassignment: modifies original object without creating new list binding
    tasks[:] = tasks[-k:] + tasks[:-k]
    print(f"Rotated by {shift_positions}: {tasks} (ID: {id(tasks)})")

queue = ["Task A", "Task B", "Task C", "Task D", "Task E"]
rotate_task_queue(queue, 2)
```

**Step-by-Step Explanation**:
1. Notice `tasks[:] = ...`: assigning to `[:]` mutates the existing list object in-place.
2. The memory identity `id(tasks)` remains identical before and after rotation.
3. Callers holding references to `queue` observe the updated schedule instantly.

**Expected Console Output**:
```text
Original Queue: ['Task A', 'Task B', 'Task C', 'Task D', 'Task E'] (ID: 140723456789120)
Rotated by 2: ['Task D', 'Task E', 'Task A', 'Task B', 'Task C'] (ID: 140723456789120)
```

### Example 2: Financial Stock Price Moving Window Smoothing
Process a live series of stock market closing prices, updating values and smoothing out anomalous price spikes.

```python
def smooth_stock_spikes(prices: list[float], max_allowed_delta: float = 15.0) -> list[float]:
    # Work on a copy to preserve original history
    smoothed = prices.copy()
    
    for i in range(1, len(smoothed) - 1):
        prev_price = smoothed[i - 1]
        curr_price = smoothed[i]
        next_price = smoothed[i + 1]
        
        # Check if current price is an outlier spike compared to neighbours
        expected_avg = (prev_price + next_price) / 2
        if abs(curr_price - expected_avg) > max_allowed_delta:
            print(f"Spike detected at index {i}: ${curr_price:.2f} -> Replaced with smoothed: ${expected_avg:.2f}")
            smoothed[i] = round(expected_avg, 2)
            
    return smoothed

stock_ticks = [102.5, 103.0, 104.2, 195.0, 105.1, 104.8, 106.0]  # 195.0 is an erroneous spike
cleaned_ticks = smooth_stock_spikes(stock_ticks)

print(f"Original Series: {stock_ticks}")
print(f"Cleaned Series : {cleaned_ticks}")
```

**Step-by-Step Explanation**:
1. Uses index access `smoothed[i]` to read surrounding temporal neighbors.
2. Mutates the outlier index directly in-place (`smoothed[i] = round(expected_avg, 2)`).
3. Preserves data structure length and alignment with timestamps.

**Expected Console Output**:
```text
Spike detected at index 3: $195.00 -> Replaced with smoothed: $104.65
Original Series: [102.5, 103.0, 104.2, 195.0, 105.1, 104.8, 106.0]
Cleaned Series : [102.5, 103.0, 104.2, 104.65, 105.1, 104.8, 106.0]
```

### Example 3: Dynamic Multi-Layer Flattening of Mixed Data Types
Traverse and extract primitive values from an arbitrarily nested heterogeneous list containing strings, integers, and sub-lists.

```python
def flatten_nested_sequence(nested_input: list) -> list:
    flat_result = []
    
    def _extract(element):
        if isinstance(element, (list, tuple)):
            for sub_item in element:
                _extract(sub_item)
        else:
            flat_result.append(element)
            
    _extract(nested_input)
    return flat_result

raw_payload = [101, ["Alpha", 45.8], True, [12, [34, "Beta", [99, False]]]]
clean_flat = flatten_nested_sequence(raw_payload)

print(f"Nested Payload: {raw_payload}")
print(f"Flattened List: {clean_flat}")
```

**Step-by-Step Explanation**:
1. Heterogeneous lists often hold data returned from unstructured APIs or databases.
2. The recursive `_extract` function unpacks nested sub-lists dynamically.
3. Demonstrates list flexibility without rigid type constraints.

**Expected Console Output**:
```text
Nested Payload: [101, ['Alpha', 45.8], True, [12, [34, 'Beta', [99, False]]]]
Flattened List: [101, 'Alpha', 45.8, True, 12, 34, 'Beta', 99, False]
```
