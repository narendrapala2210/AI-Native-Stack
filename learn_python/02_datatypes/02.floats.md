## 📖 Concept Overview
In Python, **floating-point numbers (`float`)** represent real numbers with decimal fractions. Python implements floats using the **IEEE 754 double-precision 64-bit standard**:
- 1 sign bit
- 11 exponent bits
- 52 mantissa (significand) bits

---

### 1. The Binary Representation Trap ($0.1 + 0.2$)
Computers internally calculate in base 2. In binary, fractional numbers like $0.1$ ($1/10$) are infinite repeating fractions ($0.0001100110011...$), causing minor precision approximations:
```python
print(0.1 + 0.2)
# Output: 0.30000000000000004
```
> [!WARNING]
> **Never compare floats directly using `==`!**
> ```python
> (0.1 + 0.2) == 0.3  # False!
> ```
> Use `math.isclose()` to evaluate float equality within a tolerable delta:
> ```python
> import math
> math.isclose(0.1 + 0.2, 0.3)  # True!
> ```

---

### 2. Special Float Values: `inf`, `-inf` and `nan`
- **Infinity (`inf` / `-inf`)**: Unbounded magnitudes (`float("inf")`, `float("-inf")`).
- **Not a Number (`nan`)**: Undefined operations (`float("nan")`).
> Note: `nan == nan` evaluates to **`False`**. Use `math.isnan(x)` to test for NaN.

## 🛠️ Complete Catalog of Built-in Float Methods

| Method | Syntax | Description & Example |
| :--- | :--- | :--- |
| **`is_integer()`** | `f.is_integer()` | Returns `True` if float instance is finite with integer value.<br>`(4.0).is_integer()` -> `True`<br>`(4.5).is_integer()` -> `False`. |
| **`as_integer_ratio()`** | `f.as_integer_ratio()` | Returns pair of integers `(numerator, denominator)` whose ratio is exactly equal to the float.<br>`(0.75).as_integer_ratio()` -> `(3, 4)`. |
| **`hex()`** | `f.hex()` | Returns exact hexadecimal representation string of float.<br>`(10.5).hex()` -> `'0x1.5000000000000p+3'`. |
| **`fromhex()`** | `float.fromhex(string)` | Classmethod parsing hexadecimal float string back to float.<br>`float.fromhex('0x1.5p+3')` -> `10.5`. |

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Rational Fraction Decomposition with `as_integer_ratio()`
Extract the exact mathematical numerator and denominator underlying floating-point values.

```python
def analyze_float_precision(value: float):
    numerator, denominator = value.as_integer_ratio()
    print(f"Float Value: {value}")
    print(f"  Exact Rational Ratio: {numerator} / {denominator}")
    print(f"  Is Whole Integer?   : {value.is_integer()}")

analyze_float_precision(0.75)
analyze_float_precision(12.0)
analyze_float_precision(0.1)  # Exposes underlying binary fraction
```

#### Step-by-Step Explanation:
1. `(0.75).as_integer_ratio()` yields `(3, 4)`.
2. For `0.1`, it exposes the massive 53-bit numerator/denominator IEEE 754 approximation.

#### Expected Output:
```text
Float Value: 0.75
  Exact Rational Ratio: 3 / 4
  Is Whole Integer?   : False
Float Value: 12.0
  Exact Rational Ratio: 12 / 1
  Is Whole Integer?   : True
Float Value: 0.1
  Exact Rational Ratio: 3602879701896397 / 36028797018963968
  Is Whole Integer?   : False
```

### Example 2: Financial Accuracy Defense (`float` vs `decimal.Decimal`)
Demonstrate why enterprise financial applications replace `float` with `Decimal` to eliminate rounding drift.

```python
from decimal import Decimal

def audit_banking_interest():
    transactions = 100_000
    
    # 1. Floating-point accumulation
    float_bal = 0.0
    for _ in range(transactions):
        float_bal += 0.10
        
    # 2. Decimal accumulation
    dec_bal = Decimal("0.00")
    ten_cents = Decimal("0.10")
    for _ in range(transactions):
        dec_bal += ten_cents
        
    expected = 10000.00
    print("=== Banking Accumulation Audit (100,000 txs of $0.10) ===")
    print(f"Expected Balance: ${expected:,.2f}")
    print(f"Float Result    : ${float_bal:,.8f} (Error: {float_bal - expected:+.8f})")
    print(f"Decimal Result  : ${dec_bal} (Error: 0.00)")

audit_banking_interest()
```

#### Step-by-Step Explanation:
1. Adding `0.10` in IEEE float compounds residual errors.
2. `Decimal("0.10")` maintains exact base-10 arithmetic without drift.

#### Expected Output:
```text
=== Banking Accumulation Audit (100,000 txs of $0.10) ===
Expected Balance: $10,000.00
Float Result    : $10,000.00000000188356 (Error: +0.00000000188356)
Decimal Result  : $10000.00 (Error: 0.00)
```

### Example 3: Exact Hex Float Interchange Format (`hex()` & `fromhex()`)
Serialize floating-point numbers in exact IEEE 754 hexadecimal format to prevent precision loss across network systems.

```python
def serialize_floating_constants():
    pi_val = 3.141592653589793
    hex_str = pi_val.hex()
    
    print(f"Original Float: {pi_val:.15f}")
    print(f"Exact Hex Representation: {hex_str}")
    
    # Reconstruct
    reconstructed = float.fromhex(hex_str)
    print(f"Reconstructed: {reconstructed:.15f}")
    print(f"Bit-for-bit identical? {pi_val == reconstructed}")

serialize_floating_constants()
```

#### Step-by-Step Explanation:
1. Converting floats to decimal strings (`str(f)`) often truncates or rounds precision.
2. `f.hex()` and `float.fromhex()` guarantee zero-loss bit-for-bit serialization.

#### Expected Output:
```text
Original Float: 3.141592653589793
Exact Hex Representation: 0x1.921fb54442d18p+1
Reconstructed: 3.141592653589793
Bit-for-bit identical? True
```
