# 05. String Methods & Text Manipulation

## 📖 Concept Overview
Python strings provide dozens of built-in methods implemented in optimized C. Because strings are immutable, **all string methods return a new string object** without modifying the original.

---

### 1. Case Transformation Methods
- **`s.upper()`**: Returns uppercase copy.
- **`s.lower()`**: Returns lowercase copy.
- **`s.capitalize()`**: Capitalizes first character, lowercases rest.
- **`s.title()`**: Capitalizes first letter of every word.
- **`s.swapcase()`**: Inverts casing across all characters.

---

### 2. Character Classification & Validation Methods
Methods returning boolean (`True`/`False`):
- **`s.isalpha()`**: `True` if all characters are alphabetic (`a-z`, `A-Z`).
- **`s.isdigit()`**: `True` if all characters are numeric digits (`0-9`).
- **`s.isalnum()`**: `True` if all characters are alphanumeric.
- **`s.isspace()`**: `True` if all characters are whitespace (`' '`, `'\t'`, `'\n'`).
- **`s.startswith(prefix)`**: `True` if string begins with `prefix`.
- **`s.endswith(suffix)`**: `True` if string terminates with `suffix`.

---

### 3. Searching & Modifying Methods
- **`s.strip([chars])`**: Strips leading and trailing characters (defaults to whitespace). `lstrip()` and `rstrip()` trim left or right only.
- **`s.replace(old, new[, count])`**: Replaces occurrences of substring `old` with `new`.
- **`s.find(sub)`**: Returns first index of `sub`, or **`-1`** if not found (safer than `s.index()` which raises `ValueError`).
- **`s.count(sub)`**: Counts non-overlapping occurrences of `sub`.

---

### 4. Splitting and Joining
- **`s.split(sep=None, maxsplit=-1)`**: Splits string by delimiter into a list of strings. If `sep` is omitted, splits by runs of arbitrary whitespace.
- **`sep.join(iterable)`**: Joins an iterable of strings using `sep` as glue:
  ```python
  words = ["Python", "is", "awesome"]
  sentence = " ".join(words)  # "Python is awesome"
  ```

---

## 📋 Summary & Reference Table

| Method | Syntax | Sample Input -> Output |
| :--- | :--- | :--- |
| `strip()` | `"  dev  ".strip()` | `'dev'` |
| `replace()` | `"apple".replace("p", "b")` | `'abble'` |
| `startswith()` | `"https://site".startswith("https")` | `True` |
| `split()` | `"red,green,blue".split(",")` | `['red', 'green', 'blue']` |
| `join()` | `"-".join(["2026", "09", "14"])` | `'2026-09-14'` |
| `find()` | `"hello".find("x")` | `-1` |

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Server Access Log Sanitizer & Parser
Parse Apache/Nginx web server access logs to extract client IP, HTTP verb, request path, status code, and latency.

```python
def parse_access_log_line(log_entry: str) -> dict | None:
    # Typical format: '192.168.1.10 - [2026-09-14] "GET /api/v1/users HTTP/1.1" 200 45ms'
    stripped = log_entry.strip()
    if not stripped or stripped.startswith("#"):
        return None
        
    parts = stripped.split()
    ip_address = parts[0]
    
    # Extract request inside quotes
    start_quote = stripped.find('"')
    end_quote = stripped.find('"', start_quote + 1)
    request_line = stripped[start_quote + 1:end_quote]
    http_method, path, protocol = request_line.split()
    
    # Extract status code following end quote
    remainder = stripped[end_quote + 1:].strip().split()
    status_code = int(remainder[0])
    latency = remainder[1]
    
    return {
        "ip": ip_address,
        "method": http_method,
        "endpoint": path,
        "status": status_code,
        "latency": latency
    }

sample_log = '10.0.4.15 - [14/Sep/2026:12:00:01] "POST /api/v2/orders HTTP/1.1" 201 12ms'
parsed = parse_access_log_line(sample_log)

print("Parsed Web Server Log Entry:")
for key, val in parsed.items():
    print(f"  {key:<10}: {val}")
```

**Step-by-Step Explanation**:
1. Uses `strip()` to clean surrounding whitespace.
2. Uses `find('"')` to isolate the quoted HTTP command.
3. Uses `split()` to unpack method, endpoint, and status tokens.

**Expected Console Output**:
```text
Parsed Web Server Log Entry:
  ip        : 10.0.4.15
  method    : POST
  endpoint  : /api/v2/orders
  status    : 201
  latency   : 12ms
```

### Example 2: High-Speed Text Normalizer for NLP & Search Indexing
Clean, tokenize, and normalize messy user search queries by stripping punctuation, extra whitespace, and stop words.

```python
def normalize_search_query(raw_query: str) -> list[str]:
    # 1. Lowercase
    lowered = raw_query.lower()
    
    # 2. Replace special punctuation with spaces
    punctuation = "!@#$%^&*()-_+=~`[]{}\|:;"'<>,.?/"
    for p in punctuation:
        if p in lowered:
            lowered = lowered.replace(p, " ")
            
    # 3. Split into words (automatically groups multiple whitespace runs)
    tokens = lowered.split()
    
    # 4. Filter stop words
    stop_words = {"a", "an", "the", "in", "on", "of", "and", "is", "for"}
    cleaned_tokens = [w for w in tokens if w not in stop_words and len(w) > 1]
    
    return cleaned_tokens

query = "  How to Learn Python... and Machine-Learning in 2026?!  "
tokens = normalize_search_query(query)
print(f"Original Query: '{query}'")
print(f"Search Tokens : {tokens}")
print(f"Index Key     : {'_'.join(tokens)}")
```

**Step-by-Step Explanation**:
1. Chained operations clean formatting variations across disparate user queries.
2. `split()` without arguments gracefully collapses repeated spaces into single boundaries.
3. `'_'.join(tokens)` creates a canonical hash key for database search caches.

**Expected Console Output**:
```text
Original Query: '  How to Learn Python... and Machine-Learning in 2026?!  '
Search Tokens : ['how', 'to', 'learn', 'python', 'machine', 'learning', '2026']
Index Key     : how_to_learn_python_machine_learning_2026
```

### Example 3: CSV Row Parser with Quoted Delimiter Handling
Demonstrate how simple `split(",")` fails when fields contain commas within quotes, and implement an intelligent replacement parser.

```python
def parse_csv_line(line: str) -> list[str]:
    fields = []
    current_field = []
    inside_quotes = False
    
    for char in line:
        if char == '"':
            inside_quotes = not inside_quotes  # Toggle quote state
        elif char == ',' and not inside_quotes:
            fields.append("".join(current_field).strip())
            current_field = []
        else:
            current_field.append(char)
            
    fields.append("".join(current_field).strip())
    return fields

# Notice the third column contains a comma inside quotes!
csv_record = '101, "Acme, Inc.", "54,200.00", Active'
parsed_fields = parse_csv_line(csv_record)

print(f"Raw CSV Line: {csv_record}")
print(f"Parsed Fields Count: {len(parsed_fields)}")
for idx, field in enumerate(parsed_fields, start=1):
    print(f"  Field {idx}: {field}")
```

**Step-by-Step Explanation**:
1. Demonstrates the limitation of naive `split(",")`.
2. Iterates character-by-character tracking quote boundaries.
3. Correctly preserves nested commas inside quoted company names and monetary figures.

**Expected Console Output**:
```text
Raw CSV Line: 101, "Acme, Inc.", "54,200.00", Active
Parsed Fields Count: 4
  Field 1: 101
  Field 2: Acme, Inc.
  Field 3: 54,200.00
  Field 4: Active
```
