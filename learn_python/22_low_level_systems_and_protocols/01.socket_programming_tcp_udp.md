## 1. Conceptual Deep-Dive: Berkeley Sockets in Python

Python's `socket` module exposes direct C-level Berkeley socket system calls:
1. **TCP (Transmission Control Protocol - `SOCK_STREAM`)**:
   - Connection-oriented, full-duplex byte stream.
   - Guarantees ordered delivery, retransmission on packet loss, and flow control.
   - Server lifecycle: `socket()` -> `bind()` -> `listen()` -> `accept()` -> `recv()`/`send()`.
2. **UDP (User Datagram Protocol - `SOCK_DGRAM`)**:
   - Connectionless datagram service without handshakes.
   - Low latency, minimal packet headers, but no delivery or ordering guarantees.
   - Socket lifecycle: `socket()` -> `bind()` -> `recvfrom()`/`sendto()`.

```
TCP Lifecycle (Server & Client):
Server: socket() -> bind() -> listen() -> accept() <==== (3-Way Handshake) <==== Client: connect()
           |                                  |                                       |
           +---------- recv() <---------------+---------------- send() <-------------+
           +----------> send() --------------->---------------- recv() -------------->+

UDP Lifecycle:
Server: socket() -> bind() -> recvfrom() <--- (Direct Packet) <--- Client: sendto()
```

## 2. TCP vs. UDP Protocol Matrix

| Attribute | TCP (`SOCK_STREAM`) | UDP (`SOCK_DGRAM`) |
|---|---|---|
| Handshake | 3-Way SYN / SYN-ACK / ACK | None |
| Reliability | Guaranteed & ACK-checked | Best-effort (packets may drop) |
| Ordering | Strict sequential byte stream | Out-of-order delivery possible |
| Packet Framing | Stream boundaries not preserved (requires framing) | Message boundaries preserved per packet |
| Typical Use Cases | HTTP, SSH, Database connections | DNS queries, Video streaming, Multiplayer gaming |

## 3. Practical Code Examples with Step-by-Step Explanations

### Example 1: Robust TCP Server & Client with Length-Prefixed Framing
Demonstrate proper message framing over TCP byte streams.

```python
import socket
import struct
import threading

def send_framed_msg(sock: socket.socket, msg: str):
    payload = msg.encode("utf-8")
    # Prefix payload with 4-byte unsigned integer (big-endian)
    header = struct.pack("!I", len(payload))
    sock.sendall(header + payload)

def recv_framed_msg(sock: socket.socket) -> str:
    # Read exactly 4 bytes of header
    header = sock.recv(4)
    if not header:
        return ""
    (length,) = struct.unpack("!I", header)
    
    # Read until entire payload buffer is filled
    chunks = []
    bytes_read = 0
    while bytes_read < length:
        chunk = sock.recv(min(length - bytes_read, 4096))
        if not chunk:
            break
        chunks.append(chunk)
        bytes_read += len(chunk)
    return b"".join(chunks).decode("utf-8")

def tcp_server():
    server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    server.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    server.bind(("127.0.0.1", 18881))
    server.listen(1)
    
    conn, addr = server.accept()
    with conn:
        msg = recv_framed_msg(conn)
        print(f"[Server] Received: {msg}")
        send_framed_msg(conn, f"ACK: {msg}")
    server.close()

# Run server in background thread
server_thread = threading.Thread(target=tcp_server)
server_thread.start()

# Client connection
client = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
client.connect(("127.0.0.1", 18881))
send_framed_msg(client, "Hello Secure TCP World")
response = recv_framed_msg(client)
print(f"[Client] Server Reply: {response}")
client.close()

server_thread.join()
```

#### Step-by-Step Explanation:
1. TCP treats data as a continuous stream of bytes without message boundaries; without framing, multiple `send()` calls can merge into a single `recv()` chunk.
2. `struct.pack("!I", len(payload))` prefixes each message with a 4-byte length integer.
3. The receiver reads the 4-byte header first, then reads bytes until the entire expected length is assembled.

#### Expected Output:
```text
[Server] Received: Hello Secure TCP World
[Client] Server Reply: ACK: Hello Secure TCP World
```

### Example 2: UDP Heartbeat Ping & Echo Service
Demonstrate lightweight datagram transmission without connections.

```python
import socket
import threading
import time

def udp_echo_server():
    sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    sock.bind(("127.0.0.1", 18882))
    
    data, addr = sock.recvfrom(1024)
    print(f"[UDP Server] Datagram from {addr}: {data.decode('utf-8')}")
    sock.sendto(b"PONG", addr)
    sock.close()

# Start UDP server in background
server_th = threading.Thread(target=udp_echo_server)
server_th.start()
time.sleep(0.05)

# Client sends datagram
client_sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
client_sock.settimeout(2.0)
server_addr = ("127.0.0.1", 18882)

client_sock.sendto(b"PING", server_addr)
reply, _ = client_sock.recvfrom(1024)
print(f"[UDP Client] Received reply: {reply.decode('utf-8')}")

client_sock.close()
server_th.join()
```

#### Step-by-Step Explanation:
1. UDP requires no `listen()` or `accept()` handshake; sockets transmit datagrams directly via `sendto()`.
2. `recvfrom()` returns both the received binary payload and the sender's IP/port tuple.
3. UDP is ideal for heartbeats, telemetry, and time synchronization where dropped packets are preferable to buffering delays.

#### Expected Output:
```text
[UDP Server] Datagram from ('127.0.0.1', ...): PING
[UDP Client] Received reply: PONG
```

### Example 3: Non-Blocking Sockets with `setblocking(False)` & Timeouts
Implement non-blocking socket handling to prevent hanging on idle connections.

```python
import socket

def test_nonblocking_socket():
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.settimeout(0.1)  # 100ms timeout
    
    try:
        # Attempt to read from an unaccepted connection
        s.bind(("127.0.0.1", 18883))
        s.listen(1)
        print("Waiting for incoming connection with 100ms timeout...")
        s.accept()
    except socket.timeout:
        print("Caught expected socket.timeout: no client connected in window.")
    finally:
        s.close()

test_nonblocking_socket()
```

#### Step-by-Step Explanation:
1. Default Python sockets are blocking: `recv()` and `accept()` block thread execution indefinitely until data arrives.
2. `settimeout(0.1)` raises `socket.timeout` if no event occurs within 100 milliseconds.
3. Calling `setblocking(False)` raises `BlockingIOError` immediately when buffers are empty, which powers low-level event loops (`selectors`).

#### Expected Output:
```text
Waiting for incoming connection with 100ms timeout...
Caught expected socket.timeout: no client connected in window.
```

## 4. Key Takeaways & Best Practices

1. Always frame TCP messages (e.g. length prefixing, delimiter framing) because TCP guarantees streams, not packet boundaries.
2. Use `setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)` on servers to prevent `EADDRINUSE` errors on rapid restarts.
3. For asynchronous network multiplexing, prefer standard library `asyncio` or `selectors` over raw blocking thread pools.
