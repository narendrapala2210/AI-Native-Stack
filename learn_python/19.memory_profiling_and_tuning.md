# 19. Memory Profiling, Optimization & Performance Tuning

### 19.1 CPU Profiling with `cProfile` and `pstats`

Find out exactly where your Python application spends CPU time.

```python
import cProfile
import pstats
import io

def slow_computation():
    total = 0
    for i in range(200_000):
        total += i ** 2
    return total

def fast_computation():
    return sum(range(100_000))

def main_app():
    slow_computation()
    fast_computation()

# Profile programmatically
profiler = cProfile.Profile()
profiler.enable()
main_app()
profiler.disable()

# Format and print top functions sorted by cumulative time
stream = io.StringIO()
stats = pstats.Stats(profiler, stream=stream).sort_stats("cumulative")
stats.print_stats(5)  # Print top 5 slowest functions
print("cProfile Output:\n", stream.getvalue()[:400], "...\n")
```

### 19.2 Memory Leak Detection with `tracemalloc`

`tracemalloc` tracks memory allocations back to specific file and line numbers.

```python
import tracemalloc

# Start tracing memory allocations
tracemalloc.start()

# Allocate some memory
leaky_list = [f"Allocated string chunk #{i}" for i in range(50_000)]

# Take a snapshot of memory usage
snapshot = tracemalloc.take_snapshot()
top_stats = snapshot.statistics("lineno")

print("[TRACEMALLOC] Top 3 memory allocations:")
for stat in top_stats[:3]:
    print(f"  {stat}")

tracemalloc.stop()
```

### 19.3 Weak References with `weakref` (`WeakKeyDictionary`, `WeakValueDictionary`)

Normal references prevent the Garbage Collector from freeing objects. **Weak references** reference an object without keeping it alive, preventing memory leaks in caches.

```python
import weakref

class CacheableModel:
    def __init__(self, name: str):
        self.name = name

# WeakValueDictionary drops the entry automatically when the object is deleted elsewhere!
cache = weakref.WeakValueDictionary()

item1 = CacheableModel("TensorModel_V1")
cache["v1"] = item1
print("Found in cache:", cache.get("v1").name)

# Delete strong reference
del item1

# Cache entry is automatically cleared by the Garbage Collector!
print("Cache entry after deleting strong reference:", cache.get("v1")) # None
```

### 19.4 Micro-benchmarking with `timeit`

Use `timeit` instead of `time.time()` for accurate benchmarking, as it runs iterations repeatedly and disables background interference.

```python
import timeit

# Compare list comprehension vs map()
comp_time = timeit.timeit("[str(x) for x in range(1000)]", number=1000)
map_time = timeit.timeit("list(map(str, range(1000)))", number=1000)

print(f"List comprehension: {comp_time:.5f}s")
print(f"Map function:       {map_time:.5f}s")
```

### Example 1: Memory Leak Detection with `tracemalloc` Line Tracking
Pinpoint the exact file and line number where memory consumption increases over time.

```python
import tracemalloc

def simulate_leaky_operation():
    cache = []
    for i in range(25_000):
        cache.append(f"Cached string allocation #{i} with padding data...")
    return cache

tracemalloc.start()
baseline = tracemalloc.take_snapshot()

# Run potentially leaky function
leaked_data = simulate_leaky_operation()

current = tracemalloc.take_snapshot()
stats_diff = current.compare_to(baseline, "lineno")

print("Top 3 Memory Allocators (Delta):")
for stat in stats_diff[:3]:
    print(f"  {stat}")

tracemalloc.stop()
```

### Example 2: Profiling Slow Calculations with `cProfile` and `pstats`
Identify performance bottlenecks by profiling execution duration down to individual function calls.

```python
import cProfile
import pstats
import io

def heavy_computation():
    return sum(x ** 2 for x in range(150_000))

def light_computation():
    return [x for x in range(10_000)]

def run_app():
    heavy_computation()
    light_computation()

profiler = cProfile.Profile()
profiler.enable()
run_app()
profiler.disable()

stream = io.StringIO()
stats = pstats.Stats(profiler, stream=stream).sort_stats("cumulative")
stats.print_stats(3)
print("Profile Summary (Top 3 slowest calls):", stream.getvalue()[:350])
```

### Example 3: Auto-Clearing Ephemeral Object Cache with `weakref.WeakValueDictionary`
Create a memory-safe object cache that automatically removes entries once all external references are dropped.

```python
import weakref

class HeavySessionModel:
    def __init__(self, session_id: str):
        self.session_id = session_id

session_cache = weakref.WeakValueDictionary()

# Active session
session_1 = HeavySessionModel("sess_101")
session_cache["active_user"] = session_1

print("Found in cache:", session_cache.get("active_user").session_id)

# User logs out or closes browser -> strong reference deleted
del session_1

# WeakValueDictionary automatically discards the key!
print("Found in cache after logout?", session_cache.get("active_user"))  # None
```
