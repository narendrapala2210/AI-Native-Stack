# 1. Python Architecture, Execution & Memory Model

### 1.1 CPython, Bytecode, and the PVM
Python is typically referred to as an "interpreted" language, but in reality, **CPython** (the standard reference implementation) compiles source code into an intermediate format called **bytecode** before executing it inside the **Python Virtual Machine (PVM)**.

```
Source Code (.py) ──[ CPython Compiler ]──> Bytecode (.pyc / __pycache__) ──[ PVM Execution Loop ]──> Machine Instructions (CPU)
```

1. **Parsing**: Python turns source code into an Abstract Syntax Tree (AST).
2. **Bytecode Compilation**: The AST is compiled into `.pyc` files containing opcodes.
3. **Execution**: The PVM reads opcodes in a giant loop (`ceval.c`) and executes them.

#### Inspecting Bytecode with `dis`:
```python
import dis

def calculate_total(price: float, tax_rate: float) -> float:
    total = price * (1 + tax_rate)
    return total

# Disassemble bytecode to see raw PVM instructions
dis.dis(calculate_total)
```
*Output bytecode:*
```text
  2           0 LOAD_FAST                0 (price)
              2 LOAD_CONST               1 (1)
              4 LOAD_FAST                1 (tax_rate)
              6 BINARY_OP                0 (+)
              8 BINARY_OP                5 (*)
             10 STORE_FAST               2 (total)

  3          12 LOAD_FAST                2 (total)
             14 RETURN_VALUE
```

### 1.2 Python Memory Model: Identity, Type, and Value
In Python, **everything is an object**. A variable is never a container holding data; it is merely a **name tag (reference)** bound to an object in heap memory.

Every object possesses three fundamental attributes:
1. **Identity (`id()`)**: The memory address where the object resides.
2. **Type (`type()`)**: Defines supported operations and behaviors.
3. **Value**: The data stored in the object (mutable or immutable).

```python
x = [10, 20, 30]
y = x             # y points to the EXACT same object in memory as x
z = [10, 20, 30]  # z is a distinct object with identical content

print(f"id(x): {id(x)}, id(y): {id(y)}, id(z): {id(z)}")
print(f"type of x: {type(x)}")

# 'is' checks Identity (same memory address)
print("x is y:", x is y)  # True
print("x is z:", x is z)  # False

# '==' checks Equality of Values
print("x == z:", x == z)  # True
```

### 1.3 Reference Counting & Generational Garbage Collection
Python automatically frees memory using two mechanisms:

1. **Reference Counting (Primary)**:
   - Each object tracks how many references point to it (`ob_refcnt`).
   - When the count drops to zero, its memory is immediately deallocated.
2. **Generational Garbage Collector (Cyclic GC)**:
   - Circular references (e.g., Object A -> Object B -> Object A) never reach reference count zero on their own.
   - The cyclic GC groups objects into three generations (Gen 0, 1, 2) based on survival age and runs periodic sweep cycles.

```python
import sys
import gc

# 1. Reference counting demonstration
a = [1, 2, 3]
print("Initial ref count:", sys.getrefcount(a) - 1)  # sys.getrefcount adds 1 temporary reference

b = a
print("Ref count after assignment to b:", sys.getrefcount(a) - 1)  # 2

del b
print("Ref count after deleting b:", sys.getrefcount(a) - 1)       # 1

# 2. Circular reference demonstration & Cyclic GC
class Node:
    def __init__(self, name):
        self.name = name
        self.partner = None

node1 = Node("Node A")
node2 = Node("Node B")
node1.partner = node2
node2.partner = node1  # Circular reference created

del node1
del node2

# The objects still have ref count = 1 due to each other!
# Force cyclic garbage collector to detect and collect them
unreachable_count = gc.collect()
print(f"Garbage collector reclaimed {unreachable_count} unreachable objects.")
```

### 1.4 Object Interning & Mutability Deep Dive

#### Mutability Matrix:
| Category | Types |
| :--- | :--- |
| **Immutable** (Cannot be changed in place) | `int`, `float`, `complex`, `bool`, `str`, `tuple`, `frozenset`, `bytes` |
| **Mutable** (Can be modified in place) | `list`, `dict`, `set`, `bytearray`, custom class instances |

#### Small Integer Caching & String Interning:
CPython pre-allocates and caches singleton instances of integers from **-5 to 256**. Any variable assigned an integer in this range points to this global cache.

```python
# Small Integer Caching:
a = 250
b = 250
print("250 is 250:", a is b)  # True (interned)

# String Interning:
s1 = "hello_world"
s2 = "hello_world"
print("s1 is s2:", s1 is s2)  # True

# Mutating an immutable object's mutable contents:
# A tuple is immutable, but if it contains a list, that list CAN mutate!
tup = (1, 2, [3, 4])
tup[2].append(99)
print("Tuple with modified list:", tup)  # (1, 2, [3, 4, 99])
```

### 1.5 PEP 8 Style Guide, Naming Conventions & Zen of Python

```python
# The Zen of Python
import this

# PEP 8 Naming Conventions:
MAX_RETRIES = 5                  # CONSTANTS: UPPER_CASE with underscores

class DatabaseSession:           # Classes: PascalCase
    def __init__(self, host: str):
        self.host = host         # Attributes: snake_case
        self._cache = {}         # Protected / Internal: leading single underscore
        self.__secret_token = "" # Private (name mangled): leading double underscore

    def execute_query(self):     # Methods & Functions: snake_case
        pass

def calculate_discount(price: float, rate: float = 0.05) -> float:
    """
    Calculate discounted total price.

    Args:
        price (float): Original item price.
        rate (float, optional): Discount percentage. Defaults to 0.05.

    Returns:
        float: Final discounted price.
    """
    return price * (1 - rate)
```

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Circular Reference Memory Leak Detector & Reclamation
In production services, circular references can build up unnoticed if the cyclic garbage collector is disabled or blocked. This example creates a reference detector and forces garbage reclamation.

```python
import gc
import sys

class CacheNode:
    def __init__(self, key, value):
        self.key = key
        self.value = value
        self.linked_node = None

def build_circular_graph():
    node1 = CacheNode("primary", {"data": [1, 2, 3]})
    node2 = CacheNode("secondary", {"data": [4, 5, 6]})
    # Create cycle
    node1.linked_node = node2
    node2.linked_node = node1
    return id(node1), id(node2)

# Verify leak without GC
gc.disable()  # Temporarily pause automatic GC sweeps
n1_id, n2_id = build_circular_graph()

# Nodes are out of scope, but refcount is still 1 due to the cycle!
print(f"Cycle created with IDs: {n1_id}, {n2_id}")

# Manually trigger cyclic collector
reclaimed = gc.collect()
print(f"[CLEANUP] Cyclic GC reclaimed {reclaimed} unreachable cyclic objects.")
gc.enable()
```

### Example 2: Bytecode Disassembly & Opcode Frequency Analyzer
Analyze how CPython compiles complex expressions vs simple loops to identify performance bottlenecks at the bytecode level.

```python
import dis
from collections import Counter

def complex_pipeline(items):
    return [x.upper() for x in items if len(x) > 3]

# Disassemble and extract opcodes
instructions = dis.get_instructions(complex_pipeline)
op_counts = Counter(instr.opname for instr in instructions)

print("Bytecode Opcode Frequency:")
for opcode, count in op_counts.most_common(5):
    print(f"  {opcode:<20}: {count} occurrences")
```

### Example 3: Identity-Based Caching Layer (Exploiting Interning)
Demonstrates building an identity-based memoization cache that compares keys by memory address (`is`) instead of expensive equality checks (`==`) for interned strings.

```python
import sys

class IdentityCache:
    def __init__(self):
        self._store = {}

    def get_or_compute(self, key: str, compute_fn):
        # Intern string to ensure identical memory address
        interned_key = sys.intern(key)
        for cached_key, val in self._store.items():
            if cached_key is interned_key:  # Pointer comparison O(1)
                return val, "CACHE_HIT"
        result = compute_fn(interned_key)
        self._store[interned_key] = result
        return result, "CACHE_MISS"

cache = IdentityCache()
expensive_calc = lambda k: f"Processed: {k}"

val1, status1 = cache.get_or_compute("user_auth_token", expensive_calc)
val2, status2 = cache.get_or_compute("user_auth_token", expensive_calc)

print(f"Call 1: {status1} -> {val1}")
print(f"Call 2: {status2} -> {val2}")
```
