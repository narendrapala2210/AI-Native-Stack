# 05. Nested Loops & Grid Patterns

## 📖 Concept Overview
A **Nested Loop** is a loop placed inside the repeating body of an outer loop:
- For **each single iteration** of the outer loop, the inner loop executes **all of its iterations from start to finish**.
- If the outer loop runs $M$ times and the inner loop runs $N$ times, the innermost block executes $M \times N$ times ($O(M \times N)$ time complexity).

---

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Coordinate Grid Generation & Distance Matrix
Generate a 2D Euclidean distance matrix comparing multiple points on a coordinate plane.

```python
import math

def build_distance_matrix(points: list[tuple[int, int]]):
    n = len(points)
    print(f"=== Euclidean Distance Matrix ({n} x {n} points) ===")
    
    # Outer loop iterates through each source point
    for i in range(n):
        row_distances = []
        # Inner loop iterates through each target point
        for j in range(n):
            x1, y1 = points[i]
            x2, y2 = points[j]
            dist = math.hypot(x2 - x1, y2 - y1)
            row_distances.append(f"{dist:5.2f}")
            
        print(f"Point {i} {points[i]}: [" + ", ".join(row_distances) + "]")

stations = [(0, 0), (3, 4), (6, 8)]
build_distance_matrix(stations)
```

**Step-by-Step Explanation**:
1. Outer loop `i` selects each origin point.
2. Inner loop `j` calculates distance to every destination point.

**Expected Console Output**:
```text
=== Euclidean Distance Matrix (3 x 3 points) ===
Point 0 (0, 0): [ 0.00,  5.00, 10.00]
Point 1 (3, 4): [ 5.00,  0.00,  5.00]
Point 2 (6, 8): [10.00,  5.00,  0.00]
```

### Example 2: Classic Asterisk Pyramid & Diamond Pattern Generator
Use nested loops to construct symmetric geometric asterisk patterns in the terminal.

```python
def print_diamond_pattern(n: int):
    print(f"=== Diamond Pattern (Radius {n}) ===")
    
    # 1. Top half of diamond (including center)
    for i in range(1, n + 1):
        spaces = " " * (n - i)
        stars = "*" * (2 * i - 1)
        print(spaces + stars)
        
    # 2. Bottom half of diamond
    for i in range(n - 1, 0, -1):
        spaces = " " * (n - i)
        stars = "*" * (2 * i - 1)
        print(spaces + stars)

print_diamond_pattern(4)
```

**Step-by-Step Explanation**:
1. Calculates leading padding spaces `n - i` and odd stars `2 * i - 1`.
2. First loop counts up, second loop counts down in reverse.

**Expected Console Output**:
```text
=== Diamond Pattern (Radius 4) ===
   *
  ***
 *****
*******
 *****
  ***
   *
```

### Example 3: Cross-Product Matching (Finding Complementary Pairs)
Find all pairs of numbers in an array that sum to a target value using nested loops without double-counting.

```python
def find_two_sum_pairs(numbers: list[int], target_sum: int) -> list[tuple[int, int]]:
    pairs = []
    n = len(numbers)
    
    # Outer loop picks first item
    for i in range(n):
        # Inner loop picks second item starting at i + 1 to prevent self-pairing and duplicates
        for j in range(i + 1, n):
            if numbers[i] + numbers[j] == target_sum:
                pairs.append((numbers[i], numbers[j]))
                
    return pairs

nums = [2, 7, 11, 15, 3, 6, 8, 1]
target = 9
found_pairs = find_two_sum_pairs(nums, target)

print(f"Target Sum: {target}")
print(f"Discovered Pairs: {found_pairs}")
```

**Step-by-Step Explanation**:
1. Starting the inner loop at `i + 1` avoids comparing an element with itself.
2. Prevents reciprocal duplicates `(7, 2)` when `(2, 7)` was already discovered.

**Expected Console Output**:
```text
Target Sum: 9
Discovered Pairs: [(2, 7), (3, 6), (8, 1)]
```
