# 04. For Loops & The `range()` Function

## 📖 Concept Overview
In Python, the **`for` loop** is a collection-controlled loop that iterates sequentially over elements in any iterable (strings, lists, tuples, dictionaries, or range objects).

```python
for item in sequence:
    # Process each item
```

---

### 1. The `range()` Function
`range()` generates an immutable sequence of integers on-the-fly without allocating a full list in memory:
```python
range(stop)
range(start, stop[, step])
```
- **`start`**: Starting integer (inclusive, defaults to `0`).
- **`stop`**: Stopping integer (**exclusive**, up to `stop - 1`).
- **`step`**: Increment/step value (defaults to `1`). Can be negative for countdowns.

```python
# 0 to 4
for i in range(5):
    print(i, end=" ")  # 0 1 2 3 4

# 10 down to 2 with step -2
for i in range(10, 0, -2):
    print(i, end=" ")  # 10 8 6 4 2
```

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: High-Performance Data Batch Chunking with `range(start, stop, step)`
Partition a large dataset into fixed-sized chunks for bulk database insertions.

```python
def process_batches(records: list[str], chunk_size: int):
    total = len(records)
    print(f"Total Records to Process: {total}, Chunk Size: {chunk_size}")
    
    # Use range with step = chunk_size to generate slice starting indices
    for start_idx in range(0, total, chunk_size):
        end_idx = min(start_idx + chunk_size, total)
        batch = records[start_idx:end_idx]
        batch_num = (start_idx // chunk_size) + 1
        print(f"Batch #{batch_num} (Indices {start_idx}:{end_idx}): {batch}")

data = [f"Record_{i:02d}" for i in range(1, 11)]
process_batches(data, chunk_size=3)
```

**Step-by-Step Explanation**:
1. `range(0, total, chunk_size)` steps forward by `chunk_size` on each iteration.
2. Uses slice `records[start_idx:end_idx]` to extract the sub-array in constant time.

**Expected Console Output**:
```text
Total Records to Process: 10, Chunk Size: 3
Batch #1 (Indices 0:3): ['Record_01', 'Record_02', 'Record_03']
Batch #2 (Indices 3:6): ['Record_04', 'Record_05', 'Record_06']
Batch #3 (Indices 6:9): ['Record_07', 'Record_08', 'Record_09']
Batch #4 (Indices 9:10): ['Record_10']
```

### Example 2: Mathematical Series Aggregator (Harmonic & Factorial Sum)
Compute mathematical series approximations using `for` loops and accumulators.

```python
def compute_harmonic_series(terms: int) -> float:
    # Harmonic series: H_n = 1/1 + 1/2 + 1/3 + ... + 1/n
    harmonic_sum = 0.0
    for i in range(1, terms + 1):
        harmonic_sum += 1.0 / i
    return round(harmonic_sum, 5)

for n in [1, 5, 10, 50]:
    print(f"Harmonic Sum H({n:>2}): {compute_harmonic_series(n)}")
```

**Step-by-Step Explanation**:
1. Uses `for i in range(1, terms + 1)` to generate exact fractional denominators.
2. Accumulates floating-point sums sequentially.

**Expected Console Output**:
```text
Harmonic Sum H( 1): 1.0
Harmonic Sum H( 5): 2.28333
Harmonic Sum H(10): 2.92897
Harmonic Sum H(50): 4.49921
```

### Example 3: Simultaneous Iteration with `enumerate()` and `zip()`
Combine index tracking and multi-collection parallel iteration in modern Pythonic loops.

```python
def generate_student_grade_report(students: list[str], scores: list[int]):
    print(f"{'Rank':<6} {'Student Name':<15} {'Score':>6} {'Status':>10}")
    print("-" * 40)
    
    # zip pairs items; enumerate tracks 1-based ranking index
    for rank, (name, score) in enumerate(zip(students, scores), start=1):
        status = "PASSED" if score >= 70 else "RETAKE"
        print(f"#{rank:<5} {name:<15} {score:>6} {status:>10}")

cohort = ["David", "Emma", "Frank", "Grace"]
grades = [88, 94, 62, 79]

generate_student_grade_report(cohort, grades)
```

**Step-by-Step Explanation**:
1. `zip(cohort, grades)` streams pairs simultaneously without manual index indexing.
2. `enumerate(..., start=1)` provides direct rank counters cleanly.

**Expected Console Output**:
```text
Rank   Student Name      Score     Status
----------------------------------------
#1     David                88     PASSED
#2     Emma                 94     PASSED
#3     Frank                62     RETAKE
#4     Grace                79     PASSED
```
