# 06. Loop Control: break, continue, pass, and loop-else

## 📖 Concept Overview
Loop control statements alter the sequential flow of loop iterations:

---

### 1. The `break` Statement
Terminates the loop immediately and transfers control to the statement directly following the loop:
```python
for num in [1, 2, 3, 4, 5]:
    if num == 3:
        break
    print(num)  # Prints 1, 2
```

---

### 2. The `continue` Statement
Skips the remaining statements in the **current iteration** and jumps directly to the next iteration:
```python
for num in range(5):
    if num % 2 == 0:
        continue
    print(num)  # Prints 1, 3
```

---

### 3. The `pass` Statement
A null placeholder statement. It does nothing and is used syntactically where a statement is required but no code action should be executed:
```python
for item in stream:
    pass  # To be implemented later
```

---

### 4. The Loop `else` Clause (Special Python Feature)
In Python, loops can have an **`else` clause**.
> [!IMPORTANT]
> The loop `else` block executes **ONLY if the loop terminates normally without hitting a `break` statement**!
> If the loop is terminated early via `break`, the `else` block is completely skipped.

```python
for n in range(2, 10):
    for x in range(2, n):
        if n % x == 0:
            print(f"{n} is not prime ({x} * {n // x})")
            break
    else:
        # Runs only if no break occurred in inner loop!
        print(f"{n} is a PRIME number!")
```

---

## 📋 Summary & Loop Control Reference Table

| Statement | Effect on Loop |
| :--- | :--- |
| `break` | Exits the loop immediately; skips loop `else` clause. |
| `continue` | Skips remainder of current iteration; proceeds to next iteration. |
| `pass` | No operation (NOP); syntactic placeholder. |
| `else:` | Executes when loop completes all iterations naturally without encountering `break`. |

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Prime Number Verification using Loop `else`
Implement a prime number tester utilizing the loop `else` clause to declare primality only when no divisors are found.

```python
def check_prime(candidate: int):
    if candidate <= 1:
        print(f"{candidate} is not prime.")
        return
        
    for divisor in range(2, int(candidate ** 0.5) + 1):
        if candidate % divisor == 0:
            print(f"{candidate} is NOT prime (divisible by {divisor}).")
            break
    else:
        # Reached ONLY if loop completed without hitting 'break'!
        print(f"-> {candidate} is a verified PRIME number!")

check_prime(29)
check_prime(35)
```

**Step-by-Step Explanation**:
1. Loops up to $\sqrt{candidate}$.
2. If any divisor evenly divides candidate, it triggers `break` and exits.
3. If loop finishes with zero breaks, the `else` block executes, confirming primality cleanly without temporary flag variables!

**Expected Console Output**:
```text
-> 29 is a verified PRIME number!
35 is NOT prime (divisible by 5).
```

### Example 2: Stream Data Cleaning with `continue` and Early Exit with `break`
Process incoming stream records, skipping corrupt lines with `continue` and aborting on emergency poison pill signals with `break`.

```python
def process_message_stream(raw_messages: list[str]):
    processed_count = 0
    
    for msg in raw_messages:
        # Strip whitespace
        cleaned = msg.strip()
        
        # 1. Skip empty or comment lines
        if not cleaned or cleaned.startswith("#"):
            continue
            
        # 2. Poison pill abort signal
        if cleaned == "TERMINATE_STREAM":
            print("[ABORT] Emergency kill signal received! Breaking stream processing.")
            break
            
        print(f"Successfully processed message: '{cleaned}'")
        processed_count += 1
    else:
        print("[SUCCESS] All stream messages processed to natural completion.")
        
    print(f"Total Valid Messages Processed: {processed_count}")

stream = [
    "USER_LOGIN: user_42",
    "   ",
    "# This is a comment",
    "ORDER_PLACED: item_99",
    "TERMINATE_STREAM",
    "USER_LOGOUT: user_42"
]

process_message_stream(stream)
```

**Step-by-Step Explanation**:
1. `continue` skips blank and comment lines cleanly.
2. `break` immediately cancels further stream processing upon reaching the kill signal.
3. Because `break` fired, the loop `else` block is correctly skipped.

**Expected Console Output**:
```text
Successfully processed message: 'USER_LOGIN: user_42'
Successfully processed message: 'ORDER_PLACED: item_99'
[ABORT] Emergency kill signal received! Breaking stream processing.
Total Valid Messages Processed: 2
```

### Example 3: Multi-Server Availability Health Check with Fallback
Search through a list of server endpoints for a responding service, falling back to a standby cluster via loop `else`.

```python
def find_active_server(cluster_nodes: list[dict]) -> dict:
    for node in cluster_nodes:
        name = node["name"]
        is_healthy = node["healthy"]
        latency_ms = node["latency_ms"]
        
        print(f"Checking node '{name}'...")
        if not is_healthy:
            print(f"  [SKIP] Node '{name}' marked unhealthy. Continuing...")
            continue
            
        if latency_ms < 50:
            print(f"  [ACCEPTED] Node '{name}' meets SLA criteria ({latency_ms}ms). Connecting!")
            return node
    else:
        # Only triggered if no node satisfied criteria!
        print("[ALERT] No primary nodes satisfied SLA! Routing to Disaster Recovery fallback.")
        return {"name": "Disaster_Recovery_Cold_Standby", "latency_ms": 250}

servers = [
    {"name": "Node-US-East-1", "healthy": False, "latency_ms": 30},
    {"name": "Node-US-East-2", "healthy": True, "latency_ms": 120},
    {"name": "Node-EU-Central", "healthy": True, "latency_ms": 42}
]

selected = find_active_server(servers)
print(f"Active Connected Server: {selected['name']}")
```

**Step-by-Step Explanation**:
1. Skips unhealthy nodes via `continue`.
2. Connects and returns early on the first node meeting SLA.
3. If loop finishes without returning, the `else` clause routes traffic to emergency standby.

**Expected Console Output**:
```text
Checking node 'Node-US-East-1'...
  [SKIP] Node 'Node-US-East-1' marked unhealthy. Continuing...
Checking node 'Node-US-East-2'...
Checking node 'Node-EU-Central'...
  [ACCEPTED] Node 'Node-EU-Central' meets SLA criteria (42ms). Connecting!
Active Connected Server: Node-EU-Central
```
