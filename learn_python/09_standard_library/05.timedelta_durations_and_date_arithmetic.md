# 05. `timedelta`: Durations & Date Arithmetic

## 📖 Concept Overview
A **`timedelta`** object represents a **duration** (the elapsed difference between two dates or times).

```python
from datetime import timedelta
```

### 1. Constructing `timedelta`
Accepts `days`, `seconds`, `microseconds`, `milliseconds`, `minutes`, `hours`, and `weeks`:
```python
delta = timedelta(days=5, hours=3, minutes=30)
```

---

### 2. Date Arithmetic
You can add or subtract `timedelta` objects directly to/from `date` and `datetime` objects:
- `datetime + timedelta` -> future `datetime`
- `datetime - timedelta` -> past `datetime`
- `datetime_2 - datetime_1` -> `timedelta`

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: SLA Deadline and Future Expiration Date Calculator
Compute exact deadline dates and times for customer support service level agreements (SLAs).

```python
from datetime import datetime, timedelta

def calculate_sla_deadline(ticket_opened: datetime, sla_hours: int) -> datetime:
    deadline = ticket_opened + timedelta(hours=sla_hours)
    return deadline

opened_at = datetime(2026, 9, 14, 9, 0, 0)
p1_deadline = calculate_sla_deadline(opened_at, sla_hours=4)
p3_deadline = calculate_sla_deadline(opened_at, sla_hours=72)

print(f"Ticket Opened : {opened_at}")
print(f"P1 SLA (4 hrs): {p1_deadline}")
print(f"P3 SLA (72hrs): {p3_deadline}")
```

**Step-by-Step Explanation**:
1. Adding `timedelta(hours=4)` automatically handles day rollover if past 24:00.
2. Standardizes SLA tracking.

**Expected Console Output**:
```text
Ticket Opened : 2026-09-14 09:00:00
P1 SLA (4 hrs): 2026-09-14 13:00:00
P3 SLA (72hrs): 2026-09-17 09:00:00
```

### Example 2: Countdown Timer to Future Launch Date
Calculate exact days, hours, and minutes remaining until a product launch.

```python
from datetime import datetime, timedelta

def compute_launch_countdown(target_launch: datetime, current_time: datetime) -> dict:
    remaining_delta = target_launch - current_time
    total_seconds = int(remaining_delta.total_seconds())
    
    days = remaining_delta.days
    hours, remainder = divmod(total_seconds % 86400, 3600)
    minutes, seconds = divmod(remainder, 60)
    
    return {"days": days, "hours": hours, "minutes": minutes, "seconds": seconds}

launch_date = datetime(2026, 12, 31, 23, 59, 59)
now = datetime(2026, 9, 14, 12, 0, 0)

countdown = compute_launch_countdown(launch_date, now)
print(f"Launch Countdown: {countdown['days']} days, {countdown['hours']:02d}h {countdown['minutes']:02d}m {countdown['seconds']:02d}s remaining!")
```

**Step-by-Step Explanation**:
1. `delta.total_seconds()` converts duration into absolute seconds.
2. `divmod()` unpacks days, hours, minutes, and seconds.

**Expected Console Output**:
```text
Launch Countdown: 108 days, 11h 59m 59s remaining!
```

### Example 3: Generating Weekly Rolling Date Ranges
Iterate through a 4-week date window generating weekly sprint start dates.

```python
from datetime import date, timedelta

def generate_sprint_calendar(start_date: date, num_sprints: int = 4):
    print("=== Upcoming Agile Sprint Schedule ===")
    one_sprint = timedelta(weeks=2)
    
    current_start = start_date
    for i in range(1, num_sprints + 1):
        sprint_end = current_start + timedelta(days=13)  # 2-week sprint ends on day 14
        print(f"Sprint #{i:02d}: {current_start.isoformat()} to {sprint_end.isoformat()}")
        current_start += one_sprint

generate_sprint_calendar(date(2026, 9, 14))
```

**Step-by-Step Explanation**:
1. Uses `timedelta(weeks=2)` to step through 2-week intervals cleanly.
2. Eliminates manual month boundary calculation.

**Expected Console Output**:
```text
=== Upcoming Agile Sprint Schedule ===
Sprint #01: 2026-09-14 to 2026-09-27
Sprint #02: 2026-09-28 to 2026-10-11
Sprint #03: 2026-10-12 to 2026-10-25
Sprint #04: 2026-10-26 to 2026-11-08
```
