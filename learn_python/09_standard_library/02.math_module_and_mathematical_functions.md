# 02. The `math` Module & Mathematical Operations

## 📖 Concept Overview
The Python standard library **`math` module** provides access to the underlying C library mathematical functions for real-valued floating-point math.

---

### Essential `math` Functions
- **`math.sqrt(x)`**: Returns square root of `x` ($\sqrt{x}$).
- **`math.ceil(x)`**: Rounds **up** to the nearest integer ($\lceil x \rceil$).
- **`math.floor(x)`**: Rounds **down** to the nearest integer ($\lfloor x \rfloor$).
- **`math.factorial(n)`**: Computes $n!$.
- **`math.gcd(a, b)`**: Greatest Common Divisor.
- **`math.hypot(x, y)`**: Returns Euclidean distance $\sqrt{x^2 + y^2}$.
- **Constants**: `math.pi` ($\approx 3.14159$), `math.e` ($\approx 2.71828$), `math.inf`, `math.nan`.

---

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Geometry Surface Area & Volume Calculator
Calculate the volume and surface area of cylinders and spheres using `math.pi`.

```python
import math

def compute_cylinder_metrics(radius: float, height: float) -> dict:
    # Volume: V = pi * r^2 * h
    volume = math.pi * (radius ** 2) * height
    
    # Surface Area: A = 2 * pi * r * h + 2 * pi * r^2
    surface_area = (2 * math.pi * radius * height) + (2 * math.pi * (radius ** 2))
    
    return {
        "radius": radius,
        "height": height,
        "volume": round(volume, 2),
        "surface_area": round(surface_area, 2)
    }

metrics = compute_cylinder_metrics(5.0, 12.0)
print("Cylinder Geometric Metrics:")
for k, v in metrics.items():
    print(f"  {k:<14}: {v}")
```

**Step-by-Step Explanation**:
1. Uses `math.pi` for full double-precision accuracy.
2. Applies standard volume and surface area formulas.

**Expected Console Output**:
```text
Cylinder Geometric Metrics:
  radius        : 5.0
  height        : 12.0
  volume        : 942.48
  surface_area  : 534.07
```

### Example 2: Ceiling Division & Packaging Logistics
Calculate the number of shipping boxes needed for cargo logistics using `math.ceil()`.

```python
import math

def calculate_shipping_containers(total_items: int, box_capacity: int) -> int:
    # math.ceil ensures any fractional leftover requires an extra box
    boxes_needed = math.ceil(total_items / box_capacity)
    print(f"Packaging {total_items} items (Capacity: {box_capacity}/box) -> Requires {boxes_needed} boxes.")
    return boxes_needed

calculate_shipping_containers(100, 25)
calculate_shipping_containers(101, 25)
```

**Step-by-Step Explanation**:
1. 100 items fit exactly into 4 boxes.
2. 101 items require 5 boxes, calculated cleanly via `math.ceil(101 / 25)`.

**Expected Console Output**:
```text
Packaging 100 items (Capacity: 25/box) -> Requires 4 boxes.
Packaging 101 items (Capacity: 25/box) -> Requires 5 boxes.
```

### Example 3: Euclidean Distance and Triangulation with `math.hypot()`
Compute distance between spatial sensors using `math.hypot(dx, dy)`.

```python
import math

def compute_sensor_distance(node_a: tuple[float, float], node_b: tuple[float, float]) -> float:
    dx = node_b[0] - node_a[0]
    dy = node_b[1] - node_a[1]
    # math.hypot avoids intermediate overflow/underflow errors in squaring
    distance = math.hypot(dx, dy)
    return round(distance, 3)

pos1 = (12.0, 15.0)
pos2 = (24.0, 31.0)
dist = compute_sensor_distance(pos1, pos2)
print(f"Distance between {pos1} and {pos2}: {dist} meters")
```

**Step-by-Step Explanation**:
1. `math.hypot` calculates the hypotenuse directly in C, avoiding floating-point overflow during intermediate squaring.

**Expected Console Output**:
```text
Distance between (12.0, 15.0) and (24.0, 31.0): 20.0 meters
```
