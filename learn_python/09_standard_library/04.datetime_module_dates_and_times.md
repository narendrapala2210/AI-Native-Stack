## 📖 Concept Overview
The Python **`datetime`** module provides classes for working with dates, times, and timestamps:
1. **`date`**: Represents calendar dates (year, month, day).
2. **`time`**: Represents idealized time of day independent of date (hour, minute, second, microsecond).
3. **`datetime`**: Combines both date and time into a single object.

---

### 1. Creating Date and Time Objects
```python
from datetime import date, time, datetime

# Current timestamps
today = date.today()
now = datetime.now()

# Specific dates
d = date(2026, 9, 14)
t = time(14, 30, 0)
dt = datetime(2026, 9, 14, 14, 30, 0)
```

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Inspecting Date and Time Object Attributes
Extract individual calendar components from `date` and `time` objects.

```python
from datetime import date, time, datetime

def inspect_datetime_components():
    current = datetime(2026, 9, 14, 11, 34, 56, 120000)
    
    print("=== Datetime Attributes Inspector ===")
    print(f"Year        : {current.year}")
    print(f"Month       : {current.month}")
    print(f"Day         : {current.day}")
    print(f"Hour        : {current.hour}")
    print(f"Minute      : {current.minute}")
    print(f"Second      : {current.second}")
    print(f"Microsecond : {current.microsecond}")
    print(f"Weekday Index: {current.weekday()} (0=Monday, 6=Sunday)")

inspect_datetime_components()
```

#### Step-by-Step Explanation:
1. Demonstrates direct property access on `datetime` instances.
2. `current.weekday()` maps 0 to Monday through 6 to Sunday.

#### Expected Output:
```text
=== Datetime Attributes Inspector ===
Year        : 2026
Month       : 9
Day         : 14
Hour        : 11
Minute      : 34
Second      : 56
Microsecond : 120000
Weekday Index: 0 (0=Monday, 6=Sunday)
```

### Example 2: Expiration and Age Calculator
Calculate elapsed time and remaining subscription validity using `date` comparison.

```python
from datetime import date

def evaluate_license_expiry(purchase_date: date, validity_days: int) -> dict:
    today = date(2026, 9, 14)  # Fixed reference date
    days_used = (today - purchase_date).days
    days_left = validity_days - days_used
    
    is_active = days_left > 0
    return {
        "purchase_date": purchase_date.isoformat(),
        "today": today.isoformat(),
        "days_elapsed": days_used,
        "days_remaining": max(0, days_left),
        "is_active": is_active
    }

report = evaluate_license_expiry(date(2026, 8, 15), 60)
print("License Status Report:")
for k, v in report.items():
    print(f"  {k:<16}: {v}")
```

#### Step-by-Step Explanation:
1. Subtracting two `date` objects yields a `timedelta` object.
2. Accessing `.days` extracts the elapsed calendar day count.

#### Expected Output:
```text
License Status Report:
  purchase_date   : 2026-08-15
  today           : 2026-09-14
  days_elapsed    : 30
  days_remaining  : 30
  is_active       : True
```

### Example 3: ISO 8601 String Parsing & Serialization
Serialize date and time objects to standard ISO 8601 strings and parse them back.

```python
from datetime import datetime

def test_iso_serialization():
    # 1. Object to ISO string
    now = datetime(2026, 9, 14, 15, 45, 30)
    iso_string = now.isoformat()
    print(f"Datetime -> ISO 8601 String: '{iso_string}'")
    
    # 2. ISO string back to Datetime object (Python 3.7+ fromisoformat)
    restored_dt = datetime.fromisoformat(iso_string)
    print(f"ISO String -> Restored Object: {restored_dt} (Year: {restored_dt.year})")

test_iso_serialization()
```

#### Step-by-Step Explanation:
1. `isoformat()` produces standardized timestamps for JSON APIs.
2. `fromisoformat()` parses ISO timestamps back into native datetime objects.

#### Expected Output:
```text
Datetime -> ISO 8601 String: '2026-09-14T15:45:30'
ISO String -> Restored Object: 2026-09-14 15:45:30 (Year: 2026)
```

### Example 4: Modern Timezone Conversions with `zoneinfo` (PEP 615)
Work with global IANA timezone databases (`ZoneInfo`) to handle UTC normalization and Daylight Saving Time (DST) cleanly without third-party libraries.

```python
from datetime import datetime, timezone
from zoneinfo import ZoneInfo

def convert_meeting_times():
    # 1. Create timezone-aware datetime in UTC
    utc_meeting = datetime(2026, 9, 14, 14, 30, tzinfo=timezone.utc)
    print(f"UTC Base Time:        {utc_meeting}")

    # 2. Convert to New York (Eastern Time)
    ny_tz = ZoneInfo("America/New_York")
    ny_meeting = utc_meeting.astimezone(ny_tz)
    print(f"New York Local Time:  {ny_meeting} (TZ: {ny_meeting.tzname()})")

    # 3. Convert to Tokyo (Japan Standard Time)
    tokyo_tz = ZoneInfo("Asia/Tokyo")
    tokyo_meeting = utc_meeting.astimezone(tokyo_tz)
    print(f"Tokyo Local Time:     {tokyo_meeting} (TZ: {tokyo_meeting.tzname()})")

    # 4. Convert to Kolkata (Indian Standard Time)
    kolkata_tz = ZoneInfo("Asia/Kolkata")
    kolkata_meeting = utc_meeting.astimezone(kolkata_tz)
    print(f"Kolkata Local Time:   {kolkata_meeting} (TZ: {kolkata_meeting.tzname()})")

convert_meeting_times()
```

#### Step-by-Step Explanation:
1. Python 3.9+ provides `zoneinfo.ZoneInfo`, integrating standard system and IANA tzdata databases.
2. `datetime.now(timezone.utc)` creates timezone-aware objects with zero ambiguity.
3. `.astimezone(target_tz)` accurately accounts for offsets and Daylight Saving Time transitions automatically.

#### Expected Output:
```text
UTC Base Time:        2026-09-14 14:30:00+00:00
New York Local Time:  2026-09-14 10:30:00-04:00 (TZ: EDT)
Tokyo Local Time:     2026-09-14 23:30:00+09:00 (TZ: JST)
Kolkata Local Time:   2026-09-14 20:00:00+05:30 (TZ: IST)
```
