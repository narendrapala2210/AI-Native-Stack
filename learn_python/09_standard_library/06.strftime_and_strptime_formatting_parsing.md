# 06. `strftime()` & `strptime()`: Formatting and Parsing Dates

## 📖 Concept Overview
Working with dates requires bidirectional conversion between **`datetime` objects** and **human-readable strings**:
- **`strftime()` (String Format Time)**: Converts a `datetime` object **into** a formatted string.
- **`strptime()` (String Parse Time)**: Parses a string **into** a `datetime` object based on a format template.

---

### Format Specifiers Reference Table

| Specifier | Meaning | Example Output |
| :--- | :--- | :--- |
| `%Y` | 4-digit year | `2026` |
| `%y` | 2-digit year without century | `26` |
| `%m` | 2-digit zero-padded month | `09` |
| `%B` | Full month name | `September` |
| `%b` | Abbreviated month name | `Sep` |
| `%d` | 2-digit day of month | `14` |
| `%A` | Full weekday name | `Monday` |
| `%a` | Abbreviated weekday name | `Mon` |
| `%H` | 24-hour format zero-padded | `14` |
| `%I` | 12-hour format zero-padded | `02` |
| `%p` | AM / PM designation | `PM` |
| `%M` | Minute zero-padded | `30` |
| `%S` | Second zero-padded | `45` |

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Formatting Dates for Multilingual & Regional Reports (`strftime`)
Format a single `datetime` instance into multiple regional presentation strings.

```python
from datetime import datetime

dt = datetime(2026, 9, 14, 14, 30, 45)

print("=== Datetime Formatting Catalog (strftime) ===")
print("Standard US Format  :", dt.strftime("%m/%d/%Y %I:%M %p"))
print("European Format     :", dt.strftime("%d/%m/%Y %H:%M:%S"))
print("Verbose Header      :", dt.strftime("%A, %B %d, %Y"))
print("Filename Timestamp  :", dt.strftime("backup_%Y%m%d_%H%M%S.sql"))
```

**Step-by-Step Explanation**:
1. Uses `%A, %B %d, %Y` to construct human-friendly executive titles.
2. Uses `%Y%m%d_%H%M%S` to produce sortable file timestamps.

**Expected Console Output**:
```text
=== Datetime Formatting Catalog (strftime) ===
Standard US Format  : 09/14/2026 02:30 PM
European Format     : 14/09/2026 14:30:45
Verbose Header      : Monday, September 14, 2026
Filename Timestamp  : backup_20260914_143045.sql
```

### Example 2: Parsing Diverse External API Date Strings (`strptime`)
Parse incoming timestamp strings from external third-party services into standard `datetime` objects.

```python
from datetime import datetime

def parse_external_timestamp(date_str: str) -> datetime:
    # Example format: '28 November, 2018 at 10:15 PM'
    # Clean template matching
    cleaned = date_str.replace(" at ", " ")
    parsed_dt = datetime.strptime(cleaned, "%d %B, %Y %I:%M %p")
    return parsed_dt

sample_stamp = "28 November, 2018 at 10:15 PM"
parsed = parse_external_timestamp(sample_stamp)

print(f"Raw String: '{sample_stamp}'")
print(f"Parsed Object: {parsed} (Type: {type(parsed).__name__})")
print(f"Extracted Year: {parsed.year}, Month: {parsed.month}, Hour: {parsed.hour}")
```

**Step-by-Step Explanation**:
1. `strptime` expects an exact structural match of formatting tokens.
2. Successfully extracts year, month, and 24-hour representation.

**Expected Console Output**:
```text
Raw String: '28 November, 2018 at 10:15 PM'
Parsed Object: 2018-11-28 22:15:00 (Type: datetime)
Extracted Year: 2018, Month: 11, Hour: 22
```

### Example 3: Multi-Format Tolerant Ingestion Parser
Safely attempt parsing dates across multiple common date formats without crashing.

```python
from datetime import datetime

def robust_date_parser(raw_string: str) -> datetime | None:
    candidate_formats = [
        "%Y-%m-%d",           # ISO format: 2026-09-14
        "%d/%m/%Y",           # UK format: 14/09/2026
        "%m/%d/%Y",           # US format: 09/14/2026
        "%d-%b-%Y",           # Short month: 14-Sep-2026
        "%B %d, %Y"           # Verbose: September 14, 2026
    ]
    
    cleaned = raw_string.strip()
    for fmt in candidate_formats:
        try:
            return datetime.strptime(cleaned, fmt)
        except ValueError:
            continue
            
    print(f"[REJECTED] Unrecognized date format: '{raw_string}'")
    return None

print("Parsed 1:", robust_date_parser("2026-09-14"))
print("Parsed 2:", robust_date_parser("14-Sep-2026"))
print("Parsed 3:", robust_date_parser("September 14, 2026"))
print("Parsed 4:", robust_date_parser("invalid_date_token"))
```

**Step-by-Step Explanation**:
1. Iterates through candidate templates catching `ValueError`.
2. Returns a normalized `datetime` instance regardless of input variance.

**Expected Console Output**:
```text
Parsed 1: 2026-09-14 00:00:00
Parsed 2: 2026-09-14 00:00:00
Parsed 3: 2026-09-14 00:00:00
[REJECTED] Unrecognized date format: 'invalid_date_token'
Parsed 4: None
```
