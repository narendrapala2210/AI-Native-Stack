## 📖 Concept Overview
In Python, **any file containing Python code (`.py`) is a Module**. Organizing related functions, classes, and constants into modules enables clean separation of concerns and code reuse.

### 1. Import Syntaxes
```python
# 1. Whole module import
import math
print(math.sqrt(25))

# 2. Specific symbol import
from math import sqrt, pi
print(sqrt(25))

# 3. Aliasing with 'as' (renaming for brevity or conflict avoidance)
import numpy as np
from datetime import datetime as dt
```

---

### 2. Module Execution: `if __name__ == '__main__':`
When a file is executed directly from the terminal, Python sets the special built-in variable `__name__` to `"__main__"`. When imported as a module into another file, `__name__` is set to the module's filename.

```python
def main():
    print("Running as main standalone program!")

if __name__ == "__main__":
    main()
```

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Creating and Importing a Custom Utilities Module
Simulate creating a standalone calculation module and importing its functions cleanly.

```python
# Simulated module 'string_helpers.py'
class StringHelpers:
    @staticmethod
    def slugify(text: str) -> str:
        # Convert 'Hello World' -> 'hello-world'
        return text.strip().lower().replace(" ", "-")

# Simulated importing file:
from StringHelpers import slugify as create_slug

title = "Python 3 Mastery Course"
slug = StringHelpers.slugify(title)
print(f"Original Title: '{title}'")
print(f"Generated Slug: '{slug}'")
```

#### Step-by-Step Explanation:
1. Demonstrates modular helper encapsulation.
2. Uses aliasing to make function names fit local application semantics.

#### Expected Output:
```text
Original Title: 'Python 3 Mastery Course'
Generated Slug: 'python-3-mastery-course'
```

### Example 2: Module Search Path (`sys.path`) Inspection
Inspect the directories Python searches through when executing an `import` statement.

```python
import sys

def inspect_python_import_path():
    print("=== Python Module Search Directories (sys.path) ===")
    for idx, directory in enumerate(sys.path[:5], start=1):
        print(f"  {idx}. {directory}")

inspect_python_import_path()
```

#### Step-by-Step Explanation:
1. `sys.path[0]` is always the directory containing the running script.
2. Demonstrates where Python looks to locate standard libraries and third-party packages.

#### Expected Output:
```text
=== Python Module Search Directories (sys.path) ===
  1. e:\Learnings\Courses\AI Full Stack
  2. C:\Python312\python312.zip
  3. C:\Python312\DLLs
  4. C:\Python312\Lib
  5. C:\Python312
```

### Example 3: Dynamic Module Introspection (`dir()` and `__all__`)
Inspect all public attributes and functions exported by a standard module.

```python
import math

def inspect_module_capabilities(module_obj):
    all_members = dir(module_obj)
    # Filter out private / dunder methods
    public_functions = [m for m in all_members if not m.startswith("_")]
    
    print(f"Module '{module_obj.__name__}' exports {len(public_functions)} public members.")
    print(f"Sample functions: {public_functions[:8]}")

inspect_module_capabilities(math)
```

#### Step-by-Step Explanation:
1. `dir(module)` lists all symbols in the module namespace.
2. Filtering out `_` prefixes isolates the public API.

#### Expected Output:
```text
Module 'math' exports 65 public members.
Sample functions: ['acos', 'acosh', 'asin', 'asinh', 'atan', 'atan2', 'atanh', 'cbrt']
```
