# 05. Inheritance: Single & Multilevel

## 📖 Concept Overview
**Inheritance** is a mechanism where a new class (**Subclass / Derived Class**) inherits attributes and methods from an existing class (**Superclass / Base Class**), representing an **IS-A relationship**.

### 1. Single Inheritance
A subclass inherits from a single parent class:
```python
class Product:
    def __init__(self, name, price):
        self.name = name
        self.price = price

class ElectronicItem(Product):  # ElectronicItem IS-A Product
    def __init__(self, name, price, warranty_months):
        super().__init__(name, price)  # Delegate to parent constructor
        self.warranty = warranty_months
```

---

### 2. Multilevel Inheritance
A class extends a subclass, forming an inheritance chain:
```python
class Device:           # Grandparent
    pass

class Computer(Device): # Parent
    pass

class Laptop(Computer): # Child
    pass
```
Instances of `Laptop` inherit methods and attributes from both `Computer` and `Device`.

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: E-Commerce Product Hierarchy
Model an online retail inventory hierarchy where specialized items inherit core attributes.

```python
class Product:
    def __init__(self, name: str, base_price: float):
        self.name = name
        self.price = base_price

    def get_display_details(self) -> str:
        return f"Product: {self.name} | Price: ${self.price:.2f}"

class GroceryItem(Product):
    def __init__(self, name: str, base_price: float, expiry_days: int):
        super().__init__(name, base_price)
        self.expiry_days = expiry_days

    def get_display_details(self) -> str:
        # Extend parent display details
        base = super().get_display_details()
        return f"{base} | Shelf Life: {self.expiry_days} days"

item1 = Product("Office Desk", 250.00)
item2 = GroceryItem("Organic Milk", 4.50, 7)

print(item1.get_display_details())
print(item2.get_display_details())
```

**Step-by-Step Explanation**:
1. `GroceryItem` inherits `self.name` and `self.price` via `super().__init__`.
2. Extends `get_display_details` with grocery-specific expiry metadata.

**Expected Console Output**:
```text
Product: Office Desk | Price: $250.00
Product: Organic Milk | Price: $4.50 | Shelf Life: 7 days
```

### Example 2: Multilevel Employee Hierarchy & Payroll
Model an organizational hierarchy: `Person` -> `Employee` -> `EngineeringManager`.

```python
class Person:
    def __init__(self, full_name: str, national_id: str):
        self.name = full_name
        self.id = national_id

class Employee(Person):
    def __init__(self, full_name: str, national_id: str, employee_id: str, base_salary: float):
        super().__init__(full_name, national_id)
        self.emp_id = employee_id
        self.salary = base_salary

    def compute_annual_pay(self) -> float:
        return self.salary

class EngineeringManager(Employee):
    def __init__(self, full_name: str, national_id: str, employee_id: str, base_salary: float, stock_bonus: float):
        super().__init__(full_name, national_id, employee_id, base_salary)
        self.stock_bonus = stock_bonus

    def compute_annual_pay(self) -> float:
        # Adds stock bonus to base salary
        return self.salary + self.stock_bonus

mgr = EngineeringManager("Claire Vance", "NAT-9981", "EMP-042", 140000.0, 35000.0)
print(f"Manager Name: {mgr.name} (National ID: {mgr.id})")
print(f"Employee ID : {mgr.emp_id}")
print(f"Total Annual: ${mgr.compute_annual_pay():,.2f}")
```

**Step-by-Step Explanation**:
1. Attributes cascade down 3 tiers: `Person` -> `Employee` -> `EngineeringManager`.
2. `compute_annual_pay` is overridden polymorphically.

**Expected Console Output**:
```text
Manager Name: Claire Vance (National ID: NAT-9981)
Employee ID : EMP-042
Total Annual: $175,000.00
```

### Example 3: Verification with `isinstance()` and `issubclass()`
Verify object inheritance hierarchies programmatically.

```python
class Vehicle:
    pass

class Aircraft(Vehicle):
    pass

class Drone(Aircraft):
    pass

quadcopter = Drone()

print("isinstance(quadcopter, Drone)   :", isinstance(quadcopter, Drone))
print("isinstance(quadcopter, Aircraft):", isinstance(quadcopter, Aircraft))
print("isinstance(quadcopter, Vehicle) :", isinstance(quadcopter, Vehicle))

print("\nissubclass(Drone, Aircraft) :", issubclass(Drone, Aircraft))
print("issubclass(Drone, Vehicle)  :", issubclass(Drone, Vehicle))
```

**Step-by-Step Explanation**:
1. `isinstance` checks if an object is an instance of a class or any of its ancestors.
2. `issubclass` tests class hierarchy relationships.

**Expected Console Output**:
```text
isinstance(quadcopter, Drone)   : True
isinstance(quadcopter, Aircraft): True
isinstance(quadcopter, Vehicle) : True

issubclass(Drone, Aircraft) : True
issubclass(Drone, Vehicle)  : True
```
