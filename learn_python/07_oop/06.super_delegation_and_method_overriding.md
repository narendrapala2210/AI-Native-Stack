## 📖 Concept Overview
- **Method Overriding**: When a subclass provides its own specific implementation of a method that is already defined in its superclass.
- **`super()`**: Returns a proxy object that delegates method calls to a parent or sibling class in the **Method Resolution Order (MRO)**.

---

### 1. The Power of `super()`
Instead of hardcoding parent names like `ParentClass.__init__(self, ...)`, `super().__init__(...)` automatically resolves the correct next class in the MRO, which is essential for multiple inheritance and cooperative classes.

```python
class Parent:
    def greet(self):
        print("Greetings from Parent!")

class Child(Parent):
    def greet(self):
        super().greet()  # Call parent method first
        print("Hello from Child!")
```

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Notification Dispatcher with Template Method Overriding
Implement an extensible notification pipeline where derived classes customize message formatting.

```python
class BaseNotifier:
    def format_message(self, recipient: str, body: str) -> str:
        return f"To: {recipient}\nBody: {body}"

    def send(self, recipient: str, body: str):
        formatted = self.format_message(recipient, body)
        print("=== Transmitting Notification ===")
        print(formatted)
        print("Transmission Complete.\n")

class SMSNotifier(BaseNotifier):
    def format_message(self, recipient: str, body: str) -> str:
        # Override formatting to enforce SMS 160-char truncation
        truncated = body[:160]
        return f"[SMS -> {recipient}]: {truncated}"

class EmailNotifier(BaseNotifier):
    def format_message(self, recipient: str, body: str) -> str:
        return f"[EMAIL -> {recipient}]\nSubject: Notification Alert\nMessage: {body}"

sms = SMSNotifier()
email = EmailNotifier()

sms.send("+1-555-0199", "Your one-time passcode is 884129.")
email.send("alex@dev.org", "Your monthly cloud server invoice is available for download.")
```

#### Step-by-Step Explanation:
1. `BaseNotifier.send()` calls `self.format_message()`.
2. Python invokes the overridden subclass implementation polymorphically.

#### Expected Output:
```text
=== Transmitting Notification ===
[SMS -> +1-555-0199]: Your one-time passcode is 884129.
Transmission Complete.

=== Transmitting Notification ===
[EMAIL -> alex@dev.org]
Subject: Notification Alert
Message: Your monthly cloud server invoice is available for download.
Transmission Complete.
```

### Example 2: Cooperative Multiple Inheritance & MRO Inspection
Demonstrate how `super()` cooperatively walks the Method Resolution Order (`__mro__`).

```python
class A:
    def action(self):
        print("A.action()")

class B(A):
    def action(self):
        print("B.action() start")
        super().action()
        print("B.action() end")

class C(A):
    def action(self):
        print("C.action() start")
        super().action()
        print("C.action() end")

class D(B, C):
    def action(self):
        print("D.action() start")
        super().action()
        print("D.action() end")

print("=== MRO for Class D ===")
for cls in D.__mro__:
    print(" ", cls.__name__)

print("\n=== Executing D().action() ===")
d = D()
d.action()
```

#### Step-by-Step Explanation:
1. C3 Linearization determines MRO: `D -> B -> C -> A -> object`.
2. `super().action()` inside `B` calls `C.action()`, demonstrating cooperative execution.

#### Expected Output:
```text
=== MRO for Class D ===
  D
  B
  C
  A
  object

=== Executing D().action() ===
D.action() start
B.action() start
C.action() start
A.action()
C.action() end
B.action() end
D.action() end
```

### Example 3: Transactional Order Processor with Super Delegation
Add discount validation and audit tracking to an order processor while delegating core persistence to the superclass.

```python
class BaseOrderProcessor:
    def process(self, order_id: str, amount: float) -> bool:
        print(f"Base: Charging ${amount:.2f} for Order #{order_id} to payment gateway.")
        return True

class DiscountedAuditOrderProcessor(BaseOrderProcessor):
    def process(self, order_id: str, amount: float, discount_code: str | None = None) -> bool:
        final_amount = amount
        if discount_code == "SAVE20":
            final_amount *= 0.8
            print(f"Applied 20% discount code '{discount_code}'.")
            
        # Delegate core processing to base class
        success = super().process(order_id, final_amount)
        
        if success:
            print(f"[AUDIT] Order #{order_id} recorded in secure ledger.")
        return success

processor = DiscountedAuditOrderProcessor()
processor.process("ORD-9912", 200.00, discount_code="SAVE20")
```

#### Step-by-Step Explanation:
1. Subclass intercepts parameters, computes discounts, and delegates to `super().process()`.
2. Appends post-processing audit logging upon completion.

#### Expected Output:
```text
Applied 20% discount code 'SAVE20'.
Base: Charging $160.00 for Order #ORD-9912 to payment gateway.
[AUDIT] Order #ORD-9912 recorded in secure ledger.
```
