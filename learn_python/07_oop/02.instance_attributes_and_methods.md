# 02. Instance Attributes & Methods

## 📖 Concept Overview
In Python OOP:
- **Instance Attributes**: Variables bound to a specific object instance via `self.attr`. Each instance maintains its own distinct copy of these attributes.
- **Instance Methods**: Functions defined inside a class that take `self` as their first parameter, enabling them to inspect and mutate the calling instance's state.

---

### 1. Calling Instance Methods
When you call `object.method(arg)`, Python internally translates this into:
```python
ClassName.method(object, arg)
```
This is why `self` is always passed implicitly!

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: E-Commerce Shopping Cart with Dynamic Methods
Implement item addition, quantity updates, removal, and pricing calculations.

```python
class ShoppingCart:
    def __init__(self, customer_name: str):
        self.customer = customer_name
        self.items: dict[str, dict] = {}

    def add_item(self, item_name: str, unit_price: float, quantity: int = 1):
        if item_name in self.items:
            self.items[item_name]["qty"] += quantity
        else:
            self.items[item_name] = {"price": unit_price, "qty": quantity}
        print(f"Added {quantity}x '{item_name}' for {self.customer}.")

    def remove_item(self, item_name: str):
        if item_name in self.items:
            del self.items[item_name]
            print(f"Removed '{item_name}' from cart.")
        else:
            print(f"Item '{item_name}' not present in cart.")

    def calculate_total(self) -> float:
        return sum(d["price"] * d["qty"] for d in self.items.values())

cart = ShoppingCart("Ananya")
cart.add_item("Python Book", 45.0, 2)
cart.add_item("Headphones", 80.0, 1)
print(f"Cart Total for {cart.customer}: ${cart.calculate_total():.2f}")
cart.remove_item("Headphones")
print(f"Updated Total: ${cart.calculate_total():.2f}")
```

**Step-by-Step Explanation**:
1. `self.items` stores product line items.
2. `calculate_total` dynamically iterates over the instance's dictionary values.

**Expected Console Output**:
```text
Added 2x 'Python Book' for Ananya.
Added 1x 'Headphones' for Ananya.
Cart Total for Ananya: $170.00
Removed 'Headphones' from cart.
Updated Total: $90.00
```

### Example 2: Vehicle Telemetry Odometer & Trip Computer
Track vehicle speed, mileage, and fuel efficiency via instance state modifications.

```python
class VehicleTripComputer:
    def __init__(self, vin: str, model: str, fuel_capacity_liters: float):
        self.vin = vin
        self.model = model
        self.tank_capacity = fuel_capacity_liters
        self.fuel_level = fuel_capacity_liters
        self.odometer_km = 0.0

    def drive(self, distance_km: float, km_per_liter: float = 15.0):
        fuel_needed = distance_km / km_per_liter
        if fuel_needed > self.fuel_level:
            possible_km = self.fuel_level * km_per_liter
            self.odometer_km += possible_km
            self.fuel_level = 0.0
            print(f"[OUT OF FUEL] Traveled {possible_km:.1f} km before fuel depleted. Odometer: {self.odometer_km:.1f} km")
        else:
            self.odometer_km += distance_km
            self.fuel_level -= fuel_needed
            print(f"Drove {distance_km:.1f} km. Odometer: {self.odometer_km:.1f} km, Fuel remaining: {self.fuel_level:.1f} L")

car = VehicleTripComputer("VIN-8842", "Sedan GT", 50.0)
car.drive(150.0)
car.drive(700.0)  # Exceeds remaining fuel
```

**Step-by-Step Explanation**:
1. Mutates `self.odometer_km` and `self.fuel_level` realistically.
2. Handles running out of fuel when distance exceeds remaining tank capacity.

**Expected Console Output**:
```text
Drove 150.0 km. Odometer: 150.0 km, Fuel remaining: 40.0 L
[OUT OF FUEL] Traveled 600.0 km before fuel depleted. Odometer: 750.0 km
```

### Example 3: Method Chaining (Fluent Interface Pattern)
Implement method chaining by returning `self` from instance methods.

```python
class QueryBuilder:
    def __init__(self, table_name: str):
        self.table = table_name
        self.fields = ["*"]
        self.where_clauses = []
        self.limit_val = None

    def select(self, *fields: str):
        self.fields = list(fields)
        return self  # Return self to allow chaining!

    def where(self, condition: str):
        self.where_clauses.append(condition)
        return self

    def limit(self, count: int):
        self.limit_val = count
        return self

    def build_sql(self) -> str:
        sql = f"SELECT {', '.join(self.fields)} FROM {self.table}"
        if self.where_clauses:
            sql += " WHERE " + " AND ".join(self.where_clauses)
        if self.limit_val is not None:
            sql += f" LIMIT {self.limit_val}"
        return sql + ";"

# Fluent method chaining:
query = (
    QueryBuilder("orders")
    .select("order_id", "total_price", "status")
    .where("status = 'COMPLETED'")
    .where("total_price > 100")
    .limit(10)
    .build_sql()
)

print("Constructed SQL Query:")
print(" ", query)
```

**Step-by-Step Explanation**:
1. Returning `self` allows consecutive method calls `.select().where().limit()`.
2. This is the fluent builder pattern used in modern ORMs.

**Expected Console Output**:
```text
Constructed SQL Query:
  SELECT order_id, total_price, status FROM orders WHERE status = 'COMPLETED' AND total_price > 100 LIMIT 10;
```
