## 1. Conceptual Deep-Dive: Generic Programming

Generics allow functions and data structures to operate over arbitrary types while retaining static type safety:
1. **Classic Generics (`TypeVar` & `Generic[T]`)**:
   - Prior to Python 3.12, generics required importing `TypeVar` and subclassing `Generic[T]`:
     ```python
     from typing import TypeVar, Generic
     T = TypeVar("T")
     class Stack(Generic[T]): pass
     ```
2. **Modern Python 3.12+ Type Parameter Syntax (PEP 695)**:
   - Python 3.12 introduced clean, native generic syntax without imports:
     - Generic classes: `class Stack[T]:`
     - Generic functions: `def first[T](items: list[T]) -> T:`
     - Generic type aliases: `type Matrix[T] = list[list[T]]`
   - Scoped automatically to the class or function definition.

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Generic Thread-Safe LIFO Stack
Build a generic container that enforces uniform element types.

```python
from typing import TypeVar, Generic

T = TypeVar("T")

class GenericStack(Generic[T]):
    def __init__(self):
        self._items: list[T] = []

    def push(self, item: T) -> None:
        self._items.append(item)

    def pop(self) -> T:
        if not self._items:
            raise IndexError("pop from empty stack")
        return self._items.pop()

    def __len__(self) -> int:
        return len(self._items)

def test_generic_stack():
    # Stack constrained to integers
    int_stack: GenericStack[int] = GenericStack()
    int_stack.push(10)
    int_stack.push(20)
    int_stack.push(30)

    print(f"Stack size: {len(int_stack)}")
    print(f"Popped: {int_stack.pop()}")
    print(f"Popped: {int_stack.pop()}")

test_generic_stack()
```

#### Step-by-Step Explanation:
1. `Generic[T]` parameters inform static analyzers of element consistency across `push()` and `pop()`.

#### Expected Output:
```text
Stack size: 3
Popped: 30
Popped: 20
```

### Example 2: Generic Function with Bounded `TypeVar`
Constrain generic parameters to specific allowed type hierarchies.

```python
from typing import TypeVar

# Bounded TypeVar: Must be int or float
Numeric = TypeVar("Numeric", int, float)

def calculate_midpoint(a: Numeric, b: Numeric) -> float:
    return (a + b) / 2.0

def test_bounded_generic():
    print("Midpoint of ints   (10, 20):", calculate_midpoint(10, 20))
    print("Midpoint of floats (3.5, 7.5):", calculate_midpoint(3.5, 7.5))

test_bounded_generic()
```

#### Step-by-Step Explanation:
1. `TypeVar("Numeric", int, float)` restricts arguments strictly to numeric types, disallowing strings or lists.

#### Expected Output:
```text
Midpoint of ints   (10, 20): 15.0
Midpoint of floats (3.5, 7.5): 5.5
```

### Example 3: Demonstration of Python 3.12 PEP 695 Syntax
Demonstrate the new native bracket type parameter syntax.

```python
def explain_pep_695():
    sample_code = '''
# Python 3.12+ Syntax (No TypeVar import needed!):
class Cache[T]:
    def __init__(self) -> None:
        self.storage: dict[str, T] = {}

    def set(self, key: str, value: T) -> None:
        self.storage[key] = value

    def get(self, key: str) -> T | None:
        return self.storage.get(key)
'''
    print("Python 3.12+ Native Generic Syntax (PEP 695):")
    print(sample_code.strip())

explain_pep_695()
```

#### Step-by-Step Explanation:
1. PEP 695 eliminates the need to declare explicit `T = TypeVar('T')` global variables.

#### Expected Output:
```text
Python 3.12+ Native Generic Syntax (PEP 695):
# Python 3.12+ Syntax (No TypeVar import needed!):
class Cache[T]:
    def __init__(self) -> None:
        self.storage: dict[str, T] = {}

    def set(self, key: str, value: T) -> None:
        self.storage[key] = value

    def get(self, key: str) -> T | None:
        return self.storage.get(key)
```
