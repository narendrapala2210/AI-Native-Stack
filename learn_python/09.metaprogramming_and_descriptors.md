# 9. Metaprogramming, Descriptors & Dynamic Python

### 9.1 The Descriptor Protocol (`__get__`, `__set__`, `__delete__`, `__set_name__`)
Descriptors are the underlying engine behind `@property`, methods, `@classmethod`, `@staticmethod`, and ORMs like Django and SQLAlchemy.

A descriptor is any object that implements at least one of `__get__`, `__set__`, or `__delete__`.

```python
class NonNegativeNumber:
    """Descriptor that enforces non-negative numeric values."""
    def __set_name__(self, owner, name):
        # Automatically captured attribute name
        self.public_name = name
        self.private_name = f"_{name}"

    def __get__(self, instance, owner):
        if instance is None:
            return self
        return getattr(instance, self.private_name, 0)

    def __set__(self, instance, value):
        if not isinstance(value, (int, float)) or value < 0:
            raise ValueError(f"'{self.public_name}' must be a non-negative number.")
        setattr(instance, self.private_name, value)

class InventoryItem:
    quantity = NonNegativeNumber()
    price = NonNegativeNumber()

    def __init__(self, name: str, quantity: int, price: float):
        self.name = name
        self.quantity = quantity
        self.price = price

item = InventoryItem("Monitor", 15, 299.99)
print(f"Item: {item.name}, Stock: {item.quantity}, Price: ${item.price}")

try:
    item.price = -50.0  # Raises ValueError
except ValueError as e:
    print("Descriptor validation caught error:", e)
```

### 9.2 Dynamic Type Creation with `type()`
`type()` is not just a type checker—it is the default metaclass that creates classes!
`type(name, bases, dict)` dynamically constructs a class at runtime.

```python
# Dynamic class creation:
# Equivalent to: class DynamicModel(BaseClass): def speak(self): ...

def speak_method(self):
    return f"Hello, I am {self.name}"

DynamicModel = type(
    "DynamicModel",          # Class Name
    (object,),               # Base classes tuple
    {                        # Class attributes & methods dictionary
        "species": "Canine",
        "speak": speak_method,
        "__init__": lambda self, name: setattr(self, "name", name)
    }
)

obj = DynamicModel("Buddy")
print("Class created via type():", type(obj))
print(obj.speak())
print("Species attribute:", obj.species)
```

### 9.3 Custom Metaclasses & `__init_subclass__`

#### 1. Custom Metaclass:
A metaclass is a "class of a class". It intercepts class creation.

```python
class EnforceMethodsMeta(type):
    """Metaclass ensuring all subclasses implement 'execute' method."""
    def __new__(mcs, name, bases, namespace):
        # Avoid checking the abstract base class itself
        if bases and "execute" not in namespace:
            raise TypeError(f"Class '{name}' must define an 'execute' method!")
        return super().__new__(mcs, name, bases, namespace)

class BaseTask(metaclass=EnforceMethodsMeta):
    pass

class ValidTask(BaseTask):
    def execute(self):
        return "Task completed."

# class InvalidTask(BaseTask): pass
# The line above would raise TypeError at the time the class is defined!
```

#### 2. Modern Alternative: `__init_subclass__` (PEP 487)
For 95% of use cases, `__init_subclass__` provides a much cleaner, simpler alternative to metaclasses.

```python
class PluginBase:
    registry = {}

    # Triggered whenever this class is subclassed
    def __init_subclass__(cls, plugin_name=None, **kwargs):
        super().__init_subclass__(**kwargs)
        name = plugin_name or cls.__name__
        cls.registry[name] = cls
        print(f"Registered plugin: '{name}' -> {cls}")

class PDFPlugin(PluginBase, plugin_name="pdf_export"):
    pass

class ExcelPlugin(PluginBase, plugin_name="excel_export"):
    pass

print("Discovered registry:", PluginBase.registry)
```

### 9.4 Dynamic Inspection & Attribute Hooks (`getattr`, `setattr`, `__getattr__`)

- `__getattr__(self, name)`: Fallback method called **only** when the attribute is NOT found in the instance or class hierarchy.
- `__getattribute__(self, name)`: Intercepts **every single** attribute lookup unconditionally.

```python
class DynamicConfig:
    def __init__(self, **kwargs):
        self._data = kwargs

    def __getattr__(self, item):
        # Fallback when attribute is not in normal namespace
        if item in self._data:
            return self._data[item]
        raise AttributeError(f"Config option '{item}' does not exist.")

    def __setattr__(self, key, value):
        if key == "_data":
            super().__setattr__(key, value)
        else:
            self._data[key] = value

config = DynamicConfig(env="production", port=443)
print("Config env:", config.env)
print("Config port:", config.port)

# Built-in reflection functions: getattr, hasattr, setattr
setattr(config, "timeout", 30)
print("Has timeout?", hasattr(config, "timeout"))
print("Retrieved via getattr:", getattr(config, "timeout"))
```

### 9.5 Introspection with `inspect` & AST Parsing with `ast`

#### 1. Live Runtime Introspection with `inspect`:
Inspect live objects, call stacks, frames, and signatures programmatically (used heavily by FastAPI, pytest, and dependency injection frameworks).

```python
import inspect

def calculate_premium(base_fee: float, risk_factor: float = 1.2, *tags, **opts) -> float:
    """Calculate the insurance premium given risk adjustments."""
    return base_fee * risk_factor

# Inspecting function signature and default values
sig = inspect.signature(calculate_premium)
print("Signature:", sig)
for param_name, param in sig.parameters.items():
    print(f"Param: {param_name} | Kind: {param.kind} | Default: {param.default} | Annotation: {param.annotation}")

# Inspecting caller's call stack frames
def trace_caller():
    frame = inspect.currentframe().f_back
    print(f"Called from function '{frame.f_code.co_name}' at line {frame.f_lineno}")

def trigger():
    trace_caller()

trigger()
```

#### 2. Abstract Syntax Tree (AST) Parsing & Analysis with `ast`:
Parse Python source code into an AST tree to perform static analysis, code linting, security audits, or syntax transformations.

```python
import ast

code_sample = """
def authenticate(token):
    if token == 'secret_admin_token':
        return True
    return False
"""

# Parse code into an AST
tree = ast.parse(code_sample)

# NodeVisitor walks the AST tree
class SecurityAuditor(ast.NodeVisitor):
    def visit_Constant(self, node):
        if isinstance(node.value, str) and "token" in node.value:
            print(f"[SECURITY WARNING] Hardcoded credential found at line {node.lineno}: '{node.value}'")
        self.generic_visit(node)

auditor = SecurityAuditor()
auditor.visit(tree)
```

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Production ORM Field Validator with Descriptor Protocol
Build a reusable typed schema validator for database models that enforces types and bounds.

```python
class StringField:
    def __set_name__(self, owner, name):
        self.public_name = name
        self.private_name = f"_{name}"

    def __get__(self, instance, owner):
        if instance is None:
            return self
        return getattr(instance, self.private_name, "")

    def __set__(self, instance, value):
        if not isinstance(value, str) or not value.strip():
            raise ValueError(f"Field '{self.public_name}' must be a non-empty string.")
        setattr(instance, self.private_name, value.strip())

class IntegerField:
    def __init__(self, min_val: int = 0, max_val: int = 150):
        self.min_val = min_val
        self.max_val = max_val

    def __set_name__(self, owner, name):
        self.public_name = name
        self.private_name = f"_{name}"

    def __get__(self, instance, owner):
        if instance is None:
            return self
        return getattr(instance, self.private_name, 0)

    def __set__(self, instance, value):
        if not isinstance(value, int) or not (self.min_val <= value <= self.max_val):
            raise ValueError(f"Field '{self.public_name}' must be integer between {self.min_val} and {self.max_val}.")
        setattr(instance, self.private_name, value)

class UserAccount:
    username = StringField()
    age = IntegerField(min_val=18, max_val=120)

    def __init__(self, username: str, age: int):
        self.username = username
        self.age = age

user = UserAccount("  alex_dev  ", 25)
print(f"Validated user: '{user.username}', Age: {user.age}")

try:
    user.age = 15  # Raises ValueError
except ValueError as err:
    print("[DESCRIPTOR VALIDATION FAILED]", err)
```

### Example 2: Auto-Registering Plugin Architecture via `__init_subclass__`
Automatically discover, validate, and register service handlers when classes are defined.

```python
class PaymentProcessorPlugin:
    registry = {}

    def __init_subclass__(cls, provider_id: str = None, **kwargs):
        super().__init_subclass__(**kwargs)
        if not provider_id:
            raise TypeError(f"Plugin '{cls.__name__}' must specify a 'provider_id'")
        if provider_id in cls.registry:
            raise ValueError(f"Duplicate provider_id '{provider_id}' already registered!")
        cls.registry[provider_id] = cls
        print(f"[PLUGIN SYSTEM] Registered payment provider: '{provider_id}'")

    def process(self, amount: float) -> str:
        raise NotImplementedError

class StripePlugin(PaymentProcessorPlugin, provider_id="stripe"):
    def process(self, amount: float):
        return f"Charged ${amount:.2f} via Stripe API"

class PayPalPlugin(PaymentProcessorPlugin, provider_id="paypal"):
    def process(self, amount: float):
        return f"Charged ${amount:.2f} via PayPal API"

print("Active Plugins:", list(PaymentProcessorPlugin.registry.keys()))
processor = PaymentProcessorPlugin.registry["stripe"]()
print(processor.process(99.95))
```

### Example 3: Dynamic API Proxy Client with `__getattr__`
Intercept arbitrary method calls to make dynamic RPC or REST requests on the fly without declaring methods in advance.

```python
class DynamicApiClient:
    def __init__(self, base_endpoint: str):
        self.base_endpoint = base_endpoint.rstrip("/")

    def __getattr__(self, endpoint_name: str):
        # Returns a callable that simulates requesting the endpoint
        def endpoint_caller(*args, **kwargs):
            full_url = f"{self.base_endpoint}/{endpoint_name.replace('_', '/')}"
            return {
                "url": full_url,
                "params": kwargs,
                "status": "200_OK",
                "message": f"Successfully queried endpoint: {endpoint_name}"
            }
        return endpoint_caller

client = DynamicApiClient("https://api.internal.service/v1")
# Calling non-existent methods dynamically intercepts:
res1 = client.users_list(page=1, limit=10)
res2 = client.orders_summary(user_id=884)

print("Call 1:", res1["url"], res1["params"])
print("Call 2:", res2["url"], res2["params"])
```
