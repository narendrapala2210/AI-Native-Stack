## 1. Conceptual Deep-Dive: Creational Design Patterns in Python

Creational design patterns abstract the instantiation process:
1. **Singleton Pattern**:
   - Ensures a class has only one instance and provides a global access point.
   - In Python, can be implemented via module-level singletons, `__new__` overrides, or metaclasses.
2. **Factory Method Pattern**:
   - Defines an interface for creating an object, letting subclasses or helper factories determine which class to instantiate based on parameters.
3. **Builder Pattern**:
   - Separates the construction of a complex object from its representation, allowing the same construction process to create various representations step-by-step.

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Thread-Safe Singleton with Double-Checked Locking
Build a thread-safe configuration manager singleton.

```python
import threading

class AppConfigSingleton:
    _instance = None
    _lock = threading.Lock()

    def __new__(cls, *args, **kwargs):
        if cls._instance is None:
            with cls._lock:
                if cls._instance is None:
                    cls._instance = super().__new__(cls)
                    cls._instance.settings = {"env": "prod", "version": "1.0"}
        return cls._instance

def test_singleton():
    cfg1 = AppConfigSingleton()
    cfg2 = AppConfigSingleton()

    print(f"Config 1 Pointer: {id(cfg1)}")
    print(f"Config 2 Pointer: {id(cfg2)}")
    print("Are instances identical? ", cfg1 is cfg2)

test_singleton()
```

#### Step-by-Step Explanation:
1. `__new__` overrides instance allocation, returning the cached `_instance`.

#### Expected Output:
```text
Config 1 Pointer: ...
Config 2 Pointer: ...
Are instances identical?  True
```

### Example 2: Dynamic Cloud Client Factory
Instantiate polymorphic cloud storage providers based on configuration strings.

```python
from abc import ABC, abstractmethod

class CloudStorageClient(ABC):
    @abstractmethod
    def upload(self, blob_name: str, data: bytes) -> str: pass

class S3StorageClient(CloudStorageClient):
    def upload(self, blob_name: str, data: bytes) -> str:
        return f"s3://production-bucket/{blob_name}"

class GcsStorageClient(CloudStorageClient):
    def upload(self, blob_name: str, data: bytes) -> str:
        return f"gs://production-bucket/{blob_name}"

class StorageClientFactory:
    _providers = {
        "aws": S3StorageClient,
        "gcp": GcsStorageClient
    }

    @classmethod
    def get_client(cls, provider: str) -> CloudStorageClient:
        provider_key = provider.lower()
        if provider_key not in cls._providers:
            raise ValueError(f"Unknown cloud provider: '{provider}'")
        return cls._providers[provider_key]()

def test_factory():
    client = StorageClientFactory.get_client("aws")
    url = client.upload("report.pdf", b"DATA")
    print(f"Uploaded via Factory Client: {url}")

test_factory()
```

#### Step-by-Step Explanation:
1. `StorageClientFactory` decouples client code from concrete implementations.

#### Expected Output:
```text
Uploaded via Factory Client: s3://production-bucket/report.pdf
```

### Example 3: Fluent Query Builder Pattern
Construct complex SQL query strings step-by-step using method chaining.

```python
class SqlQueryBuilder:
    def __init__(self, table_name: str):
        self.table_name = table_name
        self._fields = ["*"]
        self._conditions = []
        self._limit_val = None

    def select(self, *fields):
        self._fields = list(fields)
        return self  # Return self for fluent chaining!

    def where(self, condition: str):
        self._conditions.append(condition)
        return self

    def limit(self, count: int):
        self._limit_val = count
        return self

    def build(self) -> str:
        query = f"SELECT {', '.join(self._fields)} FROM {self.table_name}"
        if self._conditions:
            query += f" WHERE {' AND '.join(self._conditions)}"
        if self._limit_val is not None:
            query += f" LIMIT {self._limit_val}"
        return query

def test_builder():
    query = (
        SqlQueryBuilder("users")
        .select("id", "username", "email")
        .where("active = 1")
        .where("age >= 18")
        .limit(25)
        .build()
    )
    print("Constructed SQL Query:")
    print(" ", query)

test_builder()
```

#### Step-by-Step Explanation:
1. Returning `self` enables readable fluent call chaining (`.select().where().limit()`).

#### Expected Output:
```text
Constructed SQL Query:
  SELECT id, username, email FROM users WHERE active = 1 AND age >= 18 LIMIT 25
```
