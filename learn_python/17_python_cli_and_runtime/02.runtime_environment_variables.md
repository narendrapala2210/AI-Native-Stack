## 1. Conceptual Deep-Dive: Python Runtime Configuration

The Python interpreter reads several environmental variables on initialization:
1. **`PYTHONPATH`**:
   - Colon-separated (or semicolon-separated on Windows) list of directories prepended to `sys.path`.
   - Used to inject custom module locations.
2. **`PYTHONUNBUFFERED`**:
   - If set to a non-empty string (e.g. `PYTHONUNBUFFERED=1`), forces unbuffered stdout and stderr (equivalent to `-u`).
3. **`PYTHONDONTWRITEBYTECODE`**:
   - If set, prevents Python from writing `.pyc` files to `__pycache__/` directories.
4. **`PYTHONHASHSEED`**:
   - Controls string and bytes hash randomization seed (for reproducible hash-based tests and security testing).

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Environment-Driven Configuration Auditor
Audit active Python runtime environment variables programmatically.

```python
import os

def audit_python_environment():
    env_vars = [
        "PYTHONPATH",
        "PYTHONUNBUFFERED",
        "PYTHONDONTWRITEBYTECODE",
        "PYTHONHASHSEED",
        "VIRTUAL_ENV"
    ]

    print("Active Python Runtime Environment Variables:")
    for var in env_vars:
        val = os.environ.get(var, "Not Set")
        print(f"  {var:<24} : {val}")

audit_python_environment()
```

#### Step-by-Step Explanation:
1. `os.environ.get()` inspects the active process environment table.

#### Expected Output:
```text
Active Python Runtime Environment Variables:
  PYTHONPATH               : ...
  PYTHONUNBUFFERED         : ...
  PYTHONDONTWRITEBYTECODE  : ...
  PYTHONHASHSEED           : ...
  VIRTUAL_ENV              : ...
```

### Example 2: Inspecting Hash Randomization Security (`PYTHONHASHSEED`)
Demonstrate how Python randomizes hash seeds per process to defend against HashDOS denial-of-service attacks.

```python
def test_hash_randomization():
    sample_key = "sensitive_session_key"
    hash_val = hash(sample_key)
    print(f"Hash value of '{sample_key}' in current process: {hash_val}")
    print("Note: In a separate Python process, this hash will differ unless PYTHONHASHSEED is fixed.")

test_hash_randomization()
```

#### Step-by-Step Explanation:
1. CPython randomizes string hash seeds on every interpreter launch, preventing malicious attackers from crafting collision-heavy payloads to attack hash tables.

#### Expected Output:
```text
Hash value of 'sensitive_session_key' in current process: ...
Note: In a separate Python process, this hash will differ unless PYTHONHASHSEED is fixed.
```

### Example 3: Simulating Multi-Stage Dockerfile Environment Setup
Demonstrate best-practice Python container environment variables.

```python
def explain_container_env():
    dockerfile_snippet = (
        '# Production Python Dockerfile Standard:\n'
        'ENV PYTHONDONTWRITEBYTECODE=1 \\\n'
        '    PYTHONUNBUFFERED=1 \\\n'
        '    PYTHONPATH=/app/src'
    )
    print("Standard Container Environment Configuration:")
    print(dockerfile_snippet.strip())

explain_container_env()
```

#### Step-by-Step Explanation:
1. `PYTHONDONTWRITEBYTECODE=1` prevents unnecessary disk writes inside container layers.
2. `PYTHONUNBUFFERED=1` enables immediate log streaming to container stdout collectors.

#### Expected Output:
```text
Standard Container Environment Configuration:
# Production Python Dockerfile Standard:
ENV PYTHONDONTWRITEBYTECODE=1 \
    PYTHONUNBUFFERED=1 \
    PYTHONPATH=/app/src
```
