## 1. Conceptual Deep-Dive: Python Interpreter CLI Flags

When invoking Python from the command line (`python [flags] [target]`), several essential flags control execution modes, performance, and debugging:
1. **`-m <module>`**:
   - Executes a library module as a script (e.g. `python -m venv .venv`, `python -m http.server 8000`, `python -m pytest`).
   - Ensures imports resolve relative to the current working directory.
2. **`-c <command>`**:
   - Executes Python code directly from a string without creating a `.py` file.
3. **`-O` (Optimize Flag)**:
   - Strips and discards all `assert` statements and sets `__debug__ = False`.
4. **`-X dev` (Python Development Mode)**:
   - Enables runtime memory leak detection (`tracemalloc`), memory corruption checks, and unclosed resource warnings.
5. **`-u` (Unbuffered Binary stdout and stderr)**:
   - Forces stdout and stderr to flush immediately without buffering, essential in Docker containers and real-time loggers.
6. **`-v` (Verbose)**:
   - Traces all module imports and file locations.

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: Demonstrating `-O` Assertion Stripping
Demonstrate how Python completely skips `assert` statements when run with the `-O` optimization flag.

```python
def process_admin_action(is_admin: bool):
    # ANTI-PATTERN WARNING: Using assert for business logic or security!
    assert is_admin, "CRITICAL: Unauthorized non-admin user access attempt!"
    return "ADMIN_ACTION_EXECUTED"

def test_assertion_flag():
    print(f"Current __debug__ status: {__debug__}")
    try:
        # When run normally, this throws AssertionError
        process_admin_action(False)
    except AssertionError as e:
        print(f"Normal Mode: Assertion caught security check -> {e}")

test_assertion_flag()
```

#### Step-by-Step Explanation:
1. When executed normally, `assert` triggers `AssertionError`.
2. When executed with `python -O script.py`, CPython strips the `assert` statement completely from bytecode, allowing unauthorized callers through if developers misplace security logic inside asserts.

#### Expected Output:
```text
Current __debug__ status: True
Normal Mode: Assertion caught security check -> CRITICAL: Unauthorized non-admin user access attempt!
```

### Example 2: Unbuffered I/O vs Buffered Output (`-u` Flag)
Explain why Docker containers require `-u` (`PYTHONUNBUFFERED=1`) for live telemetry logs.

```python
import sys
import time

def demonstrate_buffering():
    print("Default stdout buffer mode: Line-buffered or Block-buffered.")
    print("Writing 3 progress ticks without newline:")

    for _ in range(3):
        sys.stdout.write(".")
        # Without sys.stdout.flush() or -u flag, characters remain in buffer!
        sys.stdout.flush()
        time.sleep(0.01)
    print("\nComplete.")

demonstrate_buffering()
```

#### Step-by-Step Explanation:
1. Standard stdout buffers characters until a newline `\n` or buffer flush occurs.
2. Running with `python -u` ensures every byte written to stdout is flushed to terminal immediately.

#### Expected Output:
```text
Default stdout buffer mode: Line-buffered or Block-buffered.
Writing 3 progress ticks without newline:
...
Complete.
```

### Example 3: Running Built-in Utility Modules via `-m`
Survey common Python standard library modules designed to be invoked directly via `-m`.

```python
def explain_module_flags():
    modules = {
        "python -m http.server 8080": "Instant local HTTP web server",
        "python -m json.tool input.json": "Pretty-prints and validates JSON formatting",
        "python -m venv .venv": "Creates an isolated virtual environment",
        "python -m timeit -s 'x=2' 'x**10'": "Runs accurate micro-benchmarks from terminal",
        "python -m cProfile script.py": "Profiles execution latency across functions"
    }

    print("Essential Python Standard Library CLI Utilities (-m):")
    for cmd, desc in modules.items():
        print(f"  {cmd:<35} => {desc}")

explain_module_flags()
```

#### Step-by-Step Explanation:
1. Running modules with `-m` utilizes `sys.path` resolution without hardcoding script file paths.

#### Expected Output:
```text
Essential Python Standard Library CLI Utilities (-m):
  python -m http.server 8080          => Instant local HTTP web server
  python -m json.tool input.json      => Pretty-prints and validates JSON formatting
  python -m venv .venv                => Creates an isolated virtual environment
  python -m timeit -s 'x=2' 'x**10'   => Runs accurate micro-benchmarks from terminal
  python -m cProfile script.py        => Profiles execution latency across functions
```
