# 12. Modular Architecture, Packages & Virtual Environments

### 12.1 Imports, `sys.path`, `__name__ == '__main__'`

When Python imports a module, it searches the directories listed in `sys.path` in order:
1. Directory containing the input script.
2. `PYTHONPATH` environment variable directories.
3. Standard library directories.
4. Installed site-packages (virtual environment).

```python
import sys

# Checking module search paths:
print("sys.path entries:", len(sys.path))

# The boilerplate execution guard:
if __name__ == "__main__":
    # Runs ONLY when script is executed directly (python script.py)
    # Does NOT run when imported as a module by another file!
    print("Script invoked as main execution entrypoint.")
```

### 12.2 Packages, `__init__.py`, `__all__`, and Relative Imports

A package is a directory containing Python modules.

```
my_package/
 ├── __init__.py        # Marks directory as a package; controls public exports
 ├── database.py
 ├── models/
 │    ├── __init__.py
 │    └── user.py
 └── utils.py
```

#### Controlling Exports with `__all__`:
```python
# Inside my_package/__init__.py:
from .database import DatabaseConnection
from .utils import sanitize_input

# Controls what 'from my_package import *' imports
__all__ = ["DatabaseConnection", "sanitize_input"]

# Explicit relative imports inside models/user.py:
# from ..database import DatabaseConnection  # Up one level
# from . import other_model                  # Same directory
```

### 12.3 Modern Virtual Environments (`venv`, `pip`, `pyproject.toml`)

Virtual environments isolate project-specific dependencies and Python versions.

#### Creating and activating a virtual environment:
```powershell
# Windows (PowerShell)
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# Upgrading pip and installing dependencies
python -m pip install --upgrade pip
pip install requests pydantic

# Freezing dependencies
pip freeze > requirements.txt

# Installing from lockfile
pip install -r requirements.txt
```

#### Modern `pyproject.toml` (PEP 518 / PEP 621):
```toml
[build-system]
requires = ["hatchling"]
build-backend = "hatchling.build"

[project]
name = "python-mastery"
version = "1.0.0"
description = "Comprehensive Python reference package"
requires-python = ">=3.11"
dependencies = [
    "pydantic>=2.0.0",
]
```

### Example 1: Dynamic Module Loader by File Path
Dynamically load and execute Python modules from arbitrary file paths at runtime without hardcoding imports.

```python
import importlib.util
import tempfile
from pathlib import Path

def load_module_from_path(module_name: str, file_path: Path):
    spec = importlib.util.spec_from_file_location(module_name, file_path)
    if spec is None or spec.loader is None:
        raise ImportError(f"Cannot load module from {file_path}")
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    return module

with tempfile.TemporaryDirectory() as tmpdir:
    script_file = Path(tmpdir) / "dynamic_plugin.py"
    script_file.write_text("def run_task(): return 'Plugin executed successfully!'", encoding="utf-8")

    loaded_mod = load_module_from_path("custom_plugin", script_file)
    print("Dynamically invoked result:", loaded_mod.run_task())
```

### Example 2: Package Dependency Verification Script
Inspect installed packages and verify whether installed versions satisfy requirements.

```python
import importlib.metadata

def verify_installed_package(package_name: str):
    try:
        version = importlib.metadata.version(package_name)
        return {"package": package_name, "installed": True, "version": version}
    except importlib.metadata.PackageNotFoundError:
        return {"package": package_name, "installed": False, "version": None}

for pkg in ["pip", "pydantic", "non_existent_fake_package"]:
    status = verify_installed_package(pkg)
    print(f"Package '{pkg:<25}': Installed={status['installed']}, Version={status['version']}")
```

### Example 3: Virtual Environment Isolation Auditor
Audit Python runtime paths to ensure scripts run strictly inside an isolated virtual environment rather than the system Python.

```python
import sys

def audit_environment():
    is_venv = sys.prefix != sys.base_prefix
    return {
        "is_virtualenv": is_venv,
        "executable": sys.executable,
        "prefix": sys.prefix,
        "base_prefix": sys.base_prefix
    }

audit = audit_environment()
print(f"Running inside Virtual Environment? {audit['is_virtualenv']}")
print(f"Active Interpreter: {audit['executable']}")
```
