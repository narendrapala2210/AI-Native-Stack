# 23. C-Extensions & Foreign Function Interoperability

### 23.1 Calling Native C Libraries with `ctypes` (`c_int`, `c_char_p`, `Structure`)

`ctypes` is Python's standard Foreign Function Interface (FFI) to call functions in shared libraries/DLLs without writing C extension glue code.

```python
import ctypes
import os

# 1. Calling standard C runtime library (msvcrt on Windows, libc on Linux/macOS)
if os.name == "nt":
    libc = ctypes.cdll.msvcrt
else:
    libc = ctypes.CDLL("libc.so.6")

# Set up argument types and return type
libc.puts.argtypes = [ctypes.c_char_p]
libc.puts.restype = ctypes.c_int

libc.puts(b"Hello directly from C standard library 'puts' via ctypes!")

# 2. Defining C structs in Python
class CPoint(ctypes.Structure):
    _fields_ = [
        ("x", ctypes.c_int),
        ("y", ctypes.c_int),
        ("label", ctypes.c_char * 16)
    ]

point = CPoint(x=10, y=25, label=b"OriginNode")
print(f"C Struct in Python: x={point.x}, y={point.y}, label={point.label.decode()}")
print(f"Memory size of C struct: {ctypes.sizeof(point)} bytes")
```

### 23.2 CFFI & PyBind11 Overview

- **CFFI (C Foreign Function Interface)**: The modern, alternative FFI for Python that parses C header declarations directly:
  ```python
  # Conceptual CFFI pattern:
  # from cffi import FFI
  # ffi = FFI()
  # ffi.cdef("int printf(const char *format, ...);")
  # C = ffi.dlopen(None)
  # C.printf(b"CFFI invocation\n")
  ```
- **PyBind11 / Cython**:
  - **Cython**: A superset of Python that compiles directly into C/C++ extensions with type annotations (`cdef int x`).
  - **PyBind11**: Header-only C++ library creating seamless Python bindings for existing C++ classes and functions.

### 23.3 Python C-API Foundations (`PyObject*`, GIL Release Macros)

Under the hood, all Python objects in C are represented as a pointer to a `PyObject` struct:

```c
// C-API Concept (ceval.c / object.h)
typedef struct _object {
    _PyObject_HEAD_EXTRA
    Py_ssize_t ob_refcnt;          // Reference count
    struct _typeobject *ob_type;   // Pointer to type descriptor
} PyObject;
```

#### Releasing the GIL in C Extensions:
To achieve true multi-core CPU parallelism in a C extension, wrap heavy computations with GIL macros:

```c
Py_BEGIN_ALLOW_THREADS
    // GIL is released here!
    // Native C threads can run in parallel across multiple CPU cores
    compute_matrix_multiplication(matrix_a, matrix_b);
Py_END_ALLOW_THREADS
```

## 🛠️ Practical Hands-On & Real-World Examples

### Example 1: High-Speed Native Math Calls via `ctypes`
Call standard C runtime trigonometric and math functions directly from Python.

```python
import ctypes
import os
import math

if os.name == "nt":
    libc = ctypes.cdll.msvcrt
else:
    libc = ctypes.CDLL("libc.so.6")

# Bind C math sqrt function
libc.sqrt.argtypes = [ctypes.c_double]
libc.sqrt.restype = ctypes.c_double

val = 144.0
c_res = libc.sqrt(val)
print(f"Native C sqrt({val}) = {c_res}")
```

### Example 2: C Struct Marshalling and Raw Pointer Manipulation
Define complex C structures in Python and pass them by pointer to native functions.

```python
import ctypes

class SensorData(ctypes.Structure):
    _fields_ = [
        ("sensor_id", ctypes.c_uint32),
        ("temperature", ctypes.c_float),
        ("active", ctypes.c_bool)
    ]

# Create instance
reading = SensorData(sensor_id=8001, temperature=24.5, active=True)

# Access pointer to struct
ptr = ctypes.pointer(reading)

print(f"Sensor ID: {ptr.contents.sensor_id}, Temp: {ptr.contents.temperature:.1f}°C")
print(f"Pointer memory address: {ctypes.addressof(ptr.contents)}")
```

### Example 3: C-Level Buffer Inspection and Size Validation
Directly examine the byte alignment, offsets, and binary size of C data types.

```python
import ctypes

class NetworkPacket(ctypes.BigEndianStructure):
    _fields_ = [
        ("magic", ctypes.c_uint16),
        ("code", ctypes.c_uint8),
        ("payload_size", ctypes.c_uint16)
    ]

packet = NetworkPacket(magic=0xA1B2, code=4, payload_size=1024)
buffer = bytes(packet)

print(f"Network packet struct size: {ctypes.sizeof(packet)} bytes")
print("Raw memory bytes (Hex):", buffer.hex())
```
