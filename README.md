# AI Full Stack Course

Welcome to the **AI Full Stack Engineering** course repository. This repository organizes the full end-to-end curriculum in proper learning order:

## 📚 Curriculum Structure

| Stage | Directory | Description |
|:---:|---|---|
| **01** | [`01_virtual/`](01_virtual/) | **Python Virtual Environments & Isolation**: Complete guide to `venv`, clean workspace isolation, dependency management with `requirements.txt`, and verification scripts. |
| **02** | [`02_learn_python/`](02_learn_python/) | **Master Python Engineering Curriculum**: 28 comprehensive categories covering 140 production-grade modules with 420+ runnable real-world examples, systems programming, concurrency, and Python 3.13 innovations. |

---

## 🚀 Recommended Learning Path

1. **Step 1: Set up your environment in [`01_virtual`](01_virtual/)**:
   - Create your isolated virtual environment (`python -m venv .venv`).
   - Learn how to activate/deactivate environments and manage dependencies cleanly without polluting global Python.

2. **Step 2: Master Python in [`02_learn_python`](02_learn_python/)**:
   - Proceed sequentially through the 28 numbered categories (`01_basics` to `28_practical_case_studies_and_challenges`).
   - Every module contains architectural deep dives, syntax tables, and $\ge 3$ explained real-world code examples with expected console outputs.
